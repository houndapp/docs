pub fn links(doc: &Document) -> Vec<String>
Expand description

The http/https URLs of every Inline::Link in doc, in document order, deduplicated to each URL’s first occurrence.

Labelled link and image syntax is literal text, but its destination is still an Inline::Link (see [crate::parse]), so [a](url) and ![a](url) reach the unfurler exactly as a bare autolink does — which is what lets an image URL still become a verified photo embed. hound: references are never links (they’re Inline::Reference); a mailto: link is excluded too.
