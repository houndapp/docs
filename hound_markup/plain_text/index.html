Rendering a Document to a plain-text preview — notifications, search indexing, anywhere markup syntax would be noise.

References resolve to display names through the caller-supplied Resolve; resolution is synchronous and sans-IO by contract, so implementations are expected to be an already-warm cache lookup, not a network call.
