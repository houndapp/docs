Wraps comrak behind a single, total entry point.

parse never fails and never panics on any &str: a shape comrak can’t represent in hound’s vocabulary is either downgraded (a level 4-6 heading becomes literal text) or unwrapped to its plain content (a link comrak parsed but hound doesn’t recognize as a reference or a web link). comrak’s AST (comrak::nodes::*) is used only inside this module — no comrak type crosses into crate::ast.

§Link text is the URL

A reader must never be shown one destination and sent to another, so the only clickable link hound’s dialect has is a URL displayed as itself: a bare URL comrak linkified, or an explicit <https://…>/<ada@example.com> autolink. CommonMark’s labelled forms — [label](url) and ![alt](url) — carry no link semantics at all: they are re-emitted as the literal characters the author typed ([, the label’s own inlines, ](, the destination, )), with only the destination itself linked, and only when its scheme is one hound will open. See convert_link.

That re-emission is a normalisation, not a byte-exact echo: a link title ([a](url "title")) and the reference-style forms ([a][ref] plus its [ref]: url definition) are resolved by comrak and reproduced here in the inline form without the title, because the parsed tree is the only thing this module can see.

§Renderer-protection invariant

A hostile or merely careless message can nest containers (block quotes, lists, emphasis) far deeper than any real message would. Converting that recursively would grow the call stack linearly with input size — a parser that a client or the backend cannot safely run over untrusted input. Every conversion function therefore carries a depth and, past MAX_DEPTH, stops recursing and emits the subtree’s flattened text instead: the same protection a renderer would need anyway, applied once, here.

Constants§

MAX_DEPTH 🔒
Nesting depth (blocks + inlines counted together) past which a subtree is flattened to its plain text instead of converted further.
OPENABLE_SCHEMES 🔒
Schemes hound will hand to the platform’s opener. Everything else — an unknown scheme, javascript:, data:, or a relative reference with no scheme at all — is inert text wherever a destination appears.
