Struct Sink 

Source 
struct Sink {
    out: String,
    pending_space: bool,
}
Expand description

Accumulates the flattened text, collapsing whitespace as it goes.

Collapsing during the walk rather than over the finished string is what lets code opt out: a code block’s indentation is part of what it says.

Fields§

§out: String§pending_space: bool

Whitespace seen but not yet emitted. Emitted as a single space only if something else follows it on the same line, which is what drops trailing spaces and empty-label separators.
