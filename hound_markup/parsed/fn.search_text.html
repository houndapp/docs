The body flattened for full-text search.

A separate walker from [crate::plain_text] because the two answer different questions. A preview renders what a reader would see (a mention resolved to @Ada, a link as its label, list bullets intact); an index holds what a searcher would type. So: structure markers are gone, a link contributes both its label and its URL (searching a host has to work, and a link whose label already is the URL — which, in hound’s dialect, every link is — contributes it once), a spoiler’s contents are indexed like any other text, code is verbatim, and a reference contributes nothing at all — the body never contained the display name, and indexing one would make a search match text nobody wrote.

Labelled link and image syntax is literal text ([crate::parse]), so [label](url) indexes as exactly that — the label, the brackets and the URL are all things the author typed.
