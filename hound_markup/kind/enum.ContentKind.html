Expand description

One coarse content facet of a message.

The enum is #[non_exhaustive] because it is a derived index, not a wire contract: matching on it must keep working when a kind is added.

Variants (Non-exhaustive)§

This enum is marked as non-exhaustive
Non-exhaustive enums could have additional variants added in future. Therefore, when matching against variants of non-exhaustive enums, an extra wildcard arm must be added to account for any future variants.
§

Link

The body carries at least one http(s) link — a bare autolink, or the destination of labelled link or image syntax (which renders as literal text, but still names a URL).

§

Image

A picture is actually attached or embedded. Never inferred from image syntax: ![x](https://…) is a URL the server has not verified, and promising a picture that turns out to be a 404 is worse than promising nothing.

File

An attachment that is not an image, video or audio file.

§

Embed

At least one link unfurled to a preview card.

§

Code

A fenced or indented code block.

§

Spoiler

A ||spoiler|| anywhere in the body.
