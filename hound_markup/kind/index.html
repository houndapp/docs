Module kind

Expand description

ContentKind: the coarse “what is in this message” vocabulary used to filter a search or a channel’s media view.

A kind is a fact about the stored message, derived once by crate::ParsedMessage from the source plus the facts the source alone cannot carry (see crate::MessageContext). The set is deliberately small and fixed in this crate rather than in a schema: a new kind is a variant plus a detection arm, never a database migration.
