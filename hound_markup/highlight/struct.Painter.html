Struct Painter 

Source 
struct Painter<'t> {
    text: &'t str,
    line_starts: Vec<usize>,
    words: Vec<u32>,
}
Expand description

The source, its line-start table, and one style word per byte.

One word per byte (not per char) so a comrak sourcepos — already a byte offset — indexes it directly, with no position translation inside the walk. The single UTF-16 conversion happens in Painter::runs.

fn mark_destination(&mut self, range: &Range<usize>, style: u32, url: &str)

Paints the destination of [label](url)/![alt](url), found as the last occurrence of url inside the node’s own source range (last, so a label that happens to repeat the URL cannot claim the styling).

comrak normalises a destination (entity decoding, percent-encoding, an angle-bracketed <url> form), so the URL it reports is not always a substring of the source. When it isn’t, nothing is painted: a degraded highlight, never a run over the wrong characters.

Coalesces the per-byte words into runs, converting to UTF-16 offsets in the same pass — one walk of the source, no position table.
