hound_markup

Module highlight 

Source
Expand description

Live styling of markup source: the style runs a composer paints over the characters an author is still typing.

Where [crate::parse] answers “what does this message mean”, this answers “which characters of this exact string carry which styling” — the markers (**, >, ```) stay in the text and stay visible; they are simply reported as StyleRun::marker so the composer can mute them while the text between them renders bold/quoted/monospaced.

Both questions are answered by the same comrak configuration (crate::parse::options), so what the composer highlights and what the renderer will show can never disagree about which ** opened an emphasis.

§Offsets

Runs are half-open [start, end) in UTF-16 code units — what a Dart String indexes by, and therefore what a TextEditingValue’s selection, composing range and span boundaries are measured in. comrak reports positions as 1-based (line, column) pairs whose columns count UTF-8 bytes (comrak::nodes::LineColumn; parse.sourcepos_chars would make them chars, and is deliberately not enabled), so the walk works in byte offsets throughout and converts once, at the end, in the single pass that coalesces runs.

§How a marker is derived

A delimited node’s own range covers its delimiters and its content, while its children cover only the content. The delimiters are therefore exactly “the node’s range minus the union of its children’s” — obtained by painting the node’s whole range as style | marker and letting the children repaint their own spans without the marker bit. Two shapes can’t be expressed that way and get an explicit post-pass instead: a block quote’s > and a list item’s bullet (the continuation lines’ > sits inside the child paragraph’s range, not outside it) and a fenced code block’s fence lines (the fence is not a child at all).

MAX_DEPTH 🔒
Nesting depth past which the walk stops refining. Same renderer-protection argument as [crate::parse]’s cap: a hostile message can nest containers thousands deep, and a recursive walk over it must not grow the call stack with the input. Past the cap the enclosing node’s styling simply stands for the whole subtree — a degraded highlight, never a crashed composer.
