Expand description

What fraction of a track’s bitrate the base layer carries, as an exact integer ratio: 0.7, which is the BaseLayerBitRateFraction the VideoToolbox encoder is configured with (vt_encoder.rs). Half the frames at ~70% of the bits, because the base layer’s inter-frame distance doubles — dropping half the frames does not halve the bytes.

Stated here rather than run through crate::congestion::camera_bitrate_bps at half fps for the same reason CAM_SOURCE_BPS is a constant: the price of the base layer is decided by the encoder’s split, not by the ladder’s bits-per-pixel model, and a receiver that budgeted it any other way would be budgeting for bytes that are not on the wire.
