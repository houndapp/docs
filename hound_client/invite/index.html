Module invite

Expand description

Turning whatever a user pasted into an invite code.

One pure function, with no network and no state — but it belongs in the core rather than in a UI, because the answer must be the same on every platform and it is the one place the code’s shape is written down.

Constants§

ALPHABET 🔒
The alphabet an invite code is drawn from: Crockford base32, which is the digits and the uppercase letters MINUS I, L, O and U — the four that a human transcribing a code confuses with 1, 1, 0, and a word nobody wants generated.
CODE_LEN 🔒
How many characters a code has. Fixed: a code is generated, never chosen.
INVITE_SEGMENT 🔒
The path segment that marks the code in a link, in any of the shapes a link can arrive as (https://hound.chat/invite/…, a self-hosted instance’s own host, or the hound://invite/… deep link the desktop app registers).
