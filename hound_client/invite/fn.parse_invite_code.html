pub fn parse_invite_code(input: &str) -> Option<String>
Expand description

Extract the invite code from input, uppercased, or None if there is no code in it.

Accepts all three forms a code reaches us as — a bare code typed or pasted (b3k9mn2p), an invite URL from any host (https://example.test/invite/B3K9MN2P, trailing slash, query and fragment all tolerated), and the hound://invite/B3K9MN2P deep link — because the person pasting has no reason to know which one they have.

Deliberately strict about the code itself: exactly CODE_LEN characters from ALPHABET, case-folded up. I/L/O/U are REJECTED rather than mapped onto the glyphs they resemble — a code containing one was never minted by this server, so accepting it would turn a typo into a confident 404 instead of an immediate “that isn’t an invite code”.

Total: never panics, never allocates on the rejection path.
