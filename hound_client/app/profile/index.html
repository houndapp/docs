The signed-in user’s own display identity.

Every other roster source is incidental to the user — a message they wrote, a voice room they joined, a member page someone opened — so none of them can be relied on to name the user to themselves. This fetches the global profile outright on every sign-in and files it in the roster as an ordinary Member entry, so the UI resolves “me” through the same join as everyone else.

The edit commands (rename, avatar set/clear/Steam import) answer with the profile as written and fold it in AUTHORITATIVELY (RosterView::set_profile), so a cleared avatar clears the entry rather than losing to the merge rule.

Invariant: an entry lands only for the account that is signed in at the moment it is written. A fetch that outlives its session (signed out, or signed in as someone else, while the request was in flight) is discarded.
