Module steam_link

Expand description

Redeeming a parked Steam link token against the signed-in account.

An unknown Steam ID parks a link token (10-minute lifetime). It is redeemed either by the sign-in tail (“I already have an account”: any sign-in that lands while one is parked) or explicitly by the UI (the settings browser link). Both end in a SteamLinkResult; the sign-in tail cannot return it through an AuthState, so it parks the verdict and link_steam_pending hands it over.

Invariant: a verdict is reported once, and only for the token that produced it — parking a new token drops any older verdict.
