The METHOD /route label a request is named by in errors and telemetry.

Ids are elided (/space/{id}/message, never the uuid) for two independent reasons: a tag with a uuid in it has one value per request and groups nothing, and an id in a tag is user data leaving the device in a field nobody audits. The query string goes the same way — its values are the most likely to be identifying, and the path alone already says which endpoint answered.

An invite code is elided too, by position: the segment right after a literal invite is {code}. It is an id in every sense that matters here — unbounded as a tag, and a secret good enough to join a community with — but it is neither a uuid nor a number, so it would otherwise ride out verbatim. Positional rather than shape-matching so no route segment that happens to look like a code is ever swallowed.
