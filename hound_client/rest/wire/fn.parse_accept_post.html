Split an Accept-Post value into typed media types.

Comma-separated; each item is parsed as a Mime, which is what makes the result usable — a caller compares Mime::type_/Mime::subtype (or a mime::IMAGE_JPEG-style constant) instead of guessing at string case, and the mime parser owns the grammar (case-insensitive equality, parameter syntax). Parameters (;q=0.8, ;charset=…) are cut before parsing rather than stripped after: an advertisement names types (a parameter is never what decides whether a file can be sent), and mime’s grammar is stricter than HTTP’s — it rejects the whitespace-before-; that RFC 9110 permits, so the parameter clause must not reach it.

Total tolerance is deliberate: this parses a hint. An item that is not a media type is skipped, not an error — there is no malformed input worth failing an upload over; the worst case is a shorter list, which the caller already handles (see RestClient::upload_accept_post).
