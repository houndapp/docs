Re-label a 501 from a Steam auth route as SteamLoginDisabled.

The backend answers 501 on every /auth/steam/* route when the instance has no Steam credentials (ApiError::SteamDisabled) — an instance-configuration fact, not a request failure, and the one Steam outcome the UI must never treat as retryable. As a bare HoundError::Http it reached the UI (and Sentry) as HTTP501 with whatever body the deployment happened to send, which on older backends is nothing at all; this gives it the registry code the caller branches on regardless of body.
