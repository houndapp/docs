Expand description

The liveness timings a leg needs, on top of [hound_wt::Liveness]’s probe.

Methods rather than associated consts because Leg is one type covering two transports with different answers; run_session reads them once, so the timers never borrow the pipe.

Required Methods§

Source

fn idle_period(&self) -> Option<Duration>

Quiet period after which a keepalive probe is due. None for a transport that keeps itself alive — WebTransport’s QUIC keep-alive is configured on the endpoint, so its arm simply never fires.

Source

fn silence_limit(&self) -> Option<Duration>

How long total inbound silence (frames AND pongs) may last before the peer is declared gone. None where the transport reaps its own.
