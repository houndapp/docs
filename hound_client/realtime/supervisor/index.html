Module supervisor

The supervisor: owns the [ClientSession] for the plane’s lifetime — runs it, reconnects it under the call plane’s backoff ladder, and stops only on a shutdown, a fatal auth outcome, or a version mismatch.

deadline 🔒

drain_offline 🔒
Apply commands to the reducer while there is no live transport, forever. Resolves ONLY when the plane is shutting down (an explicit Shutdown or the last RealtimeClient dropped), which is what makes it usable as the losing arm of a select!: the actions it would produce are all empty while down, so dropping the future mid-poll loses nothing.
run_session 🔒
Drive one established pipe: handshake, then pump frames and commands until something ends it.
send_all 🔒
Put every action on the wire. false means the pipe is dead. A frame that fails to ENCODE is skipped (it cannot be fixed by reconnecting, and killing the session over one malformed frame would be a self-inflicted outage); anything else is a transport failure.
supervise 🔒
Own the session for the plane’s lifetime: run it, reconnect it, and stop on a shutdown, a fatal auth outcome, or a version mismatch. initial is the connection RealtimeClient::connect already established, if it managed to.
tick_at 🔒
A select! arm that fires at at — or never, when there is no deadline.
