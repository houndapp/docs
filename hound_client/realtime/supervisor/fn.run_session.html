Drive one established pipe: handshake, then pump frames and commands until something ends it.

Mirrors the call plane’s reader discipline — a frame that fails to serialize is skipped, never fatal, and an unparseable inbound frame is skipped by [MessagePipeExt::recv_json] (that is the protocol’s additive-compatibility rule). Generic over the pipe so both legs and the test fake share one loop.

Four deadlines run alongside the two data arms, all absolute (they are NOT re-armed by an unrelated wakeup, which is exactly the bug a per-iteration sleep would have): the keepalive probe, the inbound-silence limit, the Welcome deadline, and the one retry an Unavailable answer earns.
