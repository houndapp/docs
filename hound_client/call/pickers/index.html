hound_client::call

Module pickers 

Source
Expand description

Picker enumerations + the screen-share failure surface: the shareable screen sources (with their opaque round-trip tokens and one-shot thumbnails), the mic/camera/speaker device lists, and the process-global terminal screen-share error watch. All UI-free, FFI-flat, and callable with no active call.

Structs§

DeviceListView
The available media devices grouped by kind — the data the Devices panel renders. A kind whose platform backend is absent simply comes back empty (a capability miss, not an error).
DeviceView
One enumerated media device for a picker row. FFI-flat: id is the opaque selection token to pass back to call_select_device for this kind (for audio it equals the cpal device name; for a camera the AVFoundation uniqueID), and is_default flags the host’s current default for that kind.
ScreenShareError
A screen-share failure the user must be TOLD about, split into the two things a surface needs: the stable machine code (what a support log is grepped for and what Sentry groups on) and the human message. FFI-flat (two Strings) so the FRB layer mirrors it with no reshape.
ScreenSourceView
A shareable screen source for the picker — a display, a window, or a camera streamed as a screen. UI-friendly + FFI-flat: the typed engine selection token is encoded into id (see encode_screen_source) so the UI round- trips an opaque string back into [CallSession::screen_share_start].
ScreenThumbnail
A share-picker preview image: opaque RGBA8888, width * height * 4 bytes.

Functions§

device_view 🔒
Map a typed engine DeviceDescriptor onto the FFI-flat DeviceView (id as a plain string). The typed ids keep device kinds apart inside the engine; the wire stays stringly so one call_select_device(kind, id) round-trips all three kinds.
encode_screen_source 🔒
Encode the engine’s typed selection token into the opaque "{kind}:{id}" string the UI round-trips. Inverse of parse_screen_source.
list_devices
Enumerate the available microphones, cameras, and speakers for the picker. UI-free and needs no active call. The engine enumeration is synchronous and may briefly touch the host, so the facade runs it on a blocking thread. Best-effort.
list_screen_sources
Enumerate the shareable screen sources (displays + windows). UI-free + needs no active call, so it lives as a free function the facade/FRB call directly. Blocking (round-trips ScreenCaptureKit’s async enumeration); a Screen-Recording TCC denial or an unsupported platform surfaces as a typed HoundError::Media.
parse_screen_source 🔒
Parse the opaque "{kind}:{id}" picker token back into the engine’s typed ScreenSource. Inverse of encode_screen_source.
screen_error_channel 🔒
The process-wide screen-share error surface: Some after a terminal failure, None once a share starts cleanly or the user stops one.
screen_thumbnail
One-shot preview thumbnail of a screen source for the picker, aspect-fit within (max_w, max_h). Best-effort and per-platform (ScreenCaptureKit on macOS, a WGC one-shot on Windows; unsupported on Linux, where capturing would raise the portal dialog): a capture failure — unsupported platform, a permission/portal denial, an undeliverable source — surfaces as a typed HoundError::Media the picker treats as “no thumbnail” (title-only card). Blocking (drives a one-shot engine capture); the facade runs it off-runtime.
watch_screen_error
Subscribe to the screen-share error surface (the FRB watch_screen_error stream). Needs no active call; the current value is delivered on subscribe.
