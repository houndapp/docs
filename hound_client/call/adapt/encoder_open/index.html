open_encoder_laddered 🔒
Open an encoder at target, falling back DOWN the ladder (hound_engine::types::ENCODE_PRIORITY: AV1 → H.265 → H.264) to the first codec that opens. Safe to descend without re-checking decode caps: the negotiated target means every peer decodes it, and real decode hardware is monotonic (AV1-capable ⇒ H.265-capable ⇒ H.264), so every lower rung is decodable too. H.264 is the floor, so this normally returns None only if even H.264 won’t open — which is no longer unreachable: on a device with no HW H.264, the SW codec is Cisco’s downloaded binary, so before that download lands (or with the codec switched off in settings) there is nothing to open. The caller treats None as “no video this attempt”, which is the honest outcome.
