The render stream key a just-stopped subscription should RELEASE (VideoSink::stream_ended), or None if it must not be released.

Two things must not release, and they are why this is a function rather than an unconditional call at the stop site:

  • audio (tile: None) — it feeds the mix bus, not the renderer; and
  • the losing half of a simulcast LAYER SWITCH — stopping the source track the instant the low track is subscribed (or the reverse) is one tile changing rung, not a stream ending. Both tracks feed the SAME (peer, source) stream key, so successors (the tiles that still have a video subscription after this pass) is exactly the discriminator: a switched tile is in it, a torn-down tile is not. Releasing mid-switch would drop the pending frame the make-before-break texture swap is waiting to draw into its new surface, which is the one moment the mailbox is load-bearing for the no-blank contract.

Everything else — the allocator hiding a tile, a paused call, a withdrawn track, a peer leaving — is a real end and releases.
