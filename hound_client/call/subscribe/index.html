Module subscribe 

Source
Expand description

The subscribe loop: reconcile remote tracks → decode → sink / mix bus. Diffs the SessionView roster into per-track pipelines (start_pipeline), picks nothing / low layer / source per tile demand (debounced through the policy hysteresis, and gated at join by SourceHold so an unserved tile waits for the right rung instead of stampeding the source), and self-heals: every pipeline carries a PipelineEndGuard whose Drop reports the death so the reconcile reaps + re-subscribes it (restart-paced). Invariant: audio subscribes with arrival-order drain and the smaller moq priority value — audio must strictly outrank video on the shared connection.

AudioLiveness 🔒
The audio-liveness half of a Subscription: the counter the pipeline bumps per arriving frame plus the reconcile-side watchdog state that samples it.
DownlinkCell 🔒
Lock-free single-slot handle for one video pipeline’s downlink-driven demand: the video pull loop (video_pipeline) writes its latest [hound_media::QualityRequest] here as frames arrive (via [hound_media::DownlinkDemand]); the reconcile loop below reads it every tick. A plain atomic (not a lock) so the per-frame write on the pull loop never blocks. None (audio, or a pipeline that hasn’t decided yet) reads as [hound_media::QualityRequest::Source] — the optimistic default, matching [hound_media::DownlinkDemand::new].
Gathered 🔒
One (peer, video source) group as the reconcile’s GATHER pass collected it, before any of it is committed. The split into gather → allocate → apply is what makes a cross-tile budget expressible at all: the rung a tile gets is a function of every OTHER tile’s demand, so it cannot be derived inside a per-group loop.
HoldInputs 🔒
One reconcile pass’s view of a (peer, video source) group, as SourceHold reads it. A struct rather than four bare bools so no call site can transpose them.
PipelineEndGuard 🔒
Fires (track_id, epoch) on the reap channel when the owning pipeline task ends — by ANY path: clean end-of-track, a transport error, a panic unwind, or an abort (tokio drops the future at an await point, running destructors). This is what lets the subscribe loop REAP a self-terminated pipeline: without it, a dead track would stay in active forever, every reconcile would skip it as “already subscribed”, and its tile would freeze permanently.

StallWatch 🔒
Pure liveness policy for one inbound audio subscription (unit-tested). The pipeline bumps a monotone arrival counter as frames come off the wire; this samples it on the reconcile tick and reports a subscription that has not moved for stall.
Subscription 🔒
One active remote subscription: the decode task + a stop flag.
TilePolicy 🔒
Per-(peer, video source) subscription policy state that must survive a re-establish: the bounded source gate (SourceHold) and the seeded tile’s escape clock. Owned by the session (see TilePolicies), not by the subscribe loop, because a reconnect must not re-pay a grace this tile already paid — a 1:1 call whose peer publishes no low layer would otherwise go black for SOURCE_HOLD_GRACE on every single reconnect.

Constants§

AUDIO_STALL 🔒
How long an inbound AUDIO subscription may deliver NOTHING before the reconcile treats it as wedged. The audio pull is deliberately unbounded — the moq group read is not cancel-safe mid-object, so no timeout may ever be raced against next_frame — which means a relay that stops delivering a track WITHOUT closing it parks the pipeline task forever: its PipelineEndGuard never drops, the reconcile never reaps it, and that peer is silent for the rest of the establish. This is the out-of-band equivalent of video’s FIRST_KEYFRAME_DEADLINE.
KEYFRAME_NAG_ATTEMPTS 🔒
KEYFRAME_NAG_INTERVAL 🔒
How often the receiver re-sends RequestKeyframe while a fresh video subscription is still awaiting its first keyframe, and how many times. The subscribe-time request can RACE the producer’s PLI-forced IDR (the IDR lands in a group the moq live-join skips), leaving the receiver black indefinitely on a keyframe that never comes. With the screen encoder on an on-demand cadence (no frequent periodic IDR to paper over the race), this bounded re-request is the fast recovery: producer-side the keyframe throttle coalesces duplicates, so nagging is cheap. Once the attempts are exhausted the pipeline’s [FIRST_KEYFRAME_DEADLINE] ends it — a fresh, ladder-paced resubscribe replaces a black tile that would otherwise wait on the safety-net IDR.
RECONCILE_TICK 🔒
Floor wake-up for the reconcile loop. Every OTHER wake source is event-driven (roster change, pause flip, tile-demand change, pipeline death, a pending debounced switch) and in a steady call none of them fire for minutes — so the signals the pipelines fold per frame (DownlinkCell, the audio arrival counter) would never be observed and a congestion downgrade / a wedged audio track could not actuate. LayerHysteresis’s debounce+dwell bounds any churn a periodic pass could cause, so polling is safe. 500 ms is the reconcile rate the dwell tests in super::policy already model.
SEEDED_ESCAPE_GRACE 🔒
The bounded gate on escalating a tile to the SOURCE track. One per (peer, video source); pure, so the whole policy is unit-tested.
SOURCE_HOLD_GRACE 🔒
How long a video track may go unsubscribed while the receiver waits for the evidence it needs to pick the RIGHT rung, before it gives up and takes the source.
SOURCE_SENTINEL 🔒
Sentinel encoding QualityRequest::Source in the packed atomic — a Capped bitrate this large never occurs (an encode rung tops out in the low millions).
SUBSCRIBE_ANNOUNCE_DEADLINE 🔒
How long a fresh pipeline waits for its MoQ broadcast to be ANNOUNCED before giving up. subscribe_track awaits the announce with no deadline of its own, and a task parked there never drops its PipelineEndGuard — so the reap + restart machinery written for exactly this case never runs and the tile / peer stays dead for the rest of the establish (a producer whose publish_track failed, or a broadcast parked as a same-path backup behind a zombie). Bounded in the same spirit as video’s FIRST_KEYFRAME_DEADLINE (12 s), and slightly under it: ending here yields a fresh announce cursor plus a re-sent control-plane Subscribe, which is the only thing that heals a zombie.
