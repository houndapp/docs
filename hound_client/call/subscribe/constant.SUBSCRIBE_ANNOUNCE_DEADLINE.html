const SUBSCRIBE_ANNOUNCE_DEADLINE: Duration;
Expand description

How long a fresh pipeline waits for its MoQ broadcast to be ANNOUNCED before giving up. subscribe_track awaits the announce with no deadline of its own, and a task parked there never drops its PipelineEndGuard — so the reap + restart machinery written for exactly this case never runs and the tile / peer stays dead for the rest of the establish (a producer whose publish_track failed, or a broadcast parked as a same-path backup behind a zombie). Bounded in the same spirit as video’s FIRST_KEYFRAME_DEADLINE (12 s), and slightly under it: ending here yields a fresh announce cursor plus a re-sent control-plane Subscribe, which is the only thing that heals a zombie.
