StatsEmitter
The 1 Hz emitter state: holds the previous raw snapshot so each tick can derive windowed rates from the counter deltas. Pure transform (sample) + a thin spawn wrapper, so the rate math is unit-tested without timers.

rate 🔒
Computes a per-second rate from a monotonic-counter delta over an elapsed window. Returns 0 when the window is degenerate (no elapsed time) so a rate is never inf/NaN. cur is allowed to be < prev only across a session reset (then the delta clamps to 0 — a reset is not a meaningful rate).

Snapshot one inbound-video slot’s atomics + drain its windowed latency histograms into a plain RawPeerVideo (shared by the camera and screen reads). Draining clears the histograms, so each emit reflects the last second.
spawn_emitter
Spawn the 1 Hz call:stats emitter: each tick, sample the registry, derive the windowed rates, and emit one StatsSnapshot. Aborted on teardown (the JoinHandle is held by the LiveSession). A send to a closed receiver is ignored (nobody watching) — stats are advisory.
