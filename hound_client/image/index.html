Still-image decoding for formats the platform does not know.

Flutter renders a remote image through Skia’s own codecs (JPEG/PNG/GIF/WebP); JPEG XL is not among them, so a .jxl avatar or attachment is decoded here and handed to Dart as raw pixels. The output shape is deliberately the same {width, height, rgba} triple the share picker’s ScreenThumbnail already uses, so the Dart side reuses the existing decodeImageFromPixels path rather than growing a second pixel convention.

Scope is narrow on purpose: JPEG XL only, one still frame, 8-bit sRGB. Everything the platform already decodes stays on the platform path — the Dart provider sniffs the bytes and only calls in here for JXL.

Untrusted input. These bytes come off the network from another user’s upload, so every failure is a typed HoundError::Decode and never a panic, and the canvas size is checked before the pixel buffer is allocated (a few hundred bytes of JXL can declare a gigapixel canvas).

Constants§

JXL_CODESTREAM_SIGNATURE 🔒
A bare JPEG XL codestream starts with this two-byte signature.
JXL_CONTAINER_SIGNATURE 🔒
A containerised (ISOBMFF) JPEG XL file starts with the 12-byte JXL signature box.
MAX_PIXELS 🔒
The most pixels decode_image will allocate a buffer for (64 MP — well past any avatar or chat attachment, well short of the 2^30-per-side the format allows). Refusing here is what keeps a tiny malicious file from turning into a multi-gigabyte allocation.

alpha_is_associated 🔒
Whether the frame’s alpha channel is associated (i.e. the colour channels are stored already multiplied by it). jxl-oxide streams channels as stored, and DecodedImage promises straight alpha, so this decides whether the colour has to be divided back out.
budgeted_pixels 🔒

to_rgba8 🔒
Widen an interleaved 1/2/3/4-channel frame to RGBA8888, straightening premultiplied colour on the way when associated_alpha says it is stored that way.
unassociate 🔒
Divide premultiplied colour back out of one pixel (a no-op unless the source said its alpha is associated). Fully transparent stays black — there is no colour to recover, and any value would do.
