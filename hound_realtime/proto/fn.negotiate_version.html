pub fn negotiate_version(client: u16, server: u16) -> Option<u16>
Expand description

The version two peers will speak, or None if they cannot.

The rule is “the newer side speaks down”: the outcome is the lower of the two versions, provided the client’s is one the server still supports. A client newer than the server therefore fails (ErrorCode::VersionMismatch) — the server cannot invent forward compatibility — while a client older than the server, down to MIN_PROTOCOL_VERSION, is served at its own version.

server is a parameter rather than PROTOCOL_VERSION so the negotiation is exercisable for versions this build predates.
