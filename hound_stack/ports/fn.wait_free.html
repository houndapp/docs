pub fn wait_free(ports: &[Port], budget: Duration) -> bool
Expand description

Wait (bounded) for every one of ports to be free. For the moment right after a teardown: docker’s host-side port forwarder (OrbStack’s in particular) releases a published port a beat AFTER compose down has reported the container removed, so a preflight run straight away sees the relay’s :3340 still held and refuses a stack that is, in fact, gone. Returns false if something still holds a port at the deadline — the caller then runs preflight for the named error.
