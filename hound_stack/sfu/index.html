The host SFU process, and the “is voice routable” contract.

The dev SFU runs on the HOST, not as the hound-sfu compose container (which compose.dev.yaml still defines for the prod-like topology). Two reasons, both about the address clients end up dialling:

  • A container SFU advertises the Docker bridge address, so every media packet leaves loopback. On macOS that is Local Network traffic: the client needs a per-application privacy grant, and without one the packets are dropped silently and the failure reads like an SFU bug.
  • --fresh had to rebuild the SFU’s docker image on every wipe.

ADVERTISE_IPV4 is what makes the host process loopback-only: iroh advertises exactly the address it is bound to, so binding 127.0.0.1 is the only way to publish one reachable loopback address and nothing else (see Sfu::bind in services/sfu/src/sfu.rs, and ADVERTISE_IPV4’s clap doc in services/sfu/src/main.rs).

DETACHED like the backend beside it — see crate::process.

Constants§

ADVERTISE_IPV4 🔒
Bind address AND advertised address (the SFU makes them the same thing — see the module doc). Loopback only: no media packet this stack carries ever leaves the host.
DRAIN_DEADLINE_SECS 🔒
Dev drain deadline. The SFU drains on SIGTERM before exiting; with no sessions that is immediate, and this caps what a teardown waits for when one is still up.
HEALTHY_BUDGET 🔒
How long the SFU gets to bind its iroh endpoint and answer /health (the health server only starts once the node id exists — see services/sfu/src/main.rs).
HEALTH_PORT
The SFU’s GET /health port. Answering here is what distinguishes OUR host SFU from any other node that may have registered with the backend (the reuse probe in crate::lifecycle checks both).
LISTEN_PORT
The UDP port the host SFU’s iroh endpoint binds — the same fixed port the container published, so nothing downstream had to move.
REGISTERED_BUDGET 🔒
How long the backend’s registry gets to show the node after it is healthy. One registration POST is issued as soon as the SFU starts, so this covers a retry, not the 30 s steady-state interval.
