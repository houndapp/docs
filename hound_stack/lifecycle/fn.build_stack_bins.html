Build the host backend, SFU and auth page in ONE cargo invocation, and give each this machine’s stable code signature if one is configured.

One invocation, and always under cargo::STACK_SELECTION: a different -p set is a different feature resolve, which recompiles dependencies and re-uplifts the binaries with fresh mtimes — which the staleness check reads as a code change.
