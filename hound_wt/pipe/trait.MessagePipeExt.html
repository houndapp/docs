Expand description

JSON framing over any MessagePipe, blanket-implemented so both legs get identical wire behaviour (and identical skip-on-garbage semantics) for free.

fn recv_json<T>(&mut self) -> impl Future<Output = Option<T>> + Send
where T: DeserializeOwned + Send,

Receive the next frame that deserializes into T.

A frame that fails to parse — malformed JSON, or a variant this build does not know because the peer is newer — is skipped, not fatal: the protocol’s additive-compatibility rule is that an unknown frame costs that frame, never the session. None means the pipe is finished.
