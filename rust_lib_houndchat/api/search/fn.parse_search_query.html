pub fn parse_search_query(input: String) -> ParsedSearchQuery
Expand description

Parse one line of search input.

Runs per keystroke — the field re-parses on every edit to repaint its highlighting, so this is #[frb(sync)] like highlight_markup: an await here would paint one frame of unstyled text before catching up.

Total, and that is the contract: half-typed input is the normal case, not an error case. Every input yields a runnable query; anything unreadable becomes a diagnostic, never a throw.
