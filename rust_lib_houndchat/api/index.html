Expand description

The bridge API surface the Flutter UI binds against.

One flat surface for codegen, split by domain into children:

  • mirrors — every #[frb(mirror(...))] declaration: the error surface + code registries, auth/identity snapshots, media/call enums, call + data snapshots (and the tests pinning mirror↔registry parity).
  • auth — the auth command clusters (passkey, browser-deferred, Steam, magic-link, linked identities) + the WebAuthn JSON seam.
  • call — the call_* voice/video commands.
  • links — opening a link externally + the embed debugger’s unfurl.
  • markup — message-markup commands: parse/plain-text/autolink + fetching a single message.
  • [search] — message search: the query parser (per keystroke), the search command, and the detached-history jump/resume pair. Carries its own DTOs where the language’s #[non_exhaustive] enums cannot be mirrored.
  • streams — the watch_* StreamSink forwarders + the two reshape DTOs.
  • texture — the zero-copy texture handshake + the decode→render seam.
  • log / sentry — the tracing→Dart bridge and Rust-side crash reporting.

This parent keeps the process-wide client handle (init_app + the openh264 toggle), the data commands, and re-exports every child item so the generated glue’s crate::api::X paths are stable regardless of which child defines X.

Projection rule (mirror by default; DTO only on a genuine reshape): the facade’s snapshots are hound-client’s own view-models. Rather than re-declare each one, we #[frb(mirror(T))] it — codegen emits the matching Dart class with zero field duplication, so a new field on the core type flows to Dart for free. A hand-written struct + project_* fn is written only where the shape genuinely differs from the core type:

  • LevelsDto — LevelsView.peers is a HashMap (FRB mirrors a Vec cleanly).
  • CommunityNode — the sidebar joins a community with its spaces (a composed reshape built from the mirrored Community/Space, still no duplication).
  • RegisterStartDto/LoginStartDto — command results, not snapshots.

Ids cross as uuid::Uuid (Dart UuidValue) via the FRB uuid feature.

Modules§

auth
Auth commands: passkey register/login, the browser-deferred ceremonies, Steam, email magic-link, and the linked-identities settings surface — plus the WebAuthn JSON seam (parse_credential/to_json) and the two command-result DTOs.
call
Call commands (voice/video orchestration).
links
Links: opening one in the system browser, and unfurling one through the server’s embed pipeline for the debugger.
log
Log bridge: Rust tracing → Dart (plus the stderr mirror for CI smoke runs and the persistent log file’s bridge commands), and Dart → tracing back the other way. The file mechanics themselves live in crate::logfile; this is the bridge half.
markup
Message-markup commands: parsing preview text, live source highlighting for the composer, plain-text rendering (the “Copy text” action), autolinking a reference, and fetching a single message.
mirrors
The #[frb(mirror(...))] surface: every core type that crosses the bridge as-is, plus the tests pinning the mirror↔registry contract.
search
Message search: running one, parsing what is being typed, and the detached-history commands a jump to a hit drives.
sentry
Crash reporting: Rust panics → Sentry. Policy (event-vs-breadcrumb rules, event enrichment) lives in crate::telemetry; this is the bridge half.
streams
Observable streams: the watch → StreamSink forwarders that mirror the facade’s snapshots to Dart Streams, plus the two genuine-reshape DTOs they project (LevelsDto, FrameSizesDto).
texture
The video/camera surface: the zero-copy texture handshake, plus the decode→render seam (RenderVideoSink) that init_app installs.

Structs§

CommunityNode
One node of the sidebar tree: a Community joined with its Spaces. A composed reshape (the core keeps community/space lists separately) built from the mirrored types — so there is no field duplication, only the join.

Statics§

APP_DIR 🔒
The app’s private support directory, handed over from Dart (path_provider) by init_app — the Rust core has no platform API of its own to derive it, and it is where the downloaded openh264 codec is cached.
CLIENT 🔒
The process-wide [HoundClient], set once by init_app. FRB free functions fetch it; calling a command before init_app is a usage error (surfaced as HoundError::InvalidState).

init_app
Build the [HoundClient] bound to base_url with a keyring-backed session store and install it as the process-wide handle. Idempotent at the storage layer (the keyring default store registers once); a second call after a successful first is a no-op that returns Ok (the existing client stays). Must be called before any other command/stream.
