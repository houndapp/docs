Observable streams: the watch → StreamSink forwarders that mirror the facade’s snapshots to Dart Streams, plus the two genuine-reshape DTOs they project (LevelsDto, FrameSizesDto).

Structs§

FrameSizesDto
Per-stream frame geometry — the RENDER-PATH contract that sizes each tile’s native texture. Reshaped from StatsSnapshot (the UI must never parse the debug-stats JSON for a render decision) and emitted only when a geometry actually changes, so the stream is near-silent in steady state.
LevelsDto
Speaking levels: mic + per-peer, each 0.0..=1.0. Reshaped because the core LevelsView carries peers as a HashMap, which FRB mirrors less cleanly than a Vec of pairs.
