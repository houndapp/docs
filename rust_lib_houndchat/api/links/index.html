Links: opening one in the system browser, and unfurling one through the server’s embed pipeline for the debugger.

Both commands are about URLs a stranger wrote — a message body is attacker-controlled text — so both validate the scheme before doing anything with it. That check is here rather than in the UI because it must hold for every caller, and because the consequence of missing it is platform-specific and severe: [open::that_detached] resolves to ShellExecute on Windows and open(1) on macOS, either of which will cheerfully act on file:, smb:, or a registered custom scheme.
