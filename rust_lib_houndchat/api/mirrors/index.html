Attachment
A file attached to a message.
Ban
One row of a community’s ban list: who is banned, who banned them, and why.
CallParticipant
A control-plane peer with a known identity. The UI joins user_id against the display roster (the same one text channels use) for the name + avatar. Carries no name/avatar itself — identity lives in the roster, not the call plane.
CallTrack
One published track, carried with the control-plane enums (not flattened to strings) so the binding compares them type-driven — t.kind == MediaKind::Video — with exhaustiveness on both sides. The enums are Copy + Eq (serde snake_case).
CallView
The call’s roster as the UI renders it: self id, peers, and the tracks (with kind/source/mute). Built from the control plane’s [SessionView] reducer — the same source of truth the media plane subscribes off of. Empty before Welcome.
Community
A community (server/guild). default_space is where the UI lands on entry.
CommunityMember
A member row in the community’s member list: the display identity joined with the roles they hold.
DecodedImage
A decoded still image: straight (unassociated) 8-bit sRGB RGBA, width * height * 4 bytes, row-major, no row padding.
DeviceListView
The available media devices grouped by kind — the data the Devices panel renders. A kind whose platform backend is absent simply comes back empty (a capability miss, not an error).
DeviceView
One enumerated media device for a picker row. FFI-flat: id is the opaque selection token to pass back to call_select_device for this kind (for audio it equals the cpal device name; for a camera the AVFoundation uniqueID), and is_default flags the host’s current default for that kind.
Document
A parsed message: an ordered sequence of top-level blocks.
EmbedAuthor
A byline: oEmbed author_name/author_url, or article:author.
EmbedDebugReport
Everything the unfurl of one URL saw and decided — the embed debugger’s payload.
EmbedFetchStep
One HTTP hop the unfurl made. Redirects appear as their own entries, which is what makes “this link goes somewhere else” visible in the debugger.
EmbedMedia
One image, audio track, or video the embed refers to.
EmbedProvider
The publishing service: oEmbed provider_name/provider_url.
EmbedRawField

EmbedVideo

Identities
The signed-in account’s login methods (GET /auth/identity).
IdentityEntry
One linked login method. provider is the backend’s wire value ("email" / "steam"); external_id is the email address or SteamID64.
InstanceInfo
What the instance says about itself: how it is shaped, and what the signed-in user may do to it.
Invite
One invite link to a community, as its organisers see it in the invite list.
InviteCommunity
The community an InvitePreview is for — a public summary, not the Community view-model (no default_space, no viewer permissions: the viewer is not a member yet).
InvitePreview
What a recipient sees before redeeming an invite: enough of the community to decide, and whether redeeming it would do anything.
LinkEmbed
The unfurled preview of one URL, ready to render.
Member
A community member’s display identity, merged from global + community profile (community name wins). The roster the UI joins messages + call peers against.
Message
One chat message. author keys into the roster for name/avatar (the UI joins); edited_at_ms is Some only if the message was edited.
Role
A named bundle of permissions inside one community.
RoleOverwrite
“In this channel, this role explicitly may (allow) or may not (!allow) do permission.” Absent = inherit whatever the community-wide roles say.
ScreenQuality
One stream’s video-quality preference, changeable mid-stream. Drives [QualityLadder::screen_for] / [QualityLadder::reconfigure]. The default is legibility-first, capped at 1080p60.
ScreenShareError
A screen-share failure the user must be TOLD about, split into the two things a surface needs: the stable machine code (what a support log is grepped for and what Sentry groups on) and the human message. FFI-flat (two Strings) so the FRB layer mirrors it with no reshape.
ScreenSourceView
A shareable screen source for the picker — a display, a window, or a camera streamed as a screen. UI-friendly + FFI-flat: the typed engine selection token is encoded into id (see [encode_screen_source]) so the UI round- trips an opaque string back into [CallSession::screen_share_start].
ScreenThumbnail
A share-picker preview image: opaque RGBA8888, width * height * 4 bytes.
SearchHit
One search hit: the message, the community it lives in, its relevance score, and the author’s display identity.
SearchPage
A page of search hits. There is no total: the cursor is a keyset, so “how many more” is a question the backend deliberately cannot answer cheaply.
Space
A space (channel) within a community.
SpaceOverwrites
One channel’s permission overwrites: the per-channel exceptions to what a role or a user may do there.
StyleRun
One run of uniformly-styled source text.
Term
One text term: a word, or a quoted phrase whose words must appear adjacent.
UserOverwrite
Per-user counterpart of RoleOverwrite, and the more specific of the two: a user overwrite wins over any role overwrite that would contradict it.
