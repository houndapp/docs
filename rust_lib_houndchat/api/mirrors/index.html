Structs§

Attachment
A file attached to a message.
CallParticipant
A control-plane peer with a known identity. The UI joins user_id against the display roster (the same one text channels use) for the name + avatar. Carries no name/avatar itself — identity lives in the roster, not the call plane.
CallTrack
One published track, carried with the control-plane enums (not flattened to strings) so the binding compares them type-driven — t.kind == MediaKind::Video — with exhaustiveness on both sides. The enums are Copy + Eq (serde snake_case).
CallView
The call’s roster as the UI renders it: self id, peers, and the tracks (with kind/source/mute). Built from the control plane’s [SessionView] reducer — the same source of truth the media plane subscribes off of. Empty before Welcome.
Community
A community (server/guild). default_space is where the UI lands on entry.
DecodedImage
A decoded still image: straight (unassociated) 8-bit sRGB RGBA, width * height * 4 bytes, row-major, no row padding.
DeviceListView
The available media devices grouped by kind — the data the Devices panel renders. A kind whose platform backend is absent simply comes back empty (a capability miss, not an error).
DeviceView
One enumerated media device for a picker row. FFI-flat: id is the opaque selection token to pass back to call_select_device for this kind (for audio it equals the cpal device name; for a camera the AVFoundation uniqueID), and is_default flags the host’s current default for that kind.
Identities
The signed-in account’s login methods (GET /auth/identity).
IdentityEntry
One linked login method. provider is the backend’s wire value ("email" / "steam"); external_id is the email address or SteamID64.
Member
A community member’s display identity, merged from global + community profile (community name wins). The roster the UI joins messages + call peers against.
Message
One chat message. author keys into the roster for name/avatar (the UI joins); edited_at_ms is Some only if the message was edited.
ScreenQuality
One stream’s video-quality preference, changeable mid-stream. Drives [QualityLadder::screen_for] / [QualityLadder::reconfigure]. The default is legibility-first, capped at 1080p60.
ScreenShareError
A screen-share failure the user must be TOLD about, split into the two things a surface needs: the stable machine code (what a support log is grepped for and what Sentry groups on) and the human message. FFI-flat (two Strings) so the FRB layer mirrors it with no reshape.
ScreenSourceView
A shareable screen source for the picker — a display, a window, or a camera streamed as a screen. UI-friendly + FFI-flat: the typed engine selection token is encoded into id (see [encode_screen_source]) so the UI round- trips an opaque string back into [CallSession::screen_share_start].
ScreenThumbnail
A share-picker preview image: opaque RGBA8888, width * height * 4 bytes.
Space
A space (channel) within a community.

Enums§

AuthCode
Authentication/authorization failures — the UI routes these to re-auth.
AuthFlowOutcome
Result of an auth flow that can end more than one way: a Steam sign-in (in-Steam ticket or browser OpenID) or a browser-deferred ceremony wait.
AuthState
Authentication state the UI gates routing on. A snapshot, pushed on every transition (signed-out ⇄ signed-in / token-refreshed).
Codec
Negotiated codec for a track. Mirrors hound_media::Codec (keep in sync).
ConnectionState
The connection state of the call’s control plane (and, by extension, whether media can flow). Drives a UI banner. attempt is the reconnect attempt count.
DecodeCode
Payloads that did not match the expected schema — client/backend drift.
DegradePriority
Which dimension a screen-share ladder sacrifices first as bandwidth drops — a per-stream user choice, switchable on a live stream (not asked at stream start). Gameplay wants motion; an IDE/slides wants legibility.
HoundError
All ways a client operation can fail, as a closed set the UI can exhaustively handle. Carries a stable code for grouping plus human-readable detail for logs/toasts; the variant is what callers branch on.
InternalCode
Unexpected internal failures. Their presence in logs is a prompt to add a more specific variant.
MaxResolution
The user’s maximum-resolution cap for a stream (the “Source / 1440p / 1080p / 720p / 480p” control). Source imposes no cap beyond the capture’s own geometry — the session still clamps it to the encoder’s native target.
MediaCode
Media/call-engine failures: join, transport, capture, encode/decode, device.
MediaKind
Whether a track carries audio or video samples.
NetCode
Transport failures: the request never got an answer.
NotFoundCode
The requested resource does not exist.
RealtimeCode
Realtime-plane failures: connect, handshake, subscribe, malformed event.
Source
Where a track originates. Combined with MediaKind this maps onto the media wire enum hound_media::TrackKind (e.g. Camera+Video = CamVideo); kept separate here because the control plane negotiates them independently (a screen share can carry both video and audio).
SpaceKind
What kind of channel a space is — the discriminant that selects which main-panel UI renders. Adding a variant here + a ChannelDescriptor on the Flutter side is all it takes to add a channel type (see the channel registry).
StateCode
Invariants the caller violated — a bug-class signal, not a user condition.
UploadPurpose
Which upload route an upload_accept_post probe is about. Two routes, two independent advertisements: an avatar and a message attachment are not obliged to accept the same types (nor the same size), so the caller names the one it is about to post to.
