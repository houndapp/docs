The video/camera surface: the zero-copy texture handshake, plus the decode→render seam (RenderVideoSink) that init_app installs.

Structs§

RenderVideoSink 🔒
The decode→render seam: forwards decoded I420 frames into the per-stream-key render mailbox ([hound_render::push_frame]). Keeps hound-client UI/FFI-free — the texture path lives behind the hound-render facade. The mailbox is cross-platform (macOS GPU render thread / Windows+Linux CPU render thread both drain it); a frame for a not-yet-attached key just queues-of-one until attach.

Constants§

TEXTURE_READY_DEADLINE 🔒
How long a texture swap will hold the OLD texture on screen waiting for the new one’s first frame. A layer switch delivers an immediate IDR and the renderer draws on arrival, so this is normally satisfied within one frame interval; the deadline only covers a stream that stops producing mid-swap, where showing the (black) new texture is no worse than the frozen old one.

Functions§

attach_video_texture
Attach a stream key (e.g. “cam:42”, “self”, “screen:7”) to a native GPU texture handle the Flutter plugin registered, sized width×height. native_texture is an opaque pointer (an IOSurfaceRef / id<MTLTexture> on Apple) the Rust renderer will draw into. texture_id is the Flutter texture id the same createTexture returned: macOS’s shared render loop marks it “dirty” once it draws a new frame, and the plugin’s ONE shared CVDisplayLink re-pulls only dirty ids (so copyPixelBuffer runs at video-fps, not display refresh). The plugin allocates the buffer at this SAME width×height (the decoded frame’s size, so the render target matches the source aspect with no crop/stretch); Dart recreates + re-attaches at a new size when the decoded resolution changes. Returns once the render target is bound.
detach_video_texture
Detach a stream’s texture (tile unmounted / peer left). Stops + joins the render thread (which then no longer touches the native texture/buffer) so the plugin can release it.
video_texture_ready
Resolves once a real decoded frame has been drawn into texture_id — the signal Dart’s make-before-break texture swap flips on. A freshly allocated CVPixelBuffer is zero-filled, so showing it before this would flash black; meanwhile the OLD texture keeps compositing its last frame, so the tile never goes blank either.
