Expand description

Build the [HoundClient] bound to base_url with a keyring-backed session store and install it as the process-wide handle. Idempotent at the storage layer (the keyring default store registers once); a second call after a successful first is a no-op that returns Ok (the existing client stays). Must be called before any other command/stream.

app_dir is the app’s private support directory (Dart’s path_provider); openh264_enabled is the user’s persisted setting for Cisco’s software H.264 codec. Enabled, the codec is fetched in the background — deliberately not awaited, because this call is on the path to the first frame and the download is a network round-trip against Cisco’s CDN. Software H.264 is simply unavailable until it lands; hardware H.264 is unaffected.

app_dir is optional because its ONLY consumer is that codec cache. If the platform channel that yields it fails, the app must still start: the codec is then unavailable (hardware paths and everything else are untouched) rather than the launch being lost to a black screen over an optional feature.
