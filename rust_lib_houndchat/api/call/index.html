Module call

Expand description

Call commands (voice/video orchestration).

Thin wrappers over the HoundClient call surface. The decode→texture seam is wired in init_app (the RenderVideoSink forwards to hound_render::push_frame); the Flutter side attaches a texture per tile by stream key (attach_video_texture("cam:42", ptr)), exactly as the self-camera path does.

call_audio_debug_report
Render the agent-readable audio-quality debug report (a paste-able text block that pre-attributes a glitch to a pipeline stage) from the latest stats snapshot. For the “Copy audio report” affordance; returns a “healthy” report between calls.
call_join
Join the voice/video call for space_id (publishes mic, and camera if camera_enabled). Drives the watch_call_state/watch_connection/watch_levels streams. Leaves any prior call first.
call_leave
Leave the current call (best-effort broadcast, then tear down). No-op if not in one.
call_list_devices
Enumerate the available media devices (mic / camera / speaker) for the Devices panel. Needs no active call; pass an id from a returned DeviceView back to call_select_device (or null for the host default).
call_list_screen_sources
List shareable screen sources (displays + windows) for the share picker. Returns the mirrored core type directly — no reshape needed.
call_screen_share_start
Start sharing a screen source by id (from call_list_screen_sources). Requires an active call.
call_screen_share_stop
Stop screen sharing (no-op if none).
call_screen_thumbnail
One-shot preview thumbnail of a screen source for the picker (opaque RGBA, aspect-fit within max_w×max_h). Best-effort + cross-platform; an Err is the picker’s “no thumbnail, show the title-only card” signal.
call_select_device
Select a call media device. kind is "microphone" | "camera" | "speaker"; id is the device id (None = host default).
call_set_agc_enabled
Toggle mic automatic gain control (default on). Off ships the raw device level — for a mic the automatic gain misjudges.
call_set_camera_enabled
Enable/disable the local camera publish. Enabling fails loudly when the camera is denied (see ensure_device_permitted); disabling always succeeds.
call_set_input_gain
Manual mic input trim in dB (clamped ±12, default 0).
call_set_muted
Mute/unmute the local mic. Un-muting is an enable, so it fails loudly when the mic is denied (see ensure_device_permitted); muting always succeeds.
call_set_noise_suppression
Set the mic noise-suppression mode: "off", "moderate" (default), or "high". Applies to the live call immediately and survives reconnects.
call_set_screen_audio_enabled
Toggle whether the local screen share broadcasts its app audio (the broadcaster’s “share audio” control). While off, audio frames are dropped before encode — zero CPU and zero wire cost; re-enabling resumes instantly.
call_set_screen_quality
Set the live screen-share quality (motion↔legibility + a max resolution/fps cap). Reconfigures a running share’s ladder live — no restart — and is remembered for the next share + across a reconnect. Harmless with no active call.
call_set_stream_volume
Set one remote audio stream’s playback volume — the tile right-click volume/mute control. source is Source::Microphone (the peer’s voice) or Source::Screen (their share’s app audio); volume is 0.0 (muted) … 1.0 (unity), clamped ≤ 2.0. Local-only (the sender is not told); applies within ~20 ms and survives reconnects/layer switches.
call_set_tile_quality
Report a remote video tile’s rendered size + visibility, for peer peer_id’s source (Source::Camera | Source::Screen). The tile takes the cheapest below-source rung that can fill it (and a large/visible one the full source), so a receiver only pays to decode what it is actually showing.
call_set_video_paused
Pause/resume inbound video (audio keeps flowing). Call from the app lifecycle observer: paused = true when the app is backgrounded / the call surface is not visible, so we stop receiving + rendering remote video (notably a heavy screenshare) that nobody can see. No-op when not in a call.
call_video_debug_report
Render the agent-readable video-quality debug report (the send/receive twin of call_audio_debug_report: a paste-able text block that pre-attributes a freeze or a black tile to a pipeline stage) from the latest stats snapshot. For the “Copy video report” affordance; returns a “healthy” report between calls.
