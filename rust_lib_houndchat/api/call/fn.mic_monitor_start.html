pub async fn mic_monitor_start(mic_id: Option<String>) -> Result<(), HoundError>
Expand description

Start the out-of-call microphone monitor — the settings screen’s mic test.

Opens mic_id (None = host default) through the same capture + APM path a call uses and publishes its level on the existing watch_levels stream, so the settings meter and the in-call meter are one widget over one stream. Refused while a call is live (the call owns the microphone), and fails loudly on a denied/absent device rather than showing a meter that never moves.
