pub async fn set_openh264_enabled(enabled: bool) -> Result<(), HoundError>
Expand description

Turn Cisco’s software H.264 codec on or off — the settings toggle openh264’s BINARY_LICENSE requires the app to provide (alongside the attribution notice and the license text, both rendered in the UI).

On: permit the codec and start the download if it is not cached yet. Off: stop using it immediately and delete the cached library, so “off” means the Cisco binary is neither running nor present. Returns as soon as the intent is recorded; a fresh download continues in the background.
