The signed-in user’s own global profile: rename and avatar edits.

Each command answers with the profile as written and has already folded it into the roster stream, so selfProfileProvider (the roster entry for the signed-in user) shows the edit before the future completes. set_avatar takes the file’s bytes, already read by Dart — the same seam as set_community_icon.

Functions§

clear_avatar
Drop the global avatar; every surface falls back to initials.
import_steam_avatar
Make the caller’s Steam photo the global avatar. The server copies it, so the client never re-uploads Steam’s image. Refused no_steam_identity (404) without a linked Steam account, steam_unavailable (502) when Steam does not answer.
set_avatar
Upload bytes as the global avatar and point the profile at it. mime must be one of the types this deployment advertises for avatars (supported_upload_mime_types).
set_display_name
Rename the global profile. Refused (empty_name / name_too_long, with ready-to-show copy) outside 1..=32 characters after trimming.
