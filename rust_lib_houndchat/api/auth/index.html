Auth commands: passkey register/login, the browser-deferred ceremonies, Steam, email magic-link, and the linked-identities settings surface — plus the WebAuthn JSON seam (parse_credential/to_json) and the two command-result DTOs.

Functions§

browser_login_begin
Begin a browser-deferred login — the passkey path on platforms with no system passkey provider (Linux), same flow as houndctl auth login. Binds the loopback callback, opens the system browser at the hosted auth page (auth_url, e.g. https://auth.hound.chat), and returns that URL so the UI can display it as the browser-didn’t-open fallback. Follow with browser_login_wait.
browser_login_cancel
Cancel a pending browser login (idempotent; wakes a blocked wait).
browser_login_wait
Await the browser callback for the pending browser_login_begin / browser_steam_begin flow. A token callback is adopted as a session (persist + connect realtime) → SignedIn; a Steam link-token callback parks the token and returns Unknown for the create-or-link screen. Errors on timeout or when browser_login_cancel interrupts it.
browser_steam_begin
Begin a browser Steam OpenID flow (outside a Steam launch): sign-in, or ownership-proof for the settings link when link is set. Follow with browser_login_wait; a link flow ends in Unknown — then call link_steam_pending.
ensure_session_fresh
Rotate the session access token if it is past its half-life. The app-resume hook: a device that slept through the proactive refresh ticks calls this on wake so the first real request carries a live token instead of eating a 401-and-retry. No-op when signed out or while the token is still young.
link_email_browser_begin
Begin the browser-deferred email-link ceremony (no system passkey provider, e.g. Linux): the hosted auth page collects the email and runs the create ceremony under a scoped token. Follow with browser_login_wait, which ends in EmailLinked.
link_email_finish
Complete the email link with the authenticator credential JSON.
link_email_start
Begin adding an email + passkey to the signed-in account (same options JSON seam as register_start).
link_steam_pending
Link the pending Steam link token to the current session (settings flow).
link_steam_via_ticket
Link Steam to the current session via the local Steam client (settings, in-Steam launch).
list_identities
The signed-in account’s login methods + passkey count.
login_finish
Finish passkey login with the authenticator assertion JSON. On success the session is persisted + realtime connected; returns the new auth state.
login_start
Begin passkey login: returns the user id + opaque WebAuthn request options (JSON).
logout
Sign out: tear down realtime, clear the session, reset the observable snapshots.
magic_link_begin
Begin an email magic-link login: binds the loopback listener and asks the backend to email email a sign-in link (carrying our port/state) plus a bare code for manual entry. No browser is opened — the link lives in the email. Follow with magic_link_wait (same-device link click) and/or magic_link_code (typed code); whichever completes first wins — cancel the other with magic_link_cancel.
magic_link_cancel
Cancel a pending magic-link login (idempotent; wakes a blocked wait).
magic_link_code
Verify a manually-typed sign-in code directly over REST (no loopback needed — works for a link opened on another device). Same outcome shape as magic_link_wait.
magic_link_register
“Continue as email”: create a new account for the pending email create-or-link decision.
magic_link_wait
Await the loopback callback for the pending magic_link_begin flow. A token callback signs in; an unknown-email callback parks a link token and returns EmailUnknown for the create-or-link screen. Errors on timeout or when magic_link_cancel interrupts it.
parse_credential 🔒
Parse a Dart-supplied WebAuthn credential/assertion JSON string into the typed hound-passkey type the client expects. The Dart passkeys package produces these as JSON, so this seam owns the JSON→typed conversion (the Dart-facing API stays JSON strings).
register_finish
Finish passkey registration with the authenticator credential JSON. On success the session is persisted + realtime connected; returns the new auth state.
register_start
Begin passkey registration: returns the provisional user id + the opaque WebAuthn credential-creation options (as a JSON string) for the platform authenticator.
restore
Rehydrate a persisted session at startup (restore tokens + refresh + connect). Returns the resulting auth state.
steam_available
Whether the app was launched through Steam (Steamworks init succeeded).
steam_dismiss
Abandon a pending create-or-link decision (user backed out of the screen).
steam_login
Sign in via the local Steam client. SignedIn on a linked Steam ID; Unknown { persona } parks a link token for the create-or-link screen.
steam_persona
The local Steam user’s persona name (None outside a Steam launch).
steam_register
“Continue as persona”: create a new account for the pending Steam decision.
to_json 🔒
Serialise a typed WebAuthn options value back to a JSON string for the Dart side.
unlink_identity
Unlink a login method ("email" / "steam"). The backend refuses to strand the account (400 → HoundError::Http).
