The tag enrich lifts a tracing event’s code field onto — the Rust half of what the Dart beforeSend fingerprints on, so both clients’ events for one failure group and filter by the same stable [hound_client::error] code (MEDIA024, …) rather than by build-shifted frames or interpolated message text. The key is deliberately identical to the one ui/lib/main.dart’s beforeSend sets — one query has to return both halves of a failure.
