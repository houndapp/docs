fn cooled_down(md: &Metadata<'_>) -> bool

Whether this callsite may file an event again yet, recording the attempt if so.

Keyed by tracing’s callsite Identifier, so repeats of one error! collapse regardless of the values interpolated into the message. The map is bounded by the number of distinct callsites compiled into the binary, so it needs no eviction. Lock poisoning is ignored deliberately: this runs on the failing thread, and a reporter that panics while reporting reports nothing.
