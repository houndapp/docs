Where sentry-tracing files a tracing event’s structured fields.

This is the empirical half of the lift, and it is worth stating because it is not obvious from the API: sentry-tracing’s event_from_event puts every field that is not the message into contexts["Rust Tracing Fields"] as Context::Other, and promotes to tags ONLY fields whose name is prefixed tags. — which a plain error!(code = %e.code(), …) is not. So before_send (enrich) has to find the code in the context map — never in extra, never in tags. Lifting there rather than renaming the field at every callsite keeps the emission sites plain tracing and makes the tag automatic for callsites not yet written.
