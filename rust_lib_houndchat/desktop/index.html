Module desktop

Expand description

Handing a file, folder or URL to the desktop: open it with the OS default handler, or show it selected in the platform file manager.

Every call runs on a throwaway thread, joined before returning. The Windows shell APIs initialise COM on the thread that calls them (open makes it a single-threaded apartment, STA, to open a folder), and a thread’s apartment is fixed for its lifetime. An FRB worker turned STA fails WASAPI default-device activation, which works only from a multithreaded apartment, the next time a device command lands on it — ensure_audio_apartment in hound-engine cannot re-type a thread that is already an STA. A thread that exits takes its apartment with it. The same hop keeps zbus’s blocking API (the Linux reveal) off the tokio runtime FRB runs commands on, where it panics.
