The OS’s idiomatic per-user log directory for this app, or None where the platform gives us no home to derive one from (a service account with no $HOME, a sandbox that denies it).

One arm per platform convention rather than one crate call, because the three conventions genuinely differ — dirs has no single “logs” accessor because there is no single answer:

  • macOS — ~/Library/Logs/houndchat (what Console.app reads).
  • Windows — %LOCALAPPDATA%\houndchat\logs (roaming a log is pointless).
  • elsewhere — the XDG state dir, ~/.local/state/houndchat: logs are state that persists but is not user data and not a cache, which is exactly what XDG_STATE_HOME was added for. data_local_dir is the fallback for the platforms dirs reports no state dir on.
