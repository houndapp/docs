§Derived base-layer (…_t0) tracks — the relay’s temporal-SVC half

A publisher’s camera encoder marks each frame with its L1T2 temporal layer (hound_media::TemporalLayer), carried in the MoQ object envelope’s reserved byte. This module turns that marking into something a receiver can subscribe to: for every camera video broadcast in the origin, it republishes a derived broadcast under …/cam_t0 carrying only the base-layer objects.

A receiver that takes cam_t0 instead of cam gets the same resolution at half the frame rate for ~70% of the bits, with no re-encode anywhere and no keyframe — which is the whole point: the publisher publishes once and does not know, or need to know, which of its subscribers took which.

§Why a derived TRACK and not object dropping

MOQT draft-19 §9.4 removed the relay’s licence to drop objects: “A relay MUST NOT reorder or drop objects received on a multi-object stream when forwarding to subscribers.” Sniffing a layer byte and skipping objects mid-stream is therefore not a door that is open, however convenient. Interposition is: moq_net::OriginProducer::publish_broadcast lets us consume …/cam and republish a different broadcast, to which §9.4 simply does not apply. The derived track is complete and well-formed on its own terms.

§What this costs the relay

crate::moq_relay’s central claim is that the relay never touches a byte — moq-net’s shared [moq_net::Origin] fans everything out and the SFU only owns the auth gate. This module is the first thing to break that, so it is built to break it as little as possible:

  • No transcode, no bitstream parse. The filter reads ONE byte, through [hound_transport::moq::object_temporal_id] — the same accessor the endpoints encode with, so the relay can never grow its own idea of where the layer id lives.
  • No copy. moq-net hands objects out as [bytes::Bytes]; forwarding one is a refcount bump.
  • frame_seq is never rewritten. mediasoup’s regression (versatica/mediasoup#1625) is that rewriting frame numbers corrupts the dependency structure. The gaps a filtered track leaves in the sequence space are intentional and the receiver is told to expect them (hound_media::TEMPORAL_BASE_STRIDE) rather than being lied to.
  • Nothing runs until somebody subscribes. Each derived track is announced eagerly (so a receiver’s subscribe resolves immediately) but the per-object pump is gated on [moq_net::TrackProducer::used] and stops again on unused. A call where nobody is constrained pays one idle task per camera and zero per-object work.

§Group and keyframe semantics are preserved

The derived track mirrors the source’s group structure: same group sequences, same boundaries. A derived group is created lazily, on its first surviving object, so a group whose objects are all enhancement-layer simply does not appear rather than appearing empty.

That lazy creation is also what preserves the join contract. hound’s video publisher rolls a group on every keyframe, so a group’s first object is always the IDR — and a keyframe is always base layer (an IDR is by construction referenced; the encoder additionally forces this, see vt_encoder). So the first surviving object of a derived group is the same IDR, and moq-net’s head-of-current-group replay hands a fresh …_t0 subscriber a decodable stream exactly as the source track does.

Structs§

Deriver 🔒
Owns the deriver supervisor task for one origin. Dropping it stops derivation and, with it, drops every derived broadcast’s producer — so a subscriber still on a …_t0 track sees a clean end-of-track rather than a stalled stream. Held by crate::sfu::Sfu / crate::moq_relay::Relay so the task’s lifetime is exactly the server’s.

Constants§

DERIVABLE_TRACK 🔒
The moq track name a base-layer view is derived from.
DERIVE_OUTCOMES
The closed set of sfu_derived_objects_total{outcome} label values — every verdict is_base_layer can reach. Bounded and enumerated here so main’s zero-init can expose both on a fresh scrape (an all-forwarded relay would otherwise render no filtered series at all, and “the filter is doing nothing” would be indistinguishable from “the series does not exist yet”).
