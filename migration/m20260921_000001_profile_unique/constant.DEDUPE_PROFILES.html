const DEDUPE_PROFILES: &str = "\
DELETE FROM profile
WHERE community_id IS NOT NULL
  AND EXISTS (
    SELECT 1 FROM profile AS earlier
    WHERE earlier.user_id = profile.user_id
      AND earlier.community_id = profile.community_id
      AND earlier.id < profile.id
  )";
Expand description

Keeps the oldest row of every duplicated (user_id, community_id) pair, so the unique index below can be created on a database that already has some. UUIDs order as their storage type on both backends, and these are v7, so “smallest id” is “written first”.
