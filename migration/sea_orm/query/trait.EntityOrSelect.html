Expand description

Either an Entity or a Select<Entity>; accepted by LoaderTrait so you can pass the entity directly when no filtering is needed, or a pre-filtered Select when it is.

Required Methods§

fn select(self) -> Select<E>

Lift self into a Select<E>. For an entity, this is E::find(); for an existing Select<E>, the value is returned as-is.
