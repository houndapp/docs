hound_search::parse

Module lexer 

Source
Expand description

Splitting query source into chunks, before any of them mean anything.

The lexer answers only “where does each part sit, and what shape is it”: the optional leading -, an optional recognised key:, and a value that may be quoted. Whether has:hologram names a real content kind is the parser’s problem, not this module’s.

Chunks are whitespace-delimited, except that a " swallows whitespace to its closing quote — or to the end of input, since a composer is mid-word far more often than it is mistaken.

Every span is in UTF-16 code units. The scanner walks a char vector with a parallel table of byte and UTF-16 offsets, so slicing source and reporting positions are both one index away and neither has to re-scan.
