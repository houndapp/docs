fn negation(&mut self) -> Option<Range<u32>>

A leading - negates whatever follows it. A - with nothing attached is a word the user is searching for.

Source

fn key(&mut self) -> Option<Key>

ASCII letters up to a :, and only when they name a real filter. An unrecognised key stays part of the value, so foo:bar is searched for literally rather than half-interpreted.

Source

fn value(&mut self) -> Value

A quoted run, or everything up to the next whitespace. Quotes group only when they open the value: it"s is one word, not an unterminated phrase.
