Constants§

CUSHION_HYSTERESIS_MS 🔒
Dead band around OUTPUT_CUSHION_MS within which the tick pushes exactly one chunk. It must exceed one device callback (a cpal default buffer is ~10–21 ms), because the depth sampled at tick time swings by that much purely from the tick-vs-callback phase — a narrower band would toggle the regulator on phase noise instead of on real drift.
OUTPUT_CUSHION_MS 🔒
Target depth of the output device ring the bus keeps filled (~3 chunks). The device drains the ring on its hardware clock while this thread refills it on a software clock; without a cushion the ring sits at ~0 and underruns on the slightest pacing jitter (or when encode load deschedules this thread). 30 ms absorbs normal jitter at a small, constant added output latency (AEC3 tolerates the fixed delay); the thread-priority promotion handles longer stalls.
REOPEN_BACKOFF 🔒
Initial rate-limit on device-reopen attempts when no speaker is open (a down device must not hammer start every tick); first retry after ~500 ms.
REOPEN_BACKOFF_MAX 🔒
Ceiling for the reopen backoff. A persistently unavailable output device (e.g. an ALSA hw: held exclusively by another process on Linux — where each failed open/close churn can itself prolong the EBUSY) must not retry at 2 Hz forever, flooding the log and thrashing the device. The interval doubles from REOPEN_BACKOFF up to this cap, then holds — a slow heartbeat that still recovers automatically once the device frees, without the storm.
ROUTE_SETTLE 🔒
How long the non-fatal output-stream events must stay QUIET before the bus re-syncs its sink.

Functions§

chunks_for_tick 🔒
How many mixed chunks this tick should push, from the sink’s reported ring depth (depth_ms, sampled BEFORE the push) and how late the tick fired (late_us).
cpal_sink_factory 🔒
The production sink factory: open a CpalPlayback for the choice (with the vanish-fallback inside open), boxed as AudioOutput.
open_sink 🔒
One (re)open attempt on the bus thread: run the factory and fold the outcome into OutputHealth. None leaves the endpoint down for the tick loop’s backoff ladder to retry.
prefill_output 🔒
Pre-fill a freshly-opened output sink’s ring with OUTPUT_CUSHION_MS of SILENCE — the cushion’s initial condition, from which chunks_for_tick holds it closed-loop. Silence (not slot audio) means the pre-fill costs nothing from any peer’s stream; it is a fixed ~cushion of added output latency, which AEC absorbs.
synthetic_sink_factory 🔒
The synthetic sink factory: open a [SyntheticAudioOutput] (speaker-free null playout) boxed as AudioOutput, ignoring the device choice — there is no real device to select. For a headless/CI run (a bot) so the mix bus drives a full playout path (including the honest end-of-pipeline underrun gauge) without opening a real DAC. Errors only on the (practically infallible) open failure, matching cpal_sink_factory’s shape.
warmup_reopen_at 🔒
Arm the one-shot crate::audio::ROUTE_WARMUP_DELAY timer iff the just-opened sink runs at a non-engine rate (a resampled device — in practice a Bluetooth HFP headset whose SCO link may not be carrying audio yet). 48 kHz devices return None (no warmup reopen), so the common path is untouched. See crate::audio::ROUTE_WARMUP_DELAY.

Type Aliases§

SinkFactory 🔒
Opens the output sink for a DeviceChoice on the bus thread, returning a boxed AudioOutput or the typed failure. Production passes cpal_sink_factory (CpalPlayback); tests inject a fake so they never touch a real (possibly sandbox-blocked) audio device. Runs ONLY on the bus thread, so the !Send cpal::Stream never crosses a thread boundary.
