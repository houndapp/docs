fn dither(idx: u64) -> f64
Expand description

Deterministic dither in -1.0..1.0 for one absolute sample index (the upper bound is exclusive: the LCG yields 31 bits scaled by 2^-31, so +1.0 is unreachable).

A stateless LCG hash of the index rather than a running generator: the waveform must be a pure function of position, so a source that reopens mid-call continues the same signal instead of restarting a noise sequence. Constants are the standard 64-bit LCG multiplier/increment; the high bits are taken because an LCG’s low bits are weakly random.
