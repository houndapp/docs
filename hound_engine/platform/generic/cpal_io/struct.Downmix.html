    pending: DownmixMode,

    settle_frames: f64,
    alpha: f64,
}
Expand description

Chooses to_mono_i16’s downmix from a slow per-channel energy estimate.

A plain channel average is a silent −6 dB whenever a multi-channel device carries the mic on ONE channel: USB interfaces with a single XLR occupied, “Stereo Mix”, a mono capsule wired to the left input. The dead channel contributes only its own noise and halves the level — invisible in every gauge, and exactly the headroom the loudness chain is fighting for.

Real-time discipline: this runs in the cpal capture callback. All state (including the per-buffer scratch) is sized once at stream open, so the callback only reads and writes it — no allocation, no locking, no syscall. The mode is re-evaluated once per callback buffer and applied to the WHOLE buffer, so a switch can only ever land on a buffer boundary, never mid-waveform.

Fields§

§energy: Vec<f64>

Smoothed mean-square per device channel, in FloatS16² units.

§sums: Vec<f64>

This buffer’s per-channel sum-of-squares — the evidence energy integrates. Owned (not a local array) so the channel count is unbounded and the callback still allocates nothing.

§mode: DownmixMode

The downmix in force.

§pending: DownmixMode

The mode recent evidence argues for, and how many sample-frames it has argued for it. Equal to Self::mode ⇒ nothing pending.

§pending_frames: f64§settle_frames: f64

Sample-frames of sustained evidence needed to change Self::mode.

§alpha: f64

EMA weight per sample-frame (device rate → DOWNMIX_ENERGY_TAU_MS).

Integrate Self::sums over frames sample-frames and return the mode to use for THIS buffer.

Source

fn candidate(&self) -> DownmixMode

The mode the current energy estimates argue for. Hysteresis is applied here, not in Self::decide: entering single-channel mode needs DOMINANCE_ENTER_DB, staying in it only DOMINANCE_EXIT_DB.
