pub(crate) const fn available() -> bool
Expand description

Whether this build can decode AV1 in software right now — the honest input to decode_caps().av1 alongside the hardware probe.

A compile-time answer, unlike the software H.264 twin (super::openh264::sw_h264_available), which is a runtime question because Cisco’s binary is downloaded onto the device rather than linked. dav1d is linked at build time under a permissive licence, so if it is in the build it is available, full stop.
