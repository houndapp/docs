Escape hatch naming an already-downloaded Cisco binary, for contexts with no app to run the download: CI jobs (the blob comes from the http:openh264 mise tool), benches, and offline dev. Same posture as HOUND_APP_ROLE / HOUND_ZEROCOPY_VIDEO. Consulted only when nothing was installed explicitly.

May name the library or the directory holding it — see resolve_env_blob for why the file name cannot be assumed.
