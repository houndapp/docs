Portal enumeration sentinels + thumbnail stub (see portal_screen). Portal screen-source enumeration — the sources half of [super::portal_screen] (the running-capture backend), matching the per-platform screen / screen_sources split. Wayland’s portal dialog owns the real selection, so enumeration is one sentinel row per castable KIND and thumbnails are typed-unsupported (capturing one would prompt the dialog).

Functions§

capture_thumbnail 🔒
Thumbnails require capturing, and capturing prompts the portal dialog — a per-row prompt storm. Typed Unsupported; the picker degrades to title-only cards (its documented fallback).
enumerate_sources 🔒
List the castable source kinds as picker entries — one “Screen” and/or one “Window” row (the compositor’s dialog picks the concrete source at open). An absent portal surfaces CaptureError::Unsupported so the UI degrades the same way as a platform without a screen backend.
