PipeWire share-audio legs: default-sink-monitor loopback (display shares) and app-scoped stream capture (per-application audio, the venmic/OBS model). Pure node-identity matching for the app-scoped capture (see pw_audio). Node-identity matching for the app-scoped PipeWire capture (pure): which Stream/Output/Audio nodes belong to the target application — pid within its process tree, or its binary / application name (the OBS matching order).

node_matches 🔒
Whether node belongs to the app-scoped capture. Only application output streams qualify; our own process never does (capturing the call’s own playout would feed remote audio back as an echo). Criteria are OR’d: pid in the target’s process tree, or a case-insensitive binary / application-name match — the same identity keys OBS and venmic scope by.
