pub fn drop_stream(stream_key: &str)
Expand description

Drop stream_key’s mailbox — the “this stream is gone for good” hook (the peer left / the pipeline ended), distinct from the tile-lifecycle detach. Nothing converts an unattached mailbox, so its last I420 Vec (and the key) would otherwise live for the process lifetime. If the key is still attached the mailbox is only emptied: the render thread caches the Arc, so removing the map entry would send later pushes into a mailbox nobody drains.
