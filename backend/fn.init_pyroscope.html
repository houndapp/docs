pub(crate) fn init_pyroscope() -> Option<PyroscopeAgent<PyroscopeAgentRunning>>
Expand description

Start continuous CPU profiling, pushing pprof samples to the Pyroscope server named by PYROSCOPE_SERVER_ADDRESS; None (nothing sampling, zero overhead) when the var is absent or empty — profiling is either fully on or fully off, mirroring init_sentry’s all-or-nothing convention.

The pprof-rs backend samples this process’s stacks at PYROSCOPE_SAMPLE_HZ via a SIGPROF timer; a background thread gzips and POSTs them to <addr>/ingest. The returned running agent must be held for the process lifetime — dropping it stops the sampler and flushes. Appears in Pyroscope as hound-backend. The upload is plain http://, but reqwest 0.13 still constructs its rustls connector at client-build time and panics “No provider set” without a process-default CryptoProvider — observed in prod where Sentry (the other installer) was disabled. Install ring here too; install_default is first-wins, so doubling up with init_sentry is harmless.
