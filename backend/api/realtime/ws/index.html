The WebSocket leg: universally reachable, and the fallback whenever the WebTransport endpoint is unconfigured or unreachable.

Two things this leg must do that the WebTransport one gets from QUIC: cap what a peer can make the server buffer (frame and message size), and prove the peer is still there (a server-driven ping, answered by every WebSocket stack). Both are wired here; the reaping policy itself lives in hub::run_session.
