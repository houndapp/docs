Run task for the process’s lifetime, restarting it whenever it returns or panics.

These tasks are not supposed to end: the accept loop returning means no client will ever get a WebTransport session again, on a process that answers HTTP perfectly well and so passes every health check. Backoff doubles from MIN_RESTART_BACKOFF to MAX_RESTART_BACKOFF so a persistently failing dependency is not hammered, and backend_realtime_wt_restarts_total is the series to alert on — a healthy process never increments it.
