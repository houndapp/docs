pub(crate) fn order_spaces(query: Select<Entity>) -> Select<Entity>
Expand description

The canonical channel-list order: text channels before voice ones, then by name case-insensitively. Applied wherever spaces are listed so every surface shows the same sidebar.

kind sorts correctly on both backends without a CASE: the Postgres enum is declared text, voice and SQLite stores the same two strings, which sort alphabetically the same way.
