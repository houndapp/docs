Reads a channel’s permission overwrites — the round-trip half of the PUT.

ManageChannels, like the write: an ACL names the roles and users a channel treats specially, which is moderator-visible information rather than member-visible.

user_overwrites is filtered to current members. The write refuses a stranger and departure deletes the leaver’s rows, so a row that survives both is one written before either guard existed — it must not reach an editor that would then send it straight back.
