Module cursor

Expand description

The opaque page cursor.

A keyset, not an offset: it names the last row of the page just served, and the next page is everything strictly “after” it in the active sort order. That is what makes paging stable while messages are still being posted — an offset would re-serve or skip a row every time the table grows under it.

The encoding (base64url of a JSON object) is private to the backend. Clients round-trip the string and never build or read one, so the shape can change without a client release: v is what an older cursor is recognised and rejected by.
