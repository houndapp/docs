HTML → raw metadata. Parsing only: nothing here decides what an embed says, which is super::build’s job.

§Why document order, not a map

Open Graph’s structured properties (og:image:width, og:image:alt, …) attach to the most recently declared parent property, so a page with three images is three og:image tags each followed by its own dimensions. Folding those into a HashMap — the obvious first implementation — silently keeps one image and staples the last width onto it. So the tags come out of here as an ordered list and stay that way until the builder walks it.

§Charset

Decoded through encoding_rs with the label from the Content-Type header, falling back to a <meta charset> sniff over the head of the document and then to UTF-8. Real pages are still served as windows-1252, and reading one as UTF-8 turns every curly quote in a title into a replacement character.
