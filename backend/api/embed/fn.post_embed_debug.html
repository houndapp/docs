Unfurl one URL and report everything the pipeline saw.

Backs the embed debugger in the client’s developer settings. Available to any signed-in user, deliberately: posting a message already makes this service fetch a URL of your choosing, so the debugger grants no capability that sending a message does not — it only shows you what happened.

What it does add is an uncached fetch, so it is rate limited per user.
