Fetch and decode the discovered oEmbed endpoint.

Guarded exactly like the page fetch — the endpoint URL comes out of the same untrusted markup, so it gets no more trust than the page did. A failure here is a warning, never the end of the unfurl: Open Graph alone usually carries enough for a card.
