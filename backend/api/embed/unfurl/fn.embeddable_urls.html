pub(crate) fn embeddable_urls(links: &[String]) -> Vec<Url>
Expand description

The URLs worth unfurling, out of a message’s links: the first [MAX_MESSAGE_EMBEDS] that parse, in document order.

links is [hound_markup::ParsedMessage::links] — derived from the parsed AST rather than by scanning prose, which is what makes labelled link ([label](https://…)) and image syntax unfurl exactly as a bare autolink does (both render as literal text, but their destination is still an Inline::Link), while a URL inside a code span or fenced block does not (code is verbatim, never markup). hound: references are a distinct AST node ([hound_markup::ast::Inline::Reference]) and never appear here at all.
