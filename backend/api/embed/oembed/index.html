The oEmbed 1.0 response, as far as this service reads it.

oEmbed is the only one of the three vocabularies that is a negotiated document rather than tags on a page: the page advertises an endpoint, and the endpoint answers JSON about that specific URL. That makes it the most authoritative source for provider and author attribution — the page’s own og:site_name is whatever the publisher typed, while provider_name comes from the service itself.

Two fields are deliberately read but never promoted into a LinkEmbed:

  • html — an iframe player. Captured for the debugger so an operator can see what a site offers, and dropped everywhere else. This client renders no remote markup.
  • version — checked loosely: a 2.0 that still carries 1.0’s field names is more useful than a refusal.
