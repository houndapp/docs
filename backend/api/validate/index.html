Bounds on the free text this API stores.

Every such field is the same rule twice over — trim it, then hold it to a character count — and the only thing that varies is which error names the field. Lengths are counted in characters, not bytes: the bound exists so a name fits a sidebar row, and a byte bound would cut a CJK or emoji name short of the same visible length.

bounded for optional free text. Absent and whitespace-only are the same answer — “unset” — so there is no empty case to name: a blank string is never stored.
