1//! # Receiver-side downlink demand
2//!
3//! Complements [`crate::layer::tile_quality_request`] (rendered-tile-size demand)
4//! with the BANDWIDTH half of demand-driven simulcast: when *this* receiver's
5//! downlink can't keep up with a video track, ask the producer for the low layer.
6//! The two demands are folded with [`crate::layer::most_constrained`] by the
7//! caller — this module only decides the bandwidth half.
8//!
9//! ## Signal: frame-sequence gaps, not the sender's own bitrate
10//!
11//! Each wire frame ([`crate::fragment::Frame`]) carries a per-track `frame_seq`.
12//! A gap in the sequence a receiver observes means frames were lost **between the
13//! sender and this receiver** — unlike a raw delivered-bytes rate, it is not
14//! confounded by the sender's own encoder adapting its bitrate (which changes how
15//! BIG frames are, not how many of them arrive). [`FrameSeqWindow`] folds arrivals
16//! into a windowed `(received, expected)` count; [`DownlinkDemand`] turns that
17//! ratio into a [`QualityRequest`](crate::congestion::QualityRequest).
18//!
19//! ## Thresholds: retuned after a cratering regression
20//!
21//! An earlier receive-side decider (`DownlinkEstimator`/`QualityRequestDecider`,
22//! removed as dead code — see commit history) capped a receiver at 0.85× the
23//! source bitrate. That turned a MINOR dip into a resolution cliff: a healthy 1:1
24//! 720p call would crater to 360p on a transient wobble, because 0.85 is barely
25//! below "normal" jitter in the estimate. This decider caps only a **genuinely
26//! poor** link:
27//!
28//! * drop to [`QualityRequest::Capped`] once delivery falls below **1/4** of source
29//! * restore [`QualityRequest::Source`] only once delivery climbs back above **1/2**
30//!   of source
31//!
32//! The wide `[1/4, 1/2]` band is deliberate anti-flap hysteresis — a link
33//! wobbling anywhere in that band (including the specific case of ~76% delivery,
34//! which the OLD 0.85 threshold would have capped) holds its current demand. Note
35//! also: with a single receiver, the *sender's own* loss-based AIMD
36//! ([`crate::congestion::RateController`], driven by `MediaFeedback` reports)
37//! already right-sizes the one stream it's publishing — this decider only earns
38//! its keep once a call has enough heterogeneous receivers that no single
39//! sender-side rate can serve everyone (see the module docs on the call site for
40//! how demand is gated).
41//!
42//! Sans-IO: time enters only as an explicit `now_us` argument (mirrors
43//! [`crate::congestion::RateController`] / [`crate::send_budget::SendBudget`]);
44//! no clock reads, no I/O.
45
46use crate::congestion::QualityRequest;

48/// Is `a` newer than `b` in a wrapping 32-bit sequence space (RFC 1982 serial
49/// comparison). A local copy of `crate::recovery`'s helper — this module has no
50/// dependency on `recovery` and the comparison is one line.
51fn seq_newer(a: u32, b: u32) -> bool {
52    a != b && a.wrapping_sub(b) < u32::MAX / 2
53}
54
55/// Bound on a single observed `frame_seq` gap. A restart (a fresh producer's
56/// `frame_seq` starts back at 0) or a corrupt/wild value must not be misread as
57/// millions of lost frames — far above any gap a live call could produce (a
58/// stalled pipeline is reaped and re-subscribed long before `frame_seq` could
59/// legitimately jump this far).
60const MAX_FRAME_GAP: u32 = 10_000;
61
62/// Per-track receive-completeness tracker: folds each arriving frame's wire
63/// `frame_seq` into a windowed `(received, expected)` count. One instance per
64/// subscribed video track — a fresh instance per subscription, so a resubscribe
65/// (a new producer's independent `frame_seq` space) starts clean.
66#[derive(Debug, Clone, Copy)]
67pub struct FrameSeqWindow {
68    /// How many wire `frame_seq` steps one EXPECTED arrival spans on this
69    /// subscription. `1` for an ordinary track; `2` for a relay-derived
70    /// base-layer-only (`_t0`) track — see [`FrameSeqWindow::with_stride`].
71    stride: u32,
72    last_seq: Option<u32>,
73    received: u32,
74    expected: u32,
75    /// Same counts, never drained by [`Self::take`] — the running totals a
76    /// cumulative receiver-loss gauge is derived from (see [`Self::lost_estimate`]).
77    received_total: u64,
78    expected_total: u64,
79}
80
81impl Default for FrameSeqWindow {
82    fn default() -> Self {
83        Self::with_stride(1)
84    }
85}
86
87impl FrameSeqWindow {
88    pub fn new() -> Self {
89        Self::default()
90    }
91
92    /// A window over a subscription whose wire `frame_seq` advances by `stride`
93    /// per expected arrival.
94    ///
95    /// ## Why this exists: intentional thinning is not loss
96    ///
97    /// The producer stamps `frame_seq` once per ENCODED frame and the relay
98    /// forwards it untouched (never rewriting it is the mediasoup lesson —
99    /// rewriting corrupts the dependency structure). So a receiver subscribed to
100    /// a relay-derived base-layer-only track sees `0, 2, 4, 6, …`: half the
101    /// sequence space is missing **by construction**, because the relay filtered
102    /// out every `TemporalLayer::Enhanced` object.
103    ///
104    /// Read at `stride = 1` that is 50% packet loss, sustained forever. The
105    /// receiver would cap itself to the low layer within one evaluation window,
106    /// the total-budget controller would read every `_t0` tile as DEFICIENT and
107    /// shed 15% per second, and the feature would present as a link collapse.
108    ///
109    /// With the stride, a gap of `delta` wire steps counts as
110    /// `delta.div_ceil(stride)` expected arrivals — the FEWEST base frames that
111    /// gap could contain. `div_ceil` rather than plain division so the estimate
112    /// leans toward "not loss": an odd delta (the encoder dropped a frame outright
113    /// at the fps gate, or an IDR restarted the TL0/TL1 alternation) rounds up by
114    /// at most one rather than manufacturing loss out of a pattern change. Real
115    /// loss still shows: losing a base frame doubles the delta, which the ceiling
116    /// reports in full.
117    pub fn with_stride(stride: u32) -> Self {
118        Self {
119            stride: stride.max(1),
120            last_seq: None,
121            received: 0,
122            expected: 0,
123            received_total: 0,
124            expected_total: 0,
125        }
126    }
127
128    /// Record one arrived frame's wire `frame_seq`. A frame OLDER than the last
129    /// seen (reorder or duplicate) still counts toward `received` but does not
130    /// move the continuity baseline — it was already folded into an earlier gap,
131    /// so re-counting it as "expected" again would double-count.
132    pub fn observe(&mut self, seq: u32) {
133        self.received = self.received.saturating_add(1);
134        self.received_total = self.received_total.saturating_add(1);
135        let advance = match self.last_seq {
136            None => {
137                self.last_seq = Some(seq);
138                1
139            }
140            Some(last) if seq_newer(seq, last) => {
141                self.last_seq = Some(seq);
142                // Bound the RAW distance first (a producer restart must stay
143                // bounded whatever the stride), then convert it to expected
144                // arrivals. `max(1)` because a newer seq is always at least one
145                // arrival, even on a stride that would round it to zero.
146                let raw = seq.wrapping_sub(last).min(MAX_FRAME_GAP);
147                raw.div_ceil(self.stride).max(1)
148            }
149            Some(_) => 0, // reorder/duplicate: already accounted for
150        };
151        self.expected = self.expected.saturating_add(advance);
152        self.expected_total = self.expected_total.saturating_add(advance as u64);
153    }
154
155    /// Drain the window's `(received, expected)` counts and reset them. The
156    /// continuity baseline (`last_seq`) is NOT reset — a gap spanning a window
157    /// boundary is still detected correctly on the next `observe`.
158    pub fn take(&mut self) -> (u32, u32) {
159        let out = (self.received, self.expected);
160        self.received = 0;
161        self.expected = 0;
162        out
163    }
164
165    /// The CURRENT (undrained) window's shortfall: how many of the frames the
166    /// sequence space said to expect have not arrived yet. Non-destructive, so it
167    /// never disturbs the decider's window boundary.
168    pub fn window_deficit(&self) -> u32 {
169        self.expected.saturating_sub(self.received)
170    }
171
172    /// Frames lost between the sender and here since construction/[`Self::reset`] —
173    /// the running totals' shortfall, which is what a cumulative receiver-loss gauge
174    /// wants (the per-window deficit sawtooths to zero every evaluation).
175    ///
176    /// A gap is only revealed by the arrival AFTER it, so a frame still in flight
177    /// counts as lost until it lands; a reordered arrival then takes it back off the
178    /// total. Hence an *estimate*: it tracks reality within one reorder window
179    /// rather than being monotonic.
180    pub fn lost_estimate(&self) -> u64 {
181        self.expected_total.saturating_sub(self.received_total)
182    }
183
184    /// Forget everything, including the continuity baseline. Call when the
185    /// underlying subscription restarts and a fresh instance isn't already being
186    /// used (the normal case is a fresh [`FrameSeqWindow`] per subscription; this
187    /// exists for callers that reuse one instance across restarts).
188    ///
189    /// The stride survives: it is a property of the SUBSCRIPTION, not of the
190    /// stream's history, and a restart re-subscribes to the same track.
191    pub fn reset(&mut self) {
192        *self = Self::with_stride(self.stride);
193    }
194}

196/// Tunables for [`DownlinkDemand`].
197#[derive(Debug, Clone, Copy)]
198pub struct DownlinkConfig {
199    /// How often the windowed `(received, expected)` count is turned into a
200    /// decision. 1 s mirrors the cadence of the other adaptation loops in this
201    /// crate ([`crate::congestion::RateConfig::increase_interval_us`] default,
202    /// the sender's 1 s adaptation tick).
203    pub eval_interval_us: i64,
204    /// Wire `frame_seq` steps per EXPECTED arrival on this subscription — see
205    /// [`FrameSeqWindow::with_stride`]. `1` for an ordinary track;
206    /// [`TEMPORAL_BASE_STRIDE`] for a relay-derived `_t0` track, whose sequence
207    /// space is half empty by construction.
208    pub expected_seq_stride: u32,
209}
210
211/// The `frame_seq` stride of a relay-derived base-layer-only (`_t0`) subscription:
212/// **2**, because the encoder's `BaseLayerFrameRateFraction` is 0.5 — every other
213/// encoded frame is TL0, so every other wire sequence number reaches a `_t0`
214/// subscriber. Named here rather than spelled `2` at the call site so it moves
215/// with the encoder's split if that ever changes.
216pub const TEMPORAL_BASE_STRIDE: u32 = 2;
217
218impl Default for DownlinkConfig {
219    fn default() -> Self {
220        Self {
221            eval_interval_us: 1_000_000,
222            expected_seq_stride: 1,
223        }
224    }
225}
226
227/// A `Capped` request never asks for less than this — mirrors
228/// [`crate::congestion::RateConfig`]'s default `min_bps` floor, so a genuinely
229/// terrible link still asks for a minimally-useful low layer instead of
230/// degenerating toward zero.
231const MIN_CAP_BPS: u64 = 100_000;
232
233/// A new `Capped` value while already capped is only re-emitted (and the demand
234/// updated) once it has moved at least this much relative to the standing value —
235/// otherwise ordinary window-to-window wobble in a poor-but-stable link would spam
236/// the producer with a new cap every eval tick.
237const CAP_CHATTER_NUM: u64 = 1;
238const CAP_CHATTER_DEN: u64 = 10;
239
240/// The receiver's bandwidth-driven demand for one subscribed video track. Folds
241/// arriving frames' `frame_seq` into a [`FrameSeqWindow`] and, once per
242/// [`DownlinkConfig::eval_interval_us`], turns the window's delivery ratio into a
243/// [`QualityRequest`] with the `[source/4, source/2]` hysteresis band described in
244/// the module docs. Windows are evaluated by whichever of [`Self::observe_frame`]
245/// (a frame arrived) or [`Self::on_tick`] (time passed, possibly with no frames at
246/// all) crosses the due time first. Pure/sans-IO — both take `now_us` and
247/// `source_bps` explicitly.
248#[derive(Debug)]
249pub struct DownlinkDemand {
250    cfg: DownlinkConfig,
251    window: FrameSeqWindow,
252    next_eval_us: Option<i64>,
253    current: QualityRequest,
254}
255
256impl DownlinkDemand {
257    /// A fresh decider, optimistic (assumes it can take the source until its
258    /// window proves otherwise) — the same "prove impairment before asking for
259    /// less" default as the tile-demand half and the deleted decider it replaces.
260    pub fn new(cfg: DownlinkConfig) -> Self {
261        Self {
262            window: FrameSeqWindow::with_stride(cfg.expected_seq_stride),
263            cfg,
264            next_eval_us: None,
265            current: QualityRequest::Source,
266        }
267    }
268
269    /// Record one arrived frame's wire `frame_seq` at local time `now_us`, against
270    /// the track's current `source_bps` (the top-rung bitrate the producer
271    /// encodes at — a fixed per-source constant in this codebase, mirroring what
272    /// the producer's own [`crate::congestion::SimulcastPlanner`] assumes). Folds
273    /// the frame into the current window; once [`DownlinkConfig::eval_interval_us`]
274    /// has elapsed since the last evaluation, turns the window into a (possibly
275    /// unchanged) decision. Always returns the standing demand — a faithful
276    /// projection of the last decision, matching [`Self::current`].
277    pub fn observe_frame(&mut self, seq: u32, now_us: i64, source_bps: u64) -> QualityRequest {
278        // Evaluate a DUE prior window BEFORE folding this frame in, so a window's
279        // last frame is still counted in the decision it triggers, and the frame
280        // that crosses the boundary correctly starts the next window instead of
281        // diluting the one it just closed.
282        match self.next_eval_us {
283            None => self.next_eval_us = Some(now_us + self.cfg.eval_interval_us),
284            Some(due) if now_us >= due => {
285                self.evaluate(source_bps);
286                self.next_eval_us = Some(now_us + self.cfg.eval_interval_us);
287            }
288            Some(_) => {}
289        }
290        self.window.observe(seq);
291        self.current
292    }
293
294    /// Advance the demand on a **time tick**, with no frame arrival.
295    ///
296    /// [`Self::observe_frame`] can only evaluate a window it was fed into, so a
297    /// downlink that degrades to *zero* delivery — the exact condition where this
298    /// receiver most needs to ask for the low layer — would otherwise never
299    /// evaluate at all and sit on the optimistic [`QualityRequest::Source`] default
300    /// forever. The caller drives this from its periodic reconcile/stall path;
301    /// calling it every tick alongside `observe_frame` is harmless (a window is
302    /// evaluated at most once, by whichever of the two crosses its due time).
303    pub fn on_tick(&mut self, now_us: i64, source_bps: u64) -> QualityRequest {
304        // `None` = no frame has ever arrived, so there is no window and no
305        // continuity baseline: nothing to decide (a subscription that has not
306        // started yet is not a starved one).
307        if let Some(due) = self.next_eval_us
308            && now_us >= due
309        {
310            self.evaluate(source_bps);
311            self.next_eval_us = Some(now_us + self.cfg.eval_interval_us);
312        }
313        self.current
314    }
315
316    /// Turn the current window into a decision and reset the window's counters
317    /// (not its continuity baseline).
318    fn evaluate(&mut self, source_bps: u64) {
319        let (received, expected) = self.window.take();
320        // An empty window on a stream that HAS delivered before is a starved link,
321        // not "no signal": ratio 0 so the state machine has a route from starved to
322        // `Capped`. Before the first-ever frame there is no baseline to compare
323        // against, so hold instead of manufacturing a decision from 0/0.
324        if expected == 0 && self.window.last_seq.is_none() {
325            return;
326        }
327        let ratio = if expected == 0 {
328            0.0
329        } else {
330            received as f64 / expected as f64
331        };
332        let estimate_bps =
333            ((ratio * source_bps as f64) as u64).clamp(MIN_CAP_BPS, source_bps.max(MIN_CAP_BPS));
334        let drop_below = source_bps / 4;
335        let restore_above = source_bps / 2;
336
337        self.current = match self.current {
338            QualityRequest::Source if estimate_bps < drop_below => {
339                QualityRequest::Capped(estimate_bps)
340            }
341            QualityRequest::Source => QualityRequest::Source,
342            QualityRequest::Capped(_) if estimate_bps >= restore_above => QualityRequest::Source,
343            QualityRequest::Capped(prev) => {
344                // Same layer, but only re-emit a moved cap on a MEANINGFUL move —
345                // otherwise ordinary wobble on a stable poor link re-sends the
346                // request every eval tick for no operational benefit.
347                let moved = prev.abs_diff(estimate_bps) * CAP_CHATTER_DEN > prev * CAP_CHATTER_NUM;
348                if moved {
349                    QualityRequest::Capped(estimate_bps)
350                } else {
351                    QualityRequest::Capped(prev)
352                }
353            }
354            // Visibility is not a bandwidth question, and this decider never sees
355            // one: `Hidden` is produced by the TILE half of the demand and folded in
356            // afterwards by `most_constrained`, which is where it wins. Unreachable
357            // in practice — held rather than invented, so a future caller that does
358            // seed one cannot have it silently rewritten into a rendered demand.
359            QualityRequest::Hidden(bps) => QualityRequest::Hidden(bps),
360        };
361    }
362
363    /// The demand from the last [`Self::observe_frame`] / [`Self::on_tick`]
364    /// evaluation — a faithful projection, never recomputed.
365    pub fn current(&self) -> QualityRequest {
366        self.current
367    }
368
369    /// Frames lost on the downlink since this decider was created — see
370    /// [`FrameSeqWindow::lost_estimate`]. Independent of the window boundary, so a
371    /// caller can report it per arrival without perturbing the decision.
372    pub fn lost_estimate(&self) -> u64 {
373        self.window.lost_estimate()
374    }
375
376    /// The current (undrained) window's shortfall — see
377    /// [`FrameSeqWindow::window_deficit`].
378    pub fn window_deficit(&self) -> u32 {
379        self.window.window_deficit()
380    }
381
382    /// Reset to the optimistic default and forget all window/continuity state.
383    /// The normal way a restart is handled is a fresh [`DownlinkDemand`] per
384    /// subscription (see the call site); this is for a caller that reuses one
385    /// instance across restarts instead.
386    pub fn reset(&mut self) {
387        self.window.reset();
388        self.next_eval_us = None;
389        self.current = QualityRequest::Source;
390    }
391}

397    const SRC: u64 = 4_000_000; // a 4 Mbps "source" for these cases
398    const STEP_US: i64 = 1_000; // 1 ms between frames within a window
399    const TICK_US: i64 = 1_000_000; // the default eval interval
400
401    /// Feed `n` frames, in-sequence, into `dd`, dropping frames so that
402    /// EXACTLY `keep_num/keep_den` of them are delivered (a Bresenham-style
403    /// deterministic spread, not a run of drops at the start/end), all tightly
404    /// spaced (well under one eval interval). Then jumps `now_us` a full
405    /// [`TICK_US`] forward and feeds one more (always-kept) frame to CLOSE that
406    /// window — `observe_frame` evaluates a due window before folding the frame
407    /// that crossed the boundary, so this returns exactly the just-fed window's
408    /// decision, and the closing frame cleanly starts the next window. `seq` and
409    /// `now_us` both advance monotonically across calls, so repeated calls model
410    /// consecutive windows.
411    fn feed_ratio(
412        dd: &mut DownlinkDemand,
413        seq: &mut u32,
414        now_us: &mut i64,
415        n: u32,
416        keep_num: u32,
417        keep_den: u32,
418        source_bps: u64,
419    ) -> QualityRequest {
420        let mut acc = 0u32;
421        for _ in 0..n {
422            acc += keep_num;
423            let keep = acc >= keep_den;
424            if keep {
425                acc -= keep_den;
426                dd.observe_frame(*seq, *now_us, source_bps);
427            }
428            *seq = seq.wrapping_add(1);
429            *now_us += STEP_US;
430        }
431        *now_us += TICK_US;
432        let decision = dd.observe_frame(*seq, *now_us, source_bps);
433        *seq = seq.wrapping_add(1);
434        decision
435    }

437    /// A clean link (every frame arrives) holds `Source` — the zero-cost common
438    /// case, byte-identical demand to "no bandwidth impairment".
439    #[test]
440    fn clean_link_holds_source() {
441        let mut dd = DownlinkDemand::new(DownlinkConfig::default());
442        let (mut seq, mut now) = (0u32, 0i64);
443        // Several full windows, no drops.
444        for _ in 0..5 {
445            let req = feed_ratio(&mut dd, &mut seq, &mut now, 100, 1, 1, SRC);
446            assert_eq!(req, QualityRequest::Source);
447        }
448        assert_eq!(dd.current(), QualityRequest::Source);
449    }

492    /// restore `Source` — recovering only to source/4..source/2 (the dead band)

496        let mut dd = DownlinkDemand::new(DownlinkConfig::default());

500        assert!(matches!(req, QualityRequest::Capped(_)));
501

503        let req = feed_ratio(&mut dd, &mut seq, &mut now, 100, 35, 100, SRC);
504        assert!(
505            matches!(req, QualityRequest::Capped(_)),
506            "35% is inside the dead band — must not restore Source yet: {req:?}"
507        );

509        // Recover to 60% — clears source/2: restores Source.
510        let req = feed_ratio(&mut dd, &mut seq, &mut now, 100, 60, 100, SRC);
511        assert_eq!(req, QualityRequest::Source, "60% clears the restore floor");
512    }

517    /// debounce (the caller's `LayerHysteresis` covers residual track-switch

532                matches!(req, QualityRequest::Capped(_)),
533                "window {i} at {pct}% must not flap to Source: {req:?}"

535        }

538    /// A `frame_seq` wraparound (u32::MAX -> 0) is a normal, contiguous
539    /// continuation — must NOT read as a catastrophic gap.

863    /// The stride's rounding leans AWAY from manufacturing loss, and its bounds
864    /// hold: an odd delta (an fps-gate drop, or an IDR restarting the TL0/TL1
865    /// alternation) rounds up by at most one, a newer sequence always counts as
866    /// at least one arrival, and a producer restart stays bounded.
867    #[test]
868    fn the_stride_rounds_conservatively_and_stays_bounded() {
869        let mut w = FrameSeqWindow::with_stride(2);
870        // 0, 2, 4 — the clean pattern: three arrivals, three expected.
871        for s in [0u32, 2, 4] {
872            w.observe(s);
873        }
874        assert_eq!(w.take(), (3, 3));
875
876        // An ODD step (delta 3) is one arrival's worth of gap rounded up to two —
877        // never three, which is what plain wire-distance counting would book.
878        let mut w = FrameSeqWindow::with_stride(2);
879        w.observe(0);
880        w.observe(3);
881        let (received, expected) = w.take();
882        assert_eq!(
883            (received, expected),
884            (2, 3),
885            "delta 3 ⇒ ceil(3/2) = 2 expected"
886        );
887
888        // Two ADJACENT base frames (delta 1, the post-IDR restart) are not loss.
889        let mut w = FrameSeqWindow::with_stride(2);
890        w.observe(10);
891        w.observe(11);
892        assert_eq!(w.take(), (2, 2));
893
894        // A producer restart is bounded by the same per-gap cap, stride or not.
895        let mut w = FrameSeqWindow::with_stride(2);
896        w.observe(0);
897        w.observe(5_000_000);
898        assert!(w.lost_estimate() <= MAX_FRAME_GAP as u64);
899
900        // A stride of 0 is nonsense and is clamped, not a divide-by-zero.
901        let mut w = FrameSeqWindow::with_stride(0);
902        w.observe(0);
903        w.observe(1);
904        assert_eq!(w.take(), (2, 2));
905    }
