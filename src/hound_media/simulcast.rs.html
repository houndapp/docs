1//! # Demand-driven simulcast planning (sender side)
2//!
3//! Aggregates every receiver's [`QualityRequest`] into the sender's
4//! [`LayerPlan`]: publish the source while anyone can take it, plus at most ONE
5//! shared low layer sized for the most-constrained renderer. [`plan_layers`] is
6//! the pure fold; [`SimulcastPlanner`] tracks the standing per-peer requests and
7//! reports plan *changes* so a steady call costs nothing.
8
9use crate::quality::QualityRequest;
10
11/// What a sender should publish for a video track given ALL its receivers' requests
12/// ([`plan_layers`]). At most two streams: the source and one shared low layer.
13#[derive(Debug, Clone, Copy, PartialEq, Eq)]
14pub struct LayerPlan {
15    /// Encode + publish the source/top layer (at least one receiver can take it).
16    pub send_source: bool,
17    /// `Some(bps)` → also (or *only*, if `!send_source`) publish ONE shared low layer
18    /// sized for the most-constrained requester (so every requester can decode it).
19    /// `None` → no low layer demanded.
20    pub low_layer_bps: Option<u64>,
21}
22
23impl LayerPlan {
24    /// The zero-cost default: encode only the source, no low layer. Byte-identical
25    /// to a build without simulcast — the plan a sender acts on whenever no receiver
26    /// has asked for less, and the safe plan the planner publishes while actuation is
27    /// disabled (see [`SimulcastPlanner`]).
28    pub const SOURCE_ONLY: LayerPlan = LayerPlan {
29        send_source: true,
30        low_layer_bps: None,
31    };
32}
33
34/// Aggregate every receiver's [`QualityRequest`] into the sender's [`LayerPlan`].
35///
36/// The whole demand-driven, coalesced, source-droppable policy in one pure function:
37/// * a receiver wanting `Source` (or a cap ≥ source — it can only ask for *lower*)
38///   keeps the source alive;
39/// * receivers wanting less than source collapse to ONE shared low layer at the
40///   **minimum** of their caps, so the weakest can still decode it (bounded to two
41///   total streams — no per-receiver explosion);
42/// * a [`QualityRequest::Hidden`] receiver keeps the low layer alive but is
43///   **excluded from that minimum** while anyone is actually rendering. A tile
44///   nobody is looking at must not decide the geometry everyone else watches;
45///
46/// ## The accepted cost: a fully-hidden receiver set still pins the layer
47///
48/// `min_cap.or(min_hidden)` means a producer whose every receiver is hidden keeps
49/// encoding and publishing a thumbnail rung **nobody is subscribed to** — since
50/// off-screen tiles unsubscribe outright, that is a real, if small (~130 kbps plus
51/// one downscale+encode), waste. It is deliberate, and it buys the thing the
52/// off-screen policy is sold on: the `_l0` decl stays in the roster, so a tile
53/// scrolling back into view is a subscribe on an already-live layer rather than a
54/// wait on a producer spinning an encoder up (the receiver-side equivalent of
55/// Octo's "forward every layer so a switch is instant"). Tearing the layer down at
56/// zero *visible* receivers would trade an unhide's latency for that 130 kbps, and
57/// the latency is what users feel.
58///
59/// [`crate::allocate`] has since landed, and it resolves the half of this that was
60/// always the receiver's: a receiver now knows what its whole tile set costs, so an
61/// off-screen tile is a *priced* decision (`Hidden` costs zero against the budget,
62/// and the budget it frees is spent on the tiles that are on screen) rather than a
63/// guess. What it does NOT resolve is the producer half above — this fold is still
64/// what a sender does with a fully-hidden receiver set, and a producer cannot see
65/// any receiver's budget. The ~130 kbps of pinned layer stays exactly as it is.
66///
67/// * if NO receiver can take the source, `send_source` is `false` and only the low
68///   layer is published — the optimisation that stops encoding a stream nobody wants.
69///
70/// ## The cap is a cross-receiver MINIMUM
71///
72/// Among receivers that *are* rendering, this is still one shared layer sized to
73/// the most-constrained of them: a peer showing a 180p thumbnail and a peer showing
74/// a 360p tile both get 180p. That is inherent to publishing one low layer rather
75/// than one per receiver, and excluding hidden tiles (above) only removes the
76/// pathological case.
77///
78/// [`crate::allocate`] resolves the half of this that was mis-stated as a producer
79/// problem. "Each track independently picking a rung" is gone: a receiver now ranks
80/// its whole tile set and hands out rungs against one total bitrate (and decode)
81/// budget, so it can no longer ask for more, in aggregate, than it can take — which
82/// is what actually collapsed a large call.
83///
84/// The coalescing itself is **unchanged and remains**. This fold is still a
85/// cross-receiver minimum, so a receiver whose allocator bought it the 360p rung
86/// still watches 180p if any other rendering receiver is on the thumbnail — and a
87/// receiver pinned to a rung it did not want still costs its producer that encode.
88/// Fixing *that* means publishing more than one low layer (per-receiver rungs, or a
89/// third simulcast track), which is a producer-side cost decision this function is
90/// deliberately not making. The allocator bounds what any one receiver asks for; it
91/// does not, and cannot, decide what a sender publishes.
92///
93/// With no receivers the source stays on (idle default; nothing to optimise yet).
94/// Pure/sans-IO → unit-tested below.
95pub fn plan_layers(requests: &[QualityRequest], source_bps: u64) -> LayerPlan {
96    let mut send_source = requests.is_empty();
97    let mut min_cap: Option<u64> = None;
98    let mut min_hidden: Option<u64> = None;
99    for req in requests {
100        match *req {
101            // "Only lower than what's being sent": a cap at/above source means this
102            // receiver can take the source itself.
103            QualityRequest::Source => send_source = true,
104            QualityRequest::Capped(bps) if bps >= source_bps => send_source = true,
105            QualityRequest::Capped(bps) => {
106                min_cap = Some(min_cap.map_or(bps, |m| m.min(bps)));
107            }
108            // Kept out of `min_cap` entirely: it may only decide the layer when it
109            // is the ONLY kind of requester left.
110            QualityRequest::Hidden(bps) => {
111                min_hidden = Some(min_hidden.map_or(bps, |m| m.min(bps)));
112            }
113        }
114    }
115    LayerPlan {
116        send_source,
117        low_layer_bps: min_cap.or(min_hidden),
118    }
119}

121/// Producer-side aggregator: tracks each receiver's standing [`QualityRequest`] for
122/// one published video track and yields the current [`LayerPlan`] via [`plan_layers`].
123///
124/// The sender feeds it every `QualityRequested` (peer → cap) and every peer-leave,
125/// and acts on the returned plan only when it *changes* — so a steady call costs
126/// nothing and a flapping receiver (already damped by its own send-side hysteresis)
127/// can at most toggle one layer. Peers are keyed by a plain `u32` (the session passes
128/// `PeerId.0`) so this core stays free of the control-plane types. Pure/sans-IO.
129#[derive(Debug)]
130pub struct SimulcastPlanner {
131    source_bps: u64,
132    /// Per-receiver standing request. A peer absent here has not asked for anything
133    /// → it is assumed to take the source (the default before any request arrives).
134    caps: std::collections::BTreeMap<u32, QualityRequest>,
135    /// The plan the current requests imply — what the sender publishes: a shared low
136    /// layer when a receiver asks for a below-source rung, source-only otherwise.
137    /// Recomputed on every request/roster change and acted on when it changes.
138    plan: LayerPlan,
139}
140
141impl SimulcastPlanner {
142    /// Start with the given source bitrate and no receiver requests (plan = source
143    /// only — the zero-cost common case).
144    pub fn new(source_bps: u64) -> Self {
145        Self {
146            source_bps,
147            caps: std::collections::BTreeMap::new(),
148            plan: plan_layers(&[], source_bps),
149        }
150    }
151
152    fn recompute(&mut self) -> bool {
153        let reqs: Vec<QualityRequest> = self.caps.values().copied().collect();
154        let next = plan_layers(&reqs, self.source_bps);
155        let changed = next != self.plan;
156        self.plan = next;
157        changed
158    }
159
160    /// Record a receiver's standing request; returns `true` if the resulting plan
161    /// changed (the sender re-publishes the low-layer target).
162    pub fn set_request(&mut self, peer: u32, req: QualityRequest) -> bool {
163        if self.caps.get(&peer) == Some(&req) {
164            return false;
165        }
166        self.caps.insert(peer, req);
167        self.recompute()
168    }
169
170    /// Drop a receiver (it left or unsubscribed); returns `true` if the plan changed.
171    pub fn remove_peer(&mut self, peer: u32) -> bool {
172        if self.caps.remove(&peer).is_none() {
173            return false;
174        }
175        self.recompute()
176    }
177
178    /// Reconcile against the live roster: drop caps for any peer not in `keep` (a
179    /// receiver that left without retracting its request). Returns `true` if the plan
180    /// changed. `keep` membership is tested via the closure so the caller needn't
181    /// allocate a set.
182    pub fn retain_peers(&mut self, keep: impl Fn(u32) -> bool) -> bool {
183        let before = self.caps.len();
184        self.caps.retain(|&peer, _| keep(peer));
185        if self.caps.len() == before {
186            return false;
187        }
188        self.recompute()
189    }
190
191    /// Update the source bitrate (the source rung re-negotiated); returns `true` if
192    /// the plan changed (a cap that was below the old source may now be ≥ the new one).
193    pub fn set_source_bps(&mut self, source_bps: u64) -> bool {
194        if self.source_bps == source_bps {
195            return false;
196        }
197        self.source_bps = source_bps;
198        self.recompute()
199    }
200
201    /// The peer ids currently requesting a CAPPED (below-source) layer — the receivers
202    /// the shared low layer serves. The sender's feedback partitioner excludes these
203    /// from the SOURCE adaptation so a low-layer receiver can't drag the source down
204    /// (see the simulcast notes).
205    pub fn capped_peers(&self) -> std::collections::BTreeSet<u32> {
206        self.caps
207            .iter()
208            .filter_map(|(&p, req)| match req {
209                QualityRequest::Capped(bps) | QualityRequest::Hidden(bps)
210                    if *bps < self.source_bps =>
211                {
212                    Some(p)
213                }
214                _ => None,
215            })
216            .collect()
217    }
218
219    /// The plan the sender must act on: a shared low layer when a receiver requests a
220    /// below-source rung, [`LayerPlan::SOURCE_ONLY`] otherwise. Safe because the source
221    /// encode is never dropped — the low layer is purely additive, so a constrained
222    /// receiver switches its own subscription to the low track without starving anyone.
223    pub fn plan(&self) -> LayerPlan {
224        self.plan
225    }
226}

235    const SRC: u64 = 4_000_000; // a 4 Mbps "source" for these cases
236
237    /// Everyone can take the source → publish source only, no low layer (the common
238    /// case; zero extra encode cost).
239    #[test]
240    fn plan_all_source_publishes_source_only() {
241        let plan = plan_layers(&[QualityRequest::Source, QualityRequest::Source], SRC);
242        assert_eq!(
243            plan,
244            LayerPlan {
245                send_source: true,
246                low_layer_bps: None
247            }
248        );
249        // No receivers at all → keep the source on (idle default).
250        assert!(plan_layers(&[], SRC).send_source);
251        assert_eq!(plan_layers(&[], SRC).low_layer_bps, None);
252    }
253
254    /// `capped_peers` reports exactly the peers on the low layer (Capped below source) —
255    /// the set the sender excludes from the source adaptation (feedback partitioning).
256    /// A peer on source, or one whose cap is ≥ source (treated as source), is excluded.
257    #[test]
258    fn simulcast_planner_reports_capped_peers() {
259        let mut p = SimulcastPlanner::new(SRC);
260        p.set_request(1, QualityRequest::Source);
261        p.set_request(2, QualityRequest::Capped(SRC / 4)); // genuinely low → on low layer
262        p.set_request(3, QualityRequest::Capped(SRC * 2)); // ≥ source → treated as source
263        let capped: Vec<u32> = p.capped_peers().into_iter().collect();
264        assert_eq!(
265            capped,
266            vec![2],
267            "only the below-source capped peer is on the low layer"
268        );
269        // A peer that leaves drops out of the set.
270        p.remove_peer(2);
271        assert!(p.capped_peers().is_empty());
272    }
273
274    /// Mixed: someone takes source, others are constrained → source + ONE shared low
275    /// at the MINIMUM cap (so the weakest requester can still decode it).
276    /// B2: a tile nobody is looking at must not decide the geometry everyone else
277    /// watches. The hidden receiver still gets a layer — falling back to SOURCE for
278    /// it would be far worse — it just does not participate in the minimum.
279    #[test]
280    fn a_hidden_receiver_never_drags_the_shared_low_layer_down() {
281        // One visible 360p tile, one hidden thumbnail: the shared layer stays 360p.
282        let plan = plan_layers(
283            &[
284                QualityRequest::Capped(420_000),
285                QualityRequest::Hidden(130_000),
286            ],
287            SRC,
288        );
289        assert_eq!(
290            plan.low_layer_bps,
291            Some(420_000),
292            "the hidden 130 kbps request must be excluded from the fold"
293        );
294        // Two visible tiles still coalesce to the weakest of THEM.
295        assert_eq!(
296            plan_layers(
297                &[
298                    QualityRequest::Capped(420_000),
299                    QualityRequest::Capped(130_000),
300                    QualityRequest::Hidden(130_000),
301                ],
302                SRC
303            )
304            .low_layer_bps,
305            Some(130_000)
306        );
307        // Everyone hidden: the layer must still exist, at the hidden floor. Without
308        // this the receivers' `pick` falls back to the SOURCE track — the exact
309        // join-transient failure the low rung exists to prevent.
310        let plan = plan_layers(
311            &[
312                QualityRequest::Hidden(130_000),
313                QualityRequest::Hidden(420_000),
314            ],
315            SRC,
316        );
317        assert_eq!(plan.low_layer_bps, Some(130_000));
318        assert!(!plan.send_source, "nobody is asking for the source");
319    }

397    /// The stateful planner only reports a change when the aggregate plan actually
398    /// moves — a steady call is free, and peer churn updates the plan correctly.
399    #[test]
400    fn simulcast_planner_tracks_change_transitions() {
401        let mut p = SimulcastPlanner::new(SRC);
402        // No receivers → source only.
403        assert_eq!(
404            p.plan(),
405            LayerPlan {
406                send_source: true,
407                low_layer_bps: None
408            }
409        );
410
411        // Peer 1 takes source → no change (already source-only).
412        assert!(!p.set_request(1, QualityRequest::Source));
413        // Peer 2 is constrained → now source + a low layer (a real change).
414        assert!(p.set_request(2, QualityRequest::Capped(500_000)));
415        assert_eq!(
416            p.plan(),
417            LayerPlan {
418                send_source: true,
419                low_layer_bps: Some(500_000)
420            }
421        );
422        // Same request again → no change (idempotent).
423        assert!(!p.set_request(2, QualityRequest::Capped(500_000)));
424
425        // Peer 1 (the only source consumer) leaves → source dropped, low only.
426        assert!(p.remove_peer(1));
427        assert_eq!(
428            p.plan(),
429            LayerPlan {
430                send_source: false,
431                low_layer_bps: Some(500_000)
432            }
433        );
434
435        // A second constrained peer with a lower cap → shared low drops to the min.
436        assert!(p.set_request(3, QualityRequest::Capped(300_000)));
437        assert_eq!(p.plan().low_layer_bps, Some(300_000));
438
439        // Removing peer 2 does NOT move the plan — peer 3 still pins the 300k min.
440        assert!(!p.remove_peer(2));
441        assert_eq!(p.plan().low_layer_bps, Some(300_000));
442        // The last constrained peer leaves → back to the source-only default.
443        assert!(p.remove_peer(3));
444        assert_eq!(
445            p.plan(),
446            LayerPlan {
447                send_source: true,
448                low_layer_bps: None
449            }
450        );
451    }

453    /// The plan reflects demand directly (no actuation gate): all receivers
454    /// constrained → the source drops and a shared low layer is planned at once, and
455    /// clearing the requests returns to the source-only default. Safe because the low
456    /// layer is additive — a constrained receiver moves its own subscription to the
457    /// low track rather than being starved of a dropped source.
458    #[test]
459    fn simulcast_planner_reflects_demand_directly() {
460        let mut p = SimulcastPlanner::new(SRC);
461        assert_eq!(p.plan(), LayerPlan::SOURCE_ONLY);
462
463        assert!(p.set_request(1, QualityRequest::Capped(400_000)));
464        assert!(p.set_request(2, QualityRequest::Capped(300_000)));
465        assert_eq!(
466            p.plan(),
467            LayerPlan {
468                send_source: false,
469                low_layer_bps: Some(300_000)
470            }
471        );
472
473        // Peer 1 (400k) leaves but peer 2 (300k) still pins the low → no change.
474        assert!(!p.remove_peer(1));
475        // Last constrained peer leaves → back to source-only.
476        assert!(p.remove_peer(2));
477        assert_eq!(p.plan(), LayerPlan::SOURCE_ONLY);
478    }
