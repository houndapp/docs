1//! # Acoustic echo cancellation (full-duplex APM)
2//!
3//! Wraps the [`sonora`] audio-processing module (a pure-Rust port of WebRTC's
4//! `modules/audio_processing`: AEC3 + noise suppression + AGC2 + high-pass) into
5//! the live call so speaker-mode calls (no headphones) do not feed the far-end
6//! audio back into the mic: the **render reference** (what we play out) is
7//! subtracted from the **capture** (the mic).
8//!
9//! ## Why `sonora` and not `webrtc-audio-processing`
10//!
11//! `webrtc-audio-processing` (the tonarino C++ binding) has a `-sys` crate that
12//! hard-requires `meson` to build the bundled WebRTC C++, and there is no
13//! system `libwebrtc-audio-processing` to dynamically link. `sonora` is the same
14//! WebRTC algorithms ported to pure Rust: it builds with only the toolchain. It
15//! is **v0.1.0** — newer and less battle-tested than the C++ original — so the
16//! toggle below degrades to pass-through if init ever fails.
17//!
18//! ## The timing contract (the one thing that must be right)
19//!
20//! * **Sample rate / channels:** the whole endpoint is 48 kHz mono i16
21//!   ([`SAMPLE_RATE`]/[`CHANNELS`]); the APM is configured to match, so there is
22//!   no resample on either the capture or render path.
23//! * **Frame size:** the APM's native chunk is **10 ms** (480 samples @ 48 kHz),
24//!   NOT our 20 ms Opus frame (960 samples). Every 20 ms [`PcmFrame`] is split
25//!   into **two** 10 ms passes ([`APM_FRAME_SAMPLES`]) — both for capture
26//!   ([`Apm::process_capture`]) and render ([`Apm::process_render`]). A frame
27//!   whose length is not a whole number of 10 ms chunks is passed through
28//!   unprocessed (defensive; the live path always hands exact 960-sample frames).
29//! * **Stream delay:** AEC3 needs an estimate of the capture-vs-render delay to
30//!   seed its delay search. We set a fixed [`INITIAL_STREAM_DELAY_MS`] once; AEC3
31//!   is adaptive and refines the true delay itself, so the estimate only has to
32//!   be in the right ballpark (it is not a hard alignment requirement like a
33//!   fixed-delay canceller). The render reference is tapped just before playout,
34//!   so the real loop delay is roughly the playout buffer + device output latency.
35//!
36//! ## Threading / locking
37//!
38//! One [`Apm`] is shared (`Arc`) between the **capture thread** (which calls
39//! [`Apm::process_capture`]) and the **mix-bus thread** (which calls
40//! [`Apm::process_render`] on each mixed chunk it plays).
41//! `sonora::AudioProcessing` is `Send` but not `Sync`, so it lives behind a
42//! `Mutex`. The processing calls are short (a few hundred µs for two 10 ms
43//! chunks) and the lock is never held across IO or `.await`. **Neither call
44//! happens inside a cpal RT callback** — capture processing is on the mic worker
45//! thread (between `next_frame` and the encode channel) and render processing is
46//! on the bus thread (between the mix and the playback ring),
47//! so the RT audio callbacks are never blocked on this lock.
48//!
49//! ### Render reference: the single mixed playout bus
50//!
51//! AEC3's render reference must be ONE coherent stream — exactly what the speaker
52//! plays. The [mixed-playout bus](crate::audio::mix) makes it so: all remote
53//! peers' due PCM is summed into one 10 ms chunk and fed to
54//! [`Apm::process_render`] **once per tick**, then played on the single
55//! `CpalPlayback`. Because there is exactly one render feed by construction,
56//! AEC is correct for ANY number of peers — interleaving independent per-peer
57//! references corrupts the canceller. The caller is the bus, not N per-peer
58//! pumps.

71/// Samples in one APM processing chunk: 10 ms @ 48 kHz mono = **480**. This is
72/// the APM's native frame size (`sample_rate / 100`), distinct from the 960-sample
73/// 20 ms Opus frame the rest of the pipeline carries. Every `PcmFrame` is split
74/// into `SAMPLES_PER_FRAME / APM_FRAME_SAMPLES` (= 2) chunks for the APM.
75pub const APM_FRAME_SAMPLES: usize = SAMPLE_RATE.hz() as usize / 100;
76
77/// Initial capture↔render stream-delay estimate handed to AEC3, in milliseconds.
78/// The true delay is roughly the playout jitter floor (`PLAYOUT_TARGET_US` in the
79/// client, 80 ms) plus the speaker device's output latency; 90 ms is a sane seed.
80/// AEC3 is **delay-adaptive** — it searches for and tracks the real delay from this
81/// seed — so this only has to be in the right ballpark, not exact. Exposed as a
82/// const so the live wiring and the tests agree on the value.
83pub const INITIAL_STREAM_DELAY_MS: i32 = 90;
84
85/// Fixed make-up gain AGC2 applies after its adaptive stage and before its
86/// limiter. See [`gain_controller`] for why it is not zero, and why it is not the
87/// 12 dB that a fixed-gain-only measurement suggests.
88const FIXED_MAKEUP_GAIN_DB: f32 = 7.0;
89
90/// Ceiling AGC2 is allowed to push the *post-suppression noise floor* to. This is
91/// what actually caps the gain a real microphone gets — see [`gain_controller`].
92const MAX_OUTPUT_NOISE_LEVEL_DBFS: f32 = -42.0;
93
94/// AGC2 as this endpoint configures it — **the loudness contract lives here**.
95///
96/// Target: RFC 7874's −19 dBm0 active-speech level, i.e. **−22 dBFS RMS ± 6 dB**
97/// measured above 300 Hz. Adaptive digital gain ALONE cannot reach it, which is
98/// why this is not `Default::default()`:
99///
100/// * The adaptive stage's settled target is `-(headroom_db + saturation-protector
101///   headroom)` = **−17…−30 dBFS by design** — a peak-safe trim, not a loudness
102///   normaliser. In Chrome/Discord it rides on top of an input-volume controller
103///   that drives the OS mic gain (P5, now wired — see [`Apm::set_applied_input_volume`]
104///   / [`Apm::recommended_input_volume`] and `call::audio_tx` for the platform
105///   round trip), but that controller's recommendation is orthogonal to this
106///   digital math (sonora's `GainController2::process` never reads the applied/
107///   recommended input volume — verified against 0.2.0 source), so the fixed +
108///   adaptive digital stages below still have to do the whole job whenever no OS
109///   provider is resolved (Linux today) or a write is gated off (AGC disabled,
110///   muted, unavailable device). `fixed_digital` is the standard make-up stage for
111///   exactly this, and it feeds AGC2's own limiter (−1 dBFS, 5:1), so raising it
112///   trades headroom, not clipping.
113/// * `max_output_noise_level_dbfs` clamps the adaptive gain to
114///   `ceiling − post-NS noise floor`. At the −50 dBFS default an ordinary mic is
115///   allowed 5–10 dB regardless of `max_gain_db`; −42 unclamps it. Going further
116///   (−40 and up) starts pumping room noise between words.
117///
118/// **The two knobs are not additive, and that is why the make-up gain is 7 dB and
119/// not 12.** Measured separately, each is worth ~+10 dB; together they are worth
120/// ~+19, because unclamping the noise ceiling is what lets the *adaptive* stage do
121/// the work the fixed stage was standing in for. 12 dB on top of the unclamped
122/// ceiling put this repo's speech-shaped excitation at **−13.3 dBFS RMS** — past
123/// the band's loud edge and hotter than Discord-class. 7 dB targets the clean-
124/// excitation case at ~−18 dBFS, the top of the band: that case has the best SNR
125/// any input will have, so the noise clamp binds least and it is the LOUDEST the
126/// chain gets. Real, noisier mics let the clamp bind and land further down the
127/// band — which is the right way round.
128///
129/// One function so the live config and [`Apm::set_agc_enabled`]'s rebuild cannot
130/// drift apart — a toggle that reinstated `Default::default()` would silently
131/// undo all of the above.
132fn gain_controller() -> GainController2 {
133    GainController2 {
134        // P5: drive the OS mic slider the way Chrome/Discord do. Safe to enable
135        // unconditionally — it only COMPUTES a recommendation (speech-level-driven,
136        // independent of the digital gain stages below); whether anything ever acts
137        // on it is entirely the caller's call (`call::audio_tx`'s platform round
138        // trip + AGC/mute gate), so a platform with no provider (Linux) or a device
139        // with no settable property just never gets an OS write — never a landmine
140        // for the digital path.
141        input_volume_controller: true,
142        adaptive_digital: Some(AdaptiveDigital {
143            max_output_noise_level_dbfs: MAX_OUTPUT_NOISE_LEVEL_DBFS,
144            ..Default::default()
145        }),
146        fixed_digital: FixedDigital {
147            gain_db: FIXED_MAKEUP_GAIN_DB,
148        },
149    }
150}

152/// The live-call audio-processing module: shared echo canceller + noise
153/// suppressor + gain control. Capture frames (mic) and render frames (far-end
154/// playout) are both fed through it; it subtracts the render reference from the
155/// capture so speaker audio does not echo.
156///
157/// One instance is shared (`Arc<Apm>`) across the capture thread and every
158/// per-peer playback pump. Internally a `Mutex<AudioProcessing>` — the WebRTC APM
159/// is `Send` but single-threaded, and capture/render must serialize against each
160/// other anyway (they share the canceller's adaptive state).
161pub struct Apm {
162    inner: Mutex<AudioProcessing>,
163    config: StreamConfig,
164    /// OS input volume most recently reported as **applied** (P5's round trip),
165    /// mapped 0..=255 for sonora's controller — its native units, kept private so
166    /// this type's public surface stays in the 0.0..=1.0 scalar every caller
167    /// (the platform backends, `call::audio_tx`) already speaks. Defaults to 255
168    /// (sonora's own `kFallBackInputVolume`/"fully open" convention) until a real
169    /// reading lands, so an unresolved/unsupported device never reads as
170    /// artificially quiet to the controller's speech-level math.
171    applied_input_volume: AtomicU8,
172    /// The controller's most recent **recommendation**, same 0..=255 domain,
173    /// refreshed after every [`Self::process_capture`]. Equals
174    /// `applied_input_volume` whenever the controller is disabled (AGC off) or has
175    /// not yet formed an opinion — sonora's own fallback (see
176    /// `AudioProcessing::recommended_stream_analog_level`), not something this
177    /// type computes itself.
178    recommended_input_volume: AtomicU8,
179}
180
181/// sonora's own `kFallBackInputVolume` convention: "fully open" until told
182/// otherwise, matching `AudioProcessing::recommended_stream_analog_level`'s
183/// fallback when neither an applied nor a recommended level is known yet.
184const FALLBACK_INPUT_VOLUME: u8 = 255;
185
186impl Apm {
187    /// Build the APM for the endpoint's fixed 48 kHz mono format with AEC3, noise
188    /// suppression (moderate), and AGC2 (adaptive digital) enabled, seeded with the
189    /// initial stream-delay estimate. Returns `None` if the APM cannot be built
190    /// (so the caller falls back to pass-through and the call still works — AEC
191    /// failing must never break audio).
192    pub fn new() -> Option<Self> {
193        // sonora's builder does not return a Result, but constructing it could in
194        // principle panic on an invalid config; guard so an APM failure degrades to
195        // pass-through rather than taking down the capture thread.
196        let config = StreamConfig::new(SAMPLE_RATE.hz(), CHANNELS.count());
197        let apm_config = Config {
198            // Full-band: the pipeline default caps internal processing at 32 kHz,
199            // which band-limits everything the suppressor/gain touch to 16 kHz —
200            // an audible dullness on a 48 kHz endpoint. The whole path is fixed
201            // 48 kHz mono, so process at the native rate.
202            pipeline: Pipeline {
203                maximum_internal_processing_rate: MaxProcessingRate::Rate48kHz,
204                // Mono endpoint: pin the multi-channel flags rather than inherit
205                // them (sonora flipped both defaults to `true` in 0.2). At
206                // `CHANNELS` = 1 they are inert either way; pinning keeps a future
207                // default flip from quietly changing how the APM treats the stream.
208                multi_channel_render: false,
209                multi_channel_capture: false,
210                ..Default::default()
211            },
212            // Standalone high-pass filter, full-band. AEC3 already forces one on
213            // its OWN path (`enforce_high_pass_filtering`), so this is not new
214            // filtering so much as making it explicit for the whole chain —
215            // including the AEC-off/transparent case. Rumble and DC (desk thumps,
216            // HVAC, handling noise) carry no speech but do carry peak, and peak is
217            // what the saturation protector budgets AGC2's gain against; blocking
218            // it up front is a precondition for the make-up gain above.
219            high_pass_filter: Some(HighPassFilter {
220                apply_in_full_band: true,
221            }),
222            // AEC3, default transparent mode.
223            echo_canceller: Some(EchoCanceller::default()),
224            // Background noise suppression. Moderate (~12 dB), not High: the
225            // classic spectral suppressor trades consonant detail for depth, and
226            // loudness is AGC2's job, not the suppressor's. High remains a
227            // per-user setting for loud rooms (`set_noise_suppression`).
228            noise_suppression: Some(NoiseSuppression {
229                level: NoiseSuppressionLevel::Moderate,
230                ..Default::default()
231            }),
232            // AGC2: adaptive digital gain + fixed make-up + limiter. The loudness
233            // contract (RFC 7874 −22 dBFS ± 6) lives in `gain_controller`.
234            gain_controller2: Some(gain_controller()),
235            // Unity level adjuster, enabled so `set_input_gain_db`'s runtime
236            // post-gain has a slot to land in (sonora ignores the runtime
237            // setting when this is `None`).
238            capture_level_adjustment: Some(Default::default()),
239            ..Default::default()
240        };
241
242        let build = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
243            let mut apm = AudioProcessing::builder()
244                .config(apm_config)
245                .capture_config(config)
246                .render_config(config)
247                .build();
248            // Seed the delay estimate; clamping is fine (best-effort).
249            let _ = apm.set_stream_delay_ms(INITIAL_STREAM_DELAY_MS);
250            apm
251        }));
252
253        match build {
254            Ok(apm) => Some(Self {
255                inner: Mutex::new(apm),
256                config,
257                applied_input_volume: AtomicU8::new(FALLBACK_INPUT_VOLUME),
258                recommended_input_volume: AtomicU8::new(FALLBACK_INPUT_VOLUME),
259            }),
260            Err(_) => {
261                tracing::error!(
262                    target: "audio_endpoint",
263                    "APM init panicked — falling back to pass-through (no AEC)"
264                );
265                None
266            }
267        }
268    }
269
270    /// Process one captured mic [`PcmFrame`] **in place**: AEC (subtract the render
271    /// reference) + noise suppression + gain. The 20 ms frame is split into 10 ms
272    /// APM chunks; each is processed in place. A frame whose length is not a whole
273    /// number of 10 ms chunks is left untouched (defensive — the live path always
274    /// hands exact 960-sample frames). The lock is held only for the short
275    /// processing call, never across IO.
276    pub fn process_capture(&self, frame: &mut PcmFrame) {
277        if !self.chunkable(&frame.samples) {
278            return;
279        }
280        // catch_unwind: a sonora panic here must degrade THIS frame to
281        // pass-through, not unwind the capture loop and kill the mic. The
282        // unwinding drop of the guard poisons the Mutex, so every later call
283        // takes the poisoned-lock pass-through — one-time failure, audio flows.
284        let processed = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
285            let Ok(mut apm) = self.inner.lock() else {
286                // A poisoned lock means a prior processing call panicked; degrade to
287                // pass-through rather than propagate (audio must keep flowing).
288                return;
289            };
290            // P5 round trip, ONCE per 20 ms frame (not per 10 ms chunk): feed the
291            // last OS-read applied level before the first chunk, so both chunks'
292            // internal `analyze`/`process` calls see the SAME value (the second is a
293            // no-op re-assert, matching libwebrtc's per-callback-not-per-chunk input
294            // volume semantics) — then read the freshest recommendation back after
295            // the second chunk. Unconditional: harmless when the controller is
296            // absent/inert (recommended falls back to applied — see
297            // `Self::recommended_input_volume`'s doc).
298            apm.set_stream_analog_level(self.applied_input_volume.load(Ordering::Relaxed) as i32);
299            let mut scratch = [0i16; APM_FRAME_SAMPLES];
300            for chunk in frame.samples.chunks_mut(APM_FRAME_SAMPLES) {
301                match apm.process_capture_i16(chunk, &mut scratch) {
302                    Ok(()) => chunk.copy_from_slice(&scratch),
303                    Err(e) => {
304                        // Out-of-range params clamp internally; a real error leaves the
305                        // chunk as captured. Log once-ish at debug (hot path).
306                        tracing::debug!(target: "audio_endpoint", "APM capture chunk error: {e}");
307                    }
308                }
309            }
310            self.recommended_input_volume.store(
311                apm.recommended_stream_analog_level().clamp(0, 255) as u8,
312                Ordering::Relaxed,
313            );
314        }));
315        if processed.is_err() {
316            tracing::error!(
317                target: "audio_endpoint",
318                "APM capture processing panicked — pass-through from here on"
319            );
320        }
321    }
322
323    /// Feed one render (far-end / playout) [`PcmFrame`] to the APM as the echo
324    /// reference. Called **once per mix tick** by the [mixed-playout
325    /// bus](crate::audio::mix) with the SUMMED 10/20 ms chunk — the single
326    /// coherent stream the speaker plays. The APM accumulates it as the reverse
327    /// stream it subtracts from capture; output is discarded (we do not alter what
328    /// we play, only inform the canceller). Split into 10 ms chunks like capture.
329    ///
330    /// There is exactly one render feed by construction (the bus), so AEC works for
331    /// any number of peers — no per-source gate. (Before the bus, N per-peer pumps
332    /// fed this directly and the interleaved references corrupted AEC3; that gate
333    /// is gone.)
334    pub fn process_render(&self, frame: &PcmFrame) {
335        if !self.chunkable(&frame.samples) {
336            return;
337        }
338        // Same unwind guard as capture: this runs on the RT mix thread, where a
339        // panic would take down the whole playout bus.
340        let processed = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
341            let Ok(mut apm) = self.inner.lock() else {
342                return;
343            };
344            let mut scratch = [0i16; APM_FRAME_SAMPLES];
345            for chunk in frame.samples.chunks(APM_FRAME_SAMPLES) {
346                if let Err(e) = apm.process_render_i16(chunk, &mut scratch) {
347                    tracing::debug!(target: "audio_endpoint", "APM render chunk error: {e}");
348                }
349            }
350        }));
351        if processed.is_err() {
352            tracing::error!(
353                target: "audio_endpoint",
354                "APM render processing panicked — pass-through from here on"
355            );
356        }
357    }
358
359    /// Hint the APM that the processed capture output is (not) being consumed —
360    /// driven from the mute flag. While unused, AGC2 stops adapting its gain and
361    /// the noise/speech-level estimators hold, so a long mute over keyboard
362    /// clatter does not retune the gain the first unmuted word is played at.
363    /// Capture frames must still be PROCESSED while muted (AEC3's delay tracking
364    /// needs the cadence); this only freezes adaptation.
365    pub fn set_capture_output_used(&self, used: bool) {
366        if let Ok(mut apm) = self.inner.lock() {
367            apm.set_capture_output_used(used);
368        }
369    }
370
371    /// P5 (OS input-volume controller): report the OS input volume actually in
372    /// effect right now (0.0..=1.0 scalar, clamped), so the next
373    /// [`Self::process_capture`] reasons from ground truth rather than its own
374    /// last recommendation. Cheap (one atomic store) — call it every 20 ms capture
375    /// frame, BEFORE `process_capture`, unconditionally: like the mute hint above,
376    /// this must keep flowing even while AGC is off or the mic is muted (the
377    /// caller — `call::audio_tx` — gates the OS *write* on its own AGC/mute state,
378    /// never this feed).
379    pub fn set_applied_input_volume(&self, scalar: f32) {
380        let level = (scalar.clamp(0.0, 1.0) * 255.0).round() as u8;
381        self.applied_input_volume.store(level, Ordering::Relaxed);
382    }
383
384    /// P5: the controller's recommended OS input volume (0.0..=1.0 scalar) after
385    /// the last processed capture frame. Equals whatever was last reported via
386    /// [`Self::set_applied_input_volume`] when the controller is disabled (AGC
387    /// off — `set_agc_enabled(false)` drops `GainController2` entirely) or has not
388    /// yet formed an opinion; this always reflects sonora's raw recommendation —
389    /// gating the actual OS write is the caller's job.
390    pub fn recommended_input_volume(&self) -> f32 {
391        self.recommended_input_volume.load(Ordering::Relaxed) as f32 / 255.0
392    }
393
394    /// Live-retune noise suppression: `None` disables it (the ML suppressor owns
395    /// the frame), `Some(level)` selects the classic suppressor's depth. Applied
396    /// via `apply_config` — AEC3/AGC2 state survives, no rebuild.
397    pub fn set_noise_suppression(&self, level: Option<NoiseSuppressionLevel>) {
398        if let Ok(mut apm) = self.inner.lock() {
399            let mut config = apm.config().clone();
400            config.noise_suppression = level.map(|level| NoiseSuppression {
401                level,
402                ..Default::default()
403            });
404            apm.apply_config(config);
405        }
406    }
407
408    /// Live-toggle AGC2 (adaptive digital gain + make-up + limiter). Off leaves the
409    /// mic at its raw device level — the escape hatch for a user whose mic the
410    /// estimator misjudges. Same `apply_config` route as noise suppression, and it
411    /// re-installs [`gain_controller`], not the crate defaults: re-enabling must
412    /// restore the loudness contract, not a silently quieter chain.
413    pub fn set_agc_enabled(&self, enabled: bool) {
414        if let Ok(mut apm) = self.inner.lock() {
415            let mut config = apm.config().clone();
416            config.gain_controller2 = enabled.then(gain_controller);
417            apm.apply_config(config);
418        }
419    }
420
421    /// Manual input trim in dB, applied after the rest of the capture chain via
422    /// the capture-level adjuster's post gain (which the base config enables at
423    /// unity for exactly this). Clamped to ±12 dB: enough to rescue a mis-leveled
424    /// mic, not enough to be a foot-gun.
425    pub fn set_input_gain_db(&self, gain_db: f32) {
426        if let Ok(mut apm) = self.inner.lock() {
427            let factor = 10f32.powf(gain_db.clamp(-12.0, 12.0) / 20.0);
428            apm.set_capture_post_gain(factor);
429        }
430    }
431
432    /// Whether the APM has fallen back to permanent pass-through because a
433    /// processing call panicked. The unwinding guard poisons the `Mutex`, and a
434    /// poisoned lock is exactly the "pass-through from here on" state the
435    /// capture/render paths take — so the poison flag IS the health signal.
436    /// Used by the regression tests to assert the panic guard never fired.
437    pub fn is_degraded(&self) -> bool {
438        self.inner.is_poisoned()
439    }
440
441    /// Whether `samples` is mono and a whole number of 10 ms APM chunks (so it can
442    /// be split cleanly). The live path always satisfies this (960 = 2 × 480);
443    /// anything else is passed through unprocessed.
444    fn chunkable(&self, samples: &[i16]) -> bool {
445        self.config.num_channels() == CHANNELS.count()
446            && !samples.is_empty()
447            && samples.len().is_multiple_of(APM_FRAME_SAMPLES)
448    }
449}

470    /// Smoke: init, process synthetic render + capture frames, output stays sane
471    /// (finite, in i16 range, same length — never NaN/garbage or a length change).
472    #[test]
473    fn smoke_process_capture_and_render() {
474        let apm = Apm::new().expect("APM builds headless");
475
476        // A 440 Hz-ish tone as the far-end (render) reference.
477        let render: Vec<i16> = (0..SAMPLES_PER_FRAME)
478            .map(|i| ((i as f32 * 0.1).sin() * 8000.0) as i16)
479            .collect();
480        apm.process_render(&frame(render));
481
482        // Mic capture: some near-end speech-ish signal.
483        let mut cap = frame(
484            (0..SAMPLES_PER_FRAME)
485                .map(|i| ((i as f32 * 0.05).sin() * 4000.0) as i16)
486                .collect(),
487        );
488        let before_len = cap.samples.len();
489        apm.process_capture(&mut cap);
490

492        // Output is real i16 (no panic, no garbage). RMS must be finite and within
493        // full scale — a sane processed frame, not silence-or-overflow.
494        let rms = cap.rms();
495        assert!(rms.is_finite(), "rms finite");
496        assert!((0.0..=1.0).contains(&rms), "rms within full scale: {rms}");

499    /// Speech-shaped test block: a pitch-harmonic stack under a syllabic envelope
500    /// with a noise floor — enough structure for AGC2's RNN VAD to call it speech
501    /// (a bare sine is the textbook non-speech signal, see the DTX tests).
502    fn speech_like_frame(idx: u64, peak: f32) -> PcmFrame {
503        let mut st = 0x9E37_79B9_7F4A_7C15u64 ^ idx.wrapping_mul(0x2545_F491_4F6C_DD1D);
504        let samples: Vec<i16> = (0..SAMPLES_PER_FRAME)
505            .map(|i| {
506                let t =
507                    (idx * SAMPLES_PER_FRAME as u64 + i as u64) as f32 / SAMPLE_RATE.hz() as f32;
508                // ~3 Hz syllabic amplitude modulation.
509                let envelope = 0.55 + 0.45 * (2.0 * std::f32::consts::PI * 3.0 * t).sin();
510                // 120 Hz fundamental + harmonics, roughly 1/n rolloff.
511                let mut v = 0.0f32;
512                for h in 1..=6 {
513                    v += ((2.0 * std::f32::consts::PI * 120.0 * h as f32 * t).sin()) / h as f32;
514                }
515                st ^= st << 13;
516                st ^= st >> 7;
517                st ^= st << 17;
518                let noise = ((st >> 11) as f32 / (1u64 << 53) as f32) * 2.0 - 1.0;
519                let s = (v / 2.0 * envelope + noise * 0.02) * peak;
520                (s.clamp(-1.0, 1.0) * i16::MAX as f32) as i16
521            })
522            .collect();
523        PcmFrame::at_engine_rate(samples, TimestampUs::from_micros(idx as i64 * 20_000))
524    }

526    /// 20 ms frames of excitation before the level is read. AGC2 ramps at
527    /// ≤6 dB/s from a 15 dB initial gain, only while the RNN VAD is confident for
528    /// 12 consecutive 10 ms frames, and its speech-level estimator needs ~400 ms of
529    /// speech to be confident at all — so convergence is a matter of tens of
530    /// seconds, not frames. 30 s is what the level probe behind the loudness
531    /// contract measured on.
532    const CONVERGE_FRAMES: u64 = 1_500;
533
534    /// Tail window the converged level is averaged over: the last second.
535    const TAIL_FRAMES: u64 = 50;
536
537    /// Converged levels of one run of the FULL capture chain.
538    struct ChainLevels {
539        in_dbfs: f32,
540        out_dbfs: f32,
541        /// Net gain of the whole chain (NS's ~−12 dB included), not AGC2's alone.
542        gain_db: f32,
543        /// Output samples pinned to an i16 rail — the clipping the make-up gain
544        /// must not buy.
545        clipped: usize,
546    }
547
548    fn dbfs(rms: f32) -> f32 {
549        20.0 * rms.max(f32::MIN_POSITIVE).log10()
550    }
551
552    /// Drive the live chain with [`CONVERGE_FRAMES`] of speech-shaped excitation at
553    /// `peak` (linear, 1.0 = full scale), render side ticking silence exactly like
554    /// the mix bus does, and report the tail-window levels.
555    fn run_capture_chain(peak: f32) -> ChainLevels {
556        let apm = Apm::new().expect("APM builds headless");
557        let mut in_rms = 0.0f32;
558        let mut out_rms = 0.0f32;
559        let mut clipped = 0usize;
560        for n in 0..CONVERGE_FRAMES {
561            apm.process_render(&frame(vec![0i16; SAMPLES_PER_FRAME]));
562            let mut f = speech_like_frame(n, peak);
563            let raw = f.rms();
564            apm.process_capture(&mut f);
565            clipped += f
566                .samples
567                .iter()
568                .filter(|&&s| s == i16::MIN || s == i16::MAX)
569                .count();
570            if n >= CONVERGE_FRAMES - TAIL_FRAMES {
571                in_rms += raw;
572                out_rms += f.rms();
573            }
574        }
575        in_rms /= TAIL_FRAMES as f32;
576        out_rms /= TAIL_FRAMES as f32;
577        ChainLevels {
578            in_dbfs: dbfs(in_rms),
579            out_dbfs: dbfs(out_rms),
580            gain_db: dbfs(out_rms) - dbfs(in_rms),
581            clipped,
582        }
583    }

738    /// **The echo-path-change regression** (the `two_peers_exchange_media`
739    /// killer). AEC3 starts on its 12-partition *initial* filter and grows to the
740    /// 13-partition steady-state one once it leaves the initial state (2.5 s of
741    /// active render, then a 250-block ramp). A later echo-path change — a render
742    /// buffer flush, or the delay estimator locking onto a new delay — snaps the
743    /// filter back to the 12-partition initial length, i.e. a SHRINK from 13 to
744    /// 12. sonora-aec3 0.1.0 zeroed the freed partitions with `h[old..new]`, which
745    /// panics when `old > new` ("slice index starts at 13 but ends at 12") instead
746    /// of no-op'ing like the C++ `for (k = old; k < new; ++k)` it was ported from.
747    /// On the capture thread that tripped the unwind guard and the call ran
748    /// pass-through until it starved.
749    ///
750    /// Drives the live sequence in miniature: a broadband far end echoed back at a
751    /// stable delay until the filter has grown past 12 partitions, then a step
752    /// change of the echo delay — which is what the delay estimator reports as an
753    /// echo-path change. In the call that step is any playout-path move (a device
754    /// or route change, a jitter-buffer resize, a render-buffer flush), which is
755    /// why it fired most runs but not all.
756    #[test]
757    fn echo_path_change_after_filter_growth_does_not_panic() {
758        let apm = Apm::new().expect("APM builds headless");
759
760        // Loud BROADBAND far-end reference: `active render` blocks are what carry
761        // AEC3 out of its initial state, and the delay estimator has to hold a
762        // STABLE lock while they accumulate — every delay change resets the
763        // initial state, so a narrowband reference (whose cross-correlation peak
764        // wanders) keeps the filter pinned at 12 partitions forever and the shrink
765        // never happens.
766        let total_frames = 500usize;
767        // Head room in front of frame 0 so the delayed (echo) read never underruns.
768        let head = 4 * SAMPLES_PER_FRAME;
769        let mut st = 0x1234_5678_9abc_def0u64;
770        let reference: Vec<i16> = (0..head + (total_frames + 1) * SAMPLES_PER_FRAME)
771            .map(|_| {
772                st ^= st << 13;
773                st ^= st >> 7;
774                st ^= st << 17;
775                ((st >> 40) as i16 / 2).saturating_mul(3)
776            })
777            .collect();
778        // The room: capture is the reference delayed and attenuated. A FIXED delay
779        // that the estimator can lock onto, then a step change to a new one.
780        let echo = |n: usize, delay: usize| -> PcmFrame {
781            let start = head + n * SAMPLES_PER_FRAME - delay;
782            frame(
783                reference[start..start + SAMPLES_PER_FRAME]
784                    .iter()
785                    .map(|&s| (s as i32 / 3) as i16)
786                    .collect(),
787            )
788        };
789        let render = |n: usize| -> PcmFrame {
790            let start = head + n * SAMPLES_PER_FRAME;
791            frame(reference[start..start + SAMPLES_PER_FRAME].to_vec())
792        };
793
794        // Phase 1 — 6 s at a fixed 10 ms echo delay: 2.5 s of initial state plus
795        // the 250-block size-change ramp that grows the filter 12 -> 13, with
796        // margin.
797        let grow_frames = 300usize;
798        for n in 0..grow_frames {
799            apm.process_render(&render(n));
800            let mut cap = echo(n, 480);
801            apm.process_capture(&mut cap);
802        }
803
804        // Phase 2 — the echo path moves (60 ms): the delay estimator locks the new
805        // delay and reports an echo-path change, which snaps the now-13-partition
806        // filter back to the 12-partition initial length. That shrink is the panic.
807        for n in grow_frames..total_frames {
808            apm.process_render(&render(n));
809            let mut cap = echo(n, 2880);
810            apm.process_capture(&mut cap);
811            assert!(
812                !apm.is_degraded(),
813                "APM panicked on the echo-path change at frame {n} — the guard \
814                 degraded it to pass-through and the live call starves from here"
815            );
816        }
817    }

819    /// Echo-shaped test: when the captured signal is a delayed/attenuated copy of
820    /// the render reference (pure echo, no near-end voice), the APM must measurably
821    /// attenuate the captured energy as AEC3 converges.
822    ///
823    /// Measured as a RATIO between two identical chains — one fed the true render
824    /// reference, one fed silence — not as an absolute level. The capture chain's
825    /// make-up gain sits DOWNSTREAM of the canceller, so comparing the processed
826    /// residual against the raw echo level (what this test used to do) measures the
827    /// loudness contract rather than the canceller, and inverts outright the moment
828    /// the chain has net gain: it did, the day `fixed_digital` landed.
829    ///
830    /// The far end is broadband noise, the textbook AEC stimulus. A tone is doubly
831    /// wrong here: periodic, so the matched-filter delay estimate is ambiguous at
832    /// every period (AEC3 never converges), and stationary, so the BASELINE chain's
833    /// suppressor learns it as noise and out-attenuates the canceller. Noise also
834    /// keeps both chains' AGC2 idle (no VAD hits), so the gain stages divide out.
835    #[test]
836    fn echo_reference_attenuates_capture() {
837        let cancelling = Apm::new().expect("APM builds headless");
838        let baseline = Apm::new().expect("APM builds headless");
839
840        // Far-end reference: deterministic broadband noise (xorshift, no rand dep).
841        let mut rng: u32 = 0x2545_F491;
842        let mut make_noise = move || -> Vec<i16> {
843            (0..SAMPLES_PER_FRAME)
844                .map(|_| {
845                    rng ^= rng << 13;
846                    rng ^= rng >> 17;
847                    rng ^= rng << 5;
848                    ((rng >> 16) as i16 as i32 * 10000 / 32768) as i16
849                })
850                .collect()
851        };
852
853        let mut cancelled_late = 0.0f32;
854        let mut baseline_late = 0.0f32;
855        let frames = 200; // ~4 s of audio — enough for AEC3 to converge.
856        for n in 0..frames {
857            let noise = make_noise();
858            // Capture == an attenuated copy of the far end (pure echo, no near-end).
859            let echo: Vec<i16> = noise.iter().map(|&s| (s as i32 / 2) as i16).collect();
860
861            // One chain hears the far end; the control hears silence, so its output
862            // is that same echo through the same NS/AGC stages, uncancelled.
863            cancelling.process_render(&frame(noise));
864            baseline.process_render(&frame(vec![0i16; SAMPLES_PER_FRAME]));
865
866            let mut cancelled_frame = frame(echo.clone());
867            let mut baseline_frame = frame(echo);
868            cancelling.process_capture(&mut cancelled_frame);
869            baseline.process_capture(&mut baseline_frame);
870            if n >= frames - 20 {
871                cancelled_late += cancelled_frame.rms();
872                baseline_late += baseline_frame.rms();
873            }
874        }
875        cancelled_late /= 20.0;
876        baseline_late /= 20.0;
877
878        // At least 6 dB of suppression against the identical no-reference chain.
879        // Generous on purpose: AEC3 needs convergence time and this is a synthetic
880        // single-tap echo, not a room.
881        assert!(
882            cancelled_late < baseline_late * 0.5,
883            "AEC should suppress the echo against the same chain with no reference: \
884             cancelled rms {cancelled_late} vs uncancelled {baseline_late}"
885        );
886    }
