1//! # Acoustic echo cancellation (full-duplex APM)
2//!
3//! Wraps the [`sonora`] audio-processing module (a pure-Rust port of WebRTC's
4//! `modules/audio_processing`: AEC3 + noise suppression + AGC2 + high-pass) into
5//! the live call so speaker-mode calls (no headphones) do not feed the far-end
6//! audio back into the mic: the **render reference** (what we play out) is
7//! subtracted from the **capture** (the mic).
8//!
9//! ## Why `sonora` and not `webrtc-audio-processing`
10//!
11//! `webrtc-audio-processing` (the tonarino C++ binding) has a `-sys` crate that
12//! hard-requires `meson` to build the bundled WebRTC C++, and there is no
13//! system `libwebrtc-audio-processing` to dynamically link. `sonora` is the same
14//! WebRTC algorithms ported to pure Rust: it builds with only the toolchain. It
15//! is **v0.1.0** — newer and less battle-tested than the C++ original — so the
16//! toggle below degrades to pass-through if init ever fails.
17//!
18//! ## The timing contract (the one thing that must be right)
19//!
20//! * **Sample rate / channels:** the whole endpoint is 48 kHz mono i16
21//!   ([`SAMPLE_RATE`]/[`CHANNELS`]); the APM is configured to match, so there is
22//!   no resample on either the capture or render path.
23//! * **Frame size:** the APM's native chunk is **10 ms** (480 samples @ 48 kHz),
24//!   NOT our 20 ms Opus frame (960 samples). Every 20 ms [`PcmFrame`] is split
25//!   into **two** 10 ms passes ([`APM_FRAME_SAMPLES`]) — both for capture
26//!   ([`Apm::process_capture`]) and render ([`Apm::process_render`]). A frame
27//!   whose length is not a whole number of 10 ms chunks is passed through
28//!   unprocessed (defensive; the live path always hands exact 960-sample frames).
29//! * **Stream delay:** AEC3 needs an estimate of the capture-vs-render delay to
30//!   seed its delay search. We set a fixed [`INITIAL_STREAM_DELAY_MS`] once; AEC3
31//!   is adaptive and refines the true delay itself, so the estimate only has to
32//!   be in the right ballpark (it is not a hard alignment requirement like a
33//!   fixed-delay canceller). The render reference is tapped just before playout,
34//!   so the real loop delay is roughly the playout buffer + device output latency.
35//!
36//! ## Threading / locking
37//!
38//! One [`Apm`] is shared (`Arc`) between the **capture thread** (which calls
39//! [`Apm::process_capture`]) and the **mix-bus thread** (which calls
40//! [`Apm::process_render`] on each mixed chunk it plays).
41//! `sonora::AudioProcessing` is `Send` but not `Sync`, so it lives behind a
42//! `Mutex`. The processing calls are short (a few hundred µs for two 10 ms
43//! chunks) and the lock is never held across IO or `.await`. **Neither call
44//! happens inside a cpal RT callback** — capture processing is on the mic worker
45//! thread (between `next_frame` and the encode channel) and render processing is
46//! on the bus thread (between the mix and the playback ring),
47//! so the RT audio callbacks are never blocked on this lock.
48//!
49//! ### Render reference: the single mixed playout bus
50//!
51//! AEC3's render reference must be ONE coherent stream — exactly what the speaker
52//! plays. The [mixed-playout bus](crate::audio::mix) makes it so: all remote
53//! peers' due PCM is summed into one 10 ms chunk and fed to
54//! [`Apm::process_render`] **once per tick**, then played on the single
55//! `CpalPlayback`. Because there is exactly one render feed by construction,
56//! AEC is correct for ANY number of peers — interleaving independent per-peer
57//! references corrupts the canceller. The caller is the bus, not N per-peer
58//! pumps.
59

70/// Samples in one APM processing chunk: 10 ms @ 48 kHz mono = **480**. This is
71/// the APM's native frame size (`sample_rate / 100`), distinct from the 960-sample
72/// 20 ms Opus frame the rest of the pipeline carries. Every `PcmFrame` is split
73/// into `SAMPLES_PER_FRAME / APM_FRAME_SAMPLES` (= 2) chunks for the APM.
74pub const APM_FRAME_SAMPLES: usize = SAMPLE_RATE.hz() as usize / 100;
75
76/// Initial capture↔render stream-delay estimate handed to AEC3, in milliseconds.
77/// The true delay is roughly the playout jitter floor (`PLAYOUT_TARGET_US` in the
78/// client, 80 ms) plus the speaker device's output latency; 90 ms is a sane seed.
79/// AEC3 is **delay-adaptive** — it searches for and tracks the real delay from this
80/// seed — so this only has to be in the right ballpark, not exact. Exposed as a
81/// const so the live wiring and the tests agree on the value.
82pub const INITIAL_STREAM_DELAY_MS: i32 = 90;
83
84/// The live-call audio-processing module: shared echo canceller + noise
85/// suppressor + gain control. Capture frames (mic) and render frames (far-end
86/// playout) are both fed through it; it subtracts the render reference from the
87/// capture so speaker audio does not echo.
88///
89/// One instance is shared (`Arc<Apm>`) across the capture thread and every
90/// per-peer playback pump. Internally a `Mutex<AudioProcessing>` — the WebRTC APM
91/// is `Send` but single-threaded, and capture/render must serialize against each
92/// other anyway (they share the canceller's adaptive state).
93pub struct Apm {
94    inner: Mutex<AudioProcessing>,
95    config: StreamConfig,
96}
97
98impl Apm {
99    /// Build the APM for the endpoint's fixed 48 kHz mono format with AEC3, noise
100    /// suppression (moderate), and AGC2 (adaptive digital) enabled, seeded with the
101    /// initial stream-delay estimate. Returns `None` if the APM cannot be built
102    /// (so the caller falls back to pass-through and the call still works — AEC
103    /// failing must never break audio).
104    pub fn new() -> Option<Self> {
105        // sonora's builder does not return a Result, but constructing it could in
106        // principle panic on an invalid config; guard so an APM failure degrades to
107        // pass-through rather than taking down the capture thread.
108        let config = StreamConfig::new(SAMPLE_RATE.hz(), CHANNELS.count());
109        let apm_config = Config {
110            // Full-band: the pipeline default caps internal processing at 32 kHz,
111            // which band-limits everything the suppressor/gain touch to 16 kHz —
112            // an audible dullness on a 48 kHz endpoint. The whole path is fixed
113            // 48 kHz mono, so process at the native rate.
114            pipeline: Pipeline {
115                maximum_internal_processing_rate: MaxProcessingRate::Rate48kHz,
116                ..Default::default()
117            },
118            // AEC3, default transparent mode.
119            echo_canceller: Some(EchoCanceller::default()),
120            // Background noise suppression. Moderate (~12 dB), not High: the
121            // classic spectral suppressor trades consonant detail for depth, and
122            // loudness is AGC2's job, not the suppressor's. High remains a
123            // per-user setting for loud rooms (`set_noise_suppression`).
124            noise_suppression: Some(NoiseSuppression {
125                level: NoiseSuppressionLevel::Moderate,
126                ..Default::default()
127            }),
128            // AGC2 with adaptive digital gain — levels quiet talkers without the
129            // analog-mic loop (we do not own the OS mic gain here).
130            gain_controller2: Some(GainController2 {
131                adaptive_digital: Some(Default::default()),
132                ..Default::default()
133            }),
134            // Unity level adjuster, enabled so `set_input_gain_db`'s runtime
135            // post-gain has a slot to land in (sonora ignores the runtime
136            // setting when this is `None`).
137            capture_level_adjustment: Some(Default::default()),
138            ..Default::default()
139        };
140
141        let build = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
142            let mut apm = AudioProcessing::builder()
143                .config(apm_config)
144                .capture_config(config)
145                .render_config(config)
146                .build();
147            // Seed the delay estimate; clamping is fine (best-effort).
148            let _ = apm.set_stream_delay_ms(INITIAL_STREAM_DELAY_MS);
149            apm
150        }));
151
152        match build {
153            Ok(apm) => Some(Self {
154                inner: Mutex::new(apm),
155                config,
156            }),
157            Err(_) => {
158                tracing::error!(
159                    target: "audio_endpoint",
160                    "APM init panicked — falling back to pass-through (no AEC)"
161                );
162                None
163            }
164        }
165    }
166
167    /// Process one captured mic [`PcmFrame`] **in place**: AEC (subtract the render
168    /// reference) + noise suppression + gain. The 20 ms frame is split into 10 ms
169    /// APM chunks; each is processed in place. A frame whose length is not a whole
170    /// number of 10 ms chunks is left untouched (defensive — the live path always
171    /// hands exact 960-sample frames). The lock is held only for the short
172    /// processing call, never across IO.
173    pub fn process_capture(&self, frame: &mut PcmFrame) {
174        if !self.chunkable(&frame.samples) {
175            return;
176        }
177        // catch_unwind: a sonora panic here must degrade THIS frame to
178        // pass-through, not unwind the capture loop and kill the mic. The
179        // unwinding drop of the guard poisons the Mutex, so every later call
180        // takes the poisoned-lock pass-through — one-time failure, audio flows.
181        let processed = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
182            let Ok(mut apm) = self.inner.lock() else {
183                // A poisoned lock means a prior processing call panicked; degrade to
184                // pass-through rather than propagate (audio must keep flowing).
185                return;
186            };
187            let mut scratch = [0i16; APM_FRAME_SAMPLES];
188            for chunk in frame.samples.chunks_mut(APM_FRAME_SAMPLES) {
189                match apm.process_capture_i16(chunk, &mut scratch) {
190                    Ok(()) => chunk.copy_from_slice(&scratch),
191                    Err(e) => {
192                        // Out-of-range params clamp internally; a real error leaves the
193                        // chunk as captured. Log once-ish at debug (hot path).
194                        tracing::debug!(target: "audio_endpoint", "APM capture chunk error: {e}");
195                    }
196                }
197            }
198        }));
199        if processed.is_err() {
200            tracing::error!(
201                target: "audio_endpoint",
202                "APM capture processing panicked — pass-through from here on"
203            );
204        }
205    }
206
207    /// Feed one render (far-end / playout) [`PcmFrame`] to the APM as the echo
208    /// reference. Called **once per mix tick** by the [mixed-playout
209    /// bus](crate::audio::mix) with the SUMMED 10/20 ms chunk — the single
210    /// coherent stream the speaker plays. The APM accumulates it as the reverse
211    /// stream it subtracts from capture; output is discarded (we do not alter what
212    /// we play, only inform the canceller). Split into 10 ms chunks like capture.
213    ///
214    /// There is exactly one render feed by construction (the bus), so AEC works for
215    /// any number of peers — no per-source gate. (Before the bus, N per-peer pumps
216    /// fed this directly and the interleaved references corrupted AEC3; that gate
217    /// is gone.)
218    pub fn process_render(&self, frame: &PcmFrame) {
219        if !self.chunkable(&frame.samples) {
220            return;
221        }
222        // Same unwind guard as capture: this runs on the RT mix thread, where a
223        // panic would take down the whole playout bus.
224        let processed = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
225            let Ok(mut apm) = self.inner.lock() else {
226                return;
227            };
228            let mut scratch = [0i16; APM_FRAME_SAMPLES];
229            for chunk in frame.samples.chunks(APM_FRAME_SAMPLES) {
230                if let Err(e) = apm.process_render_i16(chunk, &mut scratch) {
231                    tracing::debug!(target: "audio_endpoint", "APM render chunk error: {e}");
232                }
233            }
234        }));
235        if processed.is_err() {
236            tracing::error!(
237                target: "audio_endpoint",
238                "APM render processing panicked — pass-through from here on"
239            );
240        }
241    }

243    /// Hint the APM that the processed capture output is (not) being consumed —
244    /// driven from the mute flag. While unused, AGC2 stops adapting its gain and
245    /// the noise/speech-level estimators hold, so a long mute over keyboard
246    /// clatter does not retune the gain the first unmuted word is played at.
247    /// Capture frames must still be PROCESSED while muted (AEC3's delay tracking
248    /// needs the cadence); this only freezes adaptation.
249    pub fn set_capture_output_used(&self, used: bool) {
250        if let Ok(mut apm) = self.inner.lock() {
251            apm.set_capture_output_used(used);
252        }
253    }
254
255    /// Live-retune noise suppression: `None` disables it (the ML suppressor owns
256    /// the frame), `Some(level)` selects the classic suppressor's depth. Applied
257    /// via `apply_config` — AEC3/AGC2 state survives, no rebuild.
258    pub fn set_noise_suppression(&self, level: Option<NoiseSuppressionLevel>) {
259        if let Ok(mut apm) = self.inner.lock() {
260            let mut config = apm.config().clone();
261            config.noise_suppression = level.map(|level| NoiseSuppression {
262                level,
263                ..Default::default()
264            });
265            apm.apply_config(config);
266        }
267    }
268
269    /// Live-toggle AGC2 (adaptive digital gain). Off leaves the mic at its raw
270    /// device level — the escape hatch for a user whose mic the estimator
271    /// misjudges. Same `apply_config` route as noise suppression.
272    pub fn set_agc_enabled(&self, enabled: bool) {
273        if let Ok(mut apm) = self.inner.lock() {
274            let mut config = apm.config().clone();
275            config.gain_controller2 = enabled.then(|| GainController2 {
276                adaptive_digital: Some(Default::default()),
277                ..Default::default()
278            });
279            apm.apply_config(config);
280        }
281    }
282
283    /// Manual input trim in dB, applied after the rest of the capture chain via
284    /// the capture-level adjuster's post gain (which the base config enables at
285    /// unity for exactly this). Clamped to ±12 dB: enough to rescue a mis-leveled
286    /// mic, not enough to be a foot-gun.
287    pub fn set_input_gain_db(&self, gain_db: f32) {
288        if let Ok(mut apm) = self.inner.lock() {
289            let factor = 10f32.powf(gain_db.clamp(-12.0, 12.0) / 20.0);
290            apm.set_capture_post_gain(factor);
291        }
292    }
293
294    /// Whether `samples` is mono and a whole number of 10 ms APM chunks (so it can
295    /// be split cleanly). The live path always satisfies this (960 = 2 × 480);
296    /// anything else is passed through unprocessed.
297    fn chunkable(&self, samples: &[i16]) -> bool {
298        self.config.num_channels() == CHANNELS.count()
299            && !samples.is_empty()
300            && samples.len().is_multiple_of(APM_FRAME_SAMPLES)
301    }
302}

323    /// Smoke: init, process synthetic render + capture frames, output stays sane
324    /// (finite, in i16 range, same length — never NaN/garbage or a length change).
325    #[test]
326    fn smoke_process_capture_and_render() {
327        let apm = Apm::new().expect("APM builds headless");
328
329        // A 440 Hz-ish tone as the far-end (render) reference.
330        let render: Vec<i16> = (0..SAMPLES_PER_FRAME)
331            .map(|i| ((i as f32 * 0.1).sin() * 8000.0) as i16)
332            .collect();
333        apm.process_render(&frame(render));

335        // Mic capture: some near-end speech-ish signal.
336        let mut cap = frame(

339                .collect(),

341        let before_len = cap.samples.len();
342        apm.process_capture(&mut cap);
343
344        assert_eq!(cap.samples.len(), before_len, "frame length preserved");

352    /// Speech-shaped test block: a pitch-harmonic stack under a syllabic envelope
353    /// with a noise floor — enough structure for AGC2's RNN VAD to call it speech
354    /// (a bare sine is the textbook non-speech signal, see the DTX tests).
355    fn speech_like_frame(idx: u64, peak: f32) -> PcmFrame {
356        let mut st = 0x9E37_79B9_7F4A_7C15u64 ^ idx.wrapping_mul(0x2545_F491_4F6C_DD1D);
357        let samples: Vec<i16> = (0..SAMPLES_PER_FRAME)
358            .map(|i| {
359                let t =
360                    (idx * SAMPLES_PER_FRAME as u64 + i as u64) as f32 / SAMPLE_RATE.hz() as f32;
361                // ~3 Hz syllabic amplitude modulation.
362                let envelope = 0.55 + 0.45 * (2.0 * std::f32::consts::PI * 3.0 * t).sin();
363                // 120 Hz fundamental + harmonics, roughly 1/n rolloff.
364                let mut v = 0.0f32;
365                for h in 1..=6 {
366                    v += ((2.0 * std::f32::consts::PI * 120.0 * h as f32 * t).sin()) / h as f32;
367                }
368                st ^= st << 13;
369                st ^= st >> 7;
370                st ^= st << 17;
371                let noise = ((st >> 11) as f32 / (1u64 << 53) as f32) * 2.0 - 1.0;
372                let s = (v / 2.0 * envelope + noise * 0.02) * peak;
373                (s.clamp(-1.0, 1.0) * i16::MAX as f32) as i16
374            })
375            .collect();
376        PcmFrame::at_engine_rate(samples, TimestampUs::from_micros(idx as i64 * 20_000))
377    }

379    /// **The loudness contract**: quiet speech in, levelled speech out. Feed
380    /// ~8 s of speech-shaped signal at a low level and assert AGC2 has applied
381    /// meaningful upward gain by the tail — and that its limiter never let a
382    /// sample clip. This is the test the missing `process_capture` wiring failed
383    /// silently for months; it pins the "quieter than Discord" fix.
384    #[test]
385    fn agc_levels_quiet_speech_without_clipping() {
386        let apm = Apm::new().expect("APM builds headless");
387        // ~-30 dBFS peak input: a quiet talker on an unboosted mic.
388        let quiet_peak = 0.03f32;
389        let frames = 400; // 8 s — AGC2 adapts at ~6 dB/s from a 15 dB initial gain.
390        let mut in_rms_late = 0.0f32;
391        let mut out_rms_late = 0.0f32;
392        let mut clipped = 0usize;
393        for n in 0..frames {
394            // Keep the render side ticking silence like the live bus does.
395            apm.process_render(&frame(vec![0i16; SAMPLES_PER_FRAME]));
396            let mut f = speech_like_frame(n, quiet_peak);
397            let in_rms = f.rms();
398            apm.process_capture(&mut f);
399            clipped += f
400                .samples
401                .iter()
402                .filter(|&&s| s == i16::MIN || s == i16::MAX)
403                .count();
404            if n >= frames - 50 {
405                in_rms_late += in_rms;
406                out_rms_late += f.rms();
407            }
408        }
409        in_rms_late /= 50.0;
410        out_rms_late /= 50.0;
411        let gain_db = 20.0 * (out_rms_late / in_rms_late).log10();
412        assert!(
413            gain_db >= 6.0,
414            "AGC2 must lift quiet speech by a clearly audible margin \
415             (measured {gain_db:.1} dB late-frame gain; in {in_rms_late:.4} → out {out_rms_late:.4})"
416        );
417        assert_eq!(clipped, 0, "AGC2's limiter must never let samples clip");
418    }

420    /// The mute hint must not break processing: frames processed while the
421    /// output is flagged unused (muted) keep the capture cadence, and processing
422    /// resumes normally after unmute. (The echo test proves the cadence matters;
423    /// this proves the hint round-trips without wedging the chain.)
424    #[test]
425    fn mute_hint_keeps_the_chain_alive() {
426        let apm = Apm::new().expect("APM builds headless");
427        for n in 0..50 {
428            apm.process_render(&frame(vec![0i16; SAMPLES_PER_FRAME]));
429            let mut f = speech_like_frame(n, 0.1);
430            apm.process_capture(&mut f);
431        }
432        apm.set_capture_output_used(false);
433        for n in 50..150 {
434            apm.process_render(&frame(vec![0i16; SAMPLES_PER_FRAME]));
435            let mut f = speech_like_frame(n, 0.1);
436            apm.process_capture(&mut f);
437        }
438        apm.set_capture_output_used(true);
439        let mut post_rms = 0.0f32;
440        for n in 150..200 {
441            apm.process_render(&frame(vec![0i16; SAMPLES_PER_FRAME]));
442            let mut f = speech_like_frame(n, 0.1);
443            apm.process_capture(&mut f);

445                post_rms += f.rms();

447        }
448        post_rms /= 10.0;

465    /// Echo-shaped test: when the captured signal is a delayed/attenuated copy of
466    /// the render reference (pure echo, no near-end voice), the APM should
467    /// measurably attenuate the captured energy as AEC3 converges. The canceller is
468    /// adaptive, so we feed many frames and assert the LATE frames are quieter than
469    /// the captured echo — with a generous bound (AEC3 needs convergence time and
470    /// this is a synthetic single-tap echo, not a real room).
471    #[test]
472    fn echo_reference_attenuates_capture() {
473        let apm = Apm::new().expect("APM builds headless");
474
475        // Far-end reference: a steady tone.
476        let make_tone = |phase: f32| -> Vec<i16> {
477            (0..SAMPLES_PER_FRAME)
478                .map(|i| (((i as f32 + phase) * 0.12).sin() * 10000.0) as i16)
479                .collect()
480        };
481
482        let mut captured_rms_late = 0.0f32;
483        let echo_input_rms = frame(make_tone(0.0)).rms();
484        let frames = 200; // ~4 s of audio — enough for AEC3 to converge.
485        for n in 0..frames {
486            let tone = make_tone(n as f32);
487            // Render the far end.
488            apm.process_render(&frame(tone.clone()));
489            // Capture == an attenuated copy of the far end (pure echo, no near-end).
490            let mut echo = frame(tone.iter().map(|&s| (s as i32 / 2) as i16).collect());
491            apm.process_capture(&mut echo);
492            if n >= frames - 20 {
493                captured_rms_late += echo.rms();
494            }
495        }
496        captured_rms_late /= 20.0;
497
498        // The processed echo (late frames) should be clearly below the raw echo
499        // input level. Half-amplitude echo has rms ≈ echo_input_rms/2; a converged
500        // AEC should push the residual well under that. Generous bound: at least
501        // some suppression below the un-attenuated reference level.
502        assert!(
503            captured_rms_late < echo_input_rms * 0.5,
504            "AEC should suppress the echo: late rms {captured_rms_late} vs reference {echo_input_rms}"
505        );
506    }
