1//! # Synthetic audio source (mic-free test source)
2//!
3//! An [`AudioInput`] that fabricates a continuous SPEECH-LIKE signal at the
4//! engine's fixed 20 ms/48 kHz mono PCM contract, without any microphone — the
5//! audio counterpart to [`super::synthetic::SyntheticCapturer`]. Lets a
6//! headless client (a bot with no audio hardware) still publish a mic track.
7//!
8//! ## Why not a plain sine — the VAD trap
9//! This used to emit a bare 440 Hz tone, and that quietly defanged a CI gate.
10//! Opus gates **DTX** (discontinuous transmission) on SILK's *voice activity
11//! detector*, not on energy, and a mathematically pure steady sine is the
12//! textbook non-speech signal: a single spectral line, no envelope, no noise
13//! floor. Measured, the old tone was coded for ~1 s and then suppressed to
14//! 1-byte comfort-noise packets for ~77% of frames.
15//!
16//! Frame counts kept growing (suppressed packets are still published), so no
17//! test turned red — but the receiver's mix slot then released
18//! sub-`SILENCE_FLOOR` audio, so `crate::audio::starve` correctly classified
19//! every synthetic peer as SILENT and stopped counting dry carries. That is
20//! exactly the signal `hound_client::call_health` gates on, so
21//! `expect_steady_audio` and houndbot's nightly verdict lost their teeth
22//! against real stutter. A test source has to stay *audible to the codec*, not
23//! merely non-zero.
24//!
25//! ## The signal
26//! Three ingredients, each earning its place against the VAD (see
27//! [`sample_at`]), and all a pure function of the absolute sample index so the
28//! waveform is bit-identical run to run:
29//! * **Voiced harmonics** — a [`F0_HZ`] fundamental plus 2nd/3rd harmonics whose
30//!   weights rotate slowly, giving a moving spectral centroid (a crude formant
31//!   sweep) instead of one static line.
32//! * **Syllable envelope** — [`SYLLABLE_HZ`] amplitude modulation, the rate real
33//!   speech energy rises and falls. It dips to [`ENV_FLOOR`], never to silence:
34//!   genuine speech gaps would be legitimately DTX-suppressed, which is the
35//!   behaviour we are trying to keep out of the harness.
36//! * **Noise floor** — deterministic LCG dither ([`NOISE_GAIN`]). Real capture
37//!   always has one, and broadband energy is the strongest single cue moving
38//!   SILK off "pure tone".
39//!
40//! ## Timing contract
41//! Mirrors [`super::synthetic::SyntheticCapturer::next_frame`]: [`Self::next_frame`]
42//! paces itself to one [`SAMPLES_PER_FRAME`]-sample frame by sleeping the
43//! remainder of the 20 ms interval since the last emit — so the delivered
44//! cadence reflects real time (a real mic's callback rate) rather than
45//! free-running as fast as the caller pulls.
46

59/// One 20 ms frame interval — the engine's fixed audio framing (see [`FRAME_MS`]).
60const FRAME_INTERVAL: Duration = Duration::from_millis(FRAME_MS as u64);
61
62/// Voiced fundamental. A speech-range pitch rather than concert A — with the
63/// harmonics below it reads as a steady vowel/buzz, still obviously synthetic to
64/// a human listening in on a bot call.
65const F0_HZ: f64 = 150.0;
66/// Syllable rate of the amplitude envelope. Real speech energy rises and falls at
67/// roughly 3–5 Hz; the VAD's energy-dynamics test keys on exactly this.
68const SYLLABLE_HZ: f64 = 4.0;
69/// Rate at which the harmonic weights rotate, sweeping the spectral centroid.
70/// Deliberately incommensurate with [`SYLLABLE_HZ`] so the two never lock into a
71/// short repeating pattern.
72///
73/// 0.73, not 0.70: at 0.7 the ratio to [`SYLLABLE_HZ`] is 7:40, which repeats
74/// exactly every 10 s — inside the 30 s window
75/// `dtx_never_suppresses_the_synthetic_capture_source` measures over, so a VAD
76/// that learned the loop had 20 s to act on it. 73:400 pushes the repeat out to
77/// 100 s, past any window we assert on.
78const FORMANT_HZ: f64 = 0.73;
79/// Floor of the syllable envelope, as a fraction of full amplitude. NOT zero: a
80/// true silence gap is legitimately DTX-suppressed, and suppression is the thing
81/// this source exists to avoid (see the module doc).
82const ENV_FLOOR: f64 = 0.4;
83/// Peak amplitude of the voiced part, as a fraction of full scale — audible
84/// without clipping or reading as a hot/faulty signal.
85const VOICED_PEAK: f64 = 0.25;
86/// Broadband noise floor, as a fraction of full scale (~2%). Enough to look like
87/// a real capture's noise floor to SILK; far too low to be heard as hiss over the
88/// voiced part.
89const NOISE_GAIN: f64 = 0.02;
90
91/// Deterministic dither in `-1.0..1.0` for one absolute sample index (the upper
92/// bound is exclusive: the LCG yields 31 bits scaled by `2^-31`, so `+1.0` is
93/// unreachable).
94///
95/// A stateless LCG *hash* of the index rather than a running generator: the
96/// waveform must be a pure function of position, so a source that reopens
97/// mid-call continues the same signal instead of restarting a noise sequence.
98/// Constants are the standard 64-bit LCG multiplier/increment; the high bits are
99/// taken because an LCG's low bits are weakly random.
100fn dither(idx: u64) -> f64 {
101    let x = idx
102        .wrapping_mul(6364136223846793005)
103        .wrapping_add(1442695040888963407);
104    let bits = (x >> 33) as u32; // 31 usable bits
105    (bits as f64 / (1u32 << 31) as f64) * 2.0 - 1.0
106}
107
108/// One sample of the synthetic voice at absolute index `idx`. Pure — the whole
109/// signal is defined by this function, so tests can evaluate it without pacing.
110///
111/// `pub(crate)` so the Opus codec tests can encode the REAL source signal rather
112/// than a copy of it: the guard that DTX never suppresses synthetic clients is
113/// worthless if it drifts from what the source actually emits.
114pub(crate) fn sample_at(idx: u64) -> i16 {
115    use std::f64::consts::PI;
116    let t = idx as f64 / SAMPLE_RATE.hz() as f64;
117    let w = 2.0 * PI * F0_HZ * t;
118
119    // Rotating harmonic weights: the 2nd and 3rd move in opposition, so the
120    // spectral centroid sweeps instead of sitting still like a tone's.
121    let sweep = (2.0 * PI * FORMANT_HZ * t).sin();
122    let voiced = w.sin() + 0.5 * (1.0 + 0.5 * sweep) * (2.0 * w).sin()
123        - 0.25 * (1.0 - 0.5 * sweep) * (3.0 * w).sin();
124    // Worst-case |voiced| = 1 + 0.75 + 0.375; normalise so VOICED_PEAK is the
125    // real ceiling and the sum can never clip.
126    const VOICED_NORM: f64 = 1.0 + 0.75 + 0.375;
127
128    // Syllable envelope in ENV_FLOOR..=1.0 (raised cosine, never reaching zero).
129    let env = ENV_FLOOR + (1.0 - ENV_FLOOR) * 0.5 * (1.0 - (2.0 * PI * SYLLABLE_HZ * t).cos());
130
131    let v = voiced / VOICED_NORM * VOICED_PEAK * env + dither(idx) * NOISE_GAIN;
132    (v.clamp(-1.0, 1.0) * i16::MAX as f64) as i16
133}

135/// Generates a continuous speech-like signal as fixed 20 ms 48 kHz mono PCM
136/// frames. Open is construct ([`Self::open`]): a value that exists is producing.
137pub(crate) struct SyntheticAudioInput {
138    clock: hound_media::CaptureClock,
139    /// Running sample index — never resets, so the signal stays continuous across
140    /// frames (no seam/click at frame boundaries) in phase, envelope and dither
141    /// alike, all three being pure functions of it (see [`sample_at`]).
142    sample_idx: u64,
143    /// Next emission deadline — an ABSOLUTE schedule advanced by exactly
144    /// [`FRAME_INTERVAL`] per frame, never re-anchored to the wakeup time.
145    /// Re-anchoring folds the sleep overshoot (~0.1–1 ms/tick) into every
146    /// period: a clock a few percent slow that steadily drains the receiving
147    /// peer's jitter buffer (observed as 1–2 mix starves/sec in the e2e call).
148    /// A hardware device clock delivers exactly 48 kHz long-run; so must this.
149    /// `None` before the first frame.
150    next_emit: Option<Instant>,
151}
152
153impl SyntheticAudioInput {
154    /// Begin producing the continuous speech-like signal, stamped on `clock`.
155    /// Infallible in practice — kept `Result` to mirror the real device opener it
156    /// stands in for.
157    pub(crate) fn open(clock: hound_media::CaptureClock) -> Result<Self, AudioError> {
158        tracing::info!(
159            f0_hz = F0_HZ,
160            syllable_hz = SYLLABLE_HZ,
161            "synthetic audio source started: speech-like voiced signal (VAD-active, \
162             so Opus DTX does not suppress it), 48 kHz mono — no microphone"
163        );
164        Ok(Self {
165            clock,
166            sample_idx: 0,
167            next_emit: None,
168        })
169    }
170}
171
172impl sealed::Sealed for SyntheticAudioInput {}
173
174impl AudioInput for SyntheticAudioInput {
175    fn next_frame(&mut self) -> Result<PcmFrame, AudioError> {
176        // Pace one 20 ms frame per call against the absolute schedule (see
177        // `next_emit`): sleep until the deadline, then advance it by exactly
178        // one interval. If the caller fell far behind (paused under a
179        // debugger, descheduled), resync rather than emitting an unbounded
180        // catch-up burst.
181        let interval = FRAME_INTERVAL;
182        let deadline = self.next_emit.unwrap_or_else(Instant::now);
183        if let Some(remaining) = deadline.checked_duration_since(Instant::now()) {
184            std::thread::sleep(remaining);
185        }
186        let behind = Instant::now().saturating_duration_since(deadline);
187        self.next_emit = Some(if behind > 4 * interval {
188            Instant::now() + interval
189        } else {
190            deadline + interval
191        });
192
193        let samples: Vec<i16> = (0..SAMPLES_PER_FRAME)
194            .map(|i| sample_at(self.sample_idx + i as u64))
195            .collect();
196        self.sample_idx = self.sample_idx.wrapping_add(SAMPLES_PER_FRAME as u64);
197
198        let captured_at = Instant::now();
199        let timestamp_us = TimestampUs::from_micros(self.clock.stamp(captured_at));
200
201        Ok(PcmFrame::at_engine_rate(samples, timestamp_us))
202    }
203
204    fn negotiated(&self) -> (SampleRate, ChannelCount) {
205        (SAMPLE_RATE, CHANNELS)
206    }
207}

209#[cfg(test)]
210mod tests {
211    use super::*;
212
213    fn started() -> SyntheticAudioInput {
214        SyntheticAudioInput::open(hound_media::CaptureClock::start()).expect("open")
215    }
216
217    #[test]
218    fn emits_engine_rate_mono_frames() {
219        let mut src = started();
220        let f = src.next_frame().expect("frame");
221        assert_eq!(f.samples.len(), SAMPLES_PER_FRAME);
222        assert_eq!(f.sample_rate, SAMPLE_RATE);
223        assert_eq!(f.channels, CHANNELS);
224        assert_eq!(src.negotiated(), (SAMPLE_RATE, CHANNELS));
225    }
226
227    #[test]
228    fn signal_is_not_silence_and_stays_in_range() {
229        let mut src = started();
230        let f = src.next_frame().expect("frame");
231        assert!(
232            f.samples.iter().any(|&s| s != 0),
233            "synthetic signal must not be silent"
234        );
235        assert!(
236            f.samples
237                .iter()
238                .all(|&s| s.unsigned_abs() <= i16::MAX as u16)
239        );
240    }
241
242    /// Every frame must stay loud enough that the receiver's mix bus reads the peer
243    /// as ACTIVE. `crate::audio::starve::SILENCE_FLOOR` is a peak-|sample| threshold;
244    /// a slot below it is treated as a silent peer and its dry carries stop counting
245    /// as stutter — which is how `call_health`'s starvation gate loses its teeth.
246    /// The envelope floor ([`ENV_FLOOR`]) exists to hold this at the syllable dips,
247    /// so check a whole envelope period, not one frame.
248    #[test]
249    fn every_frame_stays_above_the_starve_silence_floor() {
250        use crate::audio::starve::SILENCE_FLOOR;
251        // A full syllable period at 4 Hz is 250 ms = 12.5 frames; cover several.
252        for frame in 0..60u64 {
253            let base = frame * SAMPLES_PER_FRAME as u64;
254            let peak = (0..SAMPLES_PER_FRAME)
255                .map(|i| sample_at(base + i as u64).unsigned_abs() as i32)
256                .max()
257                .unwrap_or(0);
258            assert!(
259                peak > SILENCE_FLOOR * 4,
260                "frame {frame}: peak {peak} must clear SILENCE_FLOOR ({SILENCE_FLOOR}) with \
261                 margin, or the mix bus reads synthetic peers as silent and the audio-health \
262                 gate stops detecting stutter"
263            );
264        }
265    }
266
267    /// The signal is a pure function of the absolute sample index — no running RNG
268    /// state — so a reopened source continues the same waveform rather than
269    /// restarting a noise sequence, and every run is bit-identical.
270    #[test]
271    fn signal_is_deterministic_and_position_addressed() {
272        let a: Vec<i16> = (0..500).map(sample_at).collect();
273        let b: Vec<i16> = (0..500).map(sample_at).collect();
274        assert_eq!(a, b, "same index must always give the same sample");
275        // Position-addressed: evaluating a later window directly matches walking to it.
276        let mid: Vec<i16> = (200..300).map(sample_at).collect();
277        assert_eq!(mid, a[200..300], "a window depends only on its position");
278    }
279
280    /// The dither is broadband, not a constant — the ingredient that moves SILK off
281    /// "pure tone". A stuck LCG would silently reintroduce the DTX trap.
282    #[test]
283    fn dither_is_broadband_and_bounded() {
284        let vals: Vec<f64> = (0..4096).map(dither).collect();
285        assert!(
286            vals.iter().all(|v| (-1.0..1.0).contains(v)),
287            "dither must stay in [-1, 1)"
288        );
289        // A stuck-generator guard, not a uniformity test: bucketed to 0.001 there are
290        // ~2000 possible values and 4096 draws, so collisions are expected (measured
291        // ~999 distinct). Anything near-constant lands orders of magnitude below this.
292        let distinct = vals
293            .iter()
294            .map(|v| (v * 1000.0) as i64)
295            .collect::<std::collections::HashSet<_>>()
296            .len();
297        assert!(distinct > 500, "dither must vary widely, got {distinct}");
298        let mean = vals.iter().sum::<f64>() / vals.len() as f64;
299        assert!(mean.abs() < 0.05, "dither must be ~zero-mean, got {mean}");
300    }
301
302    #[test]
303    fn phase_is_continuous_across_frames() {
304        // The accumulator never resets, so consecutive frames are two windows of
305        // the SAME continuous wave rather than two independent (seamed) buffers.
306        let mut src = started();
307        let a = src.next_frame().expect("a");
308        let b = src.next_frame().expect("b");
309        assert_ne!(a.samples, b.samples, "successive frames must differ");
310    }
