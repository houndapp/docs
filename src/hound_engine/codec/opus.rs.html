1//! # Opus encode / decode (libopus via `audiopus`)
2//!
3//! The runnable codec for the native audio endpoint. [`OpusEncoder`] turns a
4//! 20 ms [`PcmFrame`] (960 samples @ 48 kHz mono i16) into one [`OpusPacket`];
5//! [`OpusDecoder`] reverses it, including PLC (packet-loss concealment) on a
6//! `None` packet. Both wrap `audiopus`, which bundles libopus from source (no
7//! system lib / cmake / pkg-config — see `Cargo.toml`).
8//!
9//! ## Config (the endpoint's contract)
10//! * **48 kHz, mono** — Opus's native rate, no internal resample, half-bitrate
11//!   of stereo for voice.
12//! * **20 ms / 960-sample frames** — [`SAMPLES_PER_FRAME`].
13//! * **Per-source application mode** ([`OpusProfile`]) — `Voip` (speech-optimised)
14//!   for the mic, `Audio` (general-audio) for shared screen/system audio. Using
15//!   the speech mode on music is what makes it sound thin/"old-codec".
16//! * **Configurable bitrate** — ~24 kbps for mono voice; music-grade (≥96 kbps)
17//!   for shared audio. The mode AND the rate must match the source.
18//! * **complexity 5** — mid; encode stays microseconds-cheap. (10 is max quality
19//!   / most CPU; for real-time voice 5 is a fine default and keeps headroom on
20//!   mobile.)
21//! * **FEC on, 10% expected loss** — in-band forward error correction so the
22//!   decoder can reconstruct a lost frame from the *next* packet. Harmless on the
23//!   lossless loopback; correct default for the MoQ transport step.
24//! * **DTX on the VOICE profile only** — discontinuous transmission. Once the mic
25//!   has been silent for libopus's hangover, the encoder stops spending bits on it
26//!   and returns a 1–2 byte packet (a TOC byte, sometimes plus a SILK comfort-noise
27//!   update) instead of a full ~60-byte frame. A call is mostly silence per
28//!   participant, so this is the single biggest cheap win on outbound voice bitrate.
29//!
30//!   The encoder emits those tiny packets; whether they reach the wire is the
31//!   PUBLISHER's call, not this module's. `hound-client`'s `call::policy::SilenceGate`
32//!   withholds most of them ([`DTX_MAX_BYTES`] is the shared size test) and publishes
33//!   at least one real DTX frame per keepalive interval (500 ms), because ~95% of a
34//!   silent track's cost is framing rather than payload — see that type for the full
35//!   rationale. Capture timestamps are never invented to paper over the hole, so the
36//!   receiver DOES have to distinguish suppression from loss: `audio_rx`'s
37//!   `classify_audio_gap` does it by size of the timestamp gap, concealing only gaps
38//!   within `MAX_PLC_FRAMES` and playing silence across anything longer. Suppression
39//!   is a wire policy: this encoder still returns a packet for every frame it is
40//!   handed, and the decoder still turns a 1-byte packet into comfort noise.
41//!
42//!   **Not enabled for [`OpusProfile::Music`]** (the shared screen/system-audio
43//!   leg). It is a myth that DTX is inert outside SILK: modern libopus implements
44//!   DTX in CELT too, and measured on this encoder a 96 kbps fullband silent input
45//!   collapses to 1-byte packets exactly like voice. That is a real behaviour
46//!   change on shared audio, and the thing it risks is not bandwidth but the
47//!   *silence boundary* — music and video have quiet passages, fades and inter-track
48//!   gaps where clipping the tail into comfort noise is audible in a way a talker's
49//!   pause is not. Enabling it there is future work, gated on a listening check of
50//!   fade-outs and track boundaries; until then the music leg pays full rate for
51//!   silence, which is the conservative trade.
52//!
53//!   The receive side is already built for this: the mix bus's starvation
54//!   classifier (`crate::audio::starve`) only counts a dry playout carry as
55//!   stutter when real audio played recently, so a silent peer's DTX gaps do not
56//!   register as an audio glitch.
57//!
58//! ## Real-time safety
59//! `encode`/`decode` run on a worker thread, never the cpal device callback.
60//! Each call writes into a reused scratch buffer (`Vec<u8>`) and then clones the
61//! exact-length slice into the packet — Opus encode at 24 kbps is well under a
62//! few hundred bytes, so the one alloc per packet is trivial and off the RT
63//! thread. (A zero-alloc pool is a production refinement, not needed for the
64//! endpoint.)
65

78/// Largest encoded payload (bytes) this encoder produces that is **DTX output rather
79/// than coded signal** — the one number that separates "the encoder gave up on this
80/// frame" from "the encoder is spending bits", without anyone having to look at the
81/// audio.
82///
83/// It lives here, on the codec, because only the encoder's measured behaviour can
84/// justify it — and it is deliberately ONE constant for the whole stack: the
85/// publisher's silence gate uses it to decide what not to send, the receiver to decide
86/// that an arriving frame carries no speech (so the peer's level meter must read 0)
87/// and that the hold is worth draining. One constant, one meaning.
88///
89/// Measured on this encoder (24 kbps, `OpusProfile::Voice`), the size distribution is
90/// sharply bimodal with nothing in between:
91///
92/// | input | steady-state packet sizes |
93/// |---|---|
94/// | bit-exact digital silence | 1 B, with an 8 B SILK refresh every ~20 frames |
95/// | room tone, −70…−55 dBFS | 1 B, with a **fully coded 36–57 B** refresh every ~21 frames |
96/// | coded speech / any real signal | ≥36 B |
97///
98/// So 10 clears the 8 B digital-silence refresh with margin and sits far below the
99/// smallest coded frame ever observed. `the_dtx_threshold_straddles_the_encoders_own_gap`
100/// re-measures both edges against the live encoder rather than against literals.
101///
102/// Note what the table says about the refresh: it is only ~8 B when the input is
103/// bit-exact zeros. Give the encoder any noise floor at all — i.e. a real microphone —
104/// and the periodic refresh is a *fully coded* frame that lands well above this
105/// threshold. That is why the publisher's gate needs hysteresis on the way down
106/// (`SilenceGate::RESUME_AFTER`) rather than treating one coded frame as speech.
107pub const DTX_MAX_BYTES: usize = 10;

109/// What the encoder is tuned for. Opus's `Application` mode materially changes
110/// how it sounds: `Voip` applies speech-optimised psychoacoustics (great for a
111/// mic, but it crushes music into a thin, "old-codec" sound), while `Audio`
112/// preserves general-audio fidelity (the right choice for shared screen/system
113/// audio). Pick by the source, not globally.
114#[derive(Clone, Copy, Debug, PartialEq, Eq)]
115pub enum OpusProfile {
116    /// A microphone / speech — `Application::Voip`.
117    Voice,
118    /// General audio (shared window/system audio: music, video) — `Application::Audio`.
119    Music,
120}
121
122impl OpusProfile {
123    fn application(self) -> Application {
124        match self {
125            OpusProfile::Voice => Application::Voip,
126            OpusProfile::Music => Application::Audio,
127        }
128    }
129
130    /// Whether to run the encoder with DTX. Speech only — see the module docs: DTX
131    /// is NOT SILK-exclusive, so leaving it on for `Music` would really collapse a
132    /// shared track's quiet passages, and that silence boundary needs a listening
133    /// check before we ship it.
134    fn dtx(self) -> bool {
135        match self {
136            OpusProfile::Voice => true,
137            OpusProfile::Music => false,
138        }
139    }
140}

142/// Max bytes an Opus packet for one 20 ms frame can occupy. libopus's documented
143/// upper bound is 1275 bytes/frame for a single stream; we size the scratch
144/// buffer to 1500 for headroom. The encoder returns the true length.
145const MAX_PACKET_BYTES: usize = 1500;

147fn opus_err(context: &str, e: audiopus::Error) -> AudioError {
148    AudioError::Codec(format!("{context}: {e}"))
149}

151/// Opus encoder for the endpoint (48 kHz mono VOIP, 20 ms frames).
152pub struct OpusEncoder {
153    enc: OpusEnc,
154    /// Reused encode scratch so the per-frame path does not allocate the output
155    /// buffer each call (only the final exact-length packet `Vec` is allocated).
156    scratch: Vec<u8>,
157}
158
159impl OpusEncoder {
160    /// Build an encoder at `bitrate`, tuned by [`OpusProfile`] (speech vs music),
161    /// with FEC enabled. Use [`OpusProfile::Voice`] for the mic and
162    /// [`OpusProfile::Music`] for shared screen/system audio.
163    pub fn new(bitrate: Bitrate, profile: OpusProfile) -> Result<Self, AudioError> {
164        // CHANNELS is a compile-time const; map it to the Opus enum.
165        let channels = match CHANNELS.count() {
166            1 => Channels::Mono,
167            2 => Channels::Stereo,
168            n => return Err(AudioError::UnsupportedFormat(format!("{n} channels"))),
169        };
170
171        let mut enc = OpusEnc::new(OpusSampleRate::Hz48000, channels, profile.application())
172            .map_err(|e| opus_err("opus encoder init", e))?;
173
174        enc.set_bitrate(audiopus::Bitrate::BitsPerSecond(bitrate.bps() as i32))
175            .map_err(|e| opus_err("set bitrate", e))?;
176        // Mid complexity — plenty fast, leaves CPU headroom on mobile.
177        enc.set_complexity(5)
178            .map_err(|e| opus_err("set complexity", e))?;
179        // In-band FEC + an expected-loss hint so FEC actually engages. Lossless
180        // on the loopback; the right default for the MoQ transport step.
181        enc.set_inband_fec(true)
182            .map_err(|e| opus_err("set fec", e))?;
183        enc.set_packet_loss_perc(10)
184            .map_err(|e| opus_err("set loss perc", e))?;
185        // Discontinuous transmission, SPEECH ONLY: silence collapses to a ~1 byte
186        // packet after the hangover instead of a full frame. See the module docs for
187        // why those packets are still published (continuous timestamps + decoder
188        // comfort noise) and why the music profile deliberately opts out.
189        enc.set_dtx(profile.dtx())
190            .map_err(|e| opus_err("set dtx", e))?;
191
192        Ok(Self {
193            enc,
194            scratch: vec![0u8; MAX_PACKET_BYTES],
195        })
196    }
197
198    /// Encode one PCM frame to one Opus packet (1:1 — no look-ahead reorder
199    /// like the video encoders).
200    pub fn encode(&mut self, frame: &PcmFrame) -> Result<OpusPacket, AudioError> {
201        let expected = SAMPLES_PER_FRAME * CHANNELS.count() as usize;
202        if frame.samples.len() != expected {
203            // Opus only accepts exact frame sizes; a wrong-size frame is a
204            // pipeline bug (the capturer must chunk to SAMPLES_PER_FRAME).
205            return Err(AudioError::UnsupportedFormat(format!(
206                "opus frame must be {expected} samples ({}ms @ {}Hz mono), got {}",
207                FRAME_MS,
208                SAMPLE_RATE.hz(),
209                frame.samples.len()
210            )));
211        }
212        let n = self
213            .enc
214            .encode(&frame.samples, &mut self.scratch)
215            .map_err(|e| opus_err("opus encode", e))?;
216        Ok(OpusPacket {
217            data: self.scratch[..n].to_vec(),
218            timestamp_us: frame.timestamp_us,
219        })
220    }
221
222    /// Retarget the Opus bitrate live. Best-effort, cheap and lossless
223    /// mid-stream for Opus (a BWE loop can drive this).
224    pub fn set_bitrate(&mut self, bitrate: Bitrate) -> Result<(), AudioError> {
225        self.enc
226            .set_bitrate(audiopus::Bitrate::BitsPerSecond(bitrate.bps() as i32))
227            .map_err(|e| opus_err("set bitrate", e))
228    }
229}

231/// Opus decoder for the endpoint (48 kHz mono, 20 ms frames, PLC-capable).
232pub struct OpusDecoder {
233    dec: OpusDec,
234}
235
236impl OpusDecoder {
237    pub fn new() -> Result<Self, AudioError> {
238        let channels = match CHANNELS.count() {
239            1 => Channels::Mono,
240            2 => Channels::Stereo,
241            n => return Err(AudioError::UnsupportedFormat(format!("{n} channels"))),
242        };
243        let dec = OpusDec::new(OpusSampleRate::Hz48000, channels)
244            .map_err(|e| opus_err("opus decoder init", e))?;
245        Ok(Self { dec })
246    }
247
248    /// Decode one Opus packet to one PCM frame. `packet == None` ⇒ PLC
249    /// (conceal a lost frame). `timestamp_us` is propagated onto the output.
250    pub fn decode(
251        &mut self,
252        packet: Option<&OpusPacket>,
253        timestamp_us: TimestampUs,
254    ) -> Result<PcmFrame, AudioError> {
255        // Output buffer sized to one frame; for PLC (packet=None) Opus infers the
256        // frame length from this buffer's per-channel length, so it MUST be
257        // exactly one frame.
258        let mut out = vec![0i16; SAMPLES_PER_FRAME * CHANNELS.count() as usize];
259
260        // `audiopus` 0.3 wraps the buffers in checked newtypes: the payload (or
261        // None for PLC) becomes a `Packet`, the output a `MutSignals`; `fec=false`
262        // (we are not reconstructing from a *future* packet here — straight
263        // decode, or PLC when None).
264        let payload = packet
265            .map(|p| audiopus::packet::Packet::try_from(p.data.as_slice()))
266            .transpose()
267            .map_err(|e| opus_err("opus packet wrap", e))?;
268        let signals = audiopus::MutSignals::try_from(&mut out[..])
269            .map_err(|e| opus_err("opus output wrap", e))?;
270        let decoded = self
271            .dec
272            .decode(payload, signals, false)
273            .map_err(|e| opus_err("opus decode", e))?;
274
275        // `decoded` is samples-per-channel; for a well-formed 20 ms packet it is
276        // SAMPLES_PER_FRAME. Truncate defensively (a malformed packet could
277        // decode short — never read uninitialised tail).
278        let valid = decoded * CHANNELS.count() as usize;
279        out.truncate(valid.min(out.len()));
280
281        Ok(PcmFrame::at_engine_rate(out, timestamp_us))
282    }
283}

290    /// Deterministic 440 Hz sine, full one-frame block of i16 PCM. No RNG, no
291    /// device — the same input every run.
292    fn sine_frame() -> PcmFrame {
293        let mut samples = Vec::with_capacity(SAMPLES_PER_FRAME);
294        let freq = 440.0_f32;
295        for i in 0..SAMPLES_PER_FRAME {
296            let t = i as f32 / SAMPLE_RATE.hz() as f32;
297            // 0.5 full-scale so there is real energy but no clipping.
298            let v = (2.0 * PI * freq * t).sin() * 0.5;
299            samples.push((v * i16::MAX as f32) as i16);
300        }
301        PcmFrame::at_engine_rate(samples, TimestampUs::ZERO)
302    }

304    /// One frame of the SYNTHETIC CAPTURE SOURCE's signal — what every headless /
305    /// e2e client publishes as its mic. Calls the source's own
306    /// [`crate::platform::generic::synthetic_audio::sample_at`] rather than
307    /// reimplementing it, so this can never test a signal the source stopped
308    /// emitting. `frame_idx` walks the absolute sample index exactly as the running
309    /// source does.
310    fn synthetic_source_frame(frame_idx: u64) -> PcmFrame {
311        use crate::platform::generic::synthetic_audio::sample_at;
312        let base = frame_idx * SAMPLES_PER_FRAME as u64;
313        let samples: Vec<i16> = (0..SAMPLES_PER_FRAME)
314            .map(|i| sample_at(base + i as u64))
315            .collect();
316        PcmFrame::at_engine_rate(samples, TimestampUs::from_micros(frame_idx as i64 * 20_000))
317    }

319    /// A frame of digital silence (bit-exact zeros) at `ts_us` — what a muted room
320    /// delivers, and the only input DTX is allowed to collapse.
321    fn silent_frame(ts_us: i64) -> PcmFrame {
322        PcmFrame::at_engine_rate(
323            vec![0i16; SAMPLES_PER_FRAME * CHANNELS.count() as usize],
324            TimestampUs::from_micros(ts_us),
325        )
326    }

328    /// A SUPPRESSED frame: libopus emits 1 byte (the TOC alone), occasionally 2.
329    ///
330    /// The threshold that matters is not DTX-vs-speech (1 byte vs ~60 — trivially
331    /// separable) but DTX-vs-CODED SILENCE. With DTX off a silent 20 ms voice frame
332    /// still costs [`CODED_SILENCE_BYTES`], and that is exactly what this encoder
333    /// emits during the pre-DTX hangover — so a threshold set loosely above it would
334    /// pass on an encoder where DTX did nothing at all. Suppression is proven by
335    /// beating coded silence, not by being "small".
336    const DTX_SUPPRESSED_BYTES: usize = 2;
337
338    /// What a silent voice frame costs with DTX OFF (measured: the hangover frames
339    /// before suppression kicks in), and equally the periodic SILK comfort-noise
340    /// refresh on a bit-exact-zero input. The number the suppressed steady state must
341    /// beat. NOT the size of the refresh on a real mic — see [`DTX_MAX_BYTES`].
342    const CODED_SILENCE_BYTES: usize = 8;
343
344    /// Deterministic ROOM TONE at `dbfs` RMS: a real microphone's noise floor, which
345    /// is the input the publisher's silence gate actually sees. Distinct from
346    /// [`silent_frame`] — the encoder treats "bit-exact zeros" and "very quiet noise"
347    /// completely differently, and conflating the two is what makes a gate that works
348    /// in a test fail on a mic.
349    fn room_tone_frame(idx: u64, dbfs: f64) -> PcmFrame {
350        let amp = 10f64.powf(dbfs / 20.0) * i16::MAX as f64 * 1.7;
351        // xorshift64* seeded from the frame index: no RNG dependency, same bytes every
352        // run, and uncorrelated between frames (a repeating block would be coded once
353        // and then predicted away, which is not what a noise floor does).
354        let mut st = 0x9E37_79B9_7F4A_7C15u64 ^ idx.wrapping_mul(0x2545_F491_4F6C_DD1D);
355        let samples: Vec<i16> = (0..SAMPLES_PER_FRAME)
356            .map(|_| {
357                st ^= st << 13;
358                st ^= st >> 7;
359                st ^= st << 17;
360                let u = ((st >> 11) as f64 / (1u64 << 53) as f64) * 2.0 - 1.0;
361                (u * amp) as i16
362            })
363            .collect();
364        PcmFrame::at_engine_rate(samples, TimestampUs::from_micros(idx as i64 * 20_000))
365    }

367    fn energy(samples: &[i16]) -> f64 {
368        samples
369            .iter()
370            .map(|&s| (s as f64) * (s as f64))
371            .sum::<f64>()
372            / samples.len().max(1) as f64
373    }

375    /// THE proof that needs no device: feed a deterministic sine, encode to Opus,
376    /// decode back, and assert the round-trip preserves frame length, sample
377    /// rate, and ENERGY (the output is real audio, not silence). This is the
378    /// headless go/no-go for the codec leg of the endpoint.
379    #[test]
380    fn opus_round_trip_preserves_energy_and_shape() {
381        let frame = sine_frame();
382        let input_energy = energy(&frame.samples);
383        assert!(input_energy > 0.0, "test input must not be silent");
384
385        let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
386        let mut dec = OpusDecoder::new().expect("decoder");
387
388        let packet = enc.encode(&frame).expect("encode");
389        // A 20 ms voice frame at 24 kbps is on the order of tens of bytes — must
390        // be non-empty and within the single-frame upper bound.
391        assert!(
392            !packet.data.is_empty() && packet.data.len() < MAX_PACKET_BYTES,
393            "opus packet length sane: {}",
394            packet.data.len()
395        );
396        assert_eq!(packet.timestamp_us, frame.timestamp_us);
397
398        let out = dec
399            .decode(Some(&packet), packet.timestamp_us)
400            .expect("decode");
401
402        // Shape: exactly one frame back, at the endpoint's rate/channels.
403        assert_eq!(
404            out.samples.len(),
405            SAMPLES_PER_FRAME * CHANNELS.count() as usize
406        );
407        assert_eq!(out.sample_rate, SAMPLE_RATE);
408        assert_eq!(out.channels, CHANNELS);
409        assert_eq!(out.timestamp_us, frame.timestamp_us);
410
411        // Energy preserved: Opus is lossy, so we do not assert sample equality —
412        // we assert the decoded block carries comparable energy (NOT silence).
413        // A wide tolerance band (within ~12 dB either way) is the right test: it
414        // fails hard on silence/garbage but passes on legitimate lossy output.
415        let output_energy = energy(&out.samples);
416        let ratio = output_energy / input_energy;
417        assert!(
418            ratio > 0.25 && ratio < 4.0,
419            "decoded energy {output_energy:.0} vs input {input_energy:.0} (ratio {ratio:.3}) — \
420             expected within ~12 dB; far off means silence or corruption, not lossy codec drift"
421        );
422
423        // Explicit not-silence guard, independent of the input-relative ratio.
424        assert!(
425            out.rms() > 0.05,
426            "decoded RMS {} is ~silent — round trip lost the signal",
427            out.rms()
428        );
429    }

459    /// DTX: sustained silence must collapse to comfort-noise-sized packets. libopus
460    /// keeps coding for a hangover after the signal stops, so the assertion is on the
461    /// STEADY state — every packet past the hangover window, not the first few.
462    #[test]
463    fn opus_dtx_collapses_sustained_silence() {
464        let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
465
466        let sizes: Vec<usize> = (0..100)
467            .map(|i| {
468                enc.encode(&silent_frame(i as i64 * 20_000))
469                    .expect("encode silence")
470                    .data
471                    .len()
472            })
473            .collect();
474
475        // Past the hangover (~first 20 frames = 400 ms) every packet must be tiny.
476        let steady = &sizes[20..];
477        assert!(
478            steady.iter().all(|&n| n <= DTX_MAX_BYTES),
479            "DTX must collapse sustained silence to ≤{DTX_MAX_BYTES} bytes; steady-state \
480             sizes were {steady:?}"
481        );
482        // The load-bearing assertion: the steady state must be SUPPRESSED frames, not
483        // merely cheaply-coded silence. Without DTX every one of these would be
484        // CODED_SILENCE_BYTES, so a vast majority at ≤2 bytes is the thing that can
485        // only be true if suppression is really on. The remainder is the periodic
486        // comfort-noise refresh.
487        let suppressed = steady
488            .iter()
489            .filter(|&&n| n <= DTX_SUPPRESSED_BYTES)
490            .count();
491        assert!(
492            suppressed * 10 >= steady.len() * 9,
493            "≥90% of a silent steady state must be SUPPRESSED (≤{DTX_SUPPRESSED_BYTES} B); \
494             got {suppressed}/{} — coded silence would be {CODED_SILENCE_BYTES} B every \
495             frame, so this failing means DTX is not engaging: {steady:?}",
496            steady.len()
497        );
498        // Never zero-length: an empty payload is not a wire frame the decoder can
499        // take (`Packet::try_from` rejects it), so the encoder must always emit the
500        // TOC byte for the receiver to turn into comfort noise.
501        assert!(
502            steady.iter().all(|&n| n > 0),
503            "a DTX packet still carries its TOC byte"
504        );
505    }

507    /// **CI-sensitivity guard: DTX must NOT suppress the synthetic capture source.**
508    ///
509    /// The history this protects against. The synthetic mic used to emit a bare
510    /// 440 Hz sine, and Opus suppressed ~77% of it. DTX is gated on SILK's *voice
511    /// activity detector*, not on energy, and a mathematically pure steady tone is the
512    /// textbook non-speech signal — one spectral line, no envelope, no noise floor.
513    /// "It's never silent, so DTX can't touch it" is simply false.
514    ///
515    /// Nothing turned red, which is what made it dangerous. Frame COUNTS kept growing
516    /// (suppressed packets are still published) so `expect_audio_growth` was fine —
517    /// but the receiver's mix slot then released sub-`SILENCE_FLOOR` audio, so
518    /// `crate::audio::starve` correctly classified every synthetic peer as SILENT and
519    /// stopped counting dry carries. That is precisely the signal
520    /// `call_health::sample_call_health` gates on, so `expect_steady_audio` and
521    /// houndbot's nightly verdict silently lost their ability to detect real stutter.
522    ///
523    /// The source was fixed (speech-like envelope + harmonics + noise floor — see
524    /// `platform::generic::synthetic_audio`), and this asserts it STAYS fixed. It
525    /// encodes the source's own `sample_at`, so it cannot drift from reality.
526    ///
527    /// Threshold: measured 250/250 and 1500/1500 frames coded at full rate (zero
528    /// suppressed). Pinned at ≥98% rather than 100% to leave room for a brief VAD dip
529    /// across a syllable trough without flapping; a regression to tone-like behaviour
530    /// lands near 23% and fails by a mile.
531    #[test]
532    fn dtx_never_suppresses_the_synthetic_capture_source() {
533        /// 30 s at 20 ms/frame — long enough that a late-onset VAD decision (the old
534        /// tone gave up after ~1 s) cannot hide inside the window.
535        const FRAMES: u64 = 1500;
536        /// Fraction of frames that must be genuinely coded audio.
537        const MIN_CODED_PCT: usize = 98;
538
539        let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
540        let sizes: Vec<usize> = (0..FRAMES)
541            .map(|i| {
542                enc.encode(&synthetic_source_frame(i))
543                    .expect("encode synthetic source")
544                    .data
545                    .len()
546            })
547            .collect();
548
549        let coded = sizes.iter().filter(|&&n| n > DTX_MAX_BYTES).count();
550        eprintln!(
551            "DTX measurement: {coded}/{} frames coded ({:.1}%) over {} s",
552            sizes.len(),
553            coded as f64 * 100.0 / sizes.len() as f64,
554            FRAMES * 20 / 1000
555        );
556        assert!(
557            coded * 100 >= sizes.len() * MIN_CODED_PCT,
558            "the synthetic capture source must stay VAD-ACTIVE so Opus keeps coding it: \
559             only {coded}/{} frames were coded (<{MIN_CODED_PCT}%). Suppressed frames make \
560             every headless client read as a SILENT peer on the receiver's mix bus, which \
561             disables the starvation signal `expect_steady_audio` and houndbot's verdict \
562             depend on. Fix the SOURCE's signal (envelope / harmonics / noise floor), not \
563             this threshold.",
564            sizes.len()
565        );
566    }

568    /// **[`DTX_MAX_BYTES`] measured against the encoder, not against literals.**
569    ///
570    /// The threshold is only meaningful if the encoder's own output is bimodal around
571    /// it, so this drives both edges from libopus and asserts the gap straddles the
572    /// constant: everything DTX lands strictly below, everything coded strictly above,
573    /// and — the part a pair of hand-written literals can never check — the band
574    /// between the two is EMPTY, so the constant has margin on both sides rather than
575    /// sitting on top of a distribution.
576    #[test]
577    fn the_dtx_threshold_straddles_the_encoders_own_gap() {
578        let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
579        // Below: bit-exact silence past the hangover, plus room tone quiet enough that
580        // SILK's VAD calls it non-speech — the two inputs that legitimately produce DTX.
581        let mut dtx: Vec<usize> = (0..80u64)
582            .map(|i| {
583                enc.encode(&silent_frame(i as i64 * 20_000))
584                    .expect("enc")
585                    .data
586                    .len()
587            })
588            .collect();
589        dtx.drain(..20); // hangover
590        let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
591        let tone: Vec<usize> = (0..300u64)
592            .map(|i| {
593                enc.encode(&room_tone_frame(i, -65.0))
594                    .expect("enc")
595                    .data
596                    .len()
597            })
598            .collect();
599        // Above: real signal, at the QUIET end of it (a syllable, not a shout) — the
600        // side that would break first if the threshold crept upward.
601        let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
602        let coded: Vec<usize> = (0..300u64)
603            .map(|i| {
604                let mut f = synthetic_source_frame(i);
605                for s in &mut f.samples {
606                    *s /= 8; // ~−18 dB: still speech, nowhere near loud
607                }
608                enc.encode(&f).expect("enc").data.len()
609            })
610            .collect();
611
612        let all: Vec<usize> = dtx.iter().chain(&tone).chain(&coded).copied().collect();
613        let below = *all
614            .iter()
615            .filter(|&&n| n <= DTX_MAX_BYTES)
616            .max()
617            .unwrap_or(&0);
618        let above = *all
619            .iter()
620            .filter(|&&n| n > DTX_MAX_BYTES)
621            .min()
622            .unwrap_or(&usize::MAX);
623        eprintln!(
624            "DTX threshold: largest suppressed {below} B ≤ {DTX_MAX_BYTES} < smallest coded {above} B"
625        );
626        assert!(
627            coded.iter().all(|&n| n > DTX_MAX_BYTES),
628            "quiet speech must never read as DTX: {coded:?}"
629        );
630        assert!(
631            dtx.iter().all(|&n| n <= DTX_MAX_BYTES),
632            "sustained digital silence must always read as DTX: {dtx:?}"
633        );
634        // The gap itself. Measured 8 B below / 34 B above, so the constant has ~2 B of
635        // margin under it and ~24 B over it; requiring 2× headroom on the coded side
636        // fails long before a real regression makes the two modes touch.
637        assert!(
638            above >= DTX_MAX_BYTES * 2,
639            "the DTX/coded gap has collapsed: largest suppressed {below} B, smallest \
640             coded {above} B, threshold {DTX_MAX_BYTES} B. Re-measure the constant \
641             rather than nudging this test."
642        );
643    }

645    /// **What a real microphone's noise floor does to DTX**, and the fact the
646    /// publisher's silence gate is built around.
647    ///
648    /// On bit-exact zeros the periodic SILK refresh is [`CODED_SILENCE_BYTES`] and
649    /// stays under the threshold. Give the encoder ANY noise floor — i.e. any real room
650    /// — and that refresh is instead a fully coded 36–57 B frame, which reads as speech
651    /// to a naive size test. It is ISOLATED, though: measured 46/46 refreshes at −70 and
652    /// −60 dBFS were a single coded frame between runs of ~20 suppressed ones.
653    ///
654    /// That is precisely why `hound-client`'s `SilenceGate` needs a *run* of coded
655    /// frames to clear suppression rather than one. This pins the shape that
656    /// justifies it, so the client's modelled sequence cannot drift from the encoder.
657    #[test]
658    fn a_room_tone_refresh_is_one_isolated_coded_frame() {
659        for dbfs in [-70.0f64, -60.0] {
660            let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
661            let sizes: Vec<usize> = (0..1000u64)
662                .map(|i| {
663                    enc.encode(&room_tone_frame(i, dbfs))
664                        .expect("enc")
665                        .data
666                        .len()
667                })
668                .collect();
669            let steady = &sizes[50..];
670            let mut runs: Vec<usize> = Vec::new();
671            let mut run = 0usize;
672            for &n in steady {
673                if n > DTX_MAX_BYTES {
674                    run += 1;
675                } else if run > 0 {
676                    runs.push(run);
677                    run = 0;
678                }
679            }
680            if run > 0 {
681                runs.push(run);
682            }
683            let coded = runs.iter().sum::<usize>();
684            eprintln!(
685                "room tone {dbfs} dBFS: {coded}/{} coded ({:.1}%), {} refreshes, longest run {}",
686                steady.len(),
687                coded as f64 * 100.0 / steady.len() as f64,
688                runs.len(),
689                runs.iter().max().copied().unwrap_or(0)
690            );
691            assert!(
692                !runs.is_empty(),
693                "precondition: a noise floor must still produce periodic refreshes"
694            );
695            assert!(
696                runs.iter().all(|&r| r == 1),
697                "at {dbfs} dBFS every comfort-noise refresh must be ONE isolated coded \
698                 frame — a size-only gate treats a run as speech. Runs: {runs:?}"
699            );
700            // Cadence: ~1 refresh per 20 frames. Asserted as a band because it is the
701            // publisher's keepalive budget (a refresh IS a keepalive when it lands).
702            let per_refresh = steady.len() as f64 / runs.len() as f64;
703            assert!(
704                (15.0..=30.0).contains(&per_refresh),
705                "expected a refresh roughly every 20 frames, got every {per_refresh:.1}"
706            );
707        }
708    }

753    /// End to end for the silence path: encode silence until DTX engages, then decode
754    /// that comfort-noise packet the way `audio_rx` does — it must succeed, yield a
755    /// full frame, and be silent. Plus `decode(None)` PLC still works afterwards, so
756    /// the DTX packet does not poison the decoder's state.
757    #[test]
758    fn opus_dtx_packet_round_trips_to_silence() {
759        let mut enc = OpusEncoder::new(DEFAULT_BITRATE, OpusProfile::Voice).expect("encoder");
760        let mut dec = OpusDecoder::new().expect("decoder");
761
762        // Encode past the hangover, keeping the last (definitely-DTX) packet.
763        let mut packet = None;
764        for i in 0..60 {
765            packet = Some(enc.encode(&silent_frame(i * 20_000)).expect("encode"));
766        }
767        let packet = packet.expect("a packet");
768        assert!(
769            packet.data.len() <= DTX_MAX_BYTES,
770            "expected a DTX packet, got {} bytes",
771            packet.data.len()
772        );
773
774        let out = dec
775            .decode(Some(&packet), packet.timestamp_us)
776            .expect("a DTX comfort-noise packet must decode");
777        assert_eq!(
778            out.samples.len(),
779            SAMPLES_PER_FRAME * CHANNELS.count() as usize,
780            "a DTX packet still yields a full frame of playout"
781        );
782        assert_eq!(out.timestamp_us, packet.timestamp_us);
783        // Comfort noise, not speech: well under the mix bus's SILENCE_FLOOR
784        // (`crate::audio::starve`), so it never reads as an active talker.
785        assert!(
786            out.rms() < 0.01,
787            "DTX must decode to silence/comfort noise, got RMS {}",
788            out.rms()
789        );
790
791        // PLC after a DTX packet still produces a full concealment frame.
792        let concealed = dec
793            .decode(None, TimestampUs::from_micros(60 * 20_000))
794            .expect("PLC after DTX");
795        assert_eq!(
796            concealed.samples.len(),
797            SAMPLES_PER_FRAME * CHANNELS.count() as usize
798        );
799    }
