1//! The realtime plane: the IO shell around [`hound_realtime::ClientSession`].
2//!
3//! All protocol logic — the `Hello`→`Welcome` handshake, the desired-vs-issued
4//! subscription reconciliation that survives a reconnect, the frame→event
5//! mapping — lives in the sans-IO reducer. This module only moves bytes: it
6//! picks a transport, drives one [`MessagePipe`](hound_wt::MessagePipe), and
7//! translates the reducer's [`Action`](hound_realtime::Action)s and
8//! [`Event`](hound_realtime::Event)s into wire frames and a typed
9//! [`RealtimeEvent`] stream.
10//!
11//! ## Two legs, one loop
12//!
13//! Per attempt the shell asks the backend where the realtime plane is
14//! (`GET /realtime/config`) and tries **WebTransport** first when a URL is
15//! advertised, falling back to a plain **WebSocket** in the SAME attempt. Both
16//! legs are [`MessagePipe`](hound_wt::MessagePipe)s, so
17//! [`run_session`](supervisor::run_session) is written once and
18//! instantiated twice. The credential travels in an `Authorization: Bearer`
19//! header on both legs — never in a URL, which every proxy and access log
20//! between here and the backend would keep.
21//!
22//! ## Where an auth verdict may come from
23//!
24//! Only two places: a WebSocket handshake refused **401/403**, and an `Auth`
25//! error from `GET /realtime/config` (which is trustworthy because it has
26//! already survived the REST layer's refresh-and-retry — see
27//! [`RestClient`]'s 401 hook). Everything else is retried, **including a
28//! WebTransport [`WtError::Rejected`](hound_wt::WtError::Rejected)**: wtransport
29//! reports `SessionRejected` for any non-2xx answer to the CONNECT *and* for a
30//! CONNECT stream stopped mid-handshake, which is what a pod rollout and a
31//! misrouted host both look like. Treating that as an answer signed users out
32//! over a deploy; it is now a fallback to the WebSocket leg in the same attempt.
33//!
34//! ## The supervisor
35//!
36//! [`RealtimeClient::connect`] tries the first session inline (so a reachable
37//! backend is welcomed before the caller proceeds) and then hands it to a
38//! supervisor task that owns it. A first attempt that FAILS is not an error to
39//! the caller: it is logged and the supervisor retries, because a sign-in must
40//! not fail on a realtime plane that is merely down. The supervisor holds the
41//! [`ClientSession`](hound_realtime::ClientSession) — no lock anywhere, because
42//! exactly one task touches it — and reconnects forever under the CALL plane's
43//! ladder ([`crate::call::reconnect::Backoff`]: 500ms→15s ±20% jitter, re-armed
44//! only by a session that lived ≥30s). The invariants it exists to hold:
45//!
46//! - **Never strand a stale JWT.** Every attempt re-reads the token out of
47//!   session state (through [`RestClient`], whose 401 hook rotates it), so a
48//!   reconnect after an hour offline presents a live credential rather than the
49//!   one captured at sign-in.
50//! - **Only an auth refusal is fatal.** A WS 401/403 or an `Auth` error from the
51//!   config fetch ends the supervisor and emits [`RealtimeEvent::AuthExpired`].
52//! - **A version mismatch is terminal too**, but is NOT an auth outcome: the
53//!   build cannot talk to this server, so the supervisor stops and emits
54//!   [`RealtimeEvent::VersionMismatch`] rather than storming the backend with a
55//!   handshake it will refuse identically forever.

85/// How long one WebTransport dial may take before the shell gives up and falls
86/// back to the WebSocket leg *in the same attempt*. Short on purpose: a blocked
87/// UDP path (a corporate firewall, a NAT that drops QUIC) fails by timing out,
88/// and the user must not wait out a transport-level timeout to reach a plane
89/// the WebSocket serves fine.
90const WT_CONNECT_TIMEOUT: Duration = Duration::from_secs(3);
91
92/// How long opening the WebTransport control stream may take. A session that
93/// handshakes and then never gives us a stream is indistinguishable from a wedge
94/// and would otherwise park this attempt forever — the same reason the backend
95/// bounds its `accept`.
96const WT_STREAM_TIMEOUT: Duration = Duration::from_secs(5);
97
98/// How long the WebSocket leg's dial (TCP + TLS + upgrade) may take. Mirrors
99/// [`RestClient`]'s connect timeout and its rationale verbatim: *a half-dead
100/// server (TCP accepted, upstream never answers — a churning ingress does
101/// exactly this) hangs every caller forever*, and here "every caller" is the
102/// supervisor's ladder, which would stop retrying while it waits.
103const WS_CONNECT_TIMEOUT: Duration = Duration::from_secs(10);
104
105/// Idle period after which the WebSocket leg sends a Ping. A quiet realtime
106/// connection sends nothing for minutes and NAT/proxy idle timeouts kill it; the
107/// WebTransport leg needs no equivalent because QUIC keep-alive is configured on
108/// the endpoint ([`ClientOptions::keep_alive`](hound_wt::ClientOptions)).
109const WS_KEEPALIVE: Duration = Duration::from_secs(20);
110
111/// How long the WebSocket leg tolerates hearing *nothing at all* — not one
112/// frame, not one Pong — before declaring the peer gone.
113///
114/// Two keepalive periods, so a single lost probe is not fatal. This is the only
115/// thing that detects a blackholed TCP connection: writes into a dead path keep
116/// succeeding (they land in the kernel's send buffer), so a session with nothing
117/// to say would otherwise sit "connected" until the OS gave up, which can be
118/// hours. QUIC reaps its own, hence no equivalent on the WebTransport leg.
119const WS_SILENCE_LIMIT: Duration = Duration::from_secs(40);
120
121/// How long a session may sit unwelcomed after the transport is up. The backend
122/// closes a connection that has not said `Hello` within 10s; ours must be at
123/// least that (we are the ones who send it) plus room for the round trip, and
124/// anything past it is a peer that accepted a socket and then stopped
125/// progressing.
126const WELCOME_DEADLINE: Duration = Duration::from_secs(15);
127
128/// Consecutive WebTransport dial failures after which the shell stops trying it.
129/// On a network that blocks UDP outright, every reconnect otherwise pays
130/// [`WT_CONNECT_TIMEOUT`] before reaching the leg that works.
131const WT_FAILURE_STREAK: u32 = 2;
132
133/// How long the WebTransport leg stays skipped once the streak trips. A client
134/// moves between networks without restarting, so the skip must expire.
135const WT_RETRY_AFTER: Duration = Duration::from_secs(600);
136
137/// How long [`RealtimeClient::subscribe_space`] waits for the server to confirm
138/// that it joined this connection to the space's room.
139///
140/// Mirrors the app layer's `REALTIME_WELCOME_GRACE` in both value and doctrine:
141/// the wait exists so that opening a space *means* the space's events are
142/// arriving, and expiring it is a warning, never a failure — a slow realtime
143/// plane must not fail the open of a space whose history already loaded. Long
144/// enough to cover a reconnect (the supervisor re-issues subscriptions on the
145/// next `Welcome`, and the confirmation follows it), short enough that a plane
146/// which is simply down does not hold a UI open for longer than a person waits.
147const SUBSCRIBE_ACK_DEADLINE: Duration = Duration::from_secs(5);
148
149/// Delay before the one in-session retry an [`ErrorCode::Unavailable`] earns.
150/// The server could not *reach* the state to decide (a database blip), so the
151/// subscription is neither issued nor refused — asking again shortly is the
152/// whole recovery.
153const UNAVAILABLE_RETRY: Duration = Duration::from_secs(5);
154
155/// A live realtime plane. Cheap to hold: it is a channel to the supervisor task
156/// plus that task's handle. Dropping it aborts the supervisor; [`disconnect`]
157/// ends it gracefully.
158///
159/// [`disconnect`]: Self::disconnect
160pub struct RealtimeClient {
161    commands: mpsc::UnboundedSender<Command>,
162    supervisor: JoinHandle<()>,
163}
164
165impl RealtimeClient {
166    /// Bring the realtime plane up against `rest`'s backend, returning the live
167    /// client plus the receiver end of the typed event stream.
168    ///
169    /// Infallible by design. The first connection is attempted inline so a
170    /// reachable backend is welcomed before the caller continues, but a failure
171    /// is only logged: the supervisor owns every attempt after it, and a plane
172    /// that cannot connect yet must not fail the sign-in (or the session
173    /// restore) that asked for it. Outcomes reach the caller on the event
174    /// stream — [`RealtimeEvent::Connected`] / [`RealtimeEvent::Disconnected`],
175    /// or [`RealtimeEvent::AuthExpired`] once a credential is definitively
176    /// refused.
177    pub async fn connect(rest: Arc<RestClient>) -> (Self, mpsc::UnboundedReceiver<RealtimeEvent>) {
178        Self::start(RestDialer(rest), WtGate::new()).await
179    }
180
181    /// [`Self::connect`] over any [`Dial`] — the seam the shell's own tests
182    /// drive, so the plane's public behaviour (notably: what
183    /// [`Self::subscribe_space`] waits for) is exercised without a socket.
184    async fn start<D: Dial + 'static>(
185        dialer: D,
186        gate: WtGate,
187    ) -> (Self, mpsc::UnboundedReceiver<RealtimeEvent>) {
188        let leg = match connect_leg(&dialer, &gate).await {
189            Ok(leg) => Some(leg),
190            Err(err) => {
191                tracing::warn!(%err, "realtime: first connect attempt failed — the supervisor will keep trying");
192                None
193            }
194        };
195        let (events_tx, events_rx) = mpsc::unbounded_channel();
196        let (commands, command_rx) = mpsc::unbounded_channel();
197        let supervisor = tokio::spawn(async move {
198            supervise(dialer, gate, events_tx, command_rx, leg).await;
199        });
200        (
201            Self {
202                commands,
203                supervisor,
204            },
205            events_rx,
206        )
207    }
208
209    /// Receive a space's message events, returning once the server has
210    /// **confirmed** that this connection is in the space's room.
211    ///
212    /// The waiting is the point. Queueing the subscribe returns in microseconds,
213    /// but the room join is several hops away — a task hop onto the supervisor,
214    /// the frame, the network, the backend's session task, and its two
215    /// authorization lookups — and a message posted into the space during that
216    /// window is fanned out to a room this connection is not in yet. Nothing
217    /// re-fetches it, so it is lost outright; under load (a busy client, a
218    /// contended backend) the window stretches, which is exactly when a caller
219    /// that opened a space and immediately expected its traffic saw nothing.
220    ///
221    /// Idempotent, and safe before the session is live: the reducer records the
222    /// desire and issues it on the next `Welcome` — including the one after a
223    /// reconnect — and this call waits across that too.
224    ///
225    /// Bounded and non-fatal: a server that does not confirm subscriptions is
226    /// not waited for at all, and a confirmation that never arrives inside
227    /// [`SUBSCRIBE_ACK_DEADLINE`] is a warning rather than an error, because the
228    /// subscription remains desired and the space is still usable.
229    pub async fn subscribe_space(&self, space_id: Uuid) -> Result<()> {
230        let (ack, confirmed) = oneshot::channel();
231        self.send(Command::Subscribe {
232            space_id,
233            ack: Some(ack),
234        })?;
235        match tokio::time::timeout(SUBSCRIBE_ACK_DEADLINE, confirmed).await {
236            Ok(Ok(())) => {}
237            // The sender was dropped: the plane stopped, or the space was
238            // unsubscribed under us. Either way there is nothing left to wait
239            // for, and the desire (if any) survives in the reducer.
240            Ok(Err(_)) => tracing::debug!(%space_id, "realtime: subscribe wait released early"),
241            Err(_) => tracing::warn!(
242                %space_id,
243                deadline = ?SUBSCRIBE_ACK_DEADLINE,
244                "realtime: no subscribe confirmation within the deadline — continuing; the \
245                 subscription stays desired and is re-issued on the next welcome"
246            ),
247        }
248        Ok(())
249    }
250
251    /// Stop receiving a space's message events.
252    pub async fn unsubscribe_space(&self, space_id: Uuid) -> Result<()> {
253        self.send(Command::Unsubscribe(space_id))
254    }
255
256    /// Announce a screenshare toggle; the backend re-broadcasts it to the
257    /// community. Dropped while the session is down — it is a momentary state
258    /// change, and the next `Welcome`'s roster snapshot is authoritative anyway.
259    pub async fn set_screenshare(&self, space_id: Uuid, enabled: bool) -> Result<()> {
260        self.send(Command::Screenshare { space_id, enabled })
261    }
262
263    /// Say goodbye and tear the plane down. Bounded: a wedged transport must not
264    /// hold up a sign-out, so an unresponsive supervisor is aborted instead (by
265    /// this value's own `Drop`, on the way out).
266    pub async fn disconnect(mut self) -> Result<()> {
267        let _ = self.commands.send(Command::Shutdown);
268        if tokio::time::timeout(SHUTDOWN_GRACE, &mut self.supervisor)
269            .await
270            .is_err()
271        {
272            tracing::warn!("realtime: supervisor did not stop in time — aborting");
273        }
274        Ok(())
275    }
276
277    /// Queue a command. A closed channel means the supervisor already gave up
278    /// (a fatal auth outcome or a version mismatch), which is a dead plane, not
279    /// a transient blip.
280    fn send(&self, command: Command) -> Result<()> {
281        self.commands.send(command).map_err(|_| {
282            HoundError::realtime(RealtimeCode::NotRunning, "realtime plane is not running")
283        })
284    }
285}
286
287impl Drop for RealtimeClient {
288    fn drop(&mut self) {
289        // A dropped handle must not leave a task holding a socket open. Harmless
290        // after `disconnect` (the task has already finished).
291        self.supervisor.abort();
292    }
293}
