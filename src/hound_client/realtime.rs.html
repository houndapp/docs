1//! The realtime plane: the IO shell around [`hound_realtime::ClientSession`].
2//!
3//! All protocol logic — the `Hello`→`Welcome` handshake, the desired-vs-issued
4//! subscription reconciliation that survives a reconnect, the frame→event
5//! mapping — lives in the sans-IO reducer. This module only moves bytes: it
6//! picks a transport, drives one [`MessagePipe`], and translates the reducer's
7//! [`Action`]s and [`Event`]s into wire frames and a typed
8//! [`RealtimeEvent`] stream.
9//!
10//! ## Two legs, one loop
11//!
12//! Per attempt the shell asks the backend where the realtime plane is
13//! (`GET /realtime/config`) and tries **WebTransport** first when a URL is
14//! advertised, falling back to a plain **WebSocket** in the SAME attempt. Both
15//! legs are [`MessagePipe`]s, so [`run_session`] is written once and
16//! instantiated twice. The credential travels in an `Authorization: Bearer`
17//! header on both legs — never in a URL, which every proxy and access log
18//! between here and the backend would keep.
19//!
20//! ## Where an auth verdict may come from
21//!
22//! Only two places: a WebSocket handshake refused **401/403**, and an `Auth`
23//! error from `GET /realtime/config` (which is trustworthy because it has
24//! already survived the REST layer's refresh-and-retry — see
25//! [`RestClient`]'s 401 hook). Everything else is retried, **including a
26//! WebTransport [`WtError::Rejected`]**: wtransport reports `SessionRejected`
27//! for any non-2xx answer to the CONNECT *and* for a CONNECT stream stopped
28//! mid-handshake, which is what a pod rollout and a misrouted host both look
29//! like. Treating that as an answer signed users out over a deploy; it is now a
30//! fallback to the WebSocket leg in the same attempt.
31//!
32//! ## The supervisor
33//!
34//! [`RealtimeClient::connect`] tries the first session inline (so a reachable
35//! backend is welcomed before the caller proceeds) and then hands it to a
36//! supervisor task that owns it. A first attempt that FAILS is not an error to
37//! the caller: it is logged and the supervisor retries, because a sign-in must
38//! not fail on a realtime plane that is merely down. The supervisor holds the
39//! [`ClientSession`] — no lock anywhere, because exactly one task touches it —
40//! and reconnects forever under the CALL plane's ladder
41//! ([`crate::call::reconnect::Backoff`]: 500ms→15s ±20% jitter, re-armed only by
42//! a session that lived ≥30s). The invariants it exists to hold:
43//!
44//! - **Never strand a stale JWT.** Every attempt re-reads the token out of
45//!   session state (through [`RestClient`], whose 401 hook rotates it), so a
46//!   reconnect after an hour offline presents a live credential rather than the
47//!   one captured at sign-in.
48//! - **Only an auth refusal is fatal.** A WS 401/403 or an `Auth` error from the
49//!   config fetch ends the supervisor and emits [`RealtimeEvent::AuthExpired`].
50//! - **A version mismatch is terminal too**, but is NOT an auth outcome: the
51//!   build cannot talk to this server, so the supervisor stops and emits
52//!   [`RealtimeEvent::VersionMismatch`] rather than storming the backend with a
53//!   handshake it will refuse identically forever.

80/// How long one WebTransport dial may take before the shell gives up and falls
81/// back to the WebSocket leg *in the same attempt*. Short on purpose: a blocked
82/// UDP path (a corporate firewall, a NAT that drops QUIC) fails by timing out,
83/// and the user must not wait out a transport-level timeout to reach a plane
84/// the WebSocket serves fine.
85const WT_CONNECT_TIMEOUT: Duration = Duration::from_secs(3);
86
87/// How long opening the WebTransport control stream may take. A session that
88/// handshakes and then never gives us a stream is indistinguishable from a wedge
89/// and would otherwise park this attempt forever — the same reason the backend
90/// bounds its `accept`.
91const WT_STREAM_TIMEOUT: Duration = Duration::from_secs(5);
92
93/// How long the WebSocket leg's dial (TCP + TLS + upgrade) may take. Mirrors
94/// [`RestClient`]'s connect timeout and its rationale verbatim: *a half-dead
95/// server (TCP accepted, upstream never answers — a churning ingress does
96/// exactly this) hangs every caller forever*, and here "every caller" is the
97/// supervisor's ladder, which would stop retrying while it waits.
98const WS_CONNECT_TIMEOUT: Duration = Duration::from_secs(10);
99
100/// Idle period after which the WebSocket leg sends a Ping. A quiet realtime
101/// connection sends nothing for minutes and NAT/proxy idle timeouts kill it; the
102/// WebTransport leg needs no equivalent because QUIC keep-alive is configured on
103/// the endpoint ([`ClientOptions::keep_alive`]).
104const WS_KEEPALIVE: Duration = Duration::from_secs(20);
105
106/// How long the WebSocket leg tolerates hearing *nothing at all* — not one
107/// frame, not one Pong — before declaring the peer gone.
108///
109/// Two keepalive periods, so a single lost probe is not fatal. This is the only
110/// thing that detects a blackholed TCP connection: writes into a dead path keep
111/// succeeding (they land in the kernel's send buffer), so a session with nothing
112/// to say would otherwise sit "connected" until the OS gave up, which can be
113/// hours. QUIC reaps its own, hence no equivalent on the WebTransport leg.
114const WS_SILENCE_LIMIT: Duration = Duration::from_secs(40);
115
116/// How long a session may sit unwelcomed after the transport is up. The backend
117/// closes a connection that has not said `Hello` within 10s; ours must be at
118/// least that (we are the ones who send it) plus room for the round trip, and
119/// anything past it is a peer that accepted a socket and then stopped
120/// progressing.
121const WELCOME_DEADLINE: Duration = Duration::from_secs(15);
122
123/// Consecutive WebTransport dial failures after which the shell stops trying it.
124/// On a network that blocks UDP outright, every reconnect otherwise pays
125/// [`WT_CONNECT_TIMEOUT`] before reaching the leg that works.
126const WT_FAILURE_STREAK: u32 = 2;
127
128/// How long the WebTransport leg stays skipped once the streak trips. A client
129/// moves between networks without restarting, so the skip must expire.
130const WT_RETRY_AFTER: Duration = Duration::from_secs(600);
131
132/// Delay before the one in-session retry an [`ErrorCode::Unavailable`] earns.
133/// The server could not *reach* the state to decide (a database blip), so the
134/// subscription is neither issued nor refused — asking again shortly is the
135/// whole recovery.
136const UNAVAILABLE_RETRY: Duration = Duration::from_secs(5);

138/// A decoded server-side realtime event. The reducers fold these into
139/// view-models.
140///
141/// One-to-one with [`hound_realtime::Event`] plus [`RealtimeEvent::AuthExpired`]
142/// (no protocol frame can produce it — it is the shell's verdict that the
143/// session credential is dead) and [`RealtimeEvent::VersionMismatch`] (split out
144/// of `Error` because it, alone among the error codes, ends the plane). Kept as
145/// its own enum rather than a re-export exactly so those variants exist and so
146/// the app layer's `match` arms don't have to name a protocol type.
147#[derive(Clone, Debug, PartialEq)]
148pub enum RealtimeEvent {
149    /// A new message in a subscribed space.
150    MessageCreated(MessageEvent),
151    /// An edit to an existing message.
152    MessageUpdated(MessageEvent),
153    /// A new space in a joined community.
154    SpaceCreated(SpaceEvent),
155    /// A space was deleted.
156    SpaceRemoved { space_id: Uuid },
157    /// A user joined a voice channel (SFU peer id known).
158    VoiceJoined(VoiceJoinEvent),
159    /// A user left a voice channel.
160    VoiceLeft(VoiceLeaveEvent),
161    /// A participant toggled screenshare.
162    VoiceScreenShare(VoiceScreenShareEvent),
163    /// The full voice roster snapshot, pushed with every `Welcome` and on
164    /// server-side resync.
165    VoiceState(Vec<VoiceJoinEvent>),
166    /// The server refused something (an unauthorized subscribe, an unavailable
167    /// one). Surfaced, never swallowed, so contract drift is visible in the
168    /// logs.
169    Error { code: ErrorCode, message: String },
170    /// This build and the server cannot agree a protocol version. The plane will
171    /// NOT reconnect — retrying re-runs the same refused handshake — but the
172    /// SESSION is fine: this is never a reason to sign anyone out.
173    VersionMismatch { message: String },
174    /// The handshake completed: the session is live and fully resynced.
175    Connected,
176    /// The transport went away. The supervisor is already reconnecting; desired
177    /// subscriptions survive and are re-issued on the next `Welcome`.
178    Disconnected,
179    /// The session credential is dead — the plane will NOT reconnect. The app
180    /// layer reacts as it does to any dead session (sign out).
181    AuthExpired,
182}
183
184impl From<Event> for RealtimeEvent {
185    fn from(event: Event) -> Self {
186        match event {
187            Event::Connected => Self::Connected,
188            Event::Disconnected => Self::Disconnected,
189            Event::MessageCreated(m) => Self::MessageCreated(m),
190            Event::MessageUpdated(m) => Self::MessageUpdated(m),
191            Event::SpaceCreated(s) => Self::SpaceCreated(s),
192            Event::SpaceRemoved { space_id } => Self::SpaceRemoved { space_id },
193            Event::VoiceJoined(v) => Self::VoiceJoined(v),
194            Event::VoiceLeft(v) => Self::VoiceLeft(v),
195            Event::VoiceState(v) => Self::VoiceState(v),
196            Event::Screenshare(s) => Self::VoiceScreenShare(s),
197            // The one error code that ends the plane gets its own variant, so no
198            // caller has to know which codes are terminal.
199            Event::Error {
200                code: ErrorCode::VersionMismatch,
201                message,
202            } => Self::VersionMismatch { message },
203            Event::Error { code, message } => Self::Error { code, message },
204        }
205    }
206}

212enum Command {
213    Subscribe(Uuid),

219    /// Say goodbye and end the supervisor.
220    Shutdown,

223/// A live realtime plane. Cheap to hold: it is a channel to the supervisor task
224/// plus that task's handle. Dropping it aborts the supervisor; [`disconnect`]
225/// ends it gracefully.
226///
227/// [`disconnect`]: Self::disconnect
228pub struct RealtimeClient {
229    commands: mpsc::UnboundedSender<Command>,
230    supervisor: JoinHandle<()>,
231}
232
233impl RealtimeClient {
234    /// Bring the realtime plane up against `rest`'s backend, returning the live
235    /// client plus the receiver end of the typed event stream.
236    ///
237    /// Infallible by design. The first connection is attempted inline so a
238    /// reachable backend is welcomed before the caller continues, but a failure
239    /// is only logged: the supervisor owns every attempt after it, and a plane
240    /// that cannot connect yet must not fail the sign-in (or the session
241    /// restore) that asked for it. Outcomes reach the caller on the event
242    /// stream — [`RealtimeEvent::Connected`] / [`RealtimeEvent::Disconnected`],
243    /// or [`RealtimeEvent::AuthExpired`] once a credential is definitively
244    /// refused.
245    pub async fn connect(rest: Arc<RestClient>) -> (Self, mpsc::UnboundedReceiver<RealtimeEvent>) {
246        let dialer = RestDialer(rest);
247        let gate = WtGate::new();
248        let leg = match connect_leg(&dialer, &gate).await {
249            Ok(leg) => Some(leg),
250            Err(err) => {
251                tracing::warn!(%err, "realtime: first connect attempt failed — the supervisor will keep trying");
252                None
253            }
254        };
255        let (events_tx, events_rx) = mpsc::unbounded_channel();
256        let (commands, command_rx) = mpsc::unbounded_channel();
257        let supervisor = tokio::spawn(async move {
258            supervise(dialer, gate, events_tx, command_rx, leg).await;
259        });
260        (
261            Self {
262                commands,
263                supervisor,
264            },
265            events_rx,
266        )
267    }
268
269    /// Receive a space's message events. Idempotent, and safe before the session
270    /// is live: the reducer records the desire and issues it on the next
271    /// `Welcome` — including the one after a reconnect.
272    pub async fn subscribe_space(&self, space_id: Uuid) -> Result<()> {
273        self.send(Command::Subscribe(space_id))
274    }
275
276    /// Stop receiving a space's message events.
277    pub async fn unsubscribe_space(&self, space_id: Uuid) -> Result<()> {
278        self.send(Command::Unsubscribe(space_id))
279    }
280
281    /// Announce a screenshare toggle; the backend re-broadcasts it to the
282    /// community. Dropped while the session is down — it is a momentary state
283    /// change, and the next `Welcome`'s roster snapshot is authoritative anyway.
284    pub async fn set_screenshare(&self, space_id: Uuid, enabled: bool) -> Result<()> {
285        self.send(Command::Screenshare { space_id, enabled })
286    }
287
288    /// Say goodbye and tear the plane down. Bounded: a wedged transport must not
289    /// hold up a sign-out, so an unresponsive supervisor is aborted instead (by
290    /// this value's own `Drop`, on the way out).
291    pub async fn disconnect(mut self) -> Result<()> {
292        let _ = self.commands.send(Command::Shutdown);
293        if tokio::time::timeout(SHUTDOWN_GRACE, &mut self.supervisor)
294            .await
295            .is_err()
296        {
297            tracing::warn!("realtime: supervisor did not stop in time — aborting");
298        }
299        Ok(())
300    }
301
302    /// Queue a command. A closed channel means the supervisor already gave up
303    /// (a fatal auth outcome or a version mismatch), which is a dead plane, not
304    /// a transient blip.
305    fn send(&self, command: Command) -> Result<()> {
306        self.commands
307            .send(command)
308            .map_err(|_| HoundError::Realtime("realtime plane is not running".to_owned()))
309    }
310}

312impl Drop for RealtimeClient {
313    fn drop(&mut self) {
314        // A dropped handle must not leave a task holding a socket open. Harmless
315        // after `disconnect` (the task has already finished).
316        self.supervisor.abort();
317    }
318}

325/// Own the session for the plane's lifetime: run it, reconnect it, and stop on a
326/// shutdown, a fatal auth outcome, or a version mismatch. `initial` is the
327/// connection [`RealtimeClient::connect`] already established, if it managed to.
328async fn supervise<D: Dial>(
329    dialer: D,
330    gate: WtGate,
331    events: mpsc::UnboundedSender<RealtimeEvent>,
332    mut commands: mpsc::UnboundedReceiver<Command>,
333    initial: Option<D::Pipe>,
334) {
335    let mut session = ClientSession::new();
336    let mut backoff = Backoff::new();
337    let mut leg = initial;
338
339    loop {
340        // Establish, unless we are holding a connection already. Commands are
341        // serviced throughout: while down they only move the reducer's desired
342        // set, which is exactly what must survive an outage.
343        let pipe = match leg.take() {
344            Some(pipe) => pipe,
345            None => {
346                let delay = backoff.next_delay(rng_jitter);
347                tracing::info!(
348                    attempt = backoff.attempt(),
349                    delay_ms = delay.as_millis() as u64,
350                    "realtime: reconnect backoff"
351                );
352                // `biased` here (unlike in `run_session`): a shutdown must win
353                // over both the sleep and the dial, or a sign-out would wait out
354                // a 15s backoff rung and then a 13s dial.
355                tokio::select! {
356                    biased;
357                    _ = drain_offline(&mut commands, &mut session) => return,
358                    _ = tokio::time::sleep(delay) => {}
359                }
360                let attempt = tokio::select! {
361                    biased;
362                    _ = drain_offline(&mut commands, &mut session) => return,
363                    result = connect_leg(&dialer, &gate) => result,
364                };
365                match attempt {
366                    Ok(pipe) => pipe,
367                    Err(err) => match classify(&err) {
368                        Disposition::Fatal => {
369                            tracing::error!(%err, "realtime: session refused — giving up");
370                            let _ = events.send(RealtimeEvent::AuthExpired);
371                            return;
372                        }
373                        Disposition::Retryable => {
374                            tracing::warn!(%err, "realtime: connect attempt failed (retrying)");
375                            continue;
376                        }
377                    },
378                }
379            }
380        };
381
382        // Live. `run_session` returns when the pipe dies or a shutdown lands.
383        let started = Instant::now();
384        let stopped = run_session(pipe, &mut session, &events, &mut commands).await;
385        // Read BEFORE `disconnected()` clears it: a session that reached
386        // `Welcome` proves this network path works end to end, which is what
387        // re-arms the WebTransport probe.
388        if session.is_live() {
389            gate.note_welcomed_session();
390        }
391        for event in session.disconnected() {
392            let _ = events.send(event.into());
393        }
394        // Only a session that PROVED durable re-arms the ladder — see
395        // `Backoff::on_session_death`. A server that accepts and immediately
396        // closes must not pin us on the 500ms rung.
397        backoff.on_session_death(started.elapsed());
398        match stopped {
399            Stopped::Shutdown => return,
400            // Reconnecting would re-run a handshake the server refuses
401            // identically forever; the event already told the app.
402            Stopped::VersionMismatch => {
403                tracing::error!("realtime: protocol version mismatch — the plane is stopping");
404                return;
405            }
406            Stopped::Transport => {}
407        }
408    }
409}

411/// Apply commands to the reducer while there is no live transport, forever.
412/// Resolves ONLY when the plane is shutting down (an explicit `Shutdown` or the
413/// last [`RealtimeClient`] dropped), which is what makes it usable as the losing
414/// arm of a `select!`: the actions it would produce are all empty while down, so
415/// dropping the future mid-poll loses nothing.
416async fn drain_offline(
417    commands: &mut mpsc::UnboundedReceiver<Command>,
418    session: &mut ClientSession,
419) {
420    while let Some(command) = commands.recv().await {
421        if command == Command::Shutdown {
422            return;
423        }
424        // Down: `apply` records desire and yields no frames to drop.
425        let _ = apply(session, command);
426    }
427}

429/// Why [`run_session`] returned.
430#[derive(Debug, Clone, Copy, PartialEq, Eq)]
431enum Stopped {
432    /// The transport ended (peer closed, read error, a send failed, or a
433    /// deadline this shell owns expired).
434    Transport,
435    /// The caller asked the plane to stop.
436    Shutdown,
437    /// The server and this build cannot agree a protocol version. Terminal, and
438    /// deliberately not an auth outcome.
439    VersionMismatch,
440}

442/// Drive one established pipe: handshake, then pump frames and commands until
443/// something ends it.
444///
445/// Mirrors the call plane's reader discipline — a frame that fails to serialize
446/// is skipped, never fatal, and an unparseable inbound frame is skipped by
447/// [`MessagePipeExt::recv_json`] (that is the protocol's additive-compatibility
448/// rule). Generic over the pipe so both legs and the test fake share one loop.
449///
450/// Four deadlines run alongside the two data arms, all absolute (they are NOT
451/// re-armed by an unrelated wakeup, which is exactly the bug a per-iteration
452/// `sleep` would have): the keepalive probe, the inbound-silence limit, the
453/// `Welcome` deadline, and the one retry an `Unavailable` answer earns.
454async fn run_session<P: Probe>(
455    mut pipe: P,
456    session: &mut ClientSession,
457    events: &mpsc::UnboundedSender<RealtimeEvent>,
458    commands: &mut mpsc::UnboundedReceiver<Command>,
459) -> Stopped {
460    // The transport is up: the reducer answers with `Hello`, and nothing else
461    // may be sent until the `Welcome` comes back.
462    if !send_all(&mut pipe, session.connected()).await {
463        return Stopped::Transport;
464    }
465
466    // Read once: the timers must not borrow the pipe, which the frame arm needs
467    // mutably.
468    let idle = pipe.idle_period();
469    let silence = pipe.silence_limit();
470    let mut next_probe = deadline(idle);
471    let mut next_silence_check = deadline(silence);
472    let mut inbound_mark = pipe.inbound_count();
473    let mut welcome_by = deadline(Some(WELCOME_DEADLINE));
474    let mut retry_subscriptions_at: Option<Instant> = None;
475    let mut retried_subscriptions = false;
476
477    let stopped = loop {
478        // NOT `biased`: with a fixed order the inbound arm is always polled
479        // first, so a server flooding events starves the command, keepalive and
480        // deadline arms — a shutdown would never be seen and the liveness timers
481        // would never fire. Random order costs nothing and cannot starve.
482        tokio::select! {
483            frame = pipe.recv_json::<ServerMessage>() => {
484                let Some(msg) = frame else { break Stopped::Transport };
485                let reaction = session.handle(msg);
486                let mismatch = reaction.events.iter().any(|event| {
487                    matches!(event, Event::Error { code: ErrorCode::VersionMismatch, .. })
488                });
489                let unavailable = reaction.events.iter().any(|event| {
490                    matches!(event, Event::Error { code: ErrorCode::Unavailable, .. })
491                });
492                for event in reaction.events {
493                    let _ = events.send(event.into());
494                }
495                if mismatch {
496                    break Stopped::VersionMismatch;
497                }
498                // Welcomed: the deadline has done its job.
499                if session.is_live() {
500                    welcome_by = None;
501                }
502                // The server decided nothing, so the subscription is neither
503                // issued nor refused. Exactly one retry per session — a backend
504                // stuck answering `Unavailable` must not earn a subscribe storm
505                // every 5s — and anything past that is the next `Welcome`'s
506                // reconciliation, which re-issues the whole desired set anyway.
507                if unavailable && !retried_subscriptions {
508                    retried_subscriptions = true;
509                    retry_subscriptions_at = deadline(Some(UNAVAILABLE_RETRY));
510                }
511                if !send_all(&mut pipe, reaction.actions).await {
512                    break Stopped::Transport;
513                }
514            }
515            command = commands.recv() => {
516                // `None` = every `RealtimeClient` handle dropped without a
517                // `disconnect`; treat it as one.
518                let Some(command) = command else { break Stopped::Shutdown };
519                if command == Command::Shutdown {
520                    let _ = send_all(&mut pipe, session.bye()).await;
521                    break Stopped::Shutdown;
522                }
523                if !send_all(&mut pipe, apply(session, command)).await {
524                    break Stopped::Transport;
525                }
526            }
527            () = tick_at(next_probe) => {
528                if let Err(error) = pipe.ping().await {
529                    tracing::debug!(%error, "realtime: keepalive failed");
530                    break Stopped::Transport;
531                }
532                next_probe = deadline(idle);
533            }
534            () = tick_at(next_silence_check) => {
535                // Writes into a blackholed TCP path keep succeeding, so silence
536                // is the only evidence the peer is gone.
537                let seen = pipe.inbound_count();
538                if seen == inbound_mark {
539                    tracing::warn!(
540                        limit = ?silence,
541                        "realtime: nothing inbound (not even a pong) — treating the transport as dead"
542                    );
543                    break Stopped::Transport;
544                }
545                inbound_mark = seen;
546                next_silence_check = deadline(silence);
547            }
548            () = tick_at(welcome_by) => {
549                tracing::warn!(
550                    deadline = ?WELCOME_DEADLINE,
551                    "realtime: no Welcome after the handshake — reconnecting"
552                );
553                break Stopped::Transport;
554            }
555            () = tick_at(retry_subscriptions_at) => {
556                retry_subscriptions_at = None;
557                if !send_all(&mut pipe, session.reissue_subscriptions()).await {
558                    break Stopped::Transport;
559                }
560            }
561        }
562    };
563    pipe.close().await;
564    stopped
565}

567/// Apply one command to the reducer.
568fn apply(session: &mut ClientSession, command: Command) -> Vec<Action> {
569    match command {
570        Command::Subscribe(space_id) => session.subscribe(space_id),
571        Command::Unsubscribe(space_id) => session.unsubscribe(space_id),
572        Command::Screenshare { space_id, enabled } => session.screenshare(space_id, enabled),
573        // Handled by the caller: it also ends the loop.
574        Command::Shutdown => session.bye(),
575    }
576}

578/// Put every action on the wire. `false` means the pipe is dead. A frame that
579/// fails to ENCODE is skipped (it cannot be fixed by reconnecting, and killing
580/// the session over one malformed frame would be a self-inflicted outage);
581/// anything else is a transport failure.
582async fn send_all<P: MessagePipe>(pipe: &mut P, actions: Vec<Action>) -> bool {
583    for Action::Send(msg) in actions {
584        match pipe.send_json(&msg).await {
585            Ok(()) => {}
586            Err(PipeError::Encode(error)) => {
587                tracing::error!(%error, ?msg, "realtime: skipping unencodable frame");
588            }
589            Err(error) => {
590                tracing::debug!(%error, "realtime: send failed — transport is gone");
591                return false;
592            }
593        }
594    }
595    true
596}

614/// Where one attempt's legs come from: the config lookup, the credential, and
615/// the two dials.
616///
617/// A trait rather than three free functions so [`connect_leg`]'s *decisions* —
618/// which leg, in which order, and what a failure at each step means — are
619/// testable without a socket, and so the supervisor itself can be driven against
620/// scripted outcomes.
621trait Dial: Send + Sync {
622    /// An established connection over either leg.
623    type Pipe: Probe + Send;
624
625    /// `GET /realtime/config`.
626    fn config(&self) -> impl std::future::Future<Output = Result<RealtimeConfig>> + Send;
627
628    /// The current session credential.
629    fn token(&self) -> Result<String>;
630
631    /// Dial the advertised WebTransport endpoint.
632    fn wt(
633        &self,
634        url: &str,
635        token: &str,
636        cert_hash: Option<&str>,
637    ) -> impl std::future::Future<Output = Result<Self::Pipe>> + Send;
638
639    /// Dial the WebSocket leg (derived from the REST base URL).
640    fn ws(&self, token: &str) -> impl std::future::Future<Output = Result<Self::Pipe>> + Send;
641}
642
643/// One attempt: fetch the config, then WebTransport (if advertised, allowed, and
644/// working), else the WebSocket.
645///
646/// The config fetch is what re-mints the credential: it goes through
647/// [`RestClient`], whose 401 hook rotates the session and republishes the access
648/// token, so the token read straight after is current by construction. Reading a
649/// captured token instead is the stale-JWT strand this ordering exists to
650/// prevent.
651///
652/// A config fetch that FAILS does not fail the attempt: the WebSocket leg is
653/// derived from the REST base URL and needs nothing the config carries, so a
654/// backend blip in that one endpoint must not cost the whole plane. Only an
655/// `Auth` error propagates — that one is an answer (it has already survived the
656/// REST layer's refresh-and-retry).
657async fn connect_leg<D: Dial>(dialer: &D, gate: &WtGate) -> Result<D::Pipe> {
658    let config = match dialer.config().await {
659        Ok(config) => Some(config),
660        Err(err @ HoundError::Auth(_)) => return Err(err),
661        Err(err) => {
662            tracing::warn!(%err, "realtime: config fetch failed — going straight to the websocket leg");
663            None
664        }
665    };
666    let token = dialer.token()?;
667
668    let advertised = config
669        .as_ref()
670        .and_then(|config| config.webtransport_url.as_deref())
671        .filter(|url| !url.is_empty());
672    if let Some(url) = advertised {
673        if gate.wt_allowed() {
674            let cert_hash = config
675                .as_ref()
676                .and_then(|config| config.cert_hash.as_deref());
677            match dialer.wt(url, &token, cert_hash).await {
678                Ok(pipe) => {
679                    gate.note_wt_success();
680                    return Ok(pipe);
681                }
682                // EVERY WebTransport failure falls back, refusals included — see
683                // the module docs on where an auth verdict may come from.
684                Err(err) => {
685                    gate.note_wt_failure();
686                    tracing::warn!(%err, "realtime: webtransport unavailable — falling back to websocket");
687                }
688            }
689        } else {
690            tracing::debug!("realtime: skipping webtransport (recent dials all failed)");
691        }
692    }
693    dialer.ws(&token).await
694}

696/// Whether the WebTransport leg is worth dialling at all.
697///
698/// On a network that blocks UDP the WT dial cannot succeed, and paying
699/// [`WT_CONNECT_TIMEOUT`] before every single reconnect is a self-inflicted 3s
700/// outage on top of whatever caused the reconnect. After
701/// [`WT_FAILURE_STREAK`] failures in a row the leg is skipped until either a
702/// session actually reached `Welcome` (proof the path changed) or
703/// [`WT_RETRY_AFTER`] elapses — a laptop moves between networks without
704/// restarting, so this can never be permanent.
705///
706/// Scoped to one plane rather than the process: a fresh plane (a new sign-in)
707/// deserves a fresh probe, and process-global state would be untestable in
708/// parallel.
709struct WtGate {
710    state: std::sync::Mutex<GateState>,
711}
712
713#[derive(Default)]
714struct GateState {
715    failures: u32,
716    /// When the streak last tripped the skip, for the expiry.
717    blocked_at: Option<Instant>,
718}
719
720impl WtGate {
721    fn new() -> Self {
722        Self {
723            state: std::sync::Mutex::new(GateState::default()),
724        }
725    }
726
727    fn wt_allowed(&self) -> bool {
728        let state = self.state.lock().expect("wt gate mutex");
729        match state.blocked_at {
730            Some(blocked_at) => Instant::now().duration_since(blocked_at) >= WT_RETRY_AFTER,
731            None => state.failures < WT_FAILURE_STREAK,
732        }
733    }
734
735    fn note_wt_failure(&self) {
736        let mut state = self.state.lock().expect("wt gate mutex");
737        state.failures = state.failures.saturating_add(1);
738        if state.failures >= WT_FAILURE_STREAK {
739            // Re-stamped on every failure, so a dial let through by the expiry
740            // that fails again restarts the cooldown rather than retrying hard.
741            state.blocked_at = Some(Instant::now());
742        }
743    }
744
745    fn note_wt_success(&self) {
746        *self.state.lock().expect("wt gate mutex") = GateState::default();
747    }
748
749    /// A session reached `Welcome` — whichever leg carried it, this network path
750    /// works, so re-probe WebTransport on the next attempt.
751    fn note_welcomed_session(&self) {
752        *self.state.lock().expect("wt gate mutex") = GateState::default();
753    }
754}

800/// A WebTransport control stream, holding the endpoint and connection it rides.

802/// Both are kept alive deliberately: dropping the `Endpoint` (or the
803/// `Connection`) tears the stream down under us — the same lifetime trap the

806    stream: FramedBi,
807    _connection: hound_wt::Connection,
808    _client: WtClient,
809}

811/// The URL the WebTransport leg dials: exactly what the backend advertised, with
812/// no query of our own. The credential rides an `Authorization` header instead —
813/// a `:path` lands in access logs and proxy traces.
814fn wt_dial_url(advertised: &str) -> &str {
815    advertised.trim_end_matches('/')

818/// Dial the advertised WebTransport endpoint and open the control stream.
819///
820/// DNS pins are supplied through a [`PinnedResolver`] closure read at LOOKUP
821/// time, so a harness that installs overrides after this process started still
822/// has them honoured while the URL keeps the real hostname (TLS stays honest).
823async fn connect_wt(url: &str, token: &str, cert_hash: Option<&str>) -> Result<WtPipe> {
824    let trust = match cert_hash {
825        Some(hash) => Trust::CertHash(
826            hound_wt::CertHash::parse(hash)
827                .map_err(|e| HoundError::Realtime(format!("bad realtime cert hash: {e}")))?,
828        ),
829        None => Trust::NativeRoots,
830    };
831    let mut options = ClientOptions::new(trust);
832    options.resolver = PinnedResolver::from_fn(|| dns_overrides().to_vec());
833
834    let client = WtClient::new(options).map_err(wt_error)?;
835    let url = wt_dial_url(url);
836    let authorization = format!("Bearer {token}");
837
838    let connection = tokio::time::timeout(
839        WT_CONNECT_TIMEOUT,
840        client.connect_with_headers(url, &[("Authorization", &authorization)]),
841    )
842    .await
843    .map_err(|_| HoundError::Network("webtransport connect timed out".to_owned()))?
844    .map_err(wt_error)?;
845    // The client opens the control stream, mirroring the browser API (and what
846    // the backend's accept loop waits for). Bounded: a session that never gives
847    // us a stream must not park the attempt.
848    let stream = FramedBi::open_within(&connection, WT_STREAM_TIMEOUT)
849        .await
850        .map_err(wt_error)?;
851    Ok(WtPipe {
852        stream,
853        _connection: connection,
854        _client: client,
855    })
856}

858/// Map a WebTransport failure onto the shared error taxonomy — always as a
859/// retryable transport failure, `Rejected` included.

908/// The universally-reachable leg. Mirrors the backend's `WsPipe`: text frames
909/// are the protocol, and ping/pong/binary are skipped rather than treated as
910/// frames, so a proxy's keepalive can never desync the stream. They are still
911/// COUNTED — a pong is the only evidence a silent peer is alive.
912struct WsPipe {
913    socket: tokio_tungstenite::WebSocketStream<
914        tokio_tungstenite::MaybeTlsStream<tokio::net::TcpStream>,
915    >,
916    inbound: u64,
917}

919impl MessagePipe for WsPipe {
920    async fn send(&mut self, frame: String) -> std::result::Result<(), PipeError> {
921        use futures::SinkExt;
922        self.socket
923            .send(tokio_tungstenite::tungstenite::Message::Text(frame.into()))
924            .await
925            .map_err(|e| PipeError::Transport(e.to_string()))
926    }
927
928    async fn recv(&mut self) -> Option<std::result::Result<String, PipeError>> {
929        use futures::StreamExt;
930        use tokio_tungstenite::tungstenite::Message;
931        loop {
932            let message = self.socket.next().await?;
933            if message.is_ok() {
934                self.inbound += 1;
935            }
936            return match message {
937                Ok(Message::Text(text)) => Some(Ok(text.to_string())),
938                Ok(Message::Close(_)) => None,
939                // Pongs answer our own Pings; tungstenite answers the server's
940                // Pings itself. Binary is not part of this protocol.
941                Ok(_) => continue,
942                Err(error) => Some(Err(PipeError::Transport(error.to_string()))),
943            };
944        }
945    }
946
947    async fn close(&mut self) {
948        let _ = self.socket.close(None).await;
949    }
950}

1049/// Build the realtime WebSocket URL from the REST base — the same scheme
1050/// rewrite the call plane's `control_ws_url` does, against the route the backend
1051/// registers (`GET /realtime/ws`). No credential: it goes in a header.
1052fn realtime_ws_url(base_url: &str) -> Result<String> {
1053    let base = base_url.trim_end_matches('/');
1054    let ws_base = if let Some(rest) = base.strip_prefix("https://") {
1055        format!("wss://{rest}")
1056    } else if let Some(rest) = base.strip_prefix("http://") {
1057        format!("ws://{rest}")
1058    } else if base.starts_with("ws://") || base.starts_with("wss://") {
1059        base.to_owned()
1060    } else {
1061        return Err(HoundError::Realtime(format!(
1062            "api_base has no http(s) scheme: {base_url}"
1063        )));
1064    };
1065    Ok(format!("{ws_base}/realtime/ws"))
1066}

1078/// Open the WebSocket leg, honouring the process's DNS pins.
1079///
1080/// A pinned host is dialled by opening the TCP socket OURSELVES against the
1081/// pinned address and only then running the TLS + WebSocket handshake against
1082/// the request's original hostname — so SNI and certificate validation still
1083/// prove we reached the intended deployment, which an IP-in-the-URL rewrite
1084/// would not. An unpinned host takes `connect_async`'s ordinary path.
1085///
1086/// `timeout` bounds the WHOLE dial (TCP, TLS, upgrade); it is a parameter only
1087/// so tests can pin it.
1088async fn connect_ws(base_url: &str, token: &str, timeout: Duration) -> Result<WsPipe> {
1089    use tokio_tungstenite::tungstenite::client::IntoClientRequest;
1090    use tokio_tungstenite::tungstenite::http::header::AUTHORIZATION;
1091
1092    let url = realtime_ws_url(base_url)?;
1093    let mut request = url.into_client_request().map_err(|e| {
1094        HoundError::Realtime(format!("bad realtime ws url: {}", redact(&e.to_string())))
1095    })?;
1096    let authorization = format!("Bearer {token}")
1097        .parse()
1098        .map_err(|_| HoundError::Auth("session token is not a valid header value".to_owned()))?;
1099    request.headers_mut().insert(AUTHORIZATION, authorization);
1100    let (host, port) = ws_authority(request.uri())?;
1101
1102    let dial = async {
1103        match pinned_addr(dns_overrides(), &host, port) {
1104            Some(addr) => {
1105                tracing::debug!(%host, %addr, "realtime: dialling a pinned address");
1106                let tcp = tokio::net::TcpStream::connect(addr)
1107                    .await
1108                    .map_err(|e| HoundError::Network(format!("realtime ws tcp connect: {e}")))?;
1109                tokio_tungstenite::client_async_tls_with_config(
1110                    request,
1111                    tcp,
1112                    Some(ws_config()),
1113                    None,
1114                )
1115                .await
1116            }
1117            None => {
1118                tokio_tungstenite::connect_async_with_config(request, Some(ws_config()), false)
1119                    .await
1120            }
1121        }
1122        .map_err(ws_error)
1123    };
1124
1125    let (socket, _response) = tokio::time::timeout(timeout, dial).await.map_err(|_| {
1126        HoundError::Network(format!("realtime ws connect timed out after {timeout:?}"))
1127    })??;
1128    Ok(WsPipe { socket, inbound: 0 })
1129}

1143/// Scrub a `token=…` query value out of anything headed for a log.
1144///
1145/// This client no longer puts a credential in a URL, but the URLs it dials are
1146/// partly server-supplied (`/realtime/config`'s `webtransport_url`), and a
1147/// transport error quotes the URL it failed on. Cheap insurance that a
1148/// mis-configured deployment cannot leak one through our logs.
1149fn redact(text: &str) -> String {
1150    const KEY: &str = "token=";
1151    let mut out = String::with_capacity(text.len());
1152    let mut rest = text;
1153    while let Some(at) = rest.find(KEY) {
1154        out.push_str(&rest[..at + KEY.len()]);
1155        out.push_str("REDACTED");
1156        let tail = &rest[at + KEY.len()..];
1157        let end = tail
1158            .find(['&', ' ', '"', '\'', ',', ')'])
1159            .unwrap_or(tail.len());
1160        rest = &tail[end..];
1161    }
1162    out.push_str(rest);
1163    out
1164}

1166/// The host and port a WebSocket request dials (`wss` ⇒ 443, `ws` ⇒ 80).
1167fn ws_authority(uri: &tokio_tungstenite::tungstenite::http::Uri) -> Result<(String, u16)> {
1168    let host = uri
1169        .host()
1170        .ok_or_else(|| HoundError::Realtime(format!("realtime ws url has no host: {uri}")))?;
1171    let port = uri.port_u16().or_else(|| match uri.scheme_str() {
1172        Some("wss") => Some(443),
1173        Some("ws") => Some(80),
1174        _ => None,
1175    });
1176    let port =
1177        port.ok_or_else(|| HoundError::Realtime(format!("realtime ws url has no port: {uri}")))?;
1178    Ok((host.to_owned(), port))
1179}

1380    /// Run one session over a fake wire and collect everything it produced. The

1383    async fn drive(
1384        wire: &Arc<Mutex<Wire>>,
1385        session: &mut ClientSession,
1386        commands: Vec<Command>,
1387    ) -> (Stopped, Vec<RealtimeEvent>) {
1388        let (events_tx, mut events_rx) = mpsc::unbounded_channel();

1390        for command in commands {

1392        }

1398            events.push(event);
1399        }

1403    /// A session running in its own task, plus the ends a test drives it by.
1404    ///
1405    /// Needed wherever a command has to be ordered against the handshake:
1406    /// [`run_session`]'s arms are deliberately unbiased (see the `select!`
1407    /// comment), so a command queued before the session starts may be serviced
1408    /// before or after the `Welcome`. Waiting for `Connected` and only then
1409    /// sending is the sequencing the loop actually guarantees — and commands
1410    /// share one channel, so they are FIFO among themselves.
1411    struct Running {
1412        commands: mpsc::UnboundedSender<Command>,
1413        events: mpsc::UnboundedReceiver<RealtimeEvent>,
1414        /// Everything already taken off the stream, so waiting for one event
1415        /// doesn't lose the ones before it.
1416        seen: Vec<RealtimeEvent>,
1417        task: JoinHandle<(Stopped, ClientSession)>,
1418    }
1419
1420    fn start(wire: Arc<Mutex<Wire>>, session: ClientSession) -> Running {
1421        let (events_tx, events) = mpsc::unbounded_channel();
1422        let (commands, mut command_rx) = mpsc::unbounded_channel();
1423        let task = tokio::spawn(async move {
1424            let mut session = session;
1425            let stopped =
1426                run_session(FakePipe(wire), &mut session, &events_tx, &mut command_rx).await;
1427            (stopped, session)
1428        });
1429        Running {
1430            commands,
1431            events,
1432            seen: Vec::new(),
1433            task,
1434        }
1435    }

1437    impl Running {
1438        /// Consume events until one matches, keeping every one on the way.
1439        async fn wait_for(&mut self, mut matches: impl FnMut(&RealtimeEvent) -> bool) {
1440            loop {
1441                let event = self
1442                    .events
1443                    .recv()
1444                    .await
1445                    .expect("the session ended without the expected event");
1446                let hit = matches(&event);
1447                self.seen.push(event);
1448                if hit {
1449                    return;
1450                }
1451            }
1452        }
1453
1454        /// Await the handshake, so what follows is ordered after it.
1455        async fn connected(&mut self) {
1456            self.wait_for(|event| *event == RealtimeEvent::Connected)
1457                .await;
1458        }
1459
1460        fn send(&self, command: Command) {
1461            self.commands.send(command).expect("the session is running");
1462        }
1463
1464        /// Stop the session and collect everything it produced.
1465        async fn stop(mut self) -> (Stopped, ClientSession, Vec<RealtimeEvent>) {
1466            self.send(Command::Shutdown);
1467            let (stopped, session) = self.task.await.expect("the session task panicked");
1468            while let Ok(event) = self.events.try_recv() {
1469                self.seen.push(event);
1470            }
1471            (stopped, session, self.seen)
1472        }
1473    }

1502    /// keeps dialling would spin the test), which is also how a test asserts "no

1505        script: Mutex<VecDeque<Attempt>>,
1506        reached: Arc<Mutex<Reached>>,
1507        /// Frames every WebSocket leg delivers.
1508        ws_wire: Mutex<VecDeque<Arc<Mutex<Wire>>>>,
1509    }

1511    impl FakeDialer {
1512        fn new(script: impl IntoIterator<Item = Attempt>) -> Self {
1513            Self {
1514                script: Mutex::new(script.into_iter().collect()),
1515                reached: Arc::new(Mutex::new(Reached::default())),
1516                ws_wire: Mutex::new(VecDeque::new()),
1517            }
1518        }

1520        /// Queue the wires the scripted WebSocket legs hand back, in order.
1521        fn with_ws_wires(self, wires: impl IntoIterator<Item = Arc<Mutex<Wire>>>) -> Self {
1522            *self.ws_wire.lock().unwrap() = wires.into_iter().collect();

1524        }

1526        fn reached(&self) -> Arc<Mutex<Reached>> {
1527            self.reached.clone()
1528        }

1530        /// The step the current attempt is on. Peeked, not popped: one attempt
1531        /// spans several trait calls.

1533            match self.script.lock().unwrap().front()? {
1534                Attempt::ConfigError(_) => Some("config_error"),
1535                Attempt::WtFails(_) => Some("wt_fails"),
1536                Attempt::WtWorks(_) => Some("wt_works"),
1537                Attempt::WsOnly => Some("ws_only"),
1538                Attempt::WsFails(_) => Some("ws_fails"),

1588                Some("ws_only") => {
1589                    self.script.lock().unwrap().pop_front();
1590                }
1591                Some("ws_fails") => {
1592                    let Some(Attempt::WsFails(err)) = self.script.lock().unwrap().pop_front()
1593                    else {
1594                        unreachable!()
1595                    };
1596                    return Err(err);
1597                }
1598                _ => {}
1599            }

1601                .ws_wire
1602                .lock()
1603                .unwrap()
1604                .pop_front()
1605                .unwrap_or_else(|| open_wire([welcome()]));
1606            Ok(FakePipe(wire))
1607        }
