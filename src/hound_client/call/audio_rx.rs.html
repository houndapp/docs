1//! Inbound audio: pull → reorder by timestamp → Opus decode (bounded PLC on
2//! genuine gaps) → per-peer jitter buffer on the mix bus, plus level metering.
3//! The encoded-frame reorder hold undoes the cross-stream reordering a
4//! screenshare induces on the shared connection BEFORE the stateful decoder;
5//! release is arrival-driven — count-based in the steady state, and drained
6//! outright once the sender goes DTX (see [`release_next`]) — because the moq
7//! group read is not cancel-safe mid-object, so no recv timeout is ever raced
8//! against it. For the same reason
9//! a wedged track can't be detected here: the pipeline publishes an arrival
10//! counter instead, and the subscribe loop's stall watchdog kills it out of band.
11
12use super::*;

14/// Frames held in the encoded-audio reorder buffer to undo network reordering before
15/// the (stateful) Opus decode. `recv_group` delivers frames in ARRIVAL order; on the
16/// shared connection a screenshare reorders the tiny per-frame audio streams, so a
17/// frame can arrive after a later one. Decoding in arrival order forces dropping the
18/// late frame and concealing it with PLC — reordered becomes lost, and on a busy
19/// connection that is continuous distortion. Holding a few frames and releasing the oldest by
20/// timestamp restores a clean in-order stream into the decoder; genuine loss still
21/// surfaces as a real gap. 3 frames (~60 ms) absorbs the multi-frame reordering the
22/// screenshare induces; the added latency is recovered by the PCM jitter buffer
23/// shrinking once arrival is smooth. NOT done via a recv timeout — the moq group read
24/// is not cancel-safe mid-object — so release is arrival-driven throughout; see
25/// [`release_next`] for the count rule and the DTX drain that suspends it.
26const AUDIO_REORDER_HOLD: usize = 3;
27
28/// A pulled frame plus **when it came off the wire**.
29///
30/// The arrival instant has to be captured at the pull and carried through the hold,
31/// because the hold is count-based: how long a frame waits in it is a function of when
32/// the NEXT frames arrive, not of the network. Two consumers need the honest number
33/// and would otherwise silently measure the hold instead of the link — the jitter
34/// estimator (differential over `arrivalΔ − tsΔ`; see [`BusProducer::push_at`]) and,
35/// through it, the recommended playout depth.
36struct HeldFrame {
37    /// Local time (on the shared [`CaptureClock`]) the pull completed.
38    arrival_us: i64,
39    frame: WireFrame,
40}
41
42/// Insert `frame` into `buf` kept sorted ascending by timestamp, dropping an exact
43/// duplicate-timestamp frame (a retransmit of something already buffered). Returns
44/// false if dropped. Pure + unit-tested — the reorder correctness hinges on this.
45fn reorder_insert(buf: &mut Vec<HeldFrame>, held: HeldFrame) -> bool {
46    match buf.binary_search_by_key(&held.frame.timestamp_us, |f| f.frame.timestamp_us) {
47        Ok(_) => false,
48        Err(i) => {
49            buf.insert(i, held);
50            true
51        }
52    }
53}

55/// The hold's release decision — the whole of it, so the pull loop below is only
56/// network I/O and the policy can be driven by tests against the real jitter machinery.
57/// Returns the frame to process now, or `None` meaning "pull more".
58///
59/// Three rules, in order:
60///
61/// 1. **The suppression drain.** `drain` is set when a DTX-sized frame arrives, which is
62///    the sender telling us it has stopped transmitting: the next frame is a keepalive
63///    interval (~500 ms) away, so there is nothing left to reorder against and every
64///    frame still held is waiting on a network event that will not come for half a
65///    second. Empty the hold, then clear the flag and resume normally.
66///
67///    Holding through suppression is not merely late, it corrupts the receive-side
68///    estimates. The hold releases by COUNT, so each keepalive would be handed on one
69///    arrival later — ~1.5 s behind the wire — and every push would then land past its
70///    scheduled playout (a run of overdue arrivals → shallow re-anchors), while the
71///    500 ms release cadence would read as transit deviation and pin the recommended
72///    depth at its cap for the whole peak window.
73///
74///    What the drain gives up is reorder protection for the frames it releases early.
75///    That is the right trade and a small one: the frames in question are the tail of
76///    the confirmation window and the keepalives themselves — silence — and past the
77///    first keepalive the stream is 500 ms/frame, which no reordering reaches across.
78///    Speech is never drained early, because a coded frame never arms the flag.
79/// 2. **Steady state.** Release the oldest once more than [`AUDIO_REORDER_HOLD`] are
80///    buffered, so network reordering is undone before the stateful decode.
81/// 3. **End of track.** Drain whatever remains, oldest-first.
82///
83/// All three are arrival-driven, never timed: the moq group read is not cancel-safe
84/// mid-object, so nothing may be raced against `next_frame`.
85fn release_next(buf: &mut Vec<HeldFrame>, drain: &mut bool, ended: bool) -> Option<HeldFrame> {
86    if *drain {
87        if !buf.is_empty() {
88            return Some(buf.remove(0));
89        }
90        *drain = false;
91    }
92    if buf.len() > AUDIO_REORDER_HOLD || (ended && !buf.is_empty()) {
93        return Some(buf.remove(0));
94    }
95    None
96}

98/// One frame the receiver MANUFACTURES across a brief-loss gap, and the timestamp slot
99/// it fills. Two provenances, because the carrier packet carries in-band FEC for the
100/// frame immediately before it: the LAST missing slot is redeemed from real (re-encoded)
101/// signal, and only the earlier ones are extrapolated from nothing.
102///
103/// **Neither kind has a wire arrival of its own**, which is the property the jitter
104/// estimator hangs on and the reason this is one type rather than two code paths. PLC is
105/// fabricated outright; the FEC slot is real signal but it rode in inside its SUCCESSOR.
106/// Both go to [`BusProducer::push_concealed`] — see the single push site in
107/// [`audio_pipeline`].
108#[derive(Debug, Clone, Copy, PartialEq, Eq)]
109enum GapFill {
110    /// Extrapolated by the decoder's PLC — no signal behind it at all.
111    Plc(i64),
112    /// Redeemed from the carrier packet's in-band FEC.
113    Fec(i64),
114}
115
116impl GapFill {
117    /// The timestamp slot this fill occupies.
118    fn ts(self) -> i64 {
119        match self {
120            Self::Plc(ts) | Self::Fec(ts) => ts,
121        }
122    }
123
124    /// The arrival instant the jitter estimator may fold for this fill — **never any**,
125    /// for either kind, which is why this is stated once here rather than at the push
126    /// site. `None` selects [`BusProducer::push_concealed`] over `push_at`, and the
127    /// receive-seam tests read the same answer, so a fill that ever starts claiming a
128    /// wire arrival fails them rather than quietly deepening the buffer.
129    fn arrival_us(self) -> Option<i64> {
130        None
131    }
132}
133
134/// Plan the fill for an [`AudioGap::Conceal`] gap of `missing` frames after `prev_ts`;
135/// `fec` is whether the carrier packet is big enough to carry in-band FEC (a DTX-sized
136/// one is not — libopus would just conceal internally).
137///
138/// Oldest-first with the FEC slot LAST, and that order is load-bearing: the Opus decoder
139/// is stateful, so the recovery must be decoded before the carrier packet it was
140/// extracted from. Pure + unit-tested; the pipeline only decodes and pushes what this
141/// yields.
142fn gap_fill(prev_ts: i64, frame_us: i64, missing: i64, fec: bool) -> impl Iterator<Item = GapFill> {
143    let plc_until = if fec { missing - 1 } else { missing };
144    (1..=plc_until)
145        .map(move |i| GapFill::Plc(prev_ts + frame_us * i))
146        .chain(fec.then(|| GapFill::Fec(prev_ts + frame_us * missing)))
147}

149/// Apply one stream's playback gain and produce the TWO levels a decoded frame owes —
150/// deliberately not the same number. Returns `(ring, played)`:
151///
152/// * **ring** — the peer's speaking indicator, metered BEFORE the gain. Local
153///   volume/mute is our own listening choice about a peer, not a claim about whether
154///   they are talking, so turning someone down (or muting them outright) must never
155///   darken their ring. Mic streams only: the caller drops this for screens, whose
156///   gain stays visible on purpose — a locally-muted share should LOOK silent.
157/// * **played** — the panel / debug-report level, metered AFTER the gain, so it
158///   describes what the mix actually played (a muted stream reads 0 there).
159///
160/// Unity costs exactly what the single pre-split metering did: no gain pass, one RMS,
161/// both levels the same. Only an adjusted stream pays the second RMS (960 samples).
162/// Pure; unit-tested.
163fn gain_and_meter(
164    pcm: &mut hound_engine::types::PcmFrame,
165    gain: f32,
166    encoded_len: usize,
167) -> (f32, f32) {
168    let ring = reported_audio_level(encoded_len, pcm.rms());
169    if gain == 1.0 {
170        return (ring, ring);
171    }
172    apply_gain(&mut pcm.samples, gain);
173    (ring, reported_audio_level(encoded_len, pcm.rms()))
174}

176/// Audio decode pipeline: pull frames, **reorder by timestamp**, Opus-decode (PLC on
177/// genuine gaps via the decoder's `None`), push into the per-peer jitter buffer on the
178/// mix bus, and meter levels.
179#[allow(clippy::too_many_arguments)]
180pub(super) async fn audio_pipeline(
181    mut subscriber: MoqTrackSubscriber,
182    peer: PeerId,
183    source: Source,
184    playout_bus: Arc<PlayoutBus>,
185    levels: watch::Sender<LevelsView>,
186    clock: CaptureClock,
187    stop: Arc<AtomicBool>,
188    peer_stats: Arc<crate::stats::PeerStats>,
189    gain: Arc<std::sync::atomic::AtomicU32>,
190    delivered: Arc<AtomicBool>,
191    // Monotone count of frames pulled off the wire, sampled by the subscribe loop's
192    // stall watchdog. Bumped on ARRIVAL (not on decode) so a stream whose frames fail
193    // to decode still reads as live — the watchdog only asks "is the relay still
194    // delivering?", which is the one thing the unbounded pull can wedge on.
195    arrivals: Arc<AtomicU64>,
196) {
197    use hound_engine::types::OpusPacket;
198
199    let Ok(mut decoder) = OpusDecoder::new() else {
200        return;
201    };
202    // The mix bus mixes all slots regardless of label; the label only attributes
203    // starve-stats, so name screen app-audio honestly.
204    let is_screen = source == Source::Screen;
205    let akind = if is_screen {
206        InboundAudioKind::Screen
207    } else {
208        InboundAudioKind::Mic
209    };
210    // Tag the producer with the peer id so a recorded underflow glitch names the peer.
211    let producer =
212        playout_bus.register_tagged(if is_screen { "screen_audio" } else { "mic" }, peer.0);
213    let mut decoded: u64 = 0;
214    // Loss/reorder detection from the sender's capture timestamps. `prev_ts` advances
215    // only on in-order frames; `frame_us` (the Opus frame duration) is learned from the
216    // first decoded frame so the gap math doesn't assume 20 ms. The engine decodes at
217    // 48 kHz mono, so duration = samples · 1e6 / 48000.
218    const ENGINE_RATE_HZ: i64 = 48_000;
219    let mut prev_ts: Option<i64> = None;
220    // Was the frame before this one DTX-sized? A gap that follows one is the sender not
221    // transmitting (suppression/DTX) whatever its size — see `classify_audio_gap`.
222    let mut prev_was_dtx = false;
223    let mut frame_us: i64 = 20_000; // sane default until the first frame refines it
224    let mut learned_frame_us = false;
225    // Cadence diagnostics — a retained debug tool. Distinguishes the THREE causes of an
226    // active-stream gap that the smoothed jitter number hides: brief network loss
227    // (small ts gaps → PLC), sender DTX / capture discontinuity (large ts gaps → NOT
228    // loss, must not be PLC-fabricated), and sender↔receiver clock skew (ts-elapsed vs
229    // local-elapsed divergence → buffer slowly drains). Logged once per window.
230    let mut diag = CadenceDiag::default();
231    // Encoded-frame reorder buffer (sorted by ts): we pull from the network into it so
232    // reordering is undone BEFORE the stateful decode, and `release_next` owns when a
233    // frame comes back out — including the DTX drain `drain_hold` arms.
234    let mut reorder: Vec<HeldFrame> = Vec::with_capacity(AUDIO_REORDER_HOLD + 2);
235    let mut ended = false;
236    let mut drain_hold = false;
237    while !stop.load(Ordering::Relaxed) {
238        // Acquire the next frame to PROCESS, in TIMESTAMP order, refilling from the
239        // network until the hold will give one up. `next_frame` is never cancelled —
240        // only fully-received frames enter the buffer.
241        let held = loop {
242            if let Some(f) = release_next(&mut reorder, &mut drain_hold, ended) {
243                break Some(f);
244            }
245            if ended {
246                break None; // track over and the hold is dry
247            }
248            let now = clock.now();
249            match subscriber.next_frame(now).await {
250                Ok(Some(f)) => {
251                    arrivals.fetch_add(1, Ordering::Relaxed);
252                    // RTC-debug: one inbound Opus frame received (counted on arrival).
253                    peer_stats.audio_received(akind, f.data.len());
254                    drain_hold |= f.data.len() <= DTX_MAX_BYTES;
255                    // Stamped AFTER the await completes: this is the wire instant, and
256                    // the only place it can still be observed.
257                    let arrival_us = clock.now();
258                    reorder_insert(
259                        &mut reorder,
260                        HeldFrame {
261                            arrival_us,
262                            frame: f,
263                        },
264                    );
265                }
266                Ok(None) | Err(_) => ended = true,
267            }
268        };
269        let Some(HeldFrame { arrival_us, frame }) = held else {
270            break;
271        };
272        let ts = frame.timestamp_us;
273        // Local time at processing (after any reorder hold) — for the cadence skew calc.
274        let now = clock.now();
275        // Built up-front so the gap handler below can redeem this packet's in-band
276        // FEC for the frame that preceded it; also the decode input afterwards.
277        let encoded_len = frame.data.len();
278        let packet = OpusPacket {
279            data: frame.data,
280            timestamp_us: TimestampUs::from_micros(ts),
281        };
282
283        // Frames now arrive in timestamp order, so a non-advancing timestamp is a true
284        // duplicate/straggler the reorder buffer couldn't place (rare), not routine
285        // network reordering — skip it to keep the stateful decoder coherent.
286        if let Some(pt) = prev_ts {
287            let gap = ts - pt;
288            if gap <= 0 {
289                peer_stats.record_audio_loss(akind, 0, true);
290                continue;
291            }
292            diag.note_gap(gap);
293            // PLC conceals BRIEF loss only — see [`classify_audio_gap`], which draws
294            // the line. A larger gap is the sender not transmitting (Opus DTX plus the
295            // publisher's silence suppression: nothing but a keepalive every ~500 ms)
296            // or a capture discontinuity — NOT packet loss. Fabricating one
297            // extrapolated PLC frame per 20 ms of gap would mislabel silence as loss (a
298            // silent peer would produce more concealment than real audio), waste CPU,
299            // and — worst — splice garbage PLC into an ACTIVE stream where it
300            // leapfrogs/drops the real frame behind it.
301            match classify_audio_gap(gap, frame_us, prev_was_dtx) {
302                AudioGap::Continuous => {}
303                AudioGap::Conceal(missing) => {
304                    // A DTX-sized carrier has no FEC to spend, so its gap is filled by
305                    // PLC alone; see [`gap_fill`] for the split and the decode order.
306                    for fill in gap_fill(pt, frame_us, missing, encoded_len > DTX_MAX_BYTES) {
307                        let ts = TimestampUs::from_micros(fill.ts());
308                        let synth = match fill {
309                            GapFill::Plc(_) => decoder.decode(None, ts),
310                            GapFill::Fec(_) => decoder.decode_fec(&packet, ts),
311                        };
312                        // ONE push site for every fill kind, and the estimator instant is
313                        // read off the fill rather than written here: none of them
314                        // crossed the wire at its own timestamp, so none has an arrival
315                        // to fold, and the only instant available is the pipeline's own
316                        // `now` — exactly what the estimator must never see. The FEC slot
317                        // is the subtle one: real signal, but it rode in inside its
318                        // SUCCESSOR, so booking it charges one frame PLUS the whole
319                        // reorder hold. See [`GapFill::arrival_us`] and
320                        // [`BusProducer::push_concealed`].
321                        if let Ok(f) = synth {
322                            let now = clock.now();
323                            let _ = match fill.arrival_us() {
324                                Some(a) => producer.push_at(a, now, fill.ts(), &f.samples),
325                                None => producer.push_concealed(now, fill.ts(), &f.samples),
326                            };
327                            // Counted apart: a redeemed slot is recovered signal, an
328                            // extrapolated one is invention, and the pair is what makes
329                            // the redemption path visible in a log at all.
330                            match fill {
331                                GapFill::Plc(_) => diag.plc += 1,
332                                GapFill::Fec(_) => diag.fec += 1,
333                            }
334                        }
335                    }
336                    peer_stats.record_audio_loss(akind, missing as u64, false);
337                }
338                AudioGap::Silence => {
339                    // Silence across the gap (correct — there was no audio), no loss
340                    // recorded, and the peer's meter goes dark at once rather than
341                    // holding its last speaking level until the next frame decodes.
342                    // Resync to the new frame (prev_ts advances after decode).
343                    diag.big_gaps += 1;
344                    if !is_screen {
345                        levels.send_modify(|l| {
346                            l.peers.insert(peer.0, 0.0);
347                        });
348                    }
349                    peer_stats.set_audio_level(akind, 0.0);
350                }
351            }
352        }
353
354        let Ok(mut pcm) = decoder.decode(Some(&packet), TimestampUs::from_micros(ts)) else {
355            continue;
356        };
357        delivered.store(true, Ordering::Relaxed);
358        prev_ts = Some(ts);
359        prev_was_dtx = encoded_len <= DTX_MAX_BYTES;
360        if !learned_frame_us && !pcm.samples.is_empty() {
361            frame_us = (pcm.samples.len() as i64 * 1_000_000 / ENGINE_RATE_HZ).max(1);
362            learned_frame_us = true;
363        }
364        // Per-stream playback gain (the tile volume/mute control), applied before the
365        // mix push, and the two levels it splits apart: the speaking RING meters
366        // PRE-gain (a peer we turned down is still talking), the PANEL level meters
367        // POST-gain (it reports what was actually played). Screens have no ring, so
368        // their only reported level is the post-gain one — a locally-muted share
369        // stays visually silent. See [`gain_and_meter`]; unity is the fast path (one
370        // atomic load, one RMS).
371        let g = f32::from_bits(gain.load(Ordering::Relaxed));
372        let (ring, played) = gain_and_meter(&mut pcm, g, encoded_len);
373        peer_stats.set_audio_level(akind, played);
374        if !is_screen {
375            levels.send_modify(|l| {
376                l.peers.insert(peer.0, ring);
377            });
378        }
379        // The mix bus pulls on its own RT clock; we only FILL the jitter buffer.
380        // Surface the post-push jitter-buffer health to the panel/report: depth
381        // (cur vs recommended), late/overflow drops, and this slot's underflow total.
382        // A depth that climbs while silent = buffered-but-never-released (a playout
383        // stall); recommended ≫ target = the buffer is too shallow for the link.
384        // `arrival_us` (the wire instant, carried through the hold) feeds the jitter
385        // estimator; `clock.now()` is when the frame actually became available for
386        // playout. Conflating them makes the reorder hold's own release cadence read as
387        // link jitter — see [`BusProducer::push_at`].
388        let status = producer.push_at(arrival_us, clock.now(), ts, &pcm.samples);
389        peer_stats.set_audio_playout_depth(akind, status.buffered_frames);
390        peer_stats.set_audio_jitter(akind, status.jitter_us.max(0) as u32);
391        peer_stats.set_audio_jitterbuf(
392            akind,
393            status.target_delay_us.max(0) as u32,
394            status.recommended_delay_us.max(0) as u32,
395            status.late_drops,
396            status.overflow_drops,
397            status.underflow_total,
398        );
399        decoded += 1;
400        // Feed the cadence diagnostic and emit a window summary periodically. This is
401        // the tool for attributing an active-stream gap: high `plc`/`fec` = brief loss
402        // (extrapolated vs redeemed); high `big_gaps`/`max_gap_ms` = sender DTX or a
403        // capture stall (a sender-side problem, not network); large |skew_ppm| = clock
404        // drift slowly draining the buffer (needs resampling/retiming, not a deeper
405        // buffer). Read `plc`/`fec` ALONGSIDE `jitterbuf_ms`, and across peers: a stream
406        // carrying a couple of fills while its depth sits far above a co-present peer's
407        // is a gap-fill frame reaching the jitter estimator, not a worse link.
408        if let Some(w) = diag.observe(ts, now) {
409            tracing::info!(
410                ?source,
411                peer = peer.0,
412                real = w.real,
413                plc = w.plc,
414                fec = w.fec,
415                big_gaps = w.big_gaps,
416                max_gap_ms = w.max_gap_ms,
417                skew_ppm = w.skew_ppm,
418                jitterbuf_ms = status.target_delay_us / 1000,
419                underflow_total = status.underflow_total,
420                "audio: cadence window"
421            );
422        }
423        if decoded == 1 || decoded.is_multiple_of(500) {
424            tracing::info!(
425                ?source,
426                peer = peer.0,
427                decoded,
428                "audio: decoded+mixed frames"
429            );
430        }
431    }
432    if !is_screen {
433        levels.send_modify(|l| {
434            l.peers.remove(&peer.0);
435        });
436    }
437    tracing::info!(?source, peer = peer.0, decoded, "audio: pipeline ended");
438}

448    /// One 20 ms frame at the engine's rate — what `frame_us` is learned as.
449    const FRAME_US: i64 = 20_000;
450    /// A coded-speech payload size, and a DTX one. The gap between them is the
451    /// sender's own speech/no-speech verdict, and the drain rule reads it.
452    const VOICED_BYTES: usize = 62;
453    const DTX_BYTES: usize = 2;
454
455    /// A CODED frame at `ts` (arrival = ts, i.e. a zero-latency link).
456    fn afr(ts: i64) -> HeldFrame {
457        held(ts, ts, VOICED_BYTES)
458    }
459
460    fn held(ts: i64, arrival_us: i64, bytes: usize) -> HeldFrame {
461        HeldFrame {
462            arrival_us,
463            frame: WireFrame {
464                sender: 0,
465                track: TrackKind::CamAudio,
466                codec: WireCodec::Opus,
467                keyframe: true,
468                frame_seq: 0,
469                timestamp_us: ts,
470                temporal_id: 0,
471                data: vec![ts as u8; bytes],
472            },
473        }
474    }
475
476    /// Release everything the hold will currently give up, appending timestamps to
477    /// `out`. The real [`release_next`], looped — never a restatement of its rules.
478    fn drain_available(
479        buf: &mut Vec<HeldFrame>,
480        drain: &mut bool,
481        ended: bool,
482        out: &mut Vec<i64>,
483    ) {
484        while let Some(h) = release_next(buf, drain, ended) {
485            out.push(h.frame.timestamp_us);
486        }
487    }

489    #[test]
490    fn reorder_insert_sorts_by_timestamp() {
491        // Frames arriving out of order are placed in ascending-timestamp order, so the
492        // stateful decoder downstream sees a clean monotonic stream.
493        let mut buf = Vec::new();
494        assert!(reorder_insert(&mut buf, afr(40_000)));
495        assert!(reorder_insert(&mut buf, afr(20_000))); // arrives late
496        assert!(reorder_insert(&mut buf, afr(60_000)));
497        assert!(reorder_insert(&mut buf, afr(0))); // arrives very late
498        let order: Vec<i64> = buf.iter().map(|f| f.frame.timestamp_us).collect();
499        assert_eq!(order, vec![0, 20_000, 40_000, 60_000], "sorted by ts");
500    }

513    #[test]
514    fn reorder_release_yields_monotonic_stream() {
515        // Simulate the HOLD release policy over a reordered arrival sequence and assert
516        // the released (oldest-first) timestamps are monotonic — no frame is ever
517        // released out of order, which is what keeps the decoder coherent.
518        let arrivals = [0i64, 40_000, 20_000, 80_000, 60_000, 100_000];
519        let (mut buf, mut drain, mut released) = (Vec::new(), false, Vec::new());
520        for &ts in &arrivals {

534    /// The wire timeline of a publisher that talks, goes quiet (suppressed, one
535    /// keepalive per `KEEPALIVE_INTERVAL`) for `quiet` frames' worth of wall time, then
536    /// talks again — `(capture timestamp, payload size)`, since the SIZE is the sender's
537    /// own speech/no-speech verdict and half the classification reads it. Capture
538    /// timestamps throughout: the publisher never invents any.
539    ///
540    /// `resume_lag_frames` offsets the resume from the keepalive cadence. A speaker does
541    /// not resume on the wire's schedule, so the real gap on the resume edge is uniform
542    /// in `(0, KEEPALIVE_INTERVAL]` — and a resume that lands early in that interval is
543    /// the geometry that produced the CI failure this file's fix addresses.
544    fn suppressed_timeline(quiet_frames: i64, resume_lag_frames: i64) -> Vec<(i64, usize)> {
545        let keepalive_us = KEEPALIVE_INTERVAL.as_micros() as i64;
546        // 1 s of speech.
547        let mut wire: Vec<(i64, usize)> = (0..50).map(|i| (i * FRAME_US, VOICED_BYTES)).collect();
548        let quiet_start = 50 * FRAME_US;
549        // The confirmation window still publishes every frame — DTX-sized ones, which is
550        // what arms the gate — and then only keepalives.
551        for i in 0..SUPPRESS_AFTER as i64 {
552            wire.push((quiet_start + i * FRAME_US, DTX_BYTES));
553        }
554        let mut t = quiet_start + SUPPRESS_AFTER as i64 * FRAME_US;
555        let mut last_keepalive = t;
556        let quiet_until = quiet_start + quiet_frames * FRAME_US;
557        while t + keepalive_us < quiet_until {
558            t += keepalive_us;
559            // A keepalive is a REAL captured frame, so its stamp lands on the frame grid.
560            last_keepalive = t - t % FRAME_US;
561            wire.push((last_keepalive, DTX_BYTES));
562        }
563        let resume_at = last_keepalive + resume_lag_frames * FRAME_US;
564        wire.extend((0..50).map(|i| (resume_at + i * FRAME_US, VOICED_BYTES))); // speech again
565        wire
566    }

568    /// Classify every gap in a wire timeline the way the pipeline does — each gap
569    /// against the payload size of the frame BEFORE it. Returns (concealed frames,
570    /// silences, continuous).
571    fn classify_timeline(wire: &[(i64, usize)]) -> (i64, u32, u32) {
572        let (mut concealed, mut silences, mut continuous) = (0i64, 0u32, 0u32);
573        for w in wire.windows(2) {
574            match classify_audio_gap(w[1].0 - w[0].0, FRAME_US, w[0].1 <= DTX_MAX_BYTES) {
575                AudioGap::Continuous => continuous += 1,
576                AudioGap::Conceal(n) => concealed += n,
577                AudioGap::Silence => silences += 1,
578            }
579        }
580        (concealed, silences, continuous)
581    }

639    /// A frame on its way into the mix bus. `PlayoutBuffer` only ever reads
640    /// `timestamp_us()`, so this is the whole item.
641    #[derive(Debug)]
642    struct Pcm(i64);
643    impl Timestamped for Pcm {
644        fn timestamp_us(&self) -> i64 {
645            self.0
646        }
647    }

649    /// The receive seam: the real hold ([`reorder_insert`] + [`release_next`]) feeding
650    /// the real [`AdaptiveJitter`] + [`PlayoutBuffer`] the mix bus runs, wired the way
651    /// `BusProducer::push_at` wires them — the estimator on the WIRE arrival, the
652    /// buffer on the post-hold instant — plus the gap handler, so a test can drive loss
653    /// and concealment as well as cadence.
654    struct Seam {
655        buf: Vec<HeldFrame>,
656        drain: bool,
657        playout: PlayoutBuffer<Pcm>,
658        adapt: AdaptiveJitter,
659        /// Post-hold release instants, so a test can measure the added latency.
660        released_at: Vec<(i64, i64)>,
661        /// Gap-handler state, carried exactly as the pipeline carries it.
662        prev_ts: Option<i64>,
663        prev_was_dtx: bool,
664        /// Every fill the gap handler manufactured, so a test can prove it fired
665        /// (an assertion about concealment is vacuous if none happened).
666        fills: Vec<GapFill>,
667    }
668
669    impl Seam {
670        fn new() -> Self {
671            Self {
672                buf: Vec::new(),
673                drain: false,
674                playout: PlayoutBuffer::new(PLAYOUT_TARGET_US),
675                adapt: AdaptiveJitter::with_floor(PLAYOUT_TARGET_US),
676                released_at: Vec::new(),
677                prev_ts: None,
678                prev_was_dtx: false,
679                fills: Vec::new(),
680            }
681        }
682
683        /// One frame off the wire at `arrival_us`, then everything the hold gives up as
684        /// a result — pushed at `arrival_us` too, since the hold does not block.
685        fn arrive(&mut self, ts: i64, arrival_us: i64, bytes: usize) {
686            self.drain |= bytes <= DTX_MAX_BYTES;
687            reorder_insert(&mut self.buf, held(ts, arrival_us, bytes));
688            while let Some(h) = release_next(&mut self.buf, &mut self.drain, false) {
689                let (fts, fbytes) = (h.frame.timestamp_us, h.frame.data.len());
690                // The gap handler as the pipeline runs it: the REAL classifier against
691                // the frame before this one, the REAL fill plan, and — the line under
692                // test — the fill's OWN answer for which instant the estimator may fold,
693                // dispatched exactly as the push site dispatches it.
694                if let Some(pt) = self.prev_ts
695                    && let AudioGap::Conceal(missing) =
696                        classify_audio_gap(fts - pt, FRAME_US, self.prev_was_dtx)
697                {
698                    for fill in gap_fill(pt, FRAME_US, missing, fbytes > DTX_MAX_BYTES) {
699                        if let Some(a) = fill.arrival_us() {
700                            self.adapt.on_frame(&mut self.playout, a, fill.ts());
701                        }
702                        self.playout.push(arrival_us, Pcm(fill.ts()));
703                        self.fills.push(fill);
704                    }
705                }
706                self.prev_ts = Some(fts);
707                self.prev_was_dtx = fbytes <= DTX_MAX_BYTES;
708                // Exactly `BusProducer::push_at(h.arrival_us, now, ts, …)`.
709                self.adapt.on_frame(&mut self.playout, h.arrival_us, fts);
710                self.playout.push(arrival_us, Pcm(fts));
711                self.released_at.push((fts, arrival_us));
712                let _ = self.playout.pop_due(arrival_us);
713            }
714        }
715    }

1075    /// A suppressing publisher does not advance `frame_seq` for a frame it never sent,
1076    /// so its stream has SEQ HOLES. No audio consumer may read one as loss: the reorder
1077    /// buffer sorts by timestamp, the gap math is timestamp-driven, and the stall
1078    /// watchdog counts arrivals — video's `DownlinkDemand` (the one thing that does fold
1079    /// `frame_seq`) has no audio counterpart. This pins that the ordering is unaffected.
1080    #[test]
1081    fn the_audio_path_reads_nothing_from_frame_seq() {
1082        let (mut buf, mut drain, mut released) = (Vec::new(), false, Vec::new());
1083        // Timestamps advance on the 20 ms grid; seq jumps as suppression withholds.
1084        for (i, seq) in [0u32, 1, 2, 40, 41, 900, 901, 902].into_iter().enumerate() {
1085            let mut f = afr(i as i64 * FRAME_US);
1086            f.frame.frame_seq = seq;
1087            reorder_insert(&mut buf, f);
1088            drain_available(&mut buf, &mut drain, false, &mut released);
1089        }
1090        drain_available(&mut buf, &mut drain, true, &mut released);
1091        assert_eq!(
1092            released,
1093            (0..8).map(|i| i * FRAME_US).collect::<Vec<_>>(),
1094            "release order follows timestamps alone; seq holes are invisible here"
1095        );
1096    }
