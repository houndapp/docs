1//! # Derived base-layer (`…_t0`) tracks — the relay's temporal-SVC half
2//!
3//! A publisher's camera encoder marks each frame with its L1T2 temporal layer
4//! (`hound_media::TemporalLayer`), carried in the MoQ object envelope's reserved
5//! byte. This module turns that marking into something a receiver can subscribe
6//! to: for every camera video broadcast in the origin, it republishes a
7//! **derived** broadcast under `…/cam_t0` carrying only the base-layer objects.
8//!
9//! A receiver that takes `cam_t0` instead of `cam` gets the same resolution at
10//! half the frame rate for ~70% of the bits, with no re-encode anywhere and no
11//! keyframe — which is the whole point: the publisher publishes once and does not
12//! know, or need to know, which of its subscribers took which.
13//!
14//! ## Why a derived TRACK and not object dropping
15//!
16//! MOQT draft-19 §9.4 removed the relay's licence to drop objects: *"A relay MUST
17//! NOT reorder or drop objects received on a multi-object stream when forwarding
18//! to subscribers."* Sniffing a layer byte and skipping objects mid-stream is
19//! therefore not a door that is open, however convenient. Interposition is:
20//! [`moq_net::OriginProducer::publish_broadcast`] lets us consume `…/cam` and
21//! republish a **different** broadcast, to which §9.4 simply does not apply. The
22//! derived track is complete and well-formed on its own terms.
23//!
24//! ## What this costs the relay
25//!
26//! [`crate::moq_relay`]'s central claim is that the relay never touches a byte —
27//! moq-net's shared [`moq_net::Origin`] fans everything out and the SFU only owns
28//! the auth gate. This module is the first thing to break that, so it is built to
29//! break it as little as possible:
30//!
31//! * **No transcode, no bitstream parse.** The filter reads ONE byte, through
32//!   [`hound_transport::moq::object_temporal_id`] — the same accessor the
33//!   endpoints encode with, so the relay can never grow its own idea of where the
34//!   layer id lives.
35//! * **No copy.** moq-net hands objects out as [`bytes::Bytes`]; forwarding one is
36//!   a refcount bump.
37//! * **`frame_seq` is never rewritten.** mediasoup's regression
38//!   (versatica/mediasoup#1625) is that rewriting frame numbers corrupts the
39//!   dependency structure. The gaps a filtered track leaves in the sequence space
40//!   are intentional and the receiver is told to expect them
41//!   (`hound_media::TEMPORAL_BASE_STRIDE`) rather than being lied to.
42//! * **Nothing runs until somebody subscribes.** Each derived track is announced
43//!   eagerly (so a receiver's subscribe resolves immediately) but the per-object
44//!   pump is gated on [`moq_net::TrackProducer::used`] and stops again on
45//!   `unused`. A call where nobody is constrained pays one idle task per camera
46//!   and zero per-object work.
47//!
48//! ## Group and keyframe semantics are preserved
49//!
50//! The derived track mirrors the source's group structure: same group sequences,
51//! same boundaries. A derived group is created **lazily**, on its first surviving
52//! object, so a group whose objects are all enhancement-layer simply does not
53//! appear rather than appearing empty.
54//!
55//! That lazy creation is also what preserves the join contract. hound's video
56//! publisher rolls a group on every keyframe, so a group's first object is always
57//! the IDR — and a keyframe is always base layer (an IDR is by construction
58//! referenced; the encoder additionally forces this, see `vt_encoder`). So the
59//! first surviving object of a derived group is the same IDR, and moq-net's
60//! head-of-current-group replay hands a fresh `…_t0` subscriber a decodable
61//! stream exactly as the source track does.

70/// The moq track name a base-layer view is derived from.
71///
72/// Camera source tracks only, matching `hound_media::base_view_offered` — that
73/// function is the receiver's half of the same decision and this is the relay's,
74/// so the test below pins them equal rather than trusting two lists to agree.
75///
76/// Screen is excluded because halving a share's frame rate is not a rung anyone
77/// wants (its ladder degrades by legibility, and it already spends frames to buy
78/// resolution); `cam_l0` is excluded because its rungs are already at the
79/// frame-rate floor for a recognisable face, and deriving it would double the
80/// relay's per-object work for the rung that benefits least.
81const DERIVABLE_TRACK: &str = "cam";

83/// The closed set of `sfu_derived_objects_total{outcome}` label values — every
84/// verdict [`is_base_layer`] can reach. Bounded and enumerated here so `main`'s
85/// zero-init can expose both on a fresh scrape (an all-`forwarded` relay would
86/// otherwise render no `filtered` series at all, and "the filter is doing
87/// nothing" would be indistinguishable from "the series does not exist yet").
88pub const DERIVE_OUTCOMES: &[&str] = &["forwarded", "filtered"];

90/// Whether `path`'s track tail is one this module derives a `…_t0` view of.
91///
92/// Takes the whole broadcast path because that is what the origin announces:
93/// `space/{space}/peer/{user}/{peer}/{track}` (see
94/// [`crate::moq_relay::NAMESPACE_CONVENTION`]). A path with no `/` is not a hound
95/// broadcast and is left alone.
96pub(crate) fn derivable(path: &str) -> Option<&str> {
97    let track = path.rsplit('/').next()?;
98    // Never derive from our own output: `cam_t0_t0` would be an infinite regress
99    // of tasks, and the announce that starts it is one we made.
100    if is_base_track_name(track) || track != DERIVABLE_TRACK {
101        return None;
102    }
103    Some(track)
104}

106/// The derived broadcast path for a source path (`…/cam` → `…/cam_t0`).
107fn derived_path(path: &str) -> String {
108    base_track_name(path)
109}

111/// Owns the deriver supervisor task for one origin. Dropping it stops derivation
112/// and, with it, drops every derived broadcast's producer — so a subscriber still
113/// on a `…_t0` track sees a clean end-of-track rather than a stalled stream. Held
114/// by [`crate::sfu::Sfu`] / [`crate::moq_relay::Relay`] so the task's lifetime is
115/// exactly the server's.
116pub(crate) struct Deriver(JoinHandle<()>);
117
118impl Deriver {
119    pub(crate) fn spawn(origin: &OriginProducer) -> Self {
120        Self(spawn_deriver(origin.clone()))
121    }
122}

124impl Drop for Deriver {
125    fn drop(&mut self) {
126        self.0.abort();
127    }

130/// Watch `origin` for camera broadcasts and keep a derived `…_t0` broadcast
131/// alongside each one, for as long as it is announced.
132///
133/// Spawns one supervisor task; it owns a task per live source path and aborts
134/// that task when the source unannounces (which also drops the derived
135/// broadcast's producer, unannouncing it in turn — a receiver still subscribed
136/// sees end-of-track, exactly as it would if the publisher had simply left).
137///
138/// `origin` must be the **root** (unscoped) producer: the derived broadcast is
139/// published under the publisher's own `space/{s}/peer/{u}/{p}/` prefix, which no
140/// single connection's scoped view may write outside of.
141pub(crate) fn spawn_deriver(origin: OriginProducer) -> JoinHandle<()> {
142    tokio::spawn(async move {
143        let mut announces = origin.consume();
144        // Live derivations, keyed by SOURCE path. The `JoinHandle` is the whole
145        // lifetime: aborting it drops the derived `BroadcastProducer`.
146        let mut live: HashMap<String, JoinHandle<()>> = HashMap::new();
147
148        while let Some((path, broadcast)) = announces.announced().await {
149            let path = path.as_str().to_owned();
150            match broadcast {
151                Some(broadcast) => {
152                    let Some(track) = derivable(&path) else {
153                        continue;
154                    };
155                    let track = track.to_owned();
156                    // A re-announce on the same path (a publisher that dropped and
157                    // republished) replaces the derivation rather than racing a
158                    // second one against it.
159                    //
160                    // AWAITED, not just aborted: the old task owns the derived
161                    // `BroadcastProducer`, and it is dropping that producer which
162                    // unannounces the old `…_t0`. `create_broadcast` on a path whose
163                    // previous producer has not dropped yet is the same-path
164                    // announce race that has bitten this codebase before — the new
165                    // announce goes in and the old one's unannounce then takes it
166                    // straight back out, leaving a path subscribers can see but
167                    // nothing publishes to. Awaiting the aborted task is what makes
168                    // the drop happen-before the re-create.
169                    if let Some(prev) = live.remove(&path) {
170                        prev.abort();
171                        let _ = prev.await;
172                        metrics::gauge!("sfu_derived_broadcasts_active").decrement(1.0);
173                    }
174                    let out_path = derived_path(&path);
175                    let Some(producer) = origin.create_broadcast(Path::new(&out_path)) else {
176                        tracing::warn!(%path, %out_path, "derive: origin refused the derived path");
177                        continue;
178                    };
179                    tracing::info!(%path, %out_path, "derive: publishing base-layer track");
180                    metrics::gauge!("sfu_derived_broadcasts_active").increment(1.0);
181                    live.insert(
182                        path.clone(),
183                        tokio::spawn(derive_broadcast(broadcast, producer, track, out_path)),
184                    );
185                }
186                None => {
187                    if let Some(task) = live.remove(&path) {
188                        task.abort();
189                        metrics::gauge!("sfu_derived_broadcasts_active").decrement(1.0);
190                        tracing::info!(%path, "derive: source unannounced — dropping derived track");
191                    }
192                }
193            }
194        }
195
196        for (_, task) in live.drain() {
197            task.abort();
198        }
199    })
200}

202/// One source broadcast's derivation: announce `out_path`'s track, then pump it
203/// whenever somebody is subscribed.
204///
205/// The outer loop is the demand gate. `used()` resolves when a downstream
206/// subscriber attaches; `unused()` resolves when the last one leaves, at which
207/// point the upstream subscription is dropped and the task goes back to idle.
208/// That is what keeps a relay's per-object cost proportional to what receivers
209/// are actually taking rather than to how many cameras are publishing.
210async fn derive_broadcast(
211    source: BroadcastConsumer,
212    mut producer: moq_net::BroadcastProducer,
213    track_name: String,
214    out_path: String,
215) {
216    let derived = match producer.create_track(Track::new(base_track_name(&track_name))) {
217        Ok(t) => t,
218        Err(e) => {
219            tracing::warn!(%out_path, "derive: create_track failed: {e}");
220            return;
221        }
222    };
223    // `producer` is held for the task's lifetime: dropping it unannounces.
224    let _producer = producer;
225
226    loop {
227        if derived.used().await.is_err() {
228            return; // the derived track was closed/aborted
229        }
230        metrics::counter!("sfu_derived_subscriptions_total").increment(1);
231        metrics::gauge!("sfu_derived_pumps_active").increment(1.0);
232        // Whichever resolves first: the source ended, or the last subscriber left.
233        // The pump future is simply dropped in the second case — the moq-net
234        // consumers it holds are poll-based state machines whose cursors advance
235        // only on `Ready`, so dropping mid-poll loses nothing that mattered.
236        let source_ended = tokio::select! {
237            () = pump_base_layer(&source, derived.clone(), &track_name) => true,
238            _ = derived.unused() => false,
239        };
240        metrics::gauge!("sfu_derived_pumps_active").decrement(1.0);
241        if source_ended {
242            // Nothing left to derive; the supervisor tears this task down on the
243            // unannounce anyway.
244            tracing::debug!(%out_path, "derive: source track ended");
245            return;
246        }
247        tracing::debug!(%out_path, "derive: no subscribers — pausing");
248    }
249}

251/// Subscribe to the source track and copy its base-layer objects into `derived`,
252/// group for group, until the source ends or errors.
253///
254/// Groups are taken in ARRIVAL order (`recv_group`, not `next_group`): the derived
255/// track is a faithful re-publication, so it is not this layer's business to
256/// priority-drop a late group — the downstream subscriber's own drain already does
257/// that, on the same rule it applies to an undivided track.
258async fn pump_base_layer(source: &BroadcastConsumer, mut derived: TrackProducer, track_name: &str) {
259    let mut upstream = match source.subscribe_track(&Track::new(track_name)) {
260        Ok(t) => t,
261        Err(e) => {
262            tracing::warn!(%track_name, "derive: subscribe_track failed: {e}");
263            return;
264        }
265    };
266
267    loop {
268        let group = match upstream.recv_group().await {
269            Ok(Some(g)) => g,
270            Ok(None) => return, // source finished
271            Err(e) => {
272                tracing::debug!(%track_name, "derive: source track ended: {e}");
273                return;
274            }
275        };
276        let sequence = group.sequence;
277        if let Err(e) = derive_group(group, &mut derived, sequence).await {
278            tracing::debug!(%track_name, sequence, "derive: group abandoned: {e}");
279        }
280    }
281}

283/// Copy one source group's base-layer objects into a derived group of the SAME
284/// sequence. The derived group is created lazily on the first surviving object, so
285/// an all-enhancement group produces nothing rather than an empty group.
286async fn derive_group(
287    mut group: moq_net::GroupConsumer,
288    derived: &mut TrackProducer,
289    sequence: u64,
290) -> Result<(), String> {
291    let mut out: Option<moq_net::GroupProducer> = None;
292    loop {
293        match group.read_frame().await {
294            Ok(Some(object)) => {
295                if !is_base_layer(&object) {
296                    metrics::counter!("sfu_derived_objects_total", "outcome" => "filtered")
297                        .increment(1);
298                    continue;
299                }
300                // Lazily, on the first SURVIVING object — see this function's doc.
301                if out.is_none() {
302                    out = Some(
303                        derived
304                            .create_group(Group::from(sequence))
305                            .map_err(|e| format!("create_group: {e}"))?,
306                    );
307                }
308                out.as_mut()
309                    .expect("the branch above created it")
310                    .write_frame(object)
311                    .map_err(|e| format!("write_frame: {e}"))?;
312                metrics::counter!("sfu_derived_objects_total", "outcome" => "forwarded")
313                    .increment(1);
314            }
315            // Exhausted: finish the derived group so its stream closes cleanly.
316            Ok(None) => {
317                if let Some(mut g) = out.take() {
318                    g.finish().map_err(|e| format!("finish: {e}"))?;
319                }
320                return Ok(());
321            }
322            // A group reset mid-read is a NORMAL boundary upstream (a keyframe roll
323            // priority-drops the stale group). Abandon the derived group the same
324            // way rather than treating it as fatal.
325            Err(e) => {
326                drop(out);
327                return Err(e.to_string());
328            }
329        }
330    }
331}

333/// The filter, and the only thing this module reads out of an object: does it
334/// belong to the base temporal layer?
335///
336/// An object too short to carry an envelope at all is **kept**. It cannot be a
337/// hound frame, so it is not ours to classify, and dropping unclassifiable bytes
338/// out of a stream is how a relay silently corrupts one; the endpoint's own
339/// `decode_object` rejects it a moment later with a great deal more context.
340fn is_base_layer(object: &Bytes) -> bool {
341    hound_transport::moq::object_temporal_id(object)
342        .is_none_or(|tid| TemporalLayer::from_id(tid) == TemporalLayer::Base)
343}

345#[cfg(test)]
346mod tests {

348    use hound_media::{SpatialLayer, VideoSource, base_view_offered, track_name};

350    /// The relay derives exactly the tracks the RECEIVER believes have a base-layer
351    /// view. Two lists that disagree would produce a subscription to a broadcast
352    /// nobody publishes — a permanently black tile whose only symptom is a
353    /// subscribe timeout — so they are pinned against each other rather than
354    /// separately reviewed.
355    #[test]
356    fn the_relay_derives_exactly_what_the_receiver_asks_for() {
357        for source in [VideoSource::Camera, VideoSource::Screen] {
358            for spatial in [SpatialLayer::Source, SpatialLayer::Low] {
359                let path = format!("space/S/peer/U/1/{}", track_name(source, spatial));
360                assert_eq!(
361                    derivable(&path).is_some(),
362                    base_view_offered(source, spatial),
363                    "{path} — relay and receiver disagree about the base-layer view"
364                );
365            }
366        }
367    }
368
369    /// Nothing but a camera source track is derived — audio, screen, the low rung,
370    /// and anything unrecognised are all passed over. A relay that derived audio
371    /// would spend per-object work on a stream with no temporal layers at all.
372    #[test]
373    fn only_the_camera_source_track_is_derived() {
374        assert_eq!(derivable("space/S/peer/U/1/cam"), Some("cam"));
375        for track in [
376            "mic",
377            "cam_l0",
378            "screen",
379            "screen_l0",
380            "screen_audio",
381            "wat",
382        ] {
383            assert_eq!(
384                derivable(&format!("space/S/peer/U/1/{track}")),
385                None,
386                "{track} must not be derived"
387            );
388        }
389        // A bare path with no track tail is not a hound broadcast.
390        assert_eq!(derivable("space"), None);
391        assert_eq!(derivable(""), None);
392    }
393
394    /// THE regress guard: the deriver must never derive from its own output. The
395    /// derived broadcast is announced into the same origin the supervisor is
396    /// watching, so without this the announce it makes would feed straight back in
397    /// and spawn `cam_t0_t0`, `cam_t0_t0_t0`, … — an unbounded task and
398    /// origin-node leak from one camera.
399    #[test]
400    fn a_derived_track_is_never_itself_derived() {
401        assert_eq!(derivable("space/S/peer/U/1/cam_t0"), None);
402        assert_eq!(derivable("space/S/peer/U/1/cam_t0_t0"), None);
403        // …and the path we would announce is exactly the one that is refused.
404        let out = derived_path("space/S/peer/U/1/cam");
405        assert_eq!(out, "space/S/peer/U/1/cam_t0");
406        assert_eq!(derivable(&out), None);
407    }

409    /// The derived broadcast's path and its track name both carry the suffix, and
410    /// both agree with `hound_media`'s table — the receiver builds its subscribe
411    /// from that table and the two must land on the same string.
412    #[test]
413    fn the_derived_path_and_track_name_match_the_receivers_table() {
414        let out = derived_path("space/S/peer/U/1/cam");
415        assert!(out.ends_with(hound_media::TEMPORAL_BASE_SUFFIX));
416        assert_eq!(
417            out.rsplit('/').next(),
418            hound_media::track_name_for(
419                VideoSource::Camera,
420                SpatialLayer::Source,
421                hound_media::TemporalView::BaseOnly,
422            )
423        );
424        assert_eq!(base_track_name("cam"), "cam_t0");
425    }

427    /// The object filter: base survives, enhancement does not, and an object too
428    /// short to classify is KEPT rather than silently dropped.
429    #[test]
430    fn the_filter_keeps_base_layer_objects_and_unclassifiable_ones() {
431        let object = |tid: u8| {
432            let mut b = vec![0u8; 16];
433            b[hound_transport::moq::OBJ_TEMPORAL_OFFSET] = tid;
434            b.extend_from_slice(b"payload");
435            Bytes::from(b)
436        };
437        assert!(is_base_layer(&object(0)), "base must survive");
438        for tid in 1..=hound_media::TEMPORAL_ID_MASK {
439            assert!(!is_base_layer(&object(tid)), "tid {tid} must be filtered");
440        }
441        // A reserved bit set alongside the base id is still base — masked, not
442        // compared whole (the same rule the envelope's own decoder applies).
443        assert!(is_base_layer(&object(0b1111_1000)));
444
445        // Too short to be a hound object: not ours to classify, so it is kept.
446        for len in 0..16usize {
447            assert!(
448                is_base_layer(&Bytes::from(vec![0xFFu8; len])),
449                "a {len}-byte object must not be dropped by the relay"
450            );
451        }
452    }
