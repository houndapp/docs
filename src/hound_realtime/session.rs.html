1//! Client-side session state, derived purely from transport lifecycle and
2//! [`ServerMessage`]s.
3//!
4//! [`ClientSession`] is a deterministic reducer. It holds no I/O: the shell
5//! tells it the transport came up or went down and hands it inbound frames; it
6//! answers with [`Action`]s to send and [`Event`]s for the app.
7//!
8//! ## Why it owns subscriptions
9//!
10//! Space subscriptions are **connection state on the server** — a reconnect
11//! lands on a fresh connection with no space rooms at all. So the reducer keeps
12//! two sets: what the app *wants* (`desired`, which outlives any connection) and
13//! what has been *issued* on the current one. Every [`ServerMessage::Welcome`] —
14//! the first one and every reconnect's — reconciles them by re-issuing the whole
15//! desired set. A subscription therefore cannot be silently lost by a reconnect,
16//! which is the failure mode of tracking subscriptions at the transport.
17//!
18//! Clearing `issued` on disconnect is what makes the reconciliation correct
19//! rather than optimistic.
20//!
21//! ## Subscriptions resync; message history does not
22//!
23//! Re-issuing a subscription only restores the *flow* of events. Everything the
24//! server fanned out while this session had no connection was fanned out to a
25//! room it was not in, and no protocol frame replays it — so a client that only
26//! re-subscribes is silently missing whatever happened during the gap. That
27//! repair is a history re-fetch, which is the shell's job (it owns the REST
28//! client), and all this reducer owes it is the one fact it cannot derive:
29//! whether a given [`ServerMessage::Welcome`] is the FIRST of this session or a
30//! reconnect's. [`Event::Connected::reconnect`] carries it.
31//!
32//! ## Issued is not confirmed
33//!
34//! A third set, `confirmed`, holds the spaces the *server* has said it joined
35//! ([`ServerMessage::Subscribed`]). `issued` only means "we wrote the frame":
36//! between that and the server's room join sit a task hop, a network, and the
37//! backend's authorization lookups, and a message posted in that window reaches
38//! nobody. Only `confirmed` licenses a caller to believe it is receiving a
39//! space, which is what [`ClientSession::is_subscribed`] answers. A server too
40//! old to confirm ([`ServerMessage::Welcome::confirms_subscriptions`] absent)
41//! leaves the set empty forever — see [`ClientSession::confirms_subscriptions`],
42//! which is how the shell knows not to wait.
43

54/// Something the shell must put on the wire.
55#[derive(Debug, Clone, PartialEq, Eq)]
56pub enum Action {
57    Send(ClientMessage),
58}

60/// Something the app should react to. Mirrors the server message set plus the
61/// two lifecycle edges the transport owns.
62#[derive(Debug, Clone, PartialEq)]
63pub enum Event {
64    /// The handshake completed: the session is live and resynced.
65    Connected {
66        /// Whether this is a *re*-connect — i.e. an earlier connection of this
67        /// same session was already welcomed, so there is a gap during which
68        /// events were fanned out to rooms this session was not in.
69        ///
70        /// `false` on the first `Welcome` only. Nothing in the protocol replays
71        /// the gap, so this is the flag a shell hangs its history re-fetch on;
72        /// firing that on the first connect too would just re-fetch what the
73        /// caller is loading anyway.
74        reconnect: bool,
75    },
76    /// The transport went away. Desired subscriptions are retained and will be
77    /// re-issued on the next `Welcome`.
78    Disconnected,
79    /// The server has joined this connection to a space's room. The edge a
80    /// caller that just opened a space waits for: from here on the space's
81    /// events reach this session.
82    Subscribed {
83        space_id: Uuid,
84    },
85    MessageCreated(MessagePayload),
86    MessageUpdated(MessagePayload),
87    SpaceCreated(SpacePayload),
88    SpaceRemoved {
89        space_id: Uuid,
90    },
91    VoiceJoined(VoiceJoinEvent),
92    VoiceLeft(VoiceLeaveEvent),
93    /// A full voice-roster snapshot — from the handshake or a later resync push.
94    VoiceState(Vec<VoiceJoinEvent>),
95    Screenshare(VoiceScreenShareEvent),
96    /// The server refused something. `VersionMismatch` additionally means the
97    /// session is over (see [`ClientSession::is_live`]).
98    Error {
99        code: ErrorCode,
100        message: String,
101    },
102}

104/// What one input produced: frames to send, events to surface.
105#[derive(Debug, Default, Clone, PartialEq)]
106pub struct Reaction {
107    pub actions: Vec<Action>,
108    pub events: Vec<Event>,
109}
110
111impl Reaction {
112    fn event(event: Event) -> Self {
113        Self {
114            actions: Vec::new(),
115            events: vec![event],
116        }
117    }
118}

120/// Where the session is in its handshake.
121#[derive(Debug, Clone, Copy, PartialEq, Eq)]
122enum Link {
123    /// No transport, or one that has not been welcomed.
124    Down,
125    /// `Hello` sent, awaiting `Welcome`.
126    Handshaking,
127    /// Welcomed: subscriptions may be issued.
128    Live,
129}
130
131/// The client half of the realtime protocol.
132#[derive(Debug)]
133pub struct ClientSession {
134    link: Link,
135    /// Spaces the app wants, independent of any connection.
136    desired: BTreeSet<Uuid>,
137    /// Spaces already asked for on the *current* connection.
138    issued: BTreeSet<Uuid>,
139    /// Spaces the server has confirmed joining on the current connection.
140    confirmed: BTreeSet<Uuid>,
141    /// Whether the current connection's server confirms subscribes at all, from
142    /// its `Welcome`. `false` while down, and against a server predating the
143    /// confirmation.
144    confirms: bool,
145    /// The version the current connection settled on, from its `Welcome`.
146    negotiated: Option<u16>,
147    /// Whether any connection of this session has ever been welcomed.
148    ///
149    /// Session-lifetime, deliberately NOT cleared by [`Self::disconnected`]:
150    /// surviving the disconnect is the whole point, since it is what turns the
151    /// next `Welcome` into a *re*-connect. A fresh [`ClientSession`] (a new
152    /// sign-in, a new plane) starts over, which is correct — nothing was loaded
153    /// yet, so there is no gap to repair.
154    welcomed_before: bool,
155}
156
157impl Default for ClientSession {
158    fn default() -> Self {
159        Self::new()
160    }
161}

163impl ClientSession {
164    pub fn new() -> Self {
165        Self {
166            link: Link::Down,
167            desired: BTreeSet::new(),
168            issued: BTreeSet::new(),
169            confirmed: BTreeSet::new(),
170            confirms: false,
171            negotiated: None,
172            welcomed_before: false,
173        }
174    }
175
176    /// The transport is up. Answers with the `Hello` that opens the handshake,
177    /// offering the newest version this build speaks; nothing else may be sent
178    /// until the `Welcome` names the version actually negotiated.
179    pub fn connected(&mut self) -> Vec<Action> {
180        self.link = Link::Handshaking;
181        self.issued.clear();
182        // A fresh connection has no rooms, whatever the last one confirmed.
183        self.confirmed.clear();
184        self.confirms = false;
185        self.negotiated = None;
186        vec![Action::Send(ClientMessage::Hello {
187            protocol_version: PROTOCOL_VERSION,
188        })]
189    }
190
191    /// The transport went away (dropped, or closed after a goodbye frame).
192    /// Desired subscriptions survive; issued ones do not.
193    pub fn disconnected(&mut self) -> Vec<Event> {
194        let was_up = self.link != Link::Down;
195        self.link = Link::Down;
196        self.issued.clear();
197        self.confirmed.clear();
198        self.confirms = false;
199        self.negotiated = None;
200        if was_up {
201            vec![Event::Disconnected]
202        } else {
203            Vec::new()
204        }
205    }
206
207    /// Apply one inbound frame.
208    pub fn handle(&mut self, msg: ServerMessage) -> Reaction {
209        match msg {
210            ServerMessage::Welcome {
211                protocol_version,
212                voice_states,
213                confirms_subscriptions,
214            } => {
215                // The server answers with the NEGOTIATED version, which is at
216                // most ours: a newer server serves us at our own version. One
217                // above ours (or below the floor we still speak) is a server we
218                // cannot be trusted to interpret our frames — stay down and let
219                // the shell close rather than half-join.
220                if !(MIN_PROTOCOL_VERSION..=PROTOCOL_VERSION).contains(&protocol_version) {
221                    self.link = Link::Down;
222                    return Reaction::event(Event::Error {
223                        code: ErrorCode::VersionMismatch,
224                        message: format!(
225                            "server negotiated protocol v{protocol_version}, client speaks \
226                             v{MIN_PROTOCOL_VERSION}..=v{PROTOCOL_VERSION}"
227                        ),
228                    });
229                }
230                self.negotiated = Some(protocol_version);
231                self.confirms = confirms_subscriptions;
232                self.link = Link::Live;
233                // Set only once the version check has passed: a refused
234                // `Welcome` never made the session live, so it must not make the
235                // NEXT one look like a reconnect.
236                let reconnect = std::mem::replace(&mut self.welcomed_before, true);
237                // Reconcile: the server's connection is brand new, so everything
238                // desired must be (re-)asked for, including on the very first
239                // connect where `issued` is empty anyway. Nothing is confirmed
240                // until this connection's server says so.
241                self.issued = self.desired.clone();
242                self.confirmed.clear();
243                Reaction {
244                    actions: self
245                        .desired
246                        .iter()
247                        .map(|&space_id| Action::Send(ClientMessage::SubscribeSpace { space_id }))
248                        .collect(),
249                    events: vec![
250                        Event::Connected { reconnect },
251                        Event::VoiceState(voice_states),
252                    ],
253                }
254            }
255            ServerMessage::Subscribed { space_id } => {
256                // Recorded even for a space no longer desired (an unsubscribe
257                // that crossed the confirmation in flight): the set describes
258                // the SERVER's rooms, and the unsubscribe frame is already on
259                // its way to empty it.
260                self.confirmed.insert(space_id);
261                Reaction::event(Event::Subscribed { space_id })
262            }
263            ServerMessage::MessageCreated { message } => {
264                Reaction::event(Event::MessageCreated(message))
265            }
266            ServerMessage::MessageUpdated { message } => {
267                Reaction::event(Event::MessageUpdated(message))
268            }
269            ServerMessage::SpaceCreated { space } => Reaction::event(Event::SpaceCreated(space)),
270            ServerMessage::SpaceRemoved { space_id } => {
271                // A space that no longer exists cannot be re-subscribed to on the
272                // next reconnect; drop it from the desired set so the
273                // reconciliation doesn't ask for it forever.
274                self.desired.remove(&space_id);
275                self.issued.remove(&space_id);
276                self.confirmed.remove(&space_id);
277                Reaction::event(Event::SpaceRemoved { space_id })
278            }
279            ServerMessage::VoiceJoined { voice } => Reaction::event(Event::VoiceJoined(voice)),
280            ServerMessage::VoiceLeft { voice } => Reaction::event(Event::VoiceLeft(voice)),
281            ServerMessage::VoiceState { voice_states } => {
282                Reaction::event(Event::VoiceState(voice_states))
283            }
284            ServerMessage::Screenshare { screenshare } => {
285                Reaction::event(Event::Screenshare(screenshare))
286            }
287            ServerMessage::Error { code, message } => {
288                if code == ErrorCode::VersionMismatch {
289                    self.link = Link::Down;
290                }
291                Reaction::event(Event::Error { code, message })
292            }
293        }
294    }
295
296    /// Want a space's messages. Idempotent; issues the frame immediately when
297    /// live, otherwise waits for the next `Welcome` to reconcile it.
298    pub fn subscribe(&mut self, space_id: Uuid) -> Vec<Action> {
299        self.desired.insert(space_id);
300        if self.link != Link::Live || !self.issued.insert(space_id) {
301            return Vec::new();
302        }
303        vec![Action::Send(ClientMessage::SubscribeSpace { space_id })]
304    }
305
306    /// Stop wanting a space's messages. Idempotent; the unsubscribe only goes on
307    /// the wire if this connection ever asked for it.
308    pub fn unsubscribe(&mut self, space_id: Uuid) -> Vec<Action> {
309        self.desired.remove(&space_id);
310        self.confirmed.remove(&space_id);
311        if !self.issued.remove(&space_id) || self.link != Link::Live {
312            return Vec::new();
313        }
314        vec![Action::Send(ClientMessage::UnsubscribeSpace { space_id })]
315    }
316
317    /// Ask again for everything desired on the CURRENT connection.
318    ///
319    /// The recovery for an [`ErrorCode::Unavailable`] answer: the server could
320    /// not reach the state to decide, so it neither joined the room nor refused,
321    /// while this side still counts the subscribe as issued. The frame carries
322    /// no space id, so "which one" is unknowable — re-issuing the whole desired
323    /// set is both the cheapest and the only correct repair, and the server
324    /// treats a repeated subscribe as idempotent. Empty while not live: the next
325    /// `Welcome` reconciles the same set anyway.
326    pub fn reissue_subscriptions(&mut self) -> Vec<Action> {
327        if self.link != Link::Live {
328            return Vec::new();
329        }
330        self.issued = self.desired.clone();
331        self.desired
332            .iter()
333            .map(|&space_id| Action::Send(ClientMessage::SubscribeSpace { space_id }))
334            .collect()
335    }
336
337    /// Whether the server has confirmed joining `space_id` on the CURRENT
338    /// connection — the only state from which "this space's events reach me" is
339    /// true. Always `false` against a server that does not confirm at all; ask
340    /// [`Self::confirms_subscriptions`] to tell that apart from "not yet".
341    pub fn is_subscribed(&self, space_id: Uuid) -> bool {
342        self.confirmed.contains(&space_id)
343    }
344
345    /// Whether this connection's server confirms subscribes. `false` while down,
346    /// and for a server predating the confirmation — where waiting for one would
347    /// be waiting forever.
348    pub fn confirms_subscriptions(&self) -> bool {
349        self.confirms
350    }
351
352    /// Announce a screenshare toggle. Dropped while not live: it is a momentary
353    /// state change, and the roster is resynced by the next `Welcome` anyway.
354    pub fn screenshare(&mut self, space_id: Uuid, enabled: bool) -> Vec<Action> {
355        if self.link != Link::Live {
356            return Vec::new();
357        }
358        vec![Action::Send(ClientMessage::Screenshare {
359            space_id,
360            enabled,
361        })]
362    }
363
364    /// Leave gracefully. The session stays live until the transport actually
365    /// closes — the server's teardown is what ends it, and [`Self::disconnected`]
366    /// is still the single place that edge is surfaced.
367    pub fn bye(&mut self) -> Vec<Action> {
368        if self.link == Link::Down {
369            return Vec::new();
370        }
371        vec![Action::Send(ClientMessage::Bye)]
372    }
373
374    /// Welcomed and able to send.
375    pub fn is_live(&self) -> bool {
376        self.link == Link::Live
377    }
378
379    /// The version this connection settled on, once welcomed. `None` while down
380    /// or handshaking. Behaviour gated on a version reads this, never
381    /// [`PROTOCOL_VERSION`] — the two differ exactly when talking to an older
382    /// server.
383    pub fn negotiated_version(&self) -> Option<u16> {
384        self.negotiated
385    }
386
387    /// Spaces the app wants, across reconnects.
388    pub fn desired_spaces(&self) -> impl Iterator<Item = Uuid> + '_ {
389        self.desired.iter().copied()
390    }
391}

483    /// THE flag a history re-fetch hangs on: the first `Welcome` of a session is
484    /// a connect, every later one is a *re*-connect — because only the latter has
485    /// a gap behind it, during which the server fanned events out to rooms this
486    /// session was not in and which nothing replays.
487    ///
488    /// The distinction is session-lifetime, not connection-lifetime: it must
489    /// survive the very `disconnected` that creates the gap, and a refused
490    /// `Welcome` (one that never made the session live) must not count as the
491    /// first connect.
492    #[test]
493    fn only_the_first_welcome_of_a_session_is_not_a_reconnect() {
494        let connected = |session: &mut ClientSession| {
495            session.connected();
496            match session.handle(welcome()).events.first() {
497                Some(&Event::Connected { reconnect }) => reconnect,
498                other => panic!("expected a connect edge, got {other:?}"),
499            }
500        };
501
502        let mut session = ClientSession::new();
503        assert!(!connected(&mut session), "the first welcome is a connect");
504
505        session.disconnected();
506        assert!(
507            connected(&mut session),
508            "and every welcome after a drop is a reconnect"
509        );
510        session.disconnected();
511        assert!(connected(&mut session), "for as long as the session lives");
512
513        // A brand-new session starts over: nothing is loaded yet, so there is no
514        // gap to repair.
515        assert!(!connected(&mut ClientSession::new()));
516
517        // A `Welcome` this build cannot speak is not a connect at all, so it
518        // must not make the next one look like a reconnect.
519        let mut refused = ClientSession::new();
520        refused.connected();
521        refused.handle(ServerMessage::Welcome {
522            protocol_version: PROTOCOL_VERSION + 1,
523            voice_states: vec![],
524            confirms_subscriptions: true,

526        assert!(!connected(&mut refused));

579    /// THE subscribe-ack property: writing the frame is not being in the room.
580    /// A subscribe is "issued" the moment it goes on the wire, but not
581    /// *subscribed* until the server confirms — and the confirmation belongs to
582    /// the connection that earned it, so a reconnect starts unconfirmed again
583    /// even though the desire survives.
584    #[test]
585    fn a_subscribe_is_not_subscribed_until_the_server_confirms_it() {
586        let space = id(1);
587        let mut session = ClientSession::new();
588        session.connected();
589        session.handle(welcome());
590
591        assert_eq!(subscribed(&session.subscribe(space)), vec![space]);
592        assert!(
593            !session.is_subscribed(space),
594            "the frame is on the wire; the server has not answered it"
595        );
596
597        let reaction = session.handle(ServerMessage::Subscribed { space_id: space });
598        assert_eq!(reaction.events, vec![Event::Subscribed { space_id: space }]);
599        assert!(reaction.actions.is_empty(), "a confirmation sends nothing");
600        assert!(session.is_subscribed(space));
601
602        // The rooms belong to the connection, so the confirmation does too.
603        session.disconnected();
604        assert!(!session.is_subscribed(space));
605        session.connected();
606        assert_eq!(
607            subscribed(&session.handle(welcome()).actions),
608            vec![space],
609            "the desire survives and is re-issued"
610        );
611        assert!(
612            !session.is_subscribed(space),
613            "and must be confirmed again on the new connection"
614        );
615    }

824    /// Negotiating down: a server newer than this client answers our `Hello` with
825    /// OUR version, and the session runs at that version rather than refusing —
826    /// the whole point of carrying a negotiated version in the `Welcome`.
827    #[test]
828    fn a_newer_server_negotiates_down_to_this_clients_version() {
829        let server_version = PROTOCOL_VERSION + 1;
830        let negotiated = crate::proto::negotiate_version(PROTOCOL_VERSION, server_version)
831            .expect("a newer server serves an older client");
832        assert_eq!(negotiated, PROTOCOL_VERSION);
833
834        let mut session = ClientSession::new();
835        assert_eq!(
836            session.connected(),
837            vec![Action::Send(ClientMessage::Hello {
838                protocol_version: PROTOCOL_VERSION
839            })],
840            "the client offers its newest version"
841        );
842        let reaction = session.handle(ServerMessage::Welcome {
843            protocol_version: negotiated,
844            voice_states: vec![],
845            confirms_subscriptions: true,
846        });
847        assert!(session.is_live());
848        assert_eq!(session.negotiated_version(), Some(negotiated));
849        assert_eq!(
850            reaction.events,
851            vec![
852                Event::Connected { reconnect: false },
853                Event::VoiceState(vec![])
854            ]
855        );
856
857        session.disconnected();
858        assert_eq!(
859            session.negotiated_version(),
860            None,
861            "the negotiated version belongs to the connection, not the session"
862        );
863    }
