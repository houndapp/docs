1//! The shared stack lifecycle: ensure the stack is up (reusing a live one),
2//! and — only when asked — tear it down again.
3//!
4//! # Bring-up order
5//!
6//! 1. `docker compose up -d postgres mailpit iroh-relay`, then postgres's
7//!    health check and mailpit's.
8//! 2. The host BACKEND, detached, on :8080.
9//! 3. The host SFU, detached, once the backend answers — it registers itself
10//!    with the backend, which is what makes voice routable.
11//! 4. The host AUTH page, detached, on :3100 — last, because nothing waits
12//!    on it and it needs nothing but a fixed backend URL.
13//!
14//! The SFU is a HOST process, not the `hound-sfu` compose container (which
15//! `compose.dev.yaml` still defines for the prod-like topology). A container
16//! SFU advertises the Docker bridge address, so media leaves loopback — on
17//! macOS that is Local Network traffic behind a per-application privacy
18//! grant, silently dropped without one. On the host it binds AND advertises
19//! 127.0.0.1 (`crate::sfu`), so the only address a client is ever handed is
20//! loopback.
21//!
22//! The auth page is a host process too (`crate::auth`), for build cost
23//! alone: its container was a release cargo build inside docker on every
24//! `--fresh`. So the dev stack builds NO docker image from this repo — the
25//! compose side is two pulls (postgres, mailpit) and the relay, whose image
26//! only `cargo install`s `iroh-relay` from crates.io.
27//!
28//! # The contract
29//!
30//! The stack is PERSISTENT. `e2e`, `visual` and `up` all "ensure up and
31//! keep": a live stack is reused as-is, a missing one is brought up and left
32//! running when the command exits. Nothing tears down implicitly — no
33//! `Drop`, no end-of-run cleanup — because the expensive part of these flows
34//! is bring-up, and paying it once per working session instead of once per
35//! run is the entire point. The explicit paths are `--teardown` (what CI
36//! wants: run, then leave the host clean), `hound-stack down`, and `--fresh`
37//! (tear down first, then bring up from scratch).
38//!
39//! "Live" is four typed checks, never a port probe ([`repair::probe`]): the
40//! backend answers `GET /instance`, the host SFU answers `GET /health`, the
41//! backend's `GET /internal/sfu/nodes` reports a live non-draining node, AND
42//! the auth page answers `GET /`. A stack missing any of them would fail
43//! scenarios in a way that looks like a product bug, so it is never silently
44//! handed to the suite. Only a missing BACKEND means a full bring-up; with
45//! the backend answering, the rest is repaired in place ([`repair::plan`]):
46//! a silent SFU is spawned, a healthy-but-unregistered one restarted (it
47//! registers at startup), a silent auth page spawned. (The health check is
48//! also what stops a leftover CONTAINER SFU, registered but unreachable on
49//! loopback, from passing as live.)
50//!
51//! # What still cleans up
52//!
53//! A FAILED bring-up must not leave processes nobody knows about: whatever
54//! this invocation spawned is killed and its state entry removed. Compose is
55//! deliberately left as it is — a half-up compose stack holds no host
56//! resource the next attempt wants, and `up -d` is idempotent, so the next
57//! bring-up simply completes it. `--fresh` is the escape hatch when it is
58//! genuinely wedged.
59//!
60//! # Staleness
61//!
62//! Reuse always rebuilds the three binaries first (a no-op when nothing
63//! changed) and compares each built binary's (mtime, len) against what the
64//! state file recorded for the running process. Different ⇒ that process is
65//! the old code: stop it and spawn the new one.
66//!
67//! A restarted BACKEND also forces an SFU restart. The SFU's registration is
68//! a 30 s heartbeat (`REGISTER_INTERVAL` in `services/sfu/src/main.rs`; the
69//! 5 s retry only applies to a FAILED post), while a backend restart empties
70//! the in-memory registry — so the registry can stay empty for up to 30 s,
71//! well past the wait a reuse is willing to do. Restarting the SFU
72//! re-registers it immediately. The auth page has no such coupling
73//! (stateless, fixed upstream URL): only its own rebuilt binary restarts it.
74//!
75//! Noise contract: one console line per lifecycle step; every subprocess's
76//! full output goes to its own artifact file (`build.log`, `compose.log`,
77//! `backend.log`, `sfu.log`, `auth.log`); a failure prints the relevant
78//! log's tail inline. Success prints no log content at all.

142/// A stack this invocation has confirmed up — reused or just brought up.
143/// Holding one is NOT ownership: dropping it leaves the stack running.
144pub struct LiveStack {
145    paths: StackPaths,
146    workdir: PathBuf,
147    /// `None` when a process with no state entry is being reused — there is
148    /// no log of ours to point a failure at.
149    backend_log: Option<PathBuf>,
150    sfu_log: Option<PathBuf>,
151    auth_log: Option<PathBuf>,
152}
153
154impl LiveStack {
155    /// Ensure the stack is up and return a handle to it, leaving it running.
156    ///
157    /// `bins` are PREBUILT (see [`build_stack_bins`]) — the caller builds
158    /// them because the e2e flow folds that build into one multi-binary cargo
159    /// invocation.
160    ///
161    /// `fresh` tears any existing stack down first, volumes included, and
162    /// rebuilds the compose images.
163    pub async fn ensure_up(
164        paths: StackPaths,
165        workdir: &Path,
166        bins: &StackBins,
167        backend_url: &str,
168        mailpit_url: &str,
169        fresh: bool,
170    ) -> Result<Self> {
171        if fresh {
172            info!("--fresh: tearing the existing stack down (volumes included) first");
173            teardown(&paths, Some(workdir), true);
174            // The published ports outlive `compose down` by a beat (see
175            // `ports::wait_free`); without this the preflight below fails
176            // on the stack we just removed.
177            if !ports::wait_free(STACK_PORTS, Duration::from_secs(15)) {
178                warn!("stack ports still held 15 s after teardown");
179            }
180        } else {
181            let liveness = repair::probe(backend_url).await;
182            if let Plan::Reuse { sfu, spawn_auth } = repair::plan(liveness) {
183                return Self::reuse(paths, workdir, bins, backend_url, sfu, spawn_auth).await;
184            }
185        }
186
187        // Only now: we are about to bind these ports ourselves, so a holder
188        // is a conflict rather than the stack we would have reused.
189        ports::preflight(STACK_PORTS).context("port preflight")?;
190
191        let mut stack = Self::new(paths, workdir);
192        match stack.bring_up(bins, backend_url, mailpit_url, fresh).await {
193            Ok(()) => Ok(stack),
194            Err(e) => {
195                // Kill only what THIS invocation started; compose is left for
196                // the next attempt's idempotent `up -d` to complete.
197                stop_recorded(&stack.paths.root);
198                Err(e)
199            }
200        }
201    }

204        Self {
205            paths,
206            workdir: workdir.to_owned(),
207            backend_log: None,
208            sfu_log: None,
209            auth_log: None,
210        }

213    /// The reuse path: the backend answered, so what is left is repairing
214    /// whatever else the probes found missing and restarting whatever runs a
215    /// binary that has since been rebuilt.
216    async fn reuse(
217        paths: StackPaths,
218        workdir: &Path,
219        bins: &StackBins,
220        backend_url: &str,
221        sfu_repair: SfuRepair,
222        spawn_auth: bool,
223    ) -> Result<Self> {
224        let recorded = state::load(&paths.root);
225        // Checked before anything is touched: the error path below stops
226        // every recorded process, which this refusal is no reason to do.
227        if sfu_repair == SfuRepair::Restart && recorded.sfu.is_none() {
228            bail!(
229                "an SFU answers on :{} but is not registered with the backend, and hound-stack \
230                 never started it — stop it by hand, or replace the whole stack with `--fresh`",
231                sfu::HEALTH_PORT
232            );
233        }
234        let mut stack = Self::new(paths, workdir);
235        stack.backend_log = recorded.backend.as_ref().map(|r| r.log.clone());
236        stack.sfu_log = recorded.sfu.as_ref().map(|r| r.log.clone());
237        stack.auth_log = recorded.auth.as_ref().map(|r| r.log.clone());
238
239        // A failed restart must not leave a half-refreshed stack that the
240        // next probe would call live: stop everything recorded.
241        match stack
242            .refresh_stale(recorded, bins, backend_url, sfu_repair, spawn_auth)
243            .await
244        {
245            Ok(()) => Ok(stack),
246            Err(e) => {
247                stop_recorded(&stack.paths.root);
248                Err(e)
249            }
250        }
251    }
252
253    /// Repair what the probes found missing (`sfu_repair`, `spawn_auth`),
254    /// then restart every recorded process whose binary moved on (plus the
255    /// SFU after a backend restart — see the module doc). A process with no
256    /// state entry is someone else's: warned about, never stopped — though a
257    /// missing SFU or auth page is still spawned beside it.
258    async fn refresh_stale(
259        &mut self,
260        recorded: state::StackState,
261        bins: &StackBins,
262        backend_url: &str,
263        sfu_repair: SfuRepair,
264        spawn_auth: bool,
265    ) -> Result<()> {
266        // A foreign backend gets one warning; the per-process "never
267        // started it" warnings below would only repeat it.
268        let foreign = recorded.backend.is_none();
269        let backend_restarted = match &recorded.backend {
270            None => {
271                warn!(
272                    "reusing a live stack started outside hound-stack (no {}) — its processes \
273                     cannot be staleness-checked or stopped from here; `--fresh` replaces it",
274                    state::path(&self.paths.root).display()
275                );
276                false
277            }
278            Some(rec) if rec.matches(&bins.backend, &BinaryStamp::of(&bins.backend)?) => {
279                info!(pid = rec.pid, "reusing the live backend (binary unchanged)");
280                false
281            }
282            Some(rec) => {
283                info!(
284                    pid = rec.pid,
285                    "the backend binary changed since this stack started — restarting it \
286                     (MIGRATE=fresh resets the schema)"
287                );
288                signal::stop("backend", rec.pid).context("stopping the stale backend")?;
289                state::update(&self.paths.root, |s| s.backend = None)?;
290                self.start_backend(&bins.backend, backend_url).await?;
291                true
292            }
293        };
294
295        let sfu_stamp = BinaryStamp::of(&bins.sfu)?;
296        let restart_sfu = match (sfu_repair, &recorded.sfu) {
297            (SfuRepair::Spawn, rec) => {
298                info!(
299                    stale_pid = rec.as_ref().map(|r| r.pid),
300                    "a backend is up but nothing answers the host SFU's health port (:{}) — \
301                     spawning the SFU",
302                    sfu::HEALTH_PORT
303                );
304                true
305            }
306            // `reuse` refuses the unrecorded case before getting here.
307            (SfuRepair::Restart, rec) => {
308                info!(
309                    pid = rec.as_ref().map(|r| r.pid),
310                    "the SFU is healthy but not registered with the backend (backend restarted by \
311                     hand, or its registry entry expired) — restarting it so it re-registers"
312                );
313                true
314            }
315            (SfuRepair::Keep, None) => {
316                if !foreign {
317                    warn!(
318                        "an SFU answers on :{} but hound-stack never started it — leaving it \
319                         alone; `--fresh` replaces the whole stack",
320                        sfu::HEALTH_PORT
321                    );
322                }
323                false
324            }
325            // A restarted backend emptied its in-memory registry, and the
326            // SFU's own re-registration is up to 30 s away — restart it
327            // rather than hand the suite a stack with no routable node (see
328            // the module doc).
329            (SfuRepair::Keep, Some(rec)) if backend_restarted => {
330                info!(
331                    pid = rec.pid,
332                    "restarting the SFU so it re-registers against the restarted backend"
333                );
334                true
335            }
336            (SfuRepair::Keep, Some(rec)) if rec.matches(&bins.sfu, &sfu_stamp) => {
337                info!(pid = rec.pid, "reusing the live SFU (binary unchanged)");
338                false
339            }
340            (SfuRepair::Keep, Some(rec)) => {
341                info!(
342                    pid = rec.pid,
343                    "the hound-sfu binary changed since this stack started — restarting it"
344                );
345                true
346            }
347        };
348        if restart_sfu {
349            if let Some(rec) = &recorded.sfu {
350                signal::stop("SFU", rec.pid).context("stopping the recorded SFU")?;
351                state::update(&self.paths.root, |s| s.sfu = None)?;
352            }
353            self.start_sfu(&bins.sfu, backend_url).await?;
354        }
355
356        // No backend coupling here: the page is stateless and its upstream
357        // is a fixed URL, so only its own rebuilt binary restarts it.
358        let auth_stamp = BinaryStamp::of(&bins.auth)?;
359        let restart_auth = match &recorded.auth {
360            rec if spawn_auth => {
361                info!(
362                    stale_pid = rec.as_ref().map(|r| r.pid),
363                    "a backend is up but nothing answers the auth page's port (:{}) — spawning \
364                     the auth page",
365                    auth::PORT
366                );
367                true
368            }
369            None => {
370                if !foreign {
371                    warn!(
372                        "an auth page answers on :{} but hound-stack never started it (an older \
373                         stack's compose container?) — leaving it alone; `--fresh` replaces the \
374                         whole stack",
375                        auth::PORT
376                    );
377                }
378                false
379            }
380            Some(rec) if rec.matches(&bins.auth, &auth_stamp) => {
381                info!(
382                    pid = rec.pid,
383                    "reusing the live auth page (binary unchanged)"
384                );
385                false
386            }
387            Some(rec) => {
388                info!(
389                    pid = rec.pid,
390                    "the hound-auth binary changed since this stack started — restarting it"
391                );
392                true
393            }
394        };
395        if restart_auth {
396            if let Some(rec) = &recorded.auth {
397                signal::stop("auth", rec.pid).context("stopping the recorded auth page")?;
398                state::update(&self.paths.root, |s| s.auth = None)?;
399            }
400            self.start_auth(&bins.auth).await?;
401        }
402        Ok(())
403    }

405    /// Full bring-up: compose, health waits, the host backend, the host SFU,
406    /// the host auth page.
407    async fn bring_up(
408        &mut self,
409        bins: &StackBins,
410        backend_url: &str,
411        mailpit_url: &str,
412        build_images: bool,
413    ) -> Result<()> {
414        let compose = self.paths.compose();
415        let compose_log = self.workdir.join("compose.log");
416
417        info!(
418            services = COMPOSE_SERVICES.join(" "),
419            "compose up (output → compose.log)"
420        );
421        compose.up(&compose_log, build_images, COMPOSE_SERVICES)?;
422
423        info!("waiting for postgres to be healthy");
424        let postgres_id = compose.ps_q("postgres")?.ok_or_else(|| {
425            eyre::eyre!("postgres container not found after compose up — see docker compose ps")
426        })?;
427        wait_container_healthy(
428            &postgres_id,
429            &Deadline::after(Duration::from_secs(120), Duration::from_secs(2)),
430        )
431        .await
432        .context("postgres never became healthy")?;
433
434        let http = reqwest::Client::new();
435        // Best-effort, matching the shell scripts: mailpit runs as a compose
436        // service (no local child to guard) and a missed wait here just
437        // means the FIRST magic-link poll retries a little longer.
438        info!("waiting for mailpit to be reachable");
439        let _ = wait_http_reachable(
440            &http,
441            &format!("{mailpit_url}/api/v1/messages"),
442            &Deadline::after(Duration::from_secs(30), Duration::from_secs(1)),
443        )
444        .await;
445
446        self.start_backend(&bins.backend, backend_url).await?;
447        self.start_sfu(&bins.sfu, backend_url).await?;
448        self.start_auth(&bins.auth).await
449    }

451    /// Spawn the (prebuilt) backend detached, record it, and wait for it.
452    ///
453    /// The state entry is written as soon as the pid exists — before the
454    /// health waits — so a bring-up that dies mid-wait still leaves a
455    /// stoppable record behind rather than an orphan on :8080.
456    async fn start_backend(&mut self, backend_bin: &Path, backend_url: &str) -> Result<()> {
457        let log = self.workdir.join("backend.log");
458        let stamp = BinaryStamp::of(backend_bin)?;
459
460        info!("starting backend (output → backend.log)");
461        let storage_dir = self.workdir.join("storage");
462        let mut child = backend::spawn(backend_bin, &self.paths.root, &log, &storage_dir)?;
463        self.record(
464            |s, rec| s.backend = Some(rec),
465            child.id(),
466            &log,
467            backend_bin,
468            stamp,
469        )?;
470        self.backend_log = Some(log.clone());
471
472        info!("waiting for backend to be reachable");
473        if let Err(e) = wait_for_http_or_exit(
474            &reqwest::Client::new(),
475            &format!("{backend_url}/instance"),
476            &mut child,
477            &Deadline::after(Duration::from_secs(120), Duration::from_secs(1)),
478        )
479        .await
480        {
481            logs::print_tail("backend log", &log, 60);
482            return Err(e).context("backend never became reachable");
483        }
484        info!("backend reachable");
485        // `child` is dropped here on purpose: the backend is detached and
486        // outlives this process. The state entry above is its handle now.
487        Ok(())
488    }

490    /// Spawn the (prebuilt) SFU detached on loopback, record it, and wait
491    /// until it is healthy AND registered with the backend.
492    async fn start_sfu(&mut self, sfu_bin: &Path, backend_url: &str) -> Result<()> {
493        let log = self.workdir.join("sfu.log");
494        let stamp = BinaryStamp::of(sfu_bin)?;
495
496        info!("starting SFU on 127.0.0.1 (output → sfu.log)");
497        let mut child = sfu::spawn(sfu_bin, &self.paths.root, &log, backend_url)?;
498        self.record(|s, rec| s.sfu = Some(rec), child.id(), &log, sfu_bin, stamp)?;
499        self.sfu_log = Some(log.clone());
500
501        info!("waiting for the SFU to bind and register");
502        if let Err(e) = sfu::wait_ready(&mut child, backend_url).await {
503            logs::print_tail("sfu log", &log, 60);
504            return Err(e);
505        }
506        info!("SFU registered");
507        Ok(())
508    }

510    /// Spawn the (prebuilt) auth page detached, record it, and wait for it.
511    async fn start_auth(&mut self, auth_bin: &Path) -> Result<()> {
512        let log = self.workdir.join("auth.log");
513        let stamp = BinaryStamp::of(auth_bin)?;
514
515        info!("starting auth page (output → auth.log)");
516        let mut child = auth::spawn(auth_bin, &self.paths.root, &log)?;
517        self.record(
518            |s, rec| s.auth = Some(rec),
519            child.id(),
520            &log,
521            auth_bin,
522            stamp,
523        )?;
524        self.auth_log = Some(log.clone());
525
526        if let Err(e) = auth::wait_ready(&mut child).await {
527            logs::print_tail("auth log", &log, 60);
528            return Err(e);
529        }
530        info!("auth page reachable");
531        Ok(())
532    }

578/// Stop the recorded host processes (if any) and take the compose stack down.
579///
580/// `workdir` `Some` sends compose's output to `compose.log`; `None` is the
581/// manual `hound-stack down`, which inherits the console so an operator can
582/// watch the containers go. Neither captures an SFU log from compose any
583/// more — the host SFU has been writing `sfu.log` (the CI artifact) all
584/// along.
585///
586/// The compose `down` stays a FULL down rather than a per-service one: it
587/// also sweeps a `hound-sfu` or `hound-auth` container left by an older run
588/// (or by the prod-like topology), which would otherwise squat :7890/udp or
589/// :3100.
590///
591/// `volumes` wipes postgres's data volume. Default NO: `MIGRATE=fresh` at
592/// every backend start already gives each run a correct schema, so keeping
593/// the volume costs nothing and saves the container's initdb. Wiping is what
594/// `--fresh` and `down --volumes` are for.
595///
596/// Best-effort and idempotent throughout: a teardown step's failure must
597/// never mask the run's real outcome.
598pub fn teardown(paths: &StackPaths, workdir: Option<&Path>, volumes: bool) {
599    stop_recorded(&paths.root);
600    let compose = paths.compose();
601    match workdir {
602        Some(dir) => {
603            info!(volumes, "compose down (output → compose.log)");
604            compose.down(&dir.join("compose.log"), volumes);
605        }
606        None => {
607            info!(volumes, "docker compose down");
608            compose.down_inherit(volumes);
609        }
610    }
611}

613/// Stop every recorded process: auth, then SFU, then backend. SFU before
614/// backend because it deregisters by exiting, and stopping it while the
615/// backend still answers keeps the registry honest for anything else
616/// watching.
617fn stop_recorded(root: &Path) {
618    let recorded = state::load(root);
619    if let Some(rec) = recorded.auth {
620        info!(pid = rec.pid, "stopping auth page");
621        if let Err(e) = signal::stop("auth", rec.pid) {
622            warn!("{e:#}");
623        }
624    }
625    if let Some(rec) = recorded.sfu {
626        info!(pid = rec.pid, "stopping SFU");
627        if let Err(e) = signal::stop("SFU", rec.pid) {
628            warn!("{e:#}");
629        }
630    }
631    if let Some(rec) = recorded.backend {
632        info!(pid = rec.pid, "stopping backend");
633        if let Err(e) = signal::stop("backend", rec.pid) {
634            warn!("{e:#}");
635        }
636    }
637    state::remove(root);
638}

640/// Build the host backend, SFU and auth page in ONE cargo invocation, and
641/// give each this machine's stable code signature if one is configured.
642///
643/// One invocation, and always under [`cargo::STACK_SELECTION`]: a different
644/// `-p` set is a different feature resolve, which recompiles dependencies and
645/// re-uplifts the binaries with fresh mtimes — which the staleness check
646/// reads as a code change.
647pub fn build_stack_bins(root: &Path, build_log: &Path) -> Result<StackBins> {
648    info!("building backend + hound-sfu + hound-auth (output → build.log)");
649    let built = cargo::build_bins(
650        root,
651        cargo::STACK_SELECTION,
652        &["backend", "hound-sfu", "hound-auth"],
653        build_log,
654    )?;
655    let [backend, sfu, auth] = <[PathBuf; 3]>::try_from(built)
656        .map_err(|_| eyre::eyre!("cargo build did not produce all three stack binaries"))?;
657    for bin in [&backend, &sfu, &auth] {
658        codesign::sign(bin, build_log)?;
659    }
660    Ok(StackBins { backend, sfu, auth })
661}
