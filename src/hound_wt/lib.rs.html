1//! A reusable WebTransport shell — endpoints, the pre-accept authorization
2//! surface, and a message pipe. It knows nothing about any application
3//! protocol.
4//!
5//! ## Layers
6//!
7//! - [`WtServer`] / [`WtClient`] wrap `wtransport`'s endpoints with the knobs
8//!   this workspace always wants set: an explicit idle timeout (wtransport's
9//!   default is *infinite*, which parks a dead connection's futures forever),
10//!   a keep-alive interval, and identity/trust chosen by a small enum rather
11//!   than a typestate builder.
12//! - [`Incoming`] is a peer at the UDP boundary, before any handshake. It is
13//!   returned immediately so admission is **per-peer**: the caller spawns a task
14//!   that handshakes, authenticates, and accepts or rejects under its own
15//!   deadline, and one stalled peer never delays the accept queue behind it.
16//! - [`SessionRequest`] is the trust boundary: a peer that has completed the
17//!   QUIC+HTTP/3 handshake but has NOT been admitted. Callers read its path,
18//!   query, and headers, decide, and then [`SessionRequest::accept`] or
19//!   [`SessionRequest::reject`] — no application state exists until they do.
20//! - [`FramedBi`] is one bidirectional stream carrying length-delimited
21//!   (u32 big-endian, [`MAX_FRAME_BYTES`] cap) UTF-8 JSON frames.
22//! - [`MessagePipe`] is the transport-agnostic seam: send/recv/close over
23//!   whole text frames. [`FramedBi`] implements it, a WebSocket adapter can
24//!   implement it, and protocol shells program against the trait so one
25//!   session loop serves both legs. [`Liveness`] is the companion seam for the
26//!   probe-and-reap a keep-alive-less transport needs.
27//!
28//! ## Domain note
29//!
30//! WebTransport multiplexes independent streams over one QUIC connection, so
31//! head-of-line blocking is per-stream: a stalled control stream cannot delay
32//! anything else on the connection. This crate deliberately does not expose
33//! datagrams — a control plane wants the ordered, reliable stream.
