1//! The `/control` call control plane.
2//!
3//! Like the realtime plane (`api/realtime`), the client is the **Rust app**;
4//! here the transport is a plain authenticated axum WebSocket. The
5//! transport-agnostic [`hound_control::SessionServer`] holds the authoritative
6//! per-call state; this module is only the connection, routing, and
7//! authorization glue around it.
8//!
9//! ## Endpoint & wire shape
10//!
11//! `GET /space/{space_id}/control` upgrades to a WebSocket. A "call"
12//! is a **space** (keyed by `space_id`). Every WS text frame is JSON: inbound a
13//! [`hound_control::ClientMessage`], outbound a [`hound_control::ServerMessage`].
14//!
15//! The first inbound frame MUST be `ClientMessage::Hello { protocol_version }`;
16//! the peer is admitted via [`SessionServer::join`]. Subsequent frames are fed to
17//! [`SessionServer::handle`]. A `ClientMessage::Bye`, the stream ending, or a
18//! transport error all run the leave path.
19//!
20//! ## Authorization (trust boundary)
21//!
22//! The control plane is privileged. We authenticate & authorize **before**
23//! accepting the upgrade: the credential must be a valid, unrevoked *access*
24//! token, and `claims.sub` must be a member of the space's community
25//! (`is_community_member`). Any failure returns 401/403 and the upgrade never
26//! happens — no `PeerId` is assigned, no `ControlCall` is created.
27//!
28//! The credential rides `Authorization: Bearer`, as on the realtime plane and
29//! for the same reason: a query-string token is logged by every proxy in the
30//! path. A `?token=` query is still accepted as a fallback, and authentication
31//! itself is [`Api::authenticate_realtime`] so the two planes cannot drift.
32//!
33//! ## State / lifecycle (SPOF flag)
34//!
35//! Per-call state lives in [`ControlCall`] in `Inner::control_calls`, created on
36//! the first join for a space and dropped when the last peer leaves
37//! (`SessionServer::is_empty()`). This is **in-memory and per-process** — it does
38//! not survive a backend redeploy and does not coordinate across horizontally
39//! scaled replicas. `/control` is only correct on a single backend replica.
40//!
41//! ## Routing
42//!
43//! Each admitted peer gets an `mpsc::UnboundedSender<ServerMessage>` registered in
44//! `ControlCall::conns[peer]`; a per-connection forward task drains the receiver
45//! to the WS sink. [`route`] resolves each [`Outgoing`]'s [`Target`] to recipient
46//! `PeerId`s against `conns` and pushes the message onto each sender. Because the
47//! transport tracks each connection's own sender, `BroadcastExcept(self)` is a
48//! genuine exclusion (no join-ordering trick needed).
49//!
50//! ## Locking
51//!
52//! The per-call `SessionServer` and `conns` are behind std `Mutex`es. We NEVER
53//! hold either across an `.await`: lock → call the sync `join`/`handle`/`leave`
54//! and collect recipients → drop the lock → then send. `mpsc::UnboundedSender::send`
55//! is sync and non-blocking, so routing never awaits while locked.

74/// Per-call control-plane state: the authoritative [`SessionServer`] plus the
75/// live connection senders keyed by [`PeerId`], used to route [`Outgoing`]s.
76#[derive(Debug)]
77pub(crate) struct ControlCall {
78    server: Mutex<SessionServer>,
79    conns: Mutex<HashMap<PeerId, mpsc::UnboundedSender<ServerMessage>>>,
80    /// This call's time origin. [`SessionServer`] is sans-IO and owns no clock, so
81    /// the transport supplies one; it lives on the CALL rather than the connection
82    /// so every peer's messages land on the same monotonic timeline (the server's
83    /// per-peer rate budgets are meaningless otherwise).
84    epoch: std::time::Instant,
85}
86
87impl ControlCall {
88    fn new() -> Self {
89        Self {
90            server: Mutex::new(SessionServer::new()),
91            conns: Mutex::new(HashMap::new()),
92            epoch: std::time::Instant::now(),
93        }
94    }
95
96    /// Now, on this call's timeline, in microseconds.
97    fn now_us(&self) -> i64 {
98        self.epoch.elapsed().as_micros() as i64
99    }
100}

117/// Authenticates & authorizes the control-plane connection, then upgrades to a
118/// WebSocket. Auth happens *before* the upgrade so an unauthorized caller gets a
119/// plain 401/403 and never reaches the session machinery.
120async fn control_ws_handler(
121    State(api): State<Api>,
122    Path(space_id): Path<Uuid>,
123    bearer: Option<TypedHeader<Authorization<Bearer>>>,
124    Query(query): Query<ControlQuery>,
125    ws: WebSocketUpgrade,
126) -> Response {
127    // 1. Authenticate. Header first: a token in the query string is logged by
128    // every proxy between here and the client. `authenticate_realtime` accepts a
129    // bare or `Bearer `-prefixed value and enforces valid/unrevoked/*access*.
130    let token = bearer
131        .as_ref()
132        .map(|TypedHeader(header)| header.token())
133        .or(query.token.as_deref());
134    let Some(user_id) = api.authenticate_realtime(token.unwrap_or_default()).await else {
135        tracing::warn!(%space_id, "/control — rejected: invalid access token");
136        return StatusCode::UNAUTHORIZED.into_response();
137    };
138
139    // 2. Authorize: the user must be a member of the space's community.
140    let space = match api.find_space_by_id(space_id).await {
141        Ok(Some(s)) => s,
142        Ok(None) => {
143            tracing::warn!(%space_id, %user_id, "/control — rejected: space not found");
144            return StatusCode::NOT_FOUND.into_response();
145        }
146        Err(err) => {
147            tracing::error!(%err, %space_id, %user_id, "/control — db error finding space");
148            return StatusCode::INTERNAL_SERVER_ERROR.into_response();
149        }
150    };
151    match api.is_community_member(space.community_id, user_id).await {
152        Ok(true) => {}
153        Ok(false) => {
154            tracing::warn!(%space_id, community_id = %space.community_id, %user_id, "/control — rejected: not a community member");
155            return StatusCode::FORBIDDEN.into_response();
156        }
157        Err(err) => {
158            tracing::error!(%err, %space_id, %user_id, "/control — db error checking membership");
159            return StatusCode::INTERNAL_SERVER_ERROR.into_response();
160        }
161    }
162
163    tracing::debug!(%space_id, %user_id, "/control — authorized, upgrading");
164    // Cap what a peer can make the server buffer, at the same size the realtime
165    // plane's length-delimited codec enforces (`max_message_size` bounds a
166    // reassembled fragmented message, `max_frame_size` a single frame — either
167    // alone leaves the other unbounded). Control frames are kilobytes at most.
168    ws.max_message_size(hound_wt::MAX_FRAME_BYTES)
169        .max_frame_size(hound_wt::MAX_FRAME_BYTES)
170        .on_upgrade(move |socket| handle_socket(socket, api, space_id, user_id))
171}

173/// Drives one authorized control-plane connection for its full lifetime.
174/// `user_id` is the AUTHENTICATED identity from [`control_ws_handler`]'s JWT
175/// check — never client-supplied — and is what [`SessionServer::join`] stamps
176/// into this peer's [`hound_control::PeerInfo`] for the rest of the roster
177/// (media broadcast paths are built from it).
178async fn handle_socket(socket: WebSocket, api: Api, space_id: Uuid, user_id: Uuid) {
179    let (mut sink, mut stream) = socket.split();
180
181    // The first frame must be `Hello`. Anything else (or a closed stream) ends
182    // the connection without ever creating a peer.
183    let hello = match next_client_message(&mut stream).await {
184        Some(msg @ ClientMessage::Hello { .. }) => msg,
185        Some(_) => {
186            tracing::warn!(%space_id, "/control — first frame was not Hello; closing");
187            return;
188        }
189        None => return,
190    };
191    let ClientMessage::Hello {
192        protocol_version,
193        decode_caps,
194    } = hello
195    else {
196        unreachable!("matched Hello above");
197    };
198
199    let call = api.get_or_create_control_call(space_id);
200
201    // Admit the peer with the codecs it advertised it can decode. Lock held only
202    // for the sync `join`.
203    let join_result = {
204        let mut server = call.server.lock().unwrap();
205        server.join(protocol_version, decode_caps, user_id)
206    };
207    let (peer, join_outgoings) = match join_result {
208        Ok(ok) => ok,
209        Err(err_msg) => {
210            // Version mismatch (or other rejection): send the Error, then close.
211            let _ = sink.send(to_text(&err_msg)).await;
212            api.drop_control_call_if_empty(space_id);
213            return;
214        }
215    };
216
217    // Register this connection's sender and spawn the forward task that drains
218    // queued ServerMessages to the WS sink.
219    let (tx, mut rx) = mpsc::unbounded_channel::<ServerMessage>();
220    call.conns.lock().unwrap().insert(peer, tx);
221
222    let mut forward = tokio::spawn(async move {
223        while let Some(msg) = rx.recv().await {
224            if sink.send(to_text(&msg)).await.is_err() {
225                break;
226            }
227        }
228    });
229
230    // Route the join outgoings (Welcome → self, PeerJoined → the others). The
231    // sender for `peer` is already registered, so `Welcome` reaches this client.
232    route(&call, &join_outgoings);
233
234    tracing::debug!(%space_id, peer = peer.0, "/control — peer joined");
235
236    // Read loop: feed each inbound ClientMessage to the SessionServer and route
237    // the results. Runs until the client sends Bye, the stream ends/errors, or
238    // the forward task dies (sink closed).
239    loop {
240        tokio::select! {
241            // Forward task exiting means the sink is gone; stop reading.
242            res = &mut forward => {
243                if let Err(err) = res {
244                    tracing::warn!(%err, %space_id, peer = peer.0, "/control — forward task panicked");
245                }
246                break;
247            }
248            incoming = next_client_message(&mut stream) => {
249                let Some(msg) = incoming else { break };
250                let is_leave = matches!(msg, ClientMessage::Bye);
251                let now_us = call.now_us();
252                let outgoings = {
253                    let mut server = call.server.lock().unwrap();
254                    server.handle(peer, msg, now_us)
255                };
256                route(&call, &outgoings);
257                if is_leave {
258                    break;
259                }
260            }
261        }
262    }
263
264    // Leave path (idempotent). Drop this connection's sender first so a final
265    // PeerLeft broadcast is not delivered back to the departing peer, then run
266    // the SessionServer leave and route PeerLeft to the rest.
267    forward.abort();
268    call.conns.lock().unwrap().remove(&peer);
269    let leave_outgoings = {
270        let mut server = call.server.lock().unwrap();
271        server.leave(peer)
272    };
273    route(&call, &leave_outgoings);
274    api.drop_control_call_if_empty(space_id);
275    tracing::debug!(%space_id, peer = peer.0, "/control — peer left");
276}

278/// Reads the next WS frame and deserializes it as a [`ClientMessage`].
279///
280/// Returns `None` when the stream ends, errors, or the peer sends a Close frame.
281/// Malformed JSON or non-text frames (ping/pong/binary) are skipped, not fatal.
282async fn next_client_message(
283    stream: &mut futures::stream::SplitStream<WebSocket>,
284) -> Option<ClientMessage> {
285    loop {
286        match stream.next().await? {
287            Ok(Message::Text(text)) => match serde_json::from_str::<ClientMessage>(&text) {
288                Ok(msg) => return Some(msg),
289                Err(err) => {
290                    tracing::warn!(%err, "/control — ignoring malformed client message");
291                    continue;
292                }
293            },
294            Ok(Message::Close(_)) => return None,
295            // Ping/Pong are handled by axum; binary is unexpected — skip.
296            Ok(_) => continue,
297            Err(err) => {
298                tracing::debug!(%err, "/control — websocket stream error");
299                return None;
300            }
301        }
302    }
303}

305/// Serializes a [`ServerMessage`] to a WS text frame. Serialization of this
306/// closed enum cannot fail; if it ever did we send an empty frame rather than
307/// panic in the transport task.
308fn to_text(msg: &ServerMessage) -> Message {
309    Message::Text(serde_json::to_string(msg).unwrap_or_default().into())
310}

312/// Resolves each [`Outgoing`]'s [`Target`] to recipient senders and pushes the
313/// message onto each. NEVER holds the `conns` lock across an await: collect the
314/// senders, then send (sync, non-blocking) — all within one lock scope is fine
315/// because `send` does not await.
316fn route(call: &ControlCall, outgoings: &[Outgoing]) {
317    if outgoings.is_empty() {
318        return;
319    }
320    let conns = call.conns.lock().unwrap();
321    for out in outgoings {
322        match out.target {
323            Target::Peer(p) => {
324                if let Some(tx) = conns.get(&p) {
325                    let _ = tx.send(out.message.clone());
326                }
327            }
328            Target::Broadcast => {
329                for tx in conns.values() {
330                    let _ = tx.send(out.message.clone());
331                }
332            }
333            Target::BroadcastExcept(except) => {
334                for (p, tx) in conns.iter() {
335                    if *p != except {
336                        let _ = tx.send(out.message.clone());
337                    }
338                }
339            }
340        }
341    }
342}

346impl Api {
347    /// Returns the [`ControlCall`] for a space, creating it if absent.
348    fn get_or_create_control_call(&self, space_id: Uuid) -> Arc<ControlCall> {
349        self.control_calls
350            .write()
351            .unwrap()
352            .entry(space_id)
353            .or_insert_with(|| Arc::new(ControlCall::new()))
354            .clone()
355    }
356
357    /// Drops the [`ControlCall`] for a space if it has no remaining peers, so we
358    /// don't leak one empty entry per call ever started. Idempotent.
359    fn drop_control_call_if_empty(&self, space_id: Uuid) {
360        let mut calls = self.control_calls.write().unwrap();
361        if let Some(call) = calls.get(&space_id)
362            && call.server.lock().unwrap().is_empty()
363        {
364            calls.remove(&space_id);
365        }
366    }
367
368    /// Broadcasts [`ServerMessage::SfuMigrate`] to every peer in every live
369    /// `/control` call, across all spaces. Called from `api::sfu_registry`
370    /// when the backend's best-SFU pick changes (a new node registered, or the
371    /// previous best started draining), so already-connected clients
372    /// re-resolve `voice_join` onto the new node rather than riding out the
373    /// old one until it's forcibly killed.
374    ///
375    /// Snapshots the call list under `control_calls`, then locks each call's
376    /// `conns` in turn — never holds `control_calls` and a `conns` lock
377    /// together, matching the module's no-lock-across-await / minimal-scope
378    /// locking discipline.
379    pub(crate) fn broadcast_sfu_migrate(&self, node_id: String) {
380        let calls: Vec<Arc<ControlCall>> = self
381            .control_calls
382            .read()
383            .unwrap()
384            .values()
385            .cloned()
386            .collect();
387        if calls.is_empty() {
388            return;
389        }
390        let msg = ServerMessage::SfuMigrate { node_id };
391        for call in calls {
392            let conns = call.conns.lock().unwrap();
393            for tx in conns.values() {
394                let _ = tx.send(msg.clone());
395            }
396        }
397    }
398}

402// Regression guard for the *whole* control stack: a real client WS ↔ the
403// backend's connection/routing glue ↔ the authoritative `SessionServer` ↔
404// another real client. Unlike `crate::api::control::tests` in the sans-IO crate
405// (which test the reducer in isolation), these drive two live `tokio-tungstenite`
406// clients against the router bound to a real TCP port, because a WebSocket
407// upgrade cannot be driven through the in-memory `axum_test` request path.
408//

410// either `await`s the specific message it expects (bounded by a timeout) or
411// drains a small, bounded window of messages and asserts the expected one is
412// present. Ordering between two independent peers' streams is not assumed.
