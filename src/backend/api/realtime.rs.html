1//! The realtime plane: messages, space layout, voice roster, screenshare.
2//!
3//! The wire protocol and the routing rules are transport-agnostic and live in
4//! [`hound_realtime`]; this module is the connection, authentication, and
5//! database glue around them.
6//!
7//! ## Two legs, one session
8//!
9//! A client reaches this plane over **WebTransport** (`hound_wt`, preferred: one
10//! QUIC connection, per-stream head-of-line blocking, no TCP handshake to
11//! re-do after a network change) or a **plain WebSocket** (universally
12//! reachable, the fallback when WebTransport is unavailable or the endpoint is
13//! not configured). Both legs authenticate identically, then hand a
14//! [`hound_wt::MessagePipe`] to the same [`hub::run_session`] — the transport
15//! difference ends there.
16//!
17//! ## Endpoints
18//!
19//! - `GET /realtime/ws` — WebSocket upgrade.
20//! - `CONNECT https://<rt-host>/realtime` — WebTransport session, on the endpoint
21//!   advertised by `/realtime/config`.
22//! - `GET /realtime/config` — where the WebTransport endpoint is, and (dev only)
23//!   the certificate hash to pin. Absent URL means "WebSocket only".
24//!
25//! ## Authorization (trust boundary)
26//!
27//! Both legs take the credential from an `Authorization: Bearer <jwt>` header,
28//! falling back to a `?token=<jwt>` query parameter — the header is preferred
29//! because a token in the URL lands in access logs and proxy traces, and the
30//! query form exists because a browser can set neither headers on a
31//! `WebTransport` construction nor on a `WebSocket` one. It must be an unrevoked
32//! *access* token, and it is validated **before** the session exists: a
33//! WebSocket that fails gets a 401 instead of an upgrade, a WebTransport session
34//! a 403 CONNECT response. Per-space subscriptions and screenshare toggles are
35//! authorized separately against the owning community's membership, on every
36//! request; a live session that *loses* a membership has that community's rooms
37//! revoked (see [`Api::revoke_realtime_membership`]).
38//!
39//! ## Lifecycle (SPOF flag)
40//!
41//! Connection state is in-memory and per-process: it does not survive a redeploy
42//! and does not coordinate across replicas, so like `/control` this plane is only
43//! correct on a single backend replica. Clients recover by reconnecting — the
44//! `Welcome` snapshot is a full resync by design.

65/// Which leg a connection arrived on. Also the value of the `transport` metric
66/// label, so connection counts are attributable per leg.
67#[derive(Debug, Clone, Copy, PartialEq, Eq)]
68pub(crate) enum Transport {
69    WebTransport,
70    WebSocket,
71}

73impl Transport {
74    pub(crate) fn label(self) -> &'static str {
75        match self {
76            Transport::WebTransport => "webtransport",
77            Transport::WebSocket => "websocket",
78        }
79    }

81    /// Whether the session loop must probe the peer itself.
82    ///
83    /// A WebSocket over TCP has no idle timeout: a peer whose network vanished
84    /// leaves the socket open until the OS gives up, which can be hours. QUIC
85    /// already reaps one at [`hound_wt::DEFAULT_MAX_IDLE`], so probing there
86    /// would only add a deadline for a legitimately silent client to trip over.
87    pub(crate) fn needs_server_liveness(self) -> bool {
88        matches!(self, Transport::WebSocket)
89    }
90}

113/// How to reach the realtime plane.
114///
115/// A client calls this once at startup: a `webtransport_url` means "try
116/// WebTransport first, fall back to the WebSocket if it fails"; its absence
117/// means "go straight to the WebSocket". `cert_hash` is present only when the
118/// endpoint runs a self-signed certificate (development) and is the SHA-256
119/// digest the client must pin — in production the endpoint carries a real
120/// certificate and the field is absent.
121pub(crate) async fn get_realtime_config(
122    LoggedIn(_claims): LoggedIn,
123    State(api): State<Api>,
124) -> ApiResult<Json<RealtimeConfig>> {
125    Ok(Json(api.realtime.config()))
126}

135    /// Validate a realtime `token` and return the authenticated user.
136    ///
137    /// Shared by both legs so they cannot drift: it must be a valid, unrevoked
138    /// **access** token (a refresh token is not a session credential). Accepts
139    /// the credential bare or as a whole `Bearer …` value, because the query
140    /// fallback is sometimes populated with the header verbatim.
141    pub(crate) async fn authenticate_realtime(&self, token: &str) -> Option<Uuid> {
142        let token = hound_wt::bearer_of(token).unwrap_or(token);
143        match self.auth.jwt.validate_unrevoked_token(token).await {
144            Ok(claims) if claims.is_access_token() => Some(claims.sub),
145            _ => None,
146        }
147    }

214    /// Fans a space-layout announcement out to the channel's audience.
215    ///
216    /// A channel `@everyone` can view is one fanout to the community room. One
217    /// it cannot is addressed per-member, to those who individually resolve
218    /// `channels:view` on it — the payload carries the channel's *name*, so a
219    /// room fanout would tell the whole community what its private channels are
220    /// called. The audience is resolved from the ACL as it stands after the
221    /// write, which is why this runs post-commit.
222    ///
223    /// A failed resolution announces to nobody rather than falling back to the
224    /// room: a client that misses a layout event refetches, and no refetch
225    /// recovers something that should never have been sent.
226    async fn emit_space(&self, space: &community_space::Model, message: ServerMessage) {
227        let targets = match self.space_audience(space).await {
228            Ok(targets) => targets,
229            Err(error) => {
230                tracing::error!(
231                    %error, space_id = %space.id,
232                    "realtime: space audience unresolved — announcement withheld"
233                );
234                return;
235            }
236        };
237        let outgoings: Vec<Outgoing> = targets
238            .into_iter()
239            .map(|target| Outgoing::to(target, message.clone()))
240            .collect();
241        self.realtime.route(&outgoings);
242    }
243
244    /// Who may be told a channel exists: the community room when `@everyone`
245    /// resolves `channels:view` on it, otherwise one target per member who
246    /// does.
247    async fn space_audience(&self, space: &community_space::Model) -> DbResult<Vec<Target>> {
248        if self.everyone_can_view_space(space).await? {
249            return Ok(vec![Target::Room(Room::Community(space.community_id))]);
250        }
251        Ok(self
252            .members_who_can_view(space)
253            .await?
254            .into_iter()
255            .map(Target::User)
256            .collect())
257    }

397/// The wire summary of a space row. Create and update announce the identical
398/// shape — a client assigns either one over whatever it held.
399fn space_payload(space: &community_space::Model) -> SpacePayload {
400    SpacePayload {
401        id: space.id,
402        community_id: space.community_id,
403        name: space.name.clone(),
404        kind: match CommunitySpaceKind::from(space.kind) {
405            CommunitySpaceKind::Text => SpaceKind::Text,
406            CommunitySpaceKind::Voice => SpaceKind::Voice,
407        },
408        is_private: space.is_private,
409    }
410}

412// ── realtime-plane tests ──────────────────────────────────────────────────────
413//
414// Regression guard for the whole shell: a real client ↔ the
415// connection/auth/routing glue ↔ the sans-IO hub ↔ another real client. The
416// reducer's own rules are tested in `hound_realtime` (pure, exhaustive); what
417// these prove is the wiring — that authentication gates admission, that the
418// REST handlers' emit helpers reach exactly the right rooms, that every bound a
419// connection is held to is actually enforced, and that a dropped, reaped, or
420// panicking session is cleaned up.
421//
422// Three client shapes, each chosen for what it can prove:
423//
424// - a real WebSocket (`tokio_tungstenite`), for anything involving the axum
425//   upgrade: frame caps, the credential channels, and ping/pong liveness, none
426//   of which exist above the transport;
427// - a real WebTransport session (`hound_wt`), for the leg that would otherwise
428//   have no backend coverage at all — one test drives its full path;
429// - a `FakePipe` driven straight from the test, for the orderings a socket
430//   cannot make deterministic (an event racing admission, a mailbox overflowing,
431//   a session panicking mid-loop).
432//
433// Synchronization rule: never sleep to wait for a message. Every assertion awaits
434// the specific frame it expects (bounded), drains a bounded window, or polls a
435// server-side condition to convergence.
