1//! The realtime plane: messages, space layout, voice roster, screenshare.
2//!
3//! The wire protocol and the routing rules are transport-agnostic and live in
4//! [`hound_realtime`]; this module is the connection, authentication, and
5//! database glue around them.
6//!
7//! ## Two legs, one session
8//!
9//! A client reaches this plane over **WebTransport** (`hound_wt`, preferred: one
10//! QUIC connection, per-stream head-of-line blocking, no TCP handshake to
11//! re-do after a network change) or a **plain WebSocket** (universally
12//! reachable, the fallback when WebTransport is unavailable or the endpoint is
13//! not configured). Both legs authenticate identically, then hand a
14//! [`hound_wt::MessagePipe`] to the same [`hub::run_session`] — the transport
15//! difference ends there.
16//!
17//! ## Endpoints
18//!
19//! - `GET /realtime/ws` — WebSocket upgrade.
20//! - `CONNECT https://<rt-host>/realtime` — WebTransport session, on the endpoint
21//!   advertised by `/realtime/config`.
22//! - `GET /realtime/config` — where the WebTransport endpoint is, and (dev only)
23//!   the certificate hash to pin. Absent URL means "WebSocket only".
24//!
25//! ## Authorization (trust boundary)
26//!
27//! Both legs take the credential from an `Authorization: Bearer <jwt>` header,
28//! falling back to a `?token=<jwt>` query parameter — the header is preferred
29//! because a token in the URL lands in access logs and proxy traces, and the
30//! query form exists because a browser can set neither headers on a
31//! `WebTransport` construction nor on a `WebSocket` one. It must be an unrevoked
32//! *access* token, and it is validated **before** the session exists: a
33//! WebSocket that fails gets a 401 instead of an upgrade, a WebTransport session
34//! a 403 CONNECT response. Per-space subscriptions and screenshare toggles are
35//! authorized separately against the owning community's membership, on every
36//! request; a live session that *loses* a membership has that community's rooms
37//! revoked (see [`Api::revoke_realtime_membership`]).
38//!
39//! ## Lifecycle (SPOF flag)
40//!
41//! Connection state is in-memory and per-process: it does not survive a redeploy
42//! and does not coordinate across replicas, so like `/control` this plane is only
43//! correct on a single backend replica. Clients recover by reconnecting — the
44//! `Welcome` snapshot is a full resync by design.

63/// Which leg a connection arrived on. Also the value of the `transport` metric
64/// label, so connection counts are attributable per leg.
65#[derive(Debug, Clone, Copy, PartialEq, Eq)]
66pub(crate) enum Transport {
67    WebTransport,
68    WebSocket,
69}
70
71impl Transport {
72    pub(crate) fn label(self) -> &'static str {
73        match self {
74            Transport::WebTransport => "webtransport",
75            Transport::WebSocket => "websocket",
76        }
77    }
78
79    /// Whether the session loop must probe the peer itself.
80    ///
81    /// A WebSocket over TCP has no idle timeout: a peer whose network vanished
82    /// leaves the socket open until the OS gives up, which can be hours. QUIC
83    /// already reaps one at [`hound_wt::DEFAULT_MAX_IDLE`], so probing there
84    /// would only add a deadline for a legitimately silent client to trip over.
85    pub(crate) fn needs_server_liveness(self) -> bool {
86        matches!(self, Transport::WebSocket)
87    }
88}

90/// Every `transport` label value, so [`crate::api::metrics::init_series`] can
91/// zero-initialise both and a dashboard never waits for the first connection of
92/// a given leg before its series exists.
93pub(crate) const TRANSPORTS: [Transport; 2] = [Transport::WebTransport, Transport::WebSocket];

95/// The `/realtime/config` + `/realtime/ws` routes.
96pub(crate) fn router() -> utoipa_axum::router::OpenApiRouter<Api> {
97    utoipa_axum::router::OpenApiRouter::with_openapi(Default::default())
98        .routes(utoipa_axum::routes!(get_realtime_config))

111/// How to reach the realtime plane.
112///
113/// A client calls this once at startup: a `webtransport_url` means "try
114/// WebTransport first, fall back to the WebSocket if it fails"; its absence
115/// means "go straight to the WebSocket". `cert_hash` is present only when the
116/// endpoint runs a self-signed certificate (development) and is the SHA-256
117/// digest the client must pin — in production the endpoint carries a real
118/// certificate and the field is absent.
119pub(crate) async fn get_realtime_config(
120    LoggedIn(_claims): LoggedIn,
121    State(api): State<Api>,
122) -> ApiResult<Json<RealtimeConfig>> {
123    Ok(Json(api.realtime.config()))
124}

126/// Rejects a request with a bare status. Both legs' auth failures are
127/// deliberately opaque: a caller learns it failed, never why.
128pub(crate) fn unauthorized() -> StatusCode {
129    StatusCode::UNAUTHORIZED

132impl Api {
133    /// Validate a realtime `token` and return the authenticated user.
134    ///
135    /// Shared by both legs so they cannot drift: it must be a valid, unrevoked
136    /// **access** token (a refresh token is not a session credential). Accepts
137    /// the credential bare or as a whole `Bearer …` value, because the query
138    /// fallback is sometimes populated with the header verbatim.
139    pub(crate) async fn authenticate_realtime(&self, token: &str) -> Option<Uuid> {
140        let token = hound_wt::bearer_of(token).unwrap_or(token);
141        match self.auth.jwt.validate_unrevoked_token(token).await {
142            Ok(claims) if claims.is_access_token() => Some(claims.sub),
143            _ => None,
144        }
145    }
146
147    /// The voice roster across `communities` — the snapshot a `Welcome` carries.
148    ///
149    /// Synchronous (it reads the in-memory participant registry) because the hub
150    /// samples it while holding the routing lock: that is what makes the snapshot
151    /// atomic with the room join, and therefore what closes the join race.
152    pub(crate) fn voice_roster_for_communities(&self, communities: &[Uuid]) -> Vec<VoiceJoinEvent> {
153        communities
154            .iter()
155            .flat_map(|&id| self.get_voice_participants_for_community(id))
156            .collect()
157    }
158
159    /// A user has lost their membership of `community_id`: drop that community's
160    /// rooms from every live connection of theirs.
161    ///
162    /// Called from the leave and kick handlers. Without it a session that was
163    /// admitted while the membership existed keeps receiving the community's
164    /// events for as long as it stays connected — authorization is checked at
165    /// admission and at subscribe, so nothing else re-checks it.
166    pub(crate) fn revoke_realtime_membership(&self, user_id: Uuid, community_id: Uuid) {
167        self.realtime.revoke(user_id, community_id);
168    }
169
170    // ── emit helpers (called by the HTTP handlers in community.rs / space.rs) ──
171    //
172    // Signatures are unchanged from the socket.io plane they replace, so callers
173    // did not move. They remain `async` for the same reason: the call sites are
174    // async and the fanout may grow an awaiting step (a cross-replica bus), even
175    // though today's routing is synchronous and non-blocking.
176
177    /// A space was created — announce it to the owning community.
178    pub(crate) async fn emit_space_created(&self, space: &community_space::Model) {
179        let kind = match CommunitySpaceKind::from(space.kind.clone()) {
180            CommunitySpaceKind::Text => SpaceKind::Text,
181            CommunitySpaceKind::Voice => SpaceKind::Voice,
182        };
183        self.emit(
184            Target::Room(Room::Community(space.community_id)),
185            ServerMessage::SpaceCreated {
186                space: SpacePayload {
187                    id: space.id,
188                    community_id: space.community_id,
189                    name: space.name.clone(),
190                    kind,
191                },
192            },
193        );
194    }
195
196    /// A space was deleted — announce it to the owning community.
197    pub(crate) async fn emit_space_removed(&self, community_id: Uuid, space_id: Uuid) {
198        self.emit(
199            Target::Room(Room::Community(community_id)),
200            ServerMessage::SpaceRemoved { space_id },
201        );
202    }
203
204    /// A user's voice join is confirmed (their SFU peer id is known).
205    pub(crate) async fn emit_voice_joined(&self, event: &VoiceJoinEvent) {
206        self.emit(
207            Target::Room(Room::Community(event.community_id)),
208            ServerMessage::VoiceJoined {
209                voice: event.clone(),
210            },
211        );
212    }
213
214    /// A user left a voice space (or was evicted after their grace period).
215    pub(crate) async fn emit_voice_left(&self, event: &VoiceLeaveEvent) {
216        self.emit(
217            Target::Room(Room::Community(event.community_id)),
218            ServerMessage::VoiceLeft {
219                voice: event.clone(),
220            },
221        );
222    }
223
224    /// A message was posted — to that space's subscribers only.
225    pub(crate) async fn emit_message_created(&self, message: &CompleteCommunitySpaceMessage) {
226        self.emit(
227            Target::Room(Room::Space(message.space_id)),
228            ServerMessage::MessageCreated {
229                message: hub::message_payload(message),
230            },
231        );
232    }
233
234    /// A message was edited — to that space's subscribers only.
235    pub(crate) async fn emit_message_updated(&self, message: &CompleteCommunitySpaceMessage) {
236        self.emit(
237            Target::Room(Room::Space(message.space_id)),
238            ServerMessage::MessageUpdated {
239                message: hub::message_payload(message),
240            },
241        );
242    }
243
244    fn emit(&self, target: Target, message: ServerMessage) {
245        self.realtime.route(&[Outgoing::to(target, message)]);
246    }
247}

249// ── realtime-plane tests ──────────────────────────────────────────────────────
250//
251// Regression guard for the whole shell: a real client ↔ the
252// connection/auth/routing glue ↔ the sans-IO hub ↔ another real client. The
253// reducer's own rules are tested in `hound_realtime` (pure, exhaustive); what
254// these prove is the wiring — that authentication gates admission, that the
255// REST handlers' emit helpers reach exactly the right rooms, that every bound a
256// connection is held to is actually enforced, and that a dropped, reaped, or
257// panicking session is cleaned up.
258//
259// Three client shapes, each chosen for what it can prove:
260//
261// - a real WebSocket (`tokio_tungstenite`), for anything involving the axum
262//   upgrade: frame caps, the credential channels, and ping/pong liveness, none
263//   of which exist above the transport;
264// - a real WebTransport session (`hound_wt`), for the leg that would otherwise
265//   have no backend coverage at all — one test drives its full path;
266// - a `FakePipe` driven straight from the test, for the orderings a socket
267//   cannot make deterministic (an event racing admission, a mailbox overflowing,
268//   a session panicking mid-loop).
269//
270// Synchronization rule: never sleep to wait for a message. Every assertion awaits
271// the specific frame it expects (bounded), drains a bounded window, or polls a
272// server-side condition to convergence.

274mod tests;
