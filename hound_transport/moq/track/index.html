Module track

Expand description

The deduped per-track publish/subscribe cores, and the multiplexed-session track handles built directly on them.

Every publisher-shaped type in this crate (crate::MoqPublisher, MoqTrackPublisher) is one TrackPublisher core — an announced broadcast plus an open track mapped onto the GOP group/object model — and every subscriber-shaped type (crate::MoqSubscriber, crate::MoqRelaySubscriber, MoqTrackSubscriber) is one TrackSubscriber core sharing the drain_next_frame discipline. The wrappers differ only in how the track was obtained and in whether they own their session.
