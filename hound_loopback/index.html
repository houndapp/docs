T2 test tier: a complete hound call stack inside the test process.

LoopbackStack::start brings up, in dependency order, an iroh relay (plain HTTP on 127.0.0.1:0), the backend (its own Cli::drive, SQLite in memory, the realtime WebTransport leg self-signed on loopback) and the SFU (Sfu::bind on a specific loopback address, registered with the backend). LoopbackStack::env then hands back a hound-testkit Env, so a scenario here is written in exactly the DSL the compose-stack suite uses — only the stack underneath differs.

Loopback invariant: every service binds 127.0.0.1, and the SFU advertises only its bind address, so clients (whose endpoint binds the wildcard) are only ever told to dial loopback. Magic-link mail never leaves the process: the backend’s mail transport is a MemoryInbox the testkit reads codes from directly.
