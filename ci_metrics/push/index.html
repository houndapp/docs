POST the exposition lines to the backend’s CI metrics ingest route.

Contract (services/backend):

POST https://api.hound.chat/internal/metrics/ci
Authorization: Bearer $CI_METRICS_TOKEN
Content-Type: text/plain; version=0.0.4
body: prometheus text exposition lines, no timestamps -> 204

Best-effort by design, inherited verbatim from the push-ci-metrics.sh this replaces: a metrics-push failure must never fail a CI job, so no path here returns an error. A missing token, an empty body, a refused connection and an HTTP error are each a stderr note.

The token is passed in, never read from a shell word or a command line: the script had to hide it in a curl --config file to keep it out of ps, and that hazard is gone by construction here. It is never printed — not in the skip note, not in an error — and reqwest’s own errors carry the URL only.

How long to wait on the whole request. The push is the last thing a job does; a wedged connection must not hold a runner.
