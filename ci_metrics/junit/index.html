nextest’s JUnit report → the ci_e2e_tests counts.

This replaces the grep/sed block that lived in ci.yaml’s e2e-call metrics step, and reproduces its arithmetic exactly — the series must stay continuous with what has already been stored:

  • tests/failures/errors come from the root <testsuites> attributes (each missing attribute is 0);
  • skipped is counted from <skipped children, because nextest’s root tag carries no summary skipped attribute;
  • failed = failures + errors, passed = tests - failed - skipped, floored at 0.
